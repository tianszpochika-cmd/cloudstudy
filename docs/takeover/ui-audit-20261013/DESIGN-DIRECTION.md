# 正式页面简约重设计方向

用户于2026-10-13明确：需要全部真实页面重新排版与设计，而非仅修功能缺陷；包括提示文字、按钮位置、字号、艺术字、颜色、图标、交互与舒适度。以下方向覆盖本轮后续逐页工作，先落实认证入口。

- 以当前页面的真实主要任务组织信息；开放排版，避免嵌套框、重复状态卡和为装饰堆砌的图标/标签。
- 无操作发生时不显示“等待注册/等待登录”等状态框。等待反馈出现在实际提交中；错误靠近字段或当前动作，必要时以简短全局反馈补充。
- 正常无衬线字体；入口标题28px/1.4/650，说明14px/1.75，字段标签14px/1.6/500，输入及主按钮16px，辅助规则13px。页面依内容密度另行设计，不机械铺大标题。
- 保留既有共享语义配色和紫色强调，减少大面积渐变、重阴影、艺术字和没有业务意义的插画；四种主题各自实际复验。
- 入口表单最大420px；先主任务，再明确辅助出口；密码找回靠近密码，注册/登录切换置于主动作之后。
- 图标沿用正式组件；密码图标19px，控件命中区44×44px。其余图标按语义、视觉重量与状态逐页检查。
- 文字简短、具体、不夸大“即可开始”，不泄露账号是否存在或内部错误码。UI语言继续经`packages/i18n`，与内容语言分开。
- 每页要同时通过视觉与交互复验，修复既有问题并重查共享影响页；旧“UI缺陷修复通过”不能自动完成新的全面设计要求。

首个完整设计参照由内置Image Gen生成，用作设计规格，不作为网页或交互截图交付：[登录参照](learner-login-redesign/concept.png)。正式实现仍是Vue控件与既有认证流程。后续具名页面沿同一设计系统展开，布局随任务内容调整。
