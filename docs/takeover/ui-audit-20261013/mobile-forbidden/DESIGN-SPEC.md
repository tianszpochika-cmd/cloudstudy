# MB-005 正式页面重设计规格

状态：概念已审，正式实现候选尚未签收。MB004 已完成并推送，当前页单独推进，不把概念或 before 当作实际页面验收。

## 当前真实问题

只读预审见 `preaudit-20261015/preaudit.md`：通用 Header 与原因卡重复标题；正式英文界面仍显示中文原因和按钮；撤回与一般受限原因不清且缺可用的账号/帮助出口；退出请求 pending 时冲突按钮仍可操作。正确初始化后的暗色主题正常，不能把前一次 fixture 初始化错误列为产品暗色故障。

## 页面设计

概念见 [三态参照](concept.png)，2026-10-15 内置 Image Gen 生成，仅作布局参照。正式页面继续使用真实 Vue/uni-app 控件和现有 AppIcon、共享语义 token，图片不进入运行页面。

采用轻量品牌顶部、单原因标题、短说明、主要账号动作、次要帮助动作、独立退出区。取消外层大卡、重复访问受限 eyebrow、重阴影和缩放。最大内容宽度约420px；24px常规窄屏边距；标题28px/1.4/650，说明14px/1.75，动作16px、至少48px高度。小锁约20–24px，不照搬概念图偏大的锁；顶部和动作留白随短屏/文本放大收敛，不固定居中或底部遮挡内容。

成人拒绝标题“暂时无法开始学习”，说明“当前版本仅向年满18周岁的用户开放学习。你仍可管理账号或查看帮助。”；其余已登录受限保持泛化说明，不从 query 推断权限、角色或版权。未知/未登录另给诚实的会话说明与现有安全登录出口，不假定成人拒绝或账号功能可用。

源码核对后修正规格：现有 learningConsentWithdrawn 是无 owner 字段的 sticky 安全暂停 marker，clear/logout 会保留，不能单独证明当前账号“你已撤回”；principal accepted=false 也不能区别从未同意与已撤回。故概念图深色屏的具体撤回文案不能照搬，实际候选改中性标题“学习访问已暂停”，说明“当前无法继续打开学习内容。你仍可管理账号或查看帮助。”。仅当前可信已登录状态使用暂停 marker；未知/未登录不据它造事实。明确撤回原因需要 owner scoped 权威来源，列 GAP，本页不扩大改动到共享会话。此调整保留安全阻挡，不赋予学习权限。

已登录动作“管理账号”“帮助与反馈”，底部“退出登录”。不得将重新登录、重试成人门、修改年龄、再注册暗示为解除限制的方法。页面只管理自身 pending/error、可信 owner 与晚响应；复用现有 session.logout 和安全导航，不修改共享权限/会话模块迁就布局，不增加法律正文或发布版本。

全部新增文案使用现有 packages/i18n 注册入口，UI locale 与内容语言分离。pending 禁用冲突出口并显示一个状态；失败显示邻近单条反馈。键盘、真实 pointer、hide/切号晚响应与 logout 返回值必须实际验，不因源码逻辑看似正确签收。

## 概念到正式页面核对点

1. 一个标题与一段原因，无双层框和重复宣言。
2. 三种可信原因在中英、明暗主题均清楚，未知状态不伪造事实。
3. 账号主动作、帮助次动作、退出独立，触控/键盘焦点清楚。
4. 语义配色和现有图标，控件边界/文字对比实测，不从概念配色推断 PASS。
5. 320/390/768/1280宽度、200%文本和短屏自然重排；概念固定留白不成为实现限制。

完成前必须同次查看此概念与实际页面截图，记录差异理由。构建、模块测试与浏览器UI、真实IAM业务、native证据分别报告。原FAIL和所有版本保留。
