# MB-005 整页简约重排计划（待 Root 开页）

本计划依据同目录只读预审与 before，未实现正式页面。目标是让用户一次读懂“为什么受限、哪些事情仍可做、怎样安全离开”，保留 IAM、成人与同意 Gate 的现有权威边界。

## 1. 页面构成

取消“通用 Header 宣言 + 大圆角原因卡 + 重复标题”的双层结构。使用整页单列：轻量品牌顶栏 → 一个原因 H1 → 简短事实说明 → 可用账号/帮助动作 → 独立退出区。内容最大宽度约 420px，窄屏自然占满，沿用已重设计认证/成人页的字体、48px 主动作和留白节奏。

正文不再放第二个 eyebrow/标题；原因由文字和小图标共同表达。移除多余阴影、hover 卡片强调、按钮缩放和内联 rpx 间距。保留主题适配的现有 semantic token，不新增品牌/状态色，不因“受限”铺满红色。英文和 200% 文本允许自然换行。

账号操作以“账号与设置”作为已登录受限用户的首要可用动作，“帮助与反馈”为次要动作；退出登录独立放在末尾，避免把“重新登录”暗示成解除成人拒绝或撤回的办法。未登录入口只给实际可用的登录/公开说明，不伪造账号操作可用性。若未来保留返回动作，必须给确定的获准账号出口，不能默认 history/home 再进入学习拦截循环。

## 2. 原因与动作

| 当前可信事实 | 说明方向 | 可用动作 | 禁止推断 |
|---|---|---|---|
| 当前 owner 的成人 Gate 为 REJECTED | 当前版本仅开放成人学习，账号服务仍可访问 | 获准账号设置、帮助、退出 | 不提供改年份/再注册/重试成人门，不把重新登录说成解除办法 |
| 当前 owner 的必要学习同意已撤回 | 与该目的关联的学习功能已暂停，其他获准账号服务仍可用 | 获准账号设置、帮助、退出 | 不自动重签、重启学习、删账号，不编写新的法律/保留承诺 |
| 已登录但其余访问受限 | 当前账号不能打开这项内容；只展示已知的能力/事实 | 获准账号设置、帮助、退出 | 不从 query/returnTo 猜角色、版权、tenant 或具体拒绝码 |
| 会话未知/未登录/事实读取失败 | 诚实说明当前无法确认账号访问状态 | 已有安全登录或账号出口、失败反馈 | UNKNOWN/503 不当作成人拒绝或同意撤回，也不开放学习 |

实现前在页面内确定有限的 reason 映射和优先级：当前可信 REJECTED 优先；当前 owner 撤回事实其次；其余为通用受限/不可确认。现有 forbidden 路由没有结构化权限拒绝详情；若页面只拿到泛化状态，就保持泛化，不创造新授权字段。URL 只作安全返回导航用途，不能成为权限依据。

## 3. 交互状态

页面内管理一个可追踪的 pending action，覆盖账号导航、帮助导航和退出。动作发起后统一禁用冲突操作、显示简短进行中文案，并提供 aria-busy；键盘 Enter/Space 使用当前认证页已验证的释放激活方式和单次动作 guard。保留真实 uni 按钮语义，不改全局键盘或 session helper。

导航失败给一条邻近动作的可读反馈，允许重试同一安全动作。退出复用现有 session.logout；区分其返回值、已发生的本地清理和服务端撤销是否确认，不把失败宣称成功。账户切换、页面 hide 或晚到结果不得把新 owner 导航到旧 owner 的目标。退出本来会清身份，不能把“身份 revision 改变”一概当作失败而阻止安全登录出口。

静态限制说明只读一次；动作失败用单条 alert，pending 用状态文本，不叠加重复屏幕阅读提示。一个 H1，说明绑定对应区域；主题焦点可见，按钮触控不小于 44px。

## 4. 文件和契约边界

优先修改范围：`apps/mobile/src/pages/forbidden/forbidden.vue`、对应共享 i18n 消息的既有入口，以及与本页行为直接相关的测试/证据。文案集中到现有 `packages/i18n` 注册链，复用 mobile foundation；不在新页继续复制 b10/auth/mobile 三套同义文案。具体 key 和兼容入口在正式开页时核对，避免影响已签页面。

不修改 session、gateway-auth、navigation、共享 Header 或权限规则来迁就布局；不新增认证/法律/协议目录，不变更 B8 契约。若可信拒绝来源确实不足，先明确 GAP 和接口 owner，不能用 UI 猜测填补。保留导航层 AUTH_ONLY 的账号/设置/支持出口，但不声称这些页的每项写能力已获准。

已知测试债：`apps/mobile/tests/adult-consent-copy.test.mjs:63-66` 直接匹配当前中文出口和禁止绕门词。正式实施时应保留“拒绝不重试/不改年、出口仍可达”的业务断言，升级 i18n/实际行为验证，不能单纯删掉或改成装饰样式快照。其他相关回归按具体改动选择，不重复全仓大组。
