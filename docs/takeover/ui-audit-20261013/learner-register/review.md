# LW-002 · 正式注册页简约重设计

2026-10-13；起点`182e106b`；真实页面`http://127.0.0.1:18180/register`。追溯R1-015 / IC-052 / BC-002/003；注册和年龄/学习资格判定仍归IAM。

结论：**UI_SCOPE_PASS**，页面布局、默认文案与具名交互通过，不签真实注册/成人门/业务全链。

## 设计改动

- 原默认“等待注册”大框重复显示密码规则，已取消。等待只在实际提交时出现；不在无操作时暗示处理中。
- 使用[认证家族设计方向](../DESIGN-DIRECTION.md)：开放单列420px、无装饰侧栏/艺术字/大外框；标题“创建账号”，简短描述“面向18岁以上成人，注册后完成简短学习设置。”主按钮“创建账号”。
- 标题28px、说明/标签14px、输入/按钮16px，行高与宽度统一；主按钮在三字段之后，已有账号入口在按钮之后。去掉注册页不必要的找回密码链接，仍可经登录页进入找回流程，回跳保持。
- 密码规则改为字段旁13px“至少12个字符”，不重复在标签和默认状态卡。密码与确认各有独立19px眼睛图标、44×44px命中区与准确标签。
- 必填、密码短、确认空、两次不同分别标记；首错聚焦、逐字段错误描述；修正后清本地错误，不清服务端拒绝。空确认不会误说两次不一致。
- 账号使用显式label，错误文案不混入可访问名称；账号输入避免邮箱键盘限制，支持账号名，关闭自动大写与拼写纠正。
- 提交中三输入与两密码按钮禁用，表单busy，重复提交不发第二请求。保留原12位密码规则、IAM入口、成人门与安全回跳。

## 验证

实际Playwright Chromium：320/390/768/900/1280/1440 × 亮/暗/高对比/系统，共24组合PASS；唯一主标题、非空、无默认状态卡/框架覆盖/横溢出，输入实际16px；链接和密码按钮至少44×44。

具名实际操作：空字段 → 账号填写 → 密码过短 → 确认空 → 确认不一致 → 修正；每步焦点和错误关联正确且0注册请求。独立密码按钮鼠标/Enter正常；提交中重复事件仍1次请求。合成409不披露账号存在性，429明确稍后重试，错误恢复后可继续编辑；服务错误不会被编辑静默清除。登录/找回出口保留`/today`。

390英文与模拟200%文字放大：不溢出，主动作可滚入视口。此为文本放大，未代替原生缩放/真机软键盘。主题矩阵默认系统亮色，认证布局的系统偏好动态切换见LW-001报告。

独立Agent复查24组合中英/三主题与1280/390整体视觉，发现的账号label污染、空确认文案、过度承诺的注册说明已修正。默认卡片取消、层级与按钮位置已由真实截图核对。主Agent使用`view_image`检查最新浅/暗/英文文字放大图；注册沿同一认证设计系统展开，功能字段为保留业务必需内容。
