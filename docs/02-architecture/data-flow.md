# 数据流与边界

## 用户身份

平台登录凭证只在认证边界处理。业务服务使用内部 user id，不在日志中打印手机号、邮箱或第三方 token。

## 学习记录

每次开始、提交、完成、跳过和复习都写入不可变事件或可追踪记录，再由聚合任务生成进度视图。

## AI 会话

原始输入、脱敏后的输入、模型请求、结构化输出、用户采纳和用户重做应有清晰的数据保留策略。默认只保留完成质量分析所需的最小信息。

## 内容发布

草稿 -> 教研审核 -> 安全检查 -> 小流量发布 -> 正式发布 -> 下线。客户端只能读取已发布版本。

## 离线下载与本地同步（PRD §20.3 / §21）

- **可下载内容**：用户已授权访问的词书、阅读包、音频包、练习包；下载包经加密与授权校验，不提供批量导出完整商业题库或可直接传播的原始资源包。
- **本地存储**：App 端使用 SQLite（uni-app plus.sqlite）承载离线包索引与本地学习进度队列；H5 用 IndexedDB 降级（仅进度，不承载大体积离线包）。
- **同步策略**：学习进度本地队列先行 + 后端最终一致；上报采用幂等事件（客户端事件 ID 去重），弱网重连后批量补传；冲突以“学习事件不可变 + 服务端聚合”规避，不覆盖用户已完成记录。

## 媒体与视频分发（Language Clips）

- 真人短视频与课程音频统一走 OSS + CDN；视频采用 HLS 切片（防盗链签名 URL），音频按句切分缓存以支持逐句复读。
- 3D Avatar 快照与模型资产同样经 OSS + CDN，版本哈希寻址（见 avatar-3d-rendering-pipeline.md）。

## 数据删除

用户删除请求必须覆盖账户、学习记录、音频、分析标识和第三方同步副本；保留必要的审计记录时要做匿名化处理。
