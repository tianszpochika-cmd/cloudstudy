# 数据流与边界

## 用户身份

平台登录凭证只在认证边界处理。业务服务使用内部 user_id，不在日志中打印手机号、邮箱、第三方 token 或设备敏感标识。

## 学习记录

每次开始、提交、完成、跳过和复习都写入可追踪学习事件，再由聚合任务生成进度、报告和排行榜视图。提交必须具备客户端事件 ID 和服务端幂等处理。

## 内容发布

草稿 -> 审核中 -> 发布 -> 下线。客户端只能读取已发布版本。内容记录来源、版权状态、授权凭证、审核人员、版本与发布时间。

## 离线下载与同步

- 可下载内容：用户已授权访问的词书、阅读包、音频包和练习包。
- App 可使用 SQLite 保存离线索引和学习事件队列；H5 使用 IndexedDB 保存有限进度数据。
- 弱网恢复后批量补传；服务端按事件 ID 去重并聚合，不覆盖已完成学习记录。
- 不提供批量导出完整商业题库、原始媒体或可直接传播的资源包。

## 媒体分发

- 音频、视频、图片、离线包和 3D 资产走 OSS + CDN。
- 视频使用 HLS 或等效自适应分发；音频支持按句缓存和逐句复读。
- 资源使用版本哈希、访问授权和过期 URL 控制。

## Phase 2 AI 数据流

原始输入、脱敏输入、模型请求、结构化输出、用户采纳和重做数据必须有单独保留策略。Phase 1 不产生模型请求或 AI 会话数据。

## 数据删除

用户删除请求覆盖账户、学习记录、音频、分析标识和第三方同步副本；法律要求保留的审计记录必须匿名化并限制访问。
