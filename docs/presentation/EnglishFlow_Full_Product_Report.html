01 · 产品愿景与定位

我们要做一个什么样的产品

来源：docs/00-vision/product-vision.md · README.md
一句话愿景：让忙碌的中国成年人每天用 15 分钟，把“看得懂英语”变成“在真实场景中说得出来、写得清楚”。
产品形态
PRODUCT FORM
一个以目标和场景为中心的英语成长系统，三种力量各司其职：
  • 传统课程：提供学习顺序与内容质量，教研人工把关
  • AI 能力：提供即时陪练、角色扮演与个性化反馈
  • 数据系统：提供复习节奏、能力变化证据与进步可视化
北极星行为
NORTH STAR
用户在一个学习周期内，完成目标场景的有效表达，并在复习中再次正确调用相关表达。
  • 不以无限聊天时长作为核心价值
  • 不以模型炫技作为卖点，AI 是教练不是替代品
  • AI 不替代课程结构、教研审核与用户判断
  • 每个学习周期都要能展示“能力变化”而非仅时长
核心理念
CORE IDEA
将前沿技术与经典教学法深度融合：
  • 大语言模型 LLM：陪练、批改、润色、结构化反馈
  • 实时语音交互 ASR/TTS/RTC：低延迟口语对讲
  • 数字人渲染技术：卡通 IP 伴学与商务教练形象
  • 阶梯式教学法：CEFR 分级、场景化单元设计
  • 认知记忆算法：改进版 SuperMemo-2 间隔重复
第一条验证假设
FIRST HYPOTHESIS
产品上线前先验证一个最小假设：
  • 如果用户每天完成一条短课，并用同一能力点完成一次 AI 场景表达
  • 那么 8 周留存与自我效能感，将高于只看碎片内容的学习方式
  • 验证载体：20–50 名真实用户的 8 周试学计划
  • 验证工具：事件字典、漏斗看板与 AI 离线评测集

01 · 核心学习闭环

五步闭环：从测评到复盘

所有功能设计都服务于这条主链路，任何功能若不能挂到闭环上则暂缓
STEP 1
入学测评
10–15 分钟确定水平、目标与可用时间，生成可解释的起点建议与首个目标
STEP 2
结构化课程
按 CEFR 能力层级与真实场景组织，30–50 个微课单元起步，每单元有目标/材料/练习/反馈
STEP 3
AI 陪练
文字/语音/角色扮演，受课程上下文约束，输出问题类型+原句+建议句+原因的结构化反馈
STEP 4
记忆复习
错误自动进入复习队列，间隔重复、错题回流、个人词库，按时间与严重程度排序
STEP 5
每周复盘
展示能力变化而非学习时长，重新安排下一周计划，形成正向循环
闭环设计原则
DESIGN PRINCIPLES
  • 15 分钟可完成：目标导向的短课设计，适配碎片化时间
  • 可验证：每一步都有事件埋点，团队能看到转化与失败原因
  • 不阻塞：AI 超时自动降级为规则化练习，学习流程不中断
  • 可回放：评测结论全部留痕，具备可解释性与审计能力
  • 有边界：不做无边界的 AI 自由聊天大厅
闭环上的质量指标
LOOP METRICS
  • 反馈后重做率、重做后错误减少率
  • 复习到期完成率、七日复习完成率
  • AI 反馈采纳/纠正率
  • 场景任务完成率、建议表达复用率
  • 每位活跃用户的模型成本与语音分钟成本
MVP 成功条件：8 周试验周期内，用户能完整走完 测评 → 每日短课 → 至少一次 AI 场景练习 → 错误复习 → 周复盘，且产品团队能看到每一步的转化和失败原因。

01 · 差异化与首发策略

我们如何切入市场

首发定位
LAUNCH POSITIONING
先服务最痛、最高频的人群，用一个可承诺的结果建立信任：
  • 人群：工作 1–10 年、时间碎片化、需提升职场沟通的成年人
  • 高频场景：会议发言、汇报、邮件、面试、社交寒暄、出差旅行
  • 首个承诺：每天 15 分钟，连续 8 周，完成一条可验证的职场英语能力路径
差异化定位
DIFFERENTIATION
与纯 AI 聊天产品、纯录播课产品的本质区别：
  • 课程老师设计学习路径，保证顺序与质量
  • AI 负责个性化练习与即时反馈，保证效率
  • 人类规则负责质量与边界，保证安全合规
  • 三者组合 = 可规模化的个性化教育
明确要做
IN SCOPE
  • 目标导向的结构化短课
  • AI 场景陪练与结构化反馈
  • 间隔重复与个人词库
  • 能力变化的周度可视化
  • 教研审核下的内容发布
明确不做
OUT OF SCOPE
  • 无边界的 AI 自由聊天大厅
  • 以排行榜为主的强竞争机制
  • 无教研审核的批量自动发布
  • 首期多套完全不同的原生 UI
  • 以聊天时长/模型炫技为卖点
分期原则
PHASING
  • P0：Web + 小程序 + 核心 API 先跑闭环
  • P1：验证留存后加语音与移动端
  • P2：规模化后再扩企业版与原生能力
  • 不一开始拆十几个微服务
  • AI 先文字陪练，再接实时语音
策略要点：先做窄而深的一条闭环（一个人群 + 一个高频场景），用真实用户验证留存与效果，再横向扩人群、纵向加技术深度。3D、数字人等高级能力按阶段释放，不提前透支。

01 · 工程纪律与完成定义

Definition of Done 与性能守则

功能完成定义（DoD）
DEFINITION OF DONE
  • ① 需求与用例已对齐（requirements/ 与 docs/）
  • ② API 契约、数据库迁移与跨端类型已同步
  • ③ 单元/集成测试覆盖，关键链路有端到端测试
  • ④ 移动端/iPad/Windows 响应式与四级画质降级测试通过
  • ⑤ AI 功能具备结构化 Schema 验证与失败降级策略
  • ⑥ 文档、CHANGELOG 与本地运行说明已同步更新
性能守则
PERFORMANCE GUARDRAILS
  • AI 流式渲染采用增量虚拟切片，禁止全局 DOM 重排
  • 复杂动效与粒子效果受全局性能状态机控制
  • 随时响应降级指令，低配设备可关闭动效
  • 实时语音严禁使用粗糙的 HTTP 轮询
AI 安全与治理
AI GOVERNANCE
  • 所有 AI 输出有明确 prompt_version 与 Schema 校验
  • 解析失败时使用安全的规则化降级结果
  • 不把不确定的模型判断显示为确定事实
  • 生产请求记录模型/版本/耗时/成本，不记录敏感原文
  • 前置敏感拦截 + 后置合规核验双审机制
隐私与代码安全
PRIVACY & SECURITY
  • 严禁真实用户隐私、音频原始数据入库 Git
  • 严禁 API Key 或生产凭证提交仓库
  • 测试环境只使用合成或脱敏数据
  • 核心 API 具备鉴权、速率限制与输入校验

05 · 质量验收标准

六大验收域

来源：requirements/acceptance-criteria.md —— 功能上线前的检查清单
A. 新用户首日路径
ONBOARDING
  • 3 分钟内完成登录和目标选择
  • 测评中断可恢复，不重复提交
  • 测评后生成可解释的起点建议与今日任务
  • 首次任务后展示下次复习时间
B. 课程与练习
CONTENT
  • 每单元有目标、材料、练习、反馈和完成条件
  • 练习提交幂等，重复点击不产生重复记录
  • 题目/答案/解析/评分规则均有版本号
  • 用户可查看历史答案与建议改写
C. AI 反馈
AI FEEDBACK
  • 输出符合约定 schema，解析失败安全降级
  • 反馈必须引用当前课程目标
  • 不确定的判断不显示为确定事实
  • 失败不阻塞课程、不丢练习记录
D. 复习
REVIEW
  • 错误入复习队列，带来源和优先级
  • 到期复习按时间/严重度/可用时长排序
  • 完成复习后更新下一次复习时间
E. 后台
ADMIN
  • 草稿内容不能被学习者访问
  • 发布/下线/批量修改均有操作记录
  • 后台 API 按角色限制权限
F. 质量与安全
SECURITY
  • 核心 API 有鉴权、速率限制与输入校验
  • 关键事件可关联 request id
  • 测试环境只用合成/脱敏数据
  • 发布前完成隐私/版权/AI 安全/平台清单

05 · 支持体系与结语

让产品长期健康运转的保障层

内容支持：教研与审核
CONTENT SUPPORT
  • 内容四态审核流：草稿 → 审核中 → 已发布 → 已下线
  • AI 生成内容展示来源、prompt 版本与风险标记
  • 人工抽检机制按比例复核 AI 批改与反馈质量
  • 投诉 → 下线 → 复盘闭环，内容投诉率纳入质量指标
用户支持：客服与数据响应
USER SUPPORT
  • 客服工作台：用户/订单/学习记录三联查询
  • 数据负责人可删除或导出用户数据，响应个保法请求
  • 订阅与支付对账能力保障计费准确
  • 提醒与通知渠道可配置，不骚扰用户
技术支持：可观测与审计
TECH SUPPORT
  • 关键事件关联 request id，全链路可追踪
  • AI 请求记录模型/版本/耗时/成本/错误类型
  • 敏感操作与 AI 会话全量审计日志
  • 成本与质量告警接入统一监控
组织支持：流程与决策
ORG SUPPORT
  • 需求/用例/验收标准三件套对齐（requirements/）
  • 架构决策 ADR 透明化，不静默变更约定
  • CHANGELOG 与文档随功能同步更新
  • AI Agent 与工程师共用同一套作业规范
结语：EnglishFlow 不是一个“只会聊天的 AI”，而是一套目标导向、能复习、能量化进步的学习系统。课程提供顺序与质量，AI 提供个性化与即时反馈，规则提供边界与安全——三者合力，让每天 15 分钟真正变成可验证的能力成长。
