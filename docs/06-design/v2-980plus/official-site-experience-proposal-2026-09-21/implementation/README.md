# 官网提案 06 的正式前端实现

日期：2026-09-21。用户已明确要求按本版更新官网并本地启动。本轮改动真实应用 `apps/official-site`，设计原型仍保留在 18185；本地官网在 **http://127.0.0.1:18182/**。没有部署公网，也不修改 P1R 任务验收状态。

## 已实现

- 14 类页面模板、19 个公开内容地址：沿用深紫 / 冷白主题、咖啡和书桌插画、简洁导航及移动布局。
- 免费开始聚合首发说明，旧价格/下载页 301 到新入口；电脑注册/登录去 learner-web，手机去 mobile H5。固定安全返回地址并保留白名单 UTM。
- 六类学习方法筛选与详情、八个 FAQ 搜索与展开；首页精选四个问题，答案分段展示；学习方法示例和已发布公开课程分别呈现。
- 原生 Vue 词卡练习、理解例句和复习；个人空间、视角拖动、晨光/星夜、三角色三装扮、角色墙、两句可撤回拼句游戏。
- 双主题、跟随系统、高对比；动效默认开启，顶部动画开关已移除。接入共享四级性能引擎，继续保留系统减少动态效果、离屏暂停、省电 2D。
- 弹窗键盘退出与焦点恢复、唯一标题 ID、面板与页签关联、手机菜单、世界区域避让固定开始按钮。
- SSR 标题、canonical、结构化数据、robots/sitemap、404 恢复；真实公告/课程/公示投影、上游超时和重试。官网保持公开只读。

## 2026-09-21 后续微调：默认动效与 FAQ

按用户反馈移除电脑和手机顶部的开关按钮，动效默认开启，忽略此前按钮留下的暂停偏好；系统减少动态效果、省电 2D 与离屏暂停继续生效。

首页保留免费范围、适用人群、设备使用、学习与复习安排四个问题，每个回答扩展为两段。将“能练哪些内容”合并到适用人群，将“未注册可否体验”合并到免费说明，帮助页从十项收敛为八项；同时补充规则反馈、跨设备同步、复习与问题反馈的实用说明。所有改文共用 i18n 资源，手机答案字号调整为 13px。

此次构建与官网类型检查通过；[针对性浏览器记录](faq-motion-check.json)覆盖首页/帮助页 × 320/390/1440 宽度 × 深浅主题，共 12 组布局，全部回答展开后无横向溢出。检查了旧暂停偏好下的实际动画、系统减少动态效果、FAQ 内容搜索，无页面脚本或水合错误。旧完整矩阵仍保留为首轮实现快照，本次没有重复进行后端或全站业务验收。

## 提交与 clyunedev 发布边界

本次官网源码只有在独立提交推送到 `dev`、服务器拉取该提交并且只重建 `official-site` 容器后，才会显示在 `https://clyunedev.com`。此前服务器运行的任意镜像不会自动包含本机未提交文件；容器成功重启也只能证明它运行了已拉取的那一版源码。

官网发布前须核对当前环境、受控发布命令和回滚方案；不得为官网 UI 更新而重建数据服务、Gateway 或全部 Compose 栈。

当前 UI 为完整中文；共享官网文案已经集中，英文资源和正式译审尚未完成。正式域名、学习端地址、已核实主体与有效隐私/使用文件需沿用发布流程配置。本轮没有声称这些内容已获批准。
