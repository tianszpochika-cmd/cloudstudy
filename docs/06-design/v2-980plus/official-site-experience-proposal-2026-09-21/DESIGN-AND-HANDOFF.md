# 官网重设计：内容依据与实施承接

> 2026-09-21。对应官网提案 05。用户要求：延续移动提案 04 的样式，重构官网整体展示与交互；初期免费；只介绍第一阶段功能；避免不符实际的宣传；移动访问优先。

## 1. 产品定位与文案规则

官网让访客快速判断“适不适合我、能学什么、怎么开始”。首页不堆完整需求清单，不展示服务架构、接口名、权限判定、Phase 编号或实现术语。

主表达为“让英语，回到你的日常”。支持它的具体内容只有词汇、听读、规则练习与复习记录。品牌感来自深紫、留白、统一图标和情景插画；不通过夸大能力或堆砌愿景增加内容。

免费文案固定为**初期开放的学习功能免费使用**。它不等于终身免费、任意将来内容均免费或用户永久获得全部权益。当前稿取消 ¥39 等旧套餐；正式开发需同步核对公开价格投影和学习端准入，不能只改官网文案而继续把用户送到购买流程。

## 4. 移动体验的具体要求

- 690 像素以下使用手机布局：顶部只有品牌、主题、菜单；菜单全屏，开始与直接登录都可到达。
- 首页主按钮放在标题与两行说明之后，插画在其后；手机首屏无需滚动找开始入口。
- 当首页/详情的主行动滚出视口后，底部显示开始入口；免费开始页不重复显示这个固定按钮。
- 首页主题卡采用双列，详细内容目录用单列，正文和按钮不压缩为桌面小字；搜索先于分类，分类可自然换行。
- 免费开始页在手机上先显示当前设备的操作区，再显示免费功能说明；电脑上说明与操作并排。相同 DOM 内容通过布局调整顺序，读屏顺序后续正式实现应再次对齐。
- “怎么学”在手机上去掉重复标题和解释，让公开词卡操作进入首屏；示例和导航均可键盘操作。
- 详情与 FAQ 用原生展开/折叠；弹层支持 Escape、关闭按钮与焦点回到触发处；移动菜单关闭后进入对应页面。
- 链接、表单、主要按钮优先保证 44 像素触控区域；桌面内容区最大 1184 像素，保留阅读宽度。
- 主题在本机保存；减少动态效果，对减少动效偏好关闭平滑滚动和悬浮位移。没有自动轮播、滚动劫持、粒子或大体积依赖。

已检查 320 / 360 / 390 / 430 / 768 / 1024 / 1440 宽度下十三模板的双主题。浏览器布局检查不能替代 iOS/Android 真机、软键盘、刘海安全区、屏幕阅读器与全量可访问性验收。

## 5. 正式前端重构如何承接

当前稿在 `docs/06-design` 下独立保存，不直接替换业务应用。正式实施沿用 `apps/official-site` 的 Vue 3 + Nuxt；不引入第二个官网项目或替换框架。

1. **展示层**：先迁移公共壳、按钮、内容卡、FAQ、文档页与开始页。样式映射到 `packages/design-tokens`，文案归 `packages/i18n`，不要把原型颜色和中文常量复制成另一套业务系统。
2. **公开数据**：内容列表、详情、公告与开放状态消费已校验公开投影，保留内容撤回、版权失效、无数据、加载/失败、旧缓存与重试状态。未实现接口在任务中保留 GAP。
3. **免费策略**：和业务 owner 确认免费内容范围、权益来源与既有入口的兼容。官网不能通过前端硬编码放行受保护学习能力；正式客户端与服务端对“免费开放”必须一致。
4. **学习衔接**：根据设备推荐 mobile H5 或 learner-web；注册、成人 Gate 与 Token 均由 IAM/学习端承接，returnTo 需受控，官网不收集密码或保存业务 Token。
5. **SEO 与运行**：使用正式路径、SSR/SSG、canonical、meta、sitemap 和有效公示文件；预览中的 noindex、hash 路由、回环地址、样例课程和衔接弹层不直接上线。
6. **验收**：除了视觉和点击，还要检查真实公开投影、旧路径跳转、失败恢复、免费准入和手机实际访问；不能继承本原型检查为产品 PASS。
