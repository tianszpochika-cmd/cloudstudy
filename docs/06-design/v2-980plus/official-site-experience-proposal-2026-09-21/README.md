## 这版的主要变化

1. **初期免费**：以免费开始为主行动，取消提案中的套餐比较、月费、升级与支付介绍，不承诺终身免费或永久全内容免费。
2. **内容具体**：介绍词汇复习、语法、听力、阅读、录音自评和规则写作。课程结构为展示例子，不编造已上线课程数量、用户量、学习效果或评价。
3. **导航简化**：主导航为学习内容、学习世界、怎么学、常见问题；免费开始保持突出，关于、公告与公开信息放在页脚。
4. **先了解再注册**：访客可浏览内容分类、详情，并试“词卡回忆 → 词句理解 → 复习”的短示例；官网不收集账号密码。
5. **手机优先**：独立全屏菜单、首屏主行动、单列内容目录、紧凑筛选、滚动后的底部开始入口，以及把当前设备操作前置的开始页。
6. **主题一致**：沿用 `#5937D1`、`#F7F8FC` 和深色 `#161925 / #222638`；统一 SVG 图标，复用移动稿原创咖啡/书桌插画，无外部图片或字体请求。

## 本轮新增交互

- 首页与 `#/world` 提供个人空间、拼句小火车和角色墙三个可切换面板。角色与装扮可以带回空间；错误拼句能撤回调整。
- 顶部可暂停动效并保留偏好；跟随系统减少动态效果，离屏暂停装饰动画；体验世界时收起手机固定开始入口。
- 立体空间是 CSS 深度分层和视角交互示意，角色是原创 SVG 切片，尚未制作正式 Three.js 模型。示例不记分、不发奖、不保存真实账号资产。

## 当前边界

- 当前内容与免费开放安排是用户要求的首发设计方向，不表示线上已经发布。正式课程必须来自已授权、已发布的公开内容。
- 公开练习为词卡/词句与两道拼句设计示例，不播放真实音频、不生成学习记录或奖励；正式学习业务仍归学习端。
- “在浏览器开始”和登录会展示清楚的衔接预览，随后可打开移动端提案 04。正式注册、成人 Gate 与安全返回地址未在本稿接入。
- 换设备弹层提供的是本机预览地址，明确它不是跨设备可访问的公网域名；不伪造下载链接、二维码、应用商店上架或健康监测。
- 隐私、使用和公示页重排现有项目说明，未编造主体/备案或新法律条款；上线前需要有效的正式文件。
- 主题偏好本机保存；内容搜索条件保留在 URL；练习例子是内存状态。没有账号、支付、通知或其他业务写入。
- 本轮不修改 `apps/official-site`、共享 Token、商业权益规则或 P1R 状态。正式重构仍需补齐公开数据状态、SSR/SEO、安全深链、国际化、跟随系统、高对比及真实设备验证。
