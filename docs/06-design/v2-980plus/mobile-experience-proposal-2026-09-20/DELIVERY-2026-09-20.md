## 2. 最新版如何识别

以本目录 **index.html 的 DESIGN STUDY 03** 为当前设计。提案演变如下：

1. 提案 01：暖白、松绿、青柠；首页、课程、词汇、听力、小结五页。

3. **提案 03（当前）**：根据用户反馈读取现有前端色板，以 `#5937D1` 深紫和白字为重点，原品牌 `#596BFF/#7C5CFC` 为冷紫参考；浅色采用冷白，深色沿用移动端深蓝灰。十页与交互结构继续保留。

前两版仅记录为过程；尤其不应继续采用提案 02 的紫红渐变作为当前配色。正式实现仍应消费共享 Token，不将本原型内的 CSS 直接作为业务页另一套主题系统。

## 4. 获取后查看与检查

在仓库根执行：

```text
node docs/06-design/v2-980plus/mobile-experience-proposal-2026-09-20/preview.cjs
```

访问 `http://127.0.0.1:18185/`。该端口来自 `config/local-ports.json` 中的 mockups-static；默认只绑定本机，冲突时退出，不自动换端口。GitHub 文件页可看文档和 PNG；交互原型需在本地浏览器打开，不是已部署的在线产品。index.html 自包含，也可直接用浏览器打开本地文件。

原型提供两组五屏总览、逐页体验和浅/深主题切换。世界节点、每日目标、昵称形象、词卡、听力模拟、拼句、专注及榜单隐私等可操作。主题选择本机保存，其他演示状态刷新后重置。

在已安装仓库依赖、Playwright Chromium 可用且预览服务运行的环境，执行：

```text
node docs/06-design/v2-980plus/mobile-experience-proposal-2026-09-20/check-preview.cjs
```

脚本会重新生成主题截图及 preview-check.json。已有记录包含 25 项检查、十页双主题渲染、320/390 像素布局检查、0 个页面脚本错误。它使用独立浏览器上下文，不访问真实账号。
