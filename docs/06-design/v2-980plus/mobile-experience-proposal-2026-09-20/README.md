## 2. 配色与移动端层次

**晨雾 / 浅色**：直接采用共享 Token 的冷白 `#F7F8FC` 和白色卡片；本轮正文调整为 `#242637`、次级文字为 `#686D80`。重点卡片和按钮以已有深紫 `#5937D1` 为基础，使用同色系暗部过渡；移除紫红/玫红渐变。

**星夜 / 深色**：直接沿用移动端 `.yx-app.b10-theme--dark` 的页面 `#161925`、卡片 `#222638`、正文 `#F4F6FF`；本轮次级文字调整为 `#B2B7CD`，边框为 `#363B50`。主卡使用深紫同色系渐变，白字保持清晰；星球与选中态使用原项目冷紫，减少发光和背景染色。

主导航固定“今天 / 课程 / 复习 / 世界 / 我的”。自习室、拼句、词汇、听力、设置等详情页按任务保留返回或退出，主要操作固定在底部。长内容在手机容器内滚动。桌面上的多手机画板仅用于比较移动设计，不是 PC 产品页面。

颜色变量仅在这份隔离原型中使用。正式开发必须映射至 `packages/design-tokens`，页面用 `packages/i18n` 文案入口，由 `apps/mobile` 的 uni-app 实现，不另建业务项目。

## 4. “世界”的功能细则

### 4.1 我的学习星系

保留项目既有六节点：起源星门、词汇轨道、语法星云、听力卫星、表达恒星、星系之门。世界页聚焦“下一站”，点击可直接精听；“查看全部星系”展开六节点清单，再看条件和下一步学习入口。“已点亮 / 待点亮 / 下一站”文字与视觉状态同时呈现。

条件分别对应首次学习、词汇复习、阅读检查点、听力、写作/合格游戏、每日目标及全局成长。原型用两颗已点亮、听力为下一站的示例，不根据页面点击伪造点亮事实；最终阈值、有效学习条件和奖励版本必须来自服务端。

### 4.2 公共自习室

- 只展示 Phase 1 公共主题房。以书桌插画、同伴和在座人数营造安静陪伴，弱化座位装饰；成员与人数为示例。
- 可选 25 或 45 分钟；从世界一次点击即可入座并开始，开始后锁定时长。支持暂停/继续和切页返回，暂停时保留剩余时间。该能力是新增体验提案，正式计时和租约规则需要重新确认。
- 仅能选择“一起加油 / 保持专注 / 学有所获”预设鼓励；入座后才能操作。没有自由发帖、私聊、开麦或文件上传。
- 提前结束需确认；取消确认继续计时，确认后离座并明确未结算时长。
- 本稿不连接多人会话，不续租真实席位，也不授予专注分钟或 XP。正式端要实现 90 秒 TTL、30 秒续租、60 秒恢复宽限、5 分钟无学习活动释放，且只有满足有效租约、focusVersion 和服务端 endsAt 的 COMPLETED 才结算。离线、暂停、提前退出不可记有效时长。

### 4.3 拼句小火车

只开放项目 P0 的 Sentence Train 设计预览。使用两道固定题，选齐后自动反馈；点击已选词取回，也可撤回最后一个。答错允许就地改序，提示按需展开，答对再给完整句与解释；第二题后返回世界。原型判断不是正式 assessment-service 判分，不产生奖励。

### 4.4 成长与榜单

XP、等级、星币、连续学习可进入相应面板。成长面板显示等级距离、三个成就；星币面板说明用途，进入已拥有的基础形象选择。示例不扣币、不抽奖、不兑换资产。

榜单按“已结算专注分钟”展示周期与示例名次。隐私页可退出榜单，退出后个人条目从演示榜单移除。未实现真实多人排行、匿名模式和举报全流程；这些保留为正式设计后续状态，不能用静态排名作为验收证据。

## 5. “我的”的功能细则

| 区域 | 操作与细节 | 本轮边界 |
|---|---|---|
| 资料与形象 | 编辑昵称（最多 12 字符），在“初航星环 / 月光旅人”基础形象间切换 | 更新本次预览；不写真实资料或资产 |
| 学习节奏 | 5 / 15 / 30 / 45 分钟；日常交流、A2、英/美发音 | 目标同步首页计划和设置；不调整真实课程或 SRS |
| 学习日历 | 七日记录、累计时间、今日小结与昨天课程入口 | 历史数值是布局示例，不是实时计算 |
| 我的词本 | 收藏数量、刚刚收藏、三个示例词、释义、进入复习 | 不将收藏直接等同于已掌握 |
| 成长成就 | 成就名称、条件、等级进度、返回星系 | 示例档案，不发放奖励 |
| 学习权益 | 基础内容与兑换能力说明 | 不开放支付、兑换或真实权益变更 |
| 离线学习 | 教材、音频大小、下载就绪、待同步状态 | 只展示示例；没有实际资源下载或同步 |
| 外观 | 晨雾浅色 / 星夜深色 | 整份原型同步，主题偏好本机持久化 |
| 学习偏好 | 每日目标、发音偏好、提醒开关 | 提醒不触发系统通知；发音不加载媒体 |
| 账户安全 | 当前设备、上次登录、身份校验说明 | 未执行改密、撤销会话 |
| 隐私 | 退出学习榜；导出和注销的步骤说明 | 导出、注销只读流程，无申请或删除动作 |
| 帮助 | 同步、专注结算、反馈入口说明 | 无真实工单和消息发送 |

## 6. 保留的学习闭环与原型边界

首页 → 三个词的回忆/反馈 → 自动接听力 → 小结 → 回首页。词卡可撤销，收起后可续学；只巩固薄弱词后回小结，更新原词的结果，不重复听力或累计词数。小结只显示当前预览实际操作的词数与精听标记，不再填充固定学习分钟；历史日历、成长与人数仍是布局示例。

内容、用户、座位、余额、成就、日期、课程和学习记录全部为设计示例。播放进度和专注计时为模拟，没有真实音频、服务连接、成绩、奖励、下载或通知。主题之外的资料、目标和交互状态仅在当前页面会话保存，重置按钮清空这些演示状态并保留主题。

未启用 Phase 2 AI/ASR/RTC、K12、真实社交或商业交易。暗色/浅色已做原型检查；跟随系统、高对比、完整异常八态、正式国际化、读屏、全部触控目标及原生安全区仍需后续设计与真实设备验证。未完成这些事项前不能称为正式移动端设计 DoD 完成。
