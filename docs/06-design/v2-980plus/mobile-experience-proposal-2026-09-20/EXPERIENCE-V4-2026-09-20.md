# 移动端体验提案 04：少一点操作，多一点沉浸

> 日期：2026-09-20。依据用户对提案 03 的评审意见，对同一批十个手机界面重新组织视觉和操作路径。保留深紫、冷白与双主题；优先设计用户需要的行为，后端能力差异单独登记。此稿待用户评审，未改变正式业务契约或 P1R 验收状态。

## 1. 本轮问题与取舍

上一稿的主要问题并非缺少入口，而是下一步不够突出：课程续学需要再找一次入口；结束词卡出现额外确认；个人偏好需要层层进入；世界同时突出星系、成长和自习，缺少明确的开始方式。装饰、发光和多个不同风格的图标也分散了注意力。

本轮采用三个设计原则：**把下一步放近、让选择可以撤回、允许舒服地停下。** 首页以正在学习的主题组织内容；练习页面保留固定操作区；低成本偏好即时生效；会丢失当前专注会话的操作保留确认。星系主要承担品牌和成长表达，学习内容优先保持可读。

这不是评分承诺。美观、压力感和效率仍需用户试用判断；本次检查只能证明原型行为与既定设计一致。

## 2. 十个页面改了什么

| 页面 | 新的第一层信息与主行动 | 交互变化 |
|---|---|---|
| 今日学习 | 当前主题、今日计划、一个继续按钮 | 首次进入开始词汇；中途退出回到刚才的词卡/精听位置；上次课程直接续听；目标就地调整 |
| 课程与路径 | 当前单元先出现，再展示全部单元 | 当前卡片和底部按钮都可一步续学；章节状态以文字和图标区分 |
| 词汇回忆 | 一个词、一段解释、四档反馈 | 揭晓后评价；可撤销上一张，跨到精听后也可撤销；收藏有反馈并出现在词本；最后一张自动接精听 |
| 情景精听 | 对话逐句内容、固定播放器 | 点击句子即定位并模拟播放；拖动进度；直接选速度；译文/单句切换；收起后保留位置 |
| 今日收获 | 当次词汇、听力与待巩固数量 | 主出口允许结束今天；可选只巩固薄弱词；巩固后更新原小结，不重复听力、不重复累计词数 |
| 世界 | 一起专注，其次拼句，再看星系成长 | 选 25/45 分钟后，一次点击入座并开始；进行中直接回到当前专注；学习星系给出下一站直达入口 |
| 星光自习室 | 安静的书桌场景和大字号倒计时 | 开始、暂停、继续；暂停保留剩余时间；切页后仍可返回；提前结束确认，取消保留会话 |
| 我的 | 资料、七日记录、学习目标、词本/成就/离线 | 顶部月亮/太阳一键切主题；目标、资料、形象都可直接编辑；常用项不埋入设置 |
| 拼句小火车 | 当前句子、已选词、可选词 | 选齐自动反馈；点错误词取回再排；支持撤回最后一个；提示按需展开；连续两题后返回世界 |
| 设置 | 外观与常用学习偏好 | 主题和英/美发音直接选择；提醒即时生效，无额外保存；安全、隐私、下载和帮助保留独立详情 |

保持原来的十页范围。图标、弹层、展开状态和两套主题不作为新增业务页面。原项目 Phase 1 学习和成长功能映射见 [README](README.md)；本轮没有增加 AI、RTC 或 K12 入口。

## 3. 操作次数对比

计数从表中指定页面/状态开始，只计算所述任务的点击次数；不包括滚动、选内容或此前的学习操作。它是原型结构对比，不是实测用时或全产品效率提升百分比。

| 任务与起点 | 提案 03 | 提案 04 |
|---|---|---|
| 首页的上次课程 → 精听 | 课程卡 → 课程页继续，2 次 | 点上次课程直达，1 次 |
| 世界 → 开始默认时长的专注 | 进入自习室 → 开始，2 次 | 点“一起开始”，1 次 |
| 最后一个词评价后 → 精听 | 再点“继续听力”，1 次 | 自动衔接，0 次；仍可撤销最后评价 |
| 词卡中途 → 收起回首页 | 退出 → 保存并离开，2 次 | 点关闭收起，1 次；当前会话保留 |
| 我的 → 改深浅主题 | 设置 → 主题卡，2 次 | 顶部月亮/太阳，1 次 |
| 设置 → 修改发音 | 发音行 → 选项，2 次 | 直接点击英/美分段选项，1 次 |
| 拼句选齐 → 获得反馈 | 点击检查，1 次 | 选齐自动反馈，0 次；错误后仍能修改 |

**不一味删除确认：** 专注提前结束仍确认，因为会结束当前会话。常规收起学习保留位置，不需要再确认；词卡和拼句提供撤销，减少误点后的恢复成本。

## 4. 视觉语言

- 保留源项目深紫 `#5937D1`、冷白 `#F7F8FC`，深色页面 `#161925`、卡片 `#222638`。主卡使用低亮度紫色过渡，白字保持清楚；不再引入紫红主渐变。
- 紫色主要承担主按钮、选中态与品牌；少量灰绿和浅杏色区分陪伴、连续学习与休闲入口。辅色面积较小，均不单独承担状态含义。
- 统一 1.7 线宽的 SVG 图标，补齐主题、设置、收藏、下载、隐私、撤销、前后跳转、咖啡和同伴等动作。图片使用本稿内嵌的咖啡窗景、月夜书桌插画，无外部素材依赖。
- 统一卡片、分隔线、按钮和固定底部操作区；撤销、状态文字和按钮位置跨页面保持一致。主题切换及就地操作尽量保留当前页面滚动位置。
- 词卡、对话和拼句围绕咖啡馆主题展开。演示词为 latte、order、to go；图像与练习内容形成关联。

完整取值和选定纯色色对计算见 [palette-reference.json](palette-reference.json)。正文、次级文字、边框等部分数值为本轮调整值，不能把全部原型变量说成现有共享 Token 原值。正式开发要映射到 `packages/design-tokens`，并做完整色彩与真机可读性检查。

## 5. 后端承接与产品规则待决项

用户已允许按体验反向提出后端调整。以下是为达到设计行为需要明确的能力，不代表现有服务一定缺少，也不代表本轮已实现。

| 体验目标 | 正式实施要确认的契约/恢复行为 | 相关 owner 与现有设计映射 |
|---|---|---|
| 首页一键续学、收起不丢位置 | 统一读取当前任务、session/checkpoint、词卡索引和媒体位置；跨设备冲突、离线待同步与失效内容需有确定恢复策略 | learning / assessment / media；JNY-P1-05/06/07、DAILY-PLAN、VOCAB、LISTENING |
| 评价后自动前进，可撤销 | 请求幂等，撤销窗口及版本规则；服务端失败时不能静默丢弃评分；撤销不是删除审计记录 | assessment / learning；RULE-P1-SRS、PAGE-P1-SRS |
| 只巩固薄弱词 | 按本次记录形成准确子集；巩固结果关联原 session，避免重复计数与奖励；即时正确不等同长期掌握 | assessment / learning；PAGE-P1-REPORT、JNY-P1-08/09 |
| 一次点击入座并开始 | 服务端编排入座与专注开始；重复点击幂等；满员或开始失败时能解释并恢复/释放占位 | social；PUBLIC_THEME_ROOM、P1_FOCUS_CREDIT_V1 |
| 暂停后继续同一次专注 | **本轮新增体验提案，需专门确认规则**：暂停期间是否保留席位、多久释放、如何恢复、累计哪些有效区间；必须明确 focusVersion、租约和权威时间；暂停时间不应计学时 | social / workflow；既有 TTL、续租与结算规则不可被客户端暂停绕过 |
| 点句子定位、单句循环 | 带版本字幕时间轴与媒体版权有效期；恢复位置、速度和音频失效策略；原型计时不替代真实媒体播放 | media / content；PAGE-P1-LISTENING |
| 选齐即时判句、允许纠正 | 正式判分需取消过时请求/忽略迟到响应、版本化答案、去抖与幂等；明确提示使用、重试与奖励规则 | assessment / gamification；PAGE-P1-GAME |
| 偏好即选即保存 | 乐观更新成功/失败反馈、可重试与回滚；UI locale 与学习语言分开；主题跨端采用统一 Token | learner / notification；USR、UI locale |

“暂停可继续”与既有服务端计时/结算约束需要重新对齐，不能直接把此稿的本地计时逻辑复制到生产。正式开发认领 P1R 任务时，还要补全 FEAT/PRD-ATOM/V2-980、ARCH、ACT/JNY/PAGE/RULE/INT/E2E 映射；这里保留页面级追溯，不伪造新的批准编号。
