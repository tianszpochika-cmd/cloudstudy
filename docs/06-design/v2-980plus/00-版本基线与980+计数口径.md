# 版本基线与 V2-980 计数口径

## 1. 继承关系与禁止事项

本版的事实优先级如下：

- 本目录：下一轮开发唯一的全量业务设计、交互、阶段、数据/契约映射和验收落地基线；
- [PRD](../../../requirements/product-requirements.md)、[功能矩阵](../../../requirements/feature-matrix.md) 和 [PRD 原子候选清单](../traceability/03-PRD原子需求候选清单.md)：产品证据、编号、法规边界和追溯索引；
- [v2 微服务技术架构](../../02-architecture/v2-microservices-architecture.md)、[架构映射与任务重基线](11-架构映射与任务重基线.md) 与 [Phase 1 开发计划重基线](../../../requirements/backlog/v2-phase1-rebaseline/README.md)：服务边界、Gateway/IAM、数据/事件、任务依赖和验收字段；B7+ 只作 historical-candidate；
- 既有 `detailed-specs/`、`phase-*`、B0–B6：历史实现、术语和迁移参考；若与 v2 冲突，不得覆盖 v2。

本版禁止：为补齐数量私造 FEAT-*、把页面状态计为业务功能、把 Phase 2/3 能力提前放入 Phase 1、绕过四项目边界、在客户端复制领域事实，或用旧版文档推翻本版设计。

## 2. 冻结的范围与计数口径

功能矩阵顶部的范围目标为 Phase 1 540、Phase 2 228、Phase 3 212，共 980；业务域汇总行相加为 Phase 1 540、Phase 2 208、Phase 3 182，共 930。差额不是未核准的“功能数”，而是按本版冻结规则登记为 Phase 2 20 个、Phase 3 30 个跨域扩展登记位：

1. 930 个业务域设计单元：按矩阵每个业务域和阶段的汇总目标生成；优先绑定显式 `FEAT-*`，其次绑定 `PRD-ATOM-*`；
2. 50 个跨域扩展登记位：使用 `V2-EXT-P2-TOTAL-*` 和 `V2-EXT-P3-TOTAL-*` 保留连续登记编号，记录跨域入口、状态、事件、性能、恢复和验收模板，并统一标记为“待细化签收”；
3. 任何 `V2-EXT-*` 登记位在 v2 设计 owner 补齐正式名称、来源映射和独立验收前，不得进入开发 WBS、接口实现或上线统计；
4. `V2-980-0001` 至 `V2-980-0980` 是范围登记行，不是 980 份可实施详细设计，也不是 980 个已完成功能。编号必须保留，不因本次口径冻结重新编号。

## 3. 登记行成熟度与升格规则

980 条登记行的成熟度分布如下，三类状态互斥且合计为 980；它们不能被概括为 980 份可实施详细设计：

| 状态 | 登记行数 | 进入条件 | 可做的工作 | 不允许 |
|---|---:|---|---|---|
| 显式功能包已设计 | 184 | 有 `FEAT-*`、矩阵细节和既有设计锚点 | 进行逐条交互评审、契约拆解和实现排期评估 | 以设计完成代替代码验收 |
| PRD 原子证据已映射 | 486 | 有 `PRD-ATOM-*`、来源行和域级设计模板 | 补充独立页面/接口/权限/验收判断 | 把候选证据直接当成已签收功能 |
| 待细化签收 | 310 | 已纳入 v2 范围，但只有矩阵目标、差额信息或扩展登记位 | 做交互占位、冲突识别和独立验收细化 | 写实现代码、承诺上线或回退到 v1 取定义 |

`184 + 486 + 310 = 980` 是范围登记的成熟度分布；只有逐条通过契约、数据、权限、测试和 DoD 的登记行，才可独立评估实现排期。

## 4. 设计完整性定义

每个 V2-980 登记行必须同时拥有：来源主键、PRD/矩阵锚点、所属阶段和业务域、四项目页面宿主、主流程、成功/空/加载/错误/离线/权限/恢复状态、API/数据事实源、权限与隐私、事件埋点、验收标准和 review 状态。字段齐全是追溯完整性的要求，不代表代码、契约、迁移和测试已经完成。

## 5. 阶段门

- Phase 1：仅成人与大学生；规则化练习和反馈；不启用生成式 AI、ASR、AI 评分、数字人、K12 和开放社交。
- Phase 2：AI 请求必须经过前置敏感拦截、结构化 Schema、后置合规核验、成本/同意/超时降级和审计；实时语音使用商业 RTC，不用 HTTP 轮询。
- Phase 3：K12 仅在资质、版权、主体、监护授权、未成年人保护和专项合规通过后开启；默认关闭并可回放撤回。

PRD 原子候选证据 2342 条仅作为追溯输入，不能替代产品对 980 条范围登记行的正式签收，更不能把登记行数量当作可实施详细设计数量。
