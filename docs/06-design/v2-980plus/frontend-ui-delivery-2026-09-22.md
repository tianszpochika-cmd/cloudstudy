## 2. 主要改动

统一延续官网的深紫、薰衣草、冷白、圆角卡片、留白和轻量插画，按终端实现不同的信息密度与导航；设计颜色共用 `packages/design-tokens`，UI 文案共用 `packages/i18n`，没有新增独立业务项目。

- 管理端：权限分组导航、功能搜索、登录反馈、内容/词汇/题目编辑、列表筛选和游标加载、学员档案、订单与退款、工单、审计、发布和恢复页面；补充编辑未保存保护、请求错误隔离、防重复操作、退款确认失效与小屏抽屉/表格。
- Web 学习端：认证页面、首页任务、书架、学习路径、词汇与多题型练习、听读说写、报告、成长世界五分区、账户与显示偏好；修复任务入口和部分媒体/阅读/缓存按钮调用。保留仅开发环境使用、明确标注示例数据且拒绝真实写入的 `design-review.html`，生产入口不导入。
- 移动端：统一页头、学习功能网格、表单与反馈、明暗底部导航、登录/注册/重置、资料与设置；补齐匿名认证入口、重置成功反馈、picker 映射，修复 H5 页面初始化未触发数据加载的问题。
- 共享部分：新增三端语义 Token、体验文案及 learner-base 文案出口；管理端接入既有共享 performance，锁文件仅增加对应 workspace 依赖映射。
- 配套交付：各端截图、浏览器结果、回归测试、管理端检查脚本、移动端 E2E 脚本和运行说明。

基础设施配置已有 `infra/docker/docker-compose.dev.yml`；`infra/docker/clyunedev/` 是单机预发布编排，不能直接称为已运行的本地环境或正式生产。此次不启动 Docker、不改动其他项目容器，不发布到远程服务器。

