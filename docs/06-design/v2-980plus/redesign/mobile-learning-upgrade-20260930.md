# 移动端六类学习能力改造

范围：现有 18283 静态移动原型、原创样例和本机保存。保留四个主 Tab，不修改正式应用、后端、契约或阶段验收状态。

## 页面和状态方案

| 区域 | 主要内容 | 操作布局 |
|---|---|---|
| 首页 | 当前目标、今天进度、唯一开始/继续/回顾动作、准确续读 | 摘要在上，主要动作独立；两个次入口并排 |
| 学习 | 今日 / 课程 / 词汇 / 复习；任务与内容发现 | 分区导航；卡片标题、说明和操作分层；主次按钮最多两列 |
| 世界 | 同源学习记录、周报、学习驱动成长 | 成长指标与三条入口行，不堆三个长按钮 |
| 我的 | 档案、学习计划、记录、设置、帮助 | 单列入口行；未来能力和人工状态操作进演示工具 |
| 学习过程 | 当前题/章节/写作草稿、反馈、下一步 | 内容与操作间隔 16px；控件至少 44px；同页更新不播页面入场动画 |

## 数据规则

- 本机数据升级沿用原存储键，保留旧任务、偏好、位置和结果；旧结果缺明细时明确说明。
- 目标族：基础、大学英语（四/六级）、考研、职场；预算 5/15/30/45 分钟。模板是原型示例，计划变更先预览，保留完成记录，进行中可保留或顺延。
- 练习轮次独立保存；查看结果不重置，重练创建新轮次。记录显示预估用时和答题结果，不伪造实际学习时长。
- 错题按知识点匹配变式；自评、当次修复、次日验证、七日验证和已验证分别表达。普通页面不能提前通过未来日期验证；演示工具可推进日期。
- 阅读保存书/章身份、滚动位置、完成状态、收藏、查词上下文和笔记。写作保存草稿、确定性规则反馈、参考文本、自评和历次提交，不调用 AI。

| 能力 | 已实现的可操作路径 |
|---|---|
| 日回顾与记录 | 完成题组→本轮结果→当天回顾→历史/周报下钻；历史重练新增轮次，原 2/2 与新 1/2 同时保留 |
| 目标与日历 | 四目标族与 5/15/30/45 档；学习日/休息日；调整预览；完成项保留，进行中保留或顺延，顺延进度可继续 |

| 阅读完成 | 独立书章身份、滚动/刷新续读、章节进度、完成/下一节；上下文查词、复习添加、收藏查询、笔记自动保存 |

### 评审问题的处理

| 编号 | 修正与验证 |
|---|---|
| REV-M01 | 续读使用最近阅读 bookId/chapter，而非浏览目录状态；浏览商务目录后仍回四级第二章 |
| REV-M02 | 目标与预算重建待学模板；五分钟实际生成一个五分钟基础题组；30 分钟预览实际安排 28 分钟，并保留原题组选项 |
| REV-M03 | 以 skill 匹配变式；She 三单错误匹配 Tom studies，词义使用词库真实释义，缺变式保留待补救；阶段转换后题目与反馈保持本轮快照 |
| REV-M04 | 自评不记验证通过；变式通过只记本次修复，日期到期后逐阶段验证；D+1/D+7 实测由 lab 推进日期，未伪称实际等待七天 |
| REV-M05 | 今日回顾读取当天记录；总安排与剩余预计分钟分开；已完成查看结果不重新开始，结束动作回首页 |

首页围绕一个当前主动作；学习保留今日/课程/词汇/复习四分区；我的收敛为学习档案、记录、计划、显示和帮助。世界本周/累计 XP 与联赛自己的成绩来自同一份记录，其他成员及成就入口明确为样例。用时只显示预估；自评词汇与复习记忆计数不混入客观答题正确率。

UI 复用现有语义颜色，不新增硬编码品牌/状态色。卡片内说明与动作分层，动作间隔 12px、块间隔 16px，常用主次动作并排；窄屏和大字号流式换行，特大字号学习日改三列并保持文字单行。周报箭头置于 44px 按钮内并居中，同页选择不播放整页进场；仍存在的控件在原位更新后保留焦点。听力材料与语速改选择器，词汇今日三词任务按 3 显示，认识/加复习替代收/斩文案。

- 25 个关键页面 × 4 场景共 100 次布局采样：390×844 标准字号浅/深，320×740 特大字号浅/深。文档和内容区横向溢出、超出视口的控件、不满足 44px 触区目标的扫描控件均未发现（尺寸测量容差 0.5px）；底栏未超出视口。高对比特大字号另抽查 6 页×2 主题，12 次未发现同类问题。目检后学习日三列修正另定向复测浅/深 320px 计划页。
