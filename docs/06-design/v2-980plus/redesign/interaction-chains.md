# 交互链条文档（8 动线，76 幕）

> 通用规则（全幕）：loading/empty/error/permission/recovery 五态齐全；错误码永不直出，
> 一律人话 + 下一步按钮；幂等重试用同键（用户无感）；token 资格静默刷新（不要求重登）；
