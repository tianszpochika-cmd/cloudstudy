> 预览：`http://127.0.0.1:18283/admin/`（与移动端同一静态服务，读盘即时生效）。
> 范围：L8 内容双审 / 管理登录仪表盘权限媒体 / L9 治理举报 / 客服后台 / 商城后台 / 审计 / 观测发布门。

## 2. 玩法

1. 内容列表（`#/draft`）：搜标题/编号；切换简审/双签模式；新建草稿。
2. 送审与审核（`#/review`）：缺项（版权/报告/媒体）一次列齐并 409 式拦截，演示可一键补齐；简审 1 人发，双签 L1→L2，申请人禁自审（用同一身份审 L1 后再点 L2 会被拦截）。
3. 发布管理（`#/publish`）：普通下架 vs 强制停止分发（二次确认）；已下架可回滚上架；目录同步演示 1.5s。
4. 媒体（`#/media`）：默认未接通只显示边界；切“已接通”后可演示上传进度与资产列表。
5. 治理（`#/gov`）：R1 只读建档；R3 处置按钮隐藏并说明。
6. 举报（`#/report`）：只读队列，脱敏；无处置按钮。
7. 客服（`#/cs` → `#/csdetail`）：hash-only 旧单标信息不足；接单→回复→关闭/升级。
8. 商城（`#/shop`）：沙盒标记；日切对账演示。退款（`#/refund`）：双人审批约束——第一审批人不能点第二审批。
9. 审计（`#/audit`）：允许/拒绝筛选+搜索；导出 internal-only 只说明。
10. 观测（`#/ops`）：探针状态+发布门 checklist，回滚演练演示。
11. 我的（`#/me`）：切换 4 个演示身份，退出登录。

## 3. 前端原型规则（不是后端参数）

- 所有“通过/发布/建档/对账”都是本机状态变更，不写库、不调接口。
- 双签/双人审批的“禁自审/禁同一人”是前端演示拦截，正式约束在服务端。
- 沙盒订单不扣款、不发真实权益；价格/金额均为演示。
- 未测：读屏、软键盘、真机、横屏全路由、完整 WCAG。
