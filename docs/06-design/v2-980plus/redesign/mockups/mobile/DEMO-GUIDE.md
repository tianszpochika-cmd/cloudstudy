## 1. 演示身份与入口

- 默认已登录演示账号（`S.user=演示账号`，成人门 PASS），开箱即玩学习链。
- 退出登录后进 `#/login`；注册/门/画像链可完整走一遍。
- 演示工具集中在 `#/lab`（入口：我的 → 账号与系统 → 演示工具）。正常学习界面**没有**直接完成、切身份、故障开关。

## 2. 本机持久化（localStorage）

- 键 `yxx-demo-v3`：用户/门/目标/时长/计划/错题/今日/连胜/阅读位置（pos）/当前书章节（cur/ch）/收藏/定级作答/练习进度/复习会话/设置/主题/字号/动效/工单/订单/世界进度/消息已读。
- 会话级开关不存：lab 故障注入（失败/未知/断网）、定级/练习提交中计时器、3D 状态。
- 版本号 `v:3`，对不上则丢弃用内置种子。重置：`#/lab` → 重置全部演示数据（清键并重载）。

## 4. 今日场景切换（`#/lab` → 今日场景）

- 有任务 / 全完成 / 无内容 / 未建计划；未建计划时今日只显示引导，不显示任务统计。
  无内容＝今日任务＋到期复习同时清空；全完成＝两者同时置完成；有任务＝两者同时恢复种子（含复习 4 词）。
  场景开关会改复习队列，属演示用途，正式数据以重置为准。

## 5. 故障注入（`#/lab`，下一次提交有效，单次消耗）

| 开关 | 影响面 | 用户所见 |
|---|---|---|
| 提交失败 | 定级/练习/计划生成/支付 | 失败条＋原位重试，选择/进度不丢 |
| 结果未知 | 定级/练习 | 未知条＋查询结果（幂等，不重复计分） |
| 断网模式 | 定级/练习/计划生成 | 离线条，选择保留为草稿，联网后提交 |

## 6. 前端原型规则（不是后端参数）

- **复习**：本批≤4；“忘了/还要想想”本轮稍后再看一次，同一词一轮最多出现两次；“想起来了/很熟悉”即完成；快照撤销；本轮有明确结束总结。
- **计划生成**：成功只建一份（重复点生成不重复建）；失败可重试。
- **完成与验证分开**：任务完成记录当轮结果；自评认识仍待验证，匹配变式答对记本次修复，次日/七日到期分别再验证，通过后记“已验证”。这些日期与题目是原型固定示例，不是正式 SRS 参数或能力认证。
- **排名/XP/价格**：演示数据，不上榜、不入账、不扣款，屏内均已注明。

## 7. 主题/字号/动效（真实生效）

- 主题：跟随系统/浅色/深色（`settings` 与无障碍屏）；正文、控件、边框、选中态和反馈使用成套语义颜色。深色采用灰黑底、浅色正文和浅紫交互文字。
- 高对比：浅色与深色各有独立变量，增强正文、辅助文字、选中态与卡片描边；深色不能复用浅色的黑色正文。
- 字号：标准/大/特大 → 内容区 `#view` 的 `zoom` 1/1.12/1.25；整机与底栏保持视口高度。
- 本批 UI 修整和局部目检见修订说明 §15；旧矩阵数字只表示对应检查范围，不代表全部页面或业务已验收。读屏/软键盘/真机/TTS 真实语音仍未测。
- 历史阅读边界待办已在六能力改造修正：续读身份不再受只浏览其他目录影响，旧复现材料继续归档。
- 最新间距修复：续读卡片的章节说明与“继续读”按钮之间保留 12px；同类说明后直接跟随的小按钮共用此规则。
- 动效：仅路由切换播放短进场；同页选择、展开、更新不播放整页动画并保留滚动位置；下一题/下一词直接定位新内容顶部。关→全站动画过渡停用，文字反馈保留；首次无保存时尊重系统减少动效偏好。

## 10. 六能力的新玩法（2026-10-01）

1. 首页按状态展示开始、继续或回顾。学习 Tab 内切换今日、课程、词汇、复习；我的只保留档案、记录、计划、显示与帮助。
2. 目标支持基础、大学英语（四/六级）、考研、职场；5/15/30/45 分钟。调整前先预览，已完成保留，进行中可保留或顺延。日历显示两周学习日、休息日和复习日期。
3. 完成题组会新增轮次记录。查看结果不重做；再练创建新轮次。今日回顾与周报下钻到同一份记录；用时为预估，不当作实际学习时长。
4. 错题先按知识点做匹配变式；自评不会直接通过验证。演示工具可推进 +1/+6 天体验到期流程；普通学习页不能提前验证。工具推进产生的历史是演示日期场景。
5. 复习到期词每批最多 4 个，忘记后本轮最多再回忆一次。词数与回忆次数分开，评分可撤销，下次日期可查询。本次记得不记为长期掌握。
6. 阅读完成本节后可进入下一节；浏览别的目录不改续读身份。查词保留所在段落，收藏与笔记可在列表回到原章。笔记输入自动保存。
7. 写作是一道原创邀请信题。草稿、字数与自评保存到本机；确认提交后检查字数、信件格式、活动与时间词。参考文本固定，不调用 AI，不给完整语法或能力评分。修改后再提交新增历史；失败或未知保留原文。
8. 课程按目标/水平/在学/收藏/完成/暂无内容筛选；词汇支持搜索、详情和已加复习筛选。听力保存材料理解结果，口语保存明确的自练记录；音频仍依赖系统语音。

存储键继续使用 `yxx-demo-v3`，对象版本升级至 4，新增 `learning` 数据。兼容旧版偏好、任务、书章、位置和记录；旧总分缺少作答明细时显示“旧版汇总”，不据此补造答案或 XP。
