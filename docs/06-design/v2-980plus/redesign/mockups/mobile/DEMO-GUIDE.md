## 1. 演示身份与入口

- 默认已登录演示账号（`S.user=演示账号`，成人门 PASS），开箱即玩学习链。
- 退出登录后进 `#/login`；注册/门/画像链可完整走一遍。
- 演示工具集中在 `#/lab`（入口：我的 → 设置与帮助 → 原型演示工具）。正常学习界面**没有**直接完成、切身份、故障开关。

## 2. 本机持久化（localStorage）

- 键仍为 `yxx-demo-v3`，保存对象版本为 `v:4`。除用户、目标、今日、错题、主题等原有字段外，`learning` 保存计划、独立学习轮次、顺延任务、章节进度/笔记、查词上下文、课程收藏与写作草稿/提交；刷词进度也保存。
- 会话级故障开关不存：lab 失败/未知/断网。提交计时器和 3D 状态不存；演示日期偏移与写作空态开关属于 `learning` 数据，会保留到刷新后。
- 加载兼容对象 `v:3` 与 `v:4`，旧任务和结果先保留再归一化；缺作答明细的旧结果标为“旧版汇总”。不支持的版本或无法读取的数据回退内置种子。重置：`#/lab` → 重置全部演示数据（清键并重载，同时清除本机草稿、笔记和历史）。

## 3. 统一演示数据（稳定标识）

| 域 | 内容 |
|---|---|
| 用户 | 演示账号；目标/每日预算来自保存的计划，参考水平来自样例测评或目标起步参考 |
| 定级 | BANK 5 题（词汇1/语法2/阅读1/听力1），每题带 `why` 讲评 |
| 今日 | 5/15/30/45 分钟共用续学、到期验证/词汇复习、匹配补救和目标新学候选。同来源候选只自动安排一项；不同任务 ID 的学习轮次独立保存，日期与本机安排标识明确显示；客观作答与词汇自评分开统计 |
| 错题 | 稳定 `id`、原题/错因/来源、`skill`、`st`、修复/到期日期；状态为 `todo/self/wait1/wait7/verified`。旧 `done` 迁移为待验证 |
| 复习 | SRSQ 4 词起步；刷词/查词可追加（同词归并），章节收藏单独保存 |
| 报告 | 日回顾/历史/周报从同一本机记录读取；自己的 XP 与记录一致，联赛其他成员及成就仍为标注的固定样例 |

## 4. 今日场景切换（`#/lab` → 今日场景）

- 有任务：按当前目标、预算和学习日重建今日安排，同时恢复 4 个到期样例词；不固定为两项任务。
- 全完成：今日模板任务标完成，并保存为不计答题/XP 的样例汇总；4 个复习样例词仍到期，复习状态与今日任务完成状态分开。
- 无内容：当天保持今日空态，现有词汇复习日期移到次日；词汇保留在安排列表。已有错题的验证日期不由此清除；再次选择“有任务”或推进演示日期后恢复自动安排。
- 未建计划：今日只显示目标引导。场景切换不清除学习历史、草稿和笔记；需要干净种子时使用全部重置。
- 日期 +1/+6 天用于体验到期验证；“恢复真实日期”只撤销日期偏移，保留已生成的演示历史。它不证明实际经过了七天。

## 5. 故障注入（`#/lab`，失败/未知单次消耗，断网持续至关闭）

| 开关 | 影响面 | 用户所见 |
|---|---|---|
| 提交失败 | 定级/练习/计划生成/写作/支付 | 失败条＋原位重试，选择/进度/写作原文不丢 |
| 结果未知 | 定级/练习/写作 | 未知条＋查询结果（幂等，不重复保存同次提交） |
| 断网模式 | 定级/练习/计划生成/写作 | 离线条，选择或写作原文保留，关闭断网开关后再提交 |

## 6. 前端原型规则（不是后端参数）

- **复习**：本批≤4；“忘了/还要想想”本轮稍后再看一次，同一词一轮最多出现两次；“想起来了/很熟悉”即完成；快照撤销；本轮有明确结束总结。
- **计划生成**：成功只建一份（重复点生成不重复建）；失败可重试。
- **四档共同候选**：所有预算先保留已完成记录与选择保留的进行中任务，再安排已有续学、已到期的延迟验证和词汇复习，随后安排有匹配变式的补救及目标新学。词汇复习每批最多 4 词，样例预计 5 分钟；单项验证/补救样例预计 2 分钟；这些数值不复制或替代正式编排 policy。
- **预算与顺延**：未开始的新任务按整项进入剩余预算；装不下、休息日或缺匹配变式时列出原因，保留来源和原到期日期，不补造完成记录或 XP。已完成/选择保留的进行中任务超过新预算时保留并明确说明，停止自动新增；确认“顺延进行中”会保存当前演示学习日的选择，同内容的其他旧轮次也不会在当天刷新时自动接回。次日重新纳入候选；当天可手动“继续此轮”接回指定轮次，可能增加今日用时。
- **旧日与独立轮次**：顺延保存按任务 ID 更新最新进度，同标题、不同任务 ID 不合并草稿或作答。同内容旧轮次收在“其他学习轮次”，可按原安排日期与本机安排标识选择（标识不代表累计练习次数）；题组、刷词与写作从所选任务 ID 的进度继续，同一 ID 只保留一份顺延引用。手动接回仅撤销所选轮次的当天顺延状态。
- **来源与预览**：复习批次引用原词及到期日期，验证引用同一错题/阶段/修订，重复查看或确认不创建重复任务。不同目的的词汇复习和延迟验证不凭知识点相同就假合并；完成验证沿原错题结果写入。预览只展示派生候选，取消不改当前安排、进度或复习日期；确认后才保存。
- **完成与验证分开**：任务完成记录当轮结果；自评认识仍待验证，匹配变式答对记本次修复，次日/七日到期分别再验证，通过后记“已验证”。这些日期与题目是原型固定示例，不是正式 SRS 参数或能力认证。
- **排名/XP/价格**：演示数据，不上榜、不入账、不扣款，屏内均已注明。

## 7. 主题/字号/动效（真实生效）

- 主题：跟随系统/浅色/深色（`settings` 与无障碍屏）；正文、控件、边框、选中态和反馈使用成套语义颜色。深色采用灰黑底、浅色正文和浅紫交互文字。
- 高对比：浅色与深色各有独立变量，增强正文、辅助文字、选中态与卡片描边；深色不能复用浅色的黑色正文。
- 字号：标准/大/特大 → 内容区 `#view` 的 `zoom` 1/1.12/1.25；整机与底栏保持视口高度。
- 最新 UI 修整和目检见修订说明 §16；§15 与旧矩阵保留对应批次范围，不代表当前全部页面或业务已验收。读屏/软键盘/真机/TTS 真实语音仍未测。
- 历史阅读边界待办已在六能力改造修正：续读身份不再受只浏览其他目录影响，旧复现材料继续归档。
- 当前卡片标题、说明与操作分层；动作行与正文间隔 16px，动作间隔通常 12px，320px 窄屏为 10px；此前直接跟随说明的小按钮间距规则保留在历史 §15。
- 动效：仅路由切换播放短进场；同页选择、展开、更新不播放整页动画并保留滚动位置；下一题/下一词直接定位新内容顶部。关→全站动画过渡停用，文字反馈保留；首次无保存时尊重系统减少动效偏好。

## 10. 六能力的新玩法（2026-10-01）

1. 首页按状态展示开始、继续或回顾。学习 Tab 内切换今日、课程、词汇、复习；我的只保留档案、记录、计划、显示与帮助。
2. 目标支持基础、大学英语（四/六级）、考研、职场；5/15/30/45 分钟共用候选，续学/到期项优先于新学。调整前预览保留项、预算内安排及逐项顺延原因，已完成保留，进行中可保留或顺延。日历显示两周学习日、休息日和复习日期。
3. 完成题组会新增轮次记录。查看结果不重做；再练创建新轮次。今日回顾与周报下钻到同一份记录；用时为预估，不当作实际学习时长。
4. 错题先按知识点做匹配变式；自评不会直接通过验证。演示工具可推进 +1/+6 天体验到期流程；普通学习页不能提前验证。工具推进产生的历史是演示日期场景。
5. 复习到期词每批最多 4 个，忘记后本轮最多再回忆一次。词数与回忆次数分开，评分可撤销，下次日期可查询。本次记得不记为长期掌握。
6. 阅读完成本节后可进入下一节；浏览别的目录不改续读身份。查词保留所在段落，收藏与笔记可在列表回到原章。笔记输入自动保存。
7. 写作是一道原创邀请信题。草稿、字数与自评保存到本机；确认提交后检查字数、信件格式、活动与时间词。参考文本固定，不调用 AI，不给完整语法或能力评分。修改后再提交新增历史；失败或未知保留原文。
8. 课程按目标/水平/在学/收藏/完成/暂无内容筛选；词汇支持搜索、详情和已加复习筛选。听力保存材料理解结果，口语保存明确的自练记录；音频仍依赖系统语音。

存储键继续使用 `yxx-demo-v3`，对象版本升级至 4，新增 `learning` 数据。兼容旧版偏好、任务、书章、位置和记录；旧总分缺少作答明细时显示“旧版汇总”，不据此补造答案或 XP。
