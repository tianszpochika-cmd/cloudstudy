# 六能力改造证据（2026-09-30～2026-10-01）

对应[改造说明](../../../../mobile-learning-upgrade-20260930.md)。仅静态移动原型，不是正式应用/服务验收。

## 证据口径

- [checks.json](checks.json)：通过界面真实点击、输入、选择、刷新获取的 30 项通过断言；操作记录覆盖六类能力。断言数不当作旅程数。
- 同文件含 100 次路由布局采样：25 页×390 标准浅/深及320特大浅/深。高对比特大另抽查6页×2主题，12次。采样为真实渲染、只读 DOM 测量，没有向业务状态注入值；直接访问路由只证明渲染，操作可达性由点击路径另证。
- 纯数据规则检查用 `node scripts/verify-mobile-learning-model.cjs`，28 项通过；保存输出见 [model-checks.txt](model-checks.txt)。与浏览器断言分开。
- 下列 15 张截图逐张实际打开目检。布局截图关闭动效以捕获稳定画面，等待临时提示消失后保存；正常动效下同页选择没有进场动画，另列操作断言。目检发现的学习日换行已改三列，320px 浅/深计划页另定向复测。
- D+1/D+7 验证使用 lab 推进演示日期，不是实际等待七天。日期工具产生的未来历史属于演示场景。
