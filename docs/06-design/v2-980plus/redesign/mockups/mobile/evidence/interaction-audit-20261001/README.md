# 静态移动端交互与业务链审计（2026-10-01）

## 范围与结论

按用户要求先审计现有前端，发现问题即修复，再考虑反推业务和交互文档。本轮处理 `dev-redesign` 上 `mockups/mobile/app.js`、`learning.js` 及回归脚本。起始版本 `94b03e06`，本轮修改为本地工作区成果，尚未提交或推送。

首先修复任务切换丢作答进度和复习撤销回滚其他学习成果，随后检查学习、恢复、计划、辅助功能和本机演示订单。下表记录本轮确认并关闭的问题；“模型”指在隔离状态运行实际源文件，“浏览器”指通过页面控件操作。路由渲染和模型通过不等于整条业务链通过。

已测试的静态链路未发现剩余阻断。测试范围和未测边界列在后文，不以“完美”替代验收证据。本轮没有反推业务规格、交互规格或开发计划，也没有修改正式应用、后端、冻结业务链和 canonical 验收台账。

## 真实浏览器操作

使用已有 18283 静态服务，保留用户 `127.0.0.1` 的原始存储。操作在同一服务的 `localhost` 独立存储中完成，测试档案与日期偏移只用于演示。未通过脚本注入页面业务状态，故障和日期场景使用原型自己的工具控件。

重点结果：

- [撤销后阅读仍保留](undo-preserves-reading.jpg)：阅读完成记录 2/2、14 XP，SRS 撤销不删除它。
- [两批复习累计结果](review-across-two-batches.jpg)：4 个目标词、2 个真实来源批次；[撤销后的任务状态](review-undo-task-state.txt)显示新任务重开，其他成果保留。
- [实际词汇测验答案](vocabulary-actual-answers.jpg)：错误答案仍显示原选项，测验 2/3。
- [未知写作查询后结果](writing-unknown-resolved.jpg)、[第二天草稿恢复](writing-day-two-restored.jpg)：独立轮次和草稿。
- [限时暂停刷新](timed-drill-paused.jpg)、[刷新前后文本](timed-drill-refresh.txt)：剩余 51 秒不变。
- [订单、续订和两类请求](sandbox-order-and-receipts.jpg)：明确本机演示，无真实扣款或开票。
- [角色关闭动效试穿](avatar-motion-disabled.jpg)：服装和背景实际变化，挥手禁用。

`route-layout-scan.json` 保存 91 个路由在 320px 深色/高对比/特大字号、390px 浅色/标准字号下的 182 次检查，以及显式开启管理预览后的 12 次检查。前两矩阵各有 13 次预期守卫跳转（未完成测评报告和 12 个管理入口）。这 194 次检查无空白页或水平溢出，不能把跳转计作目标页验收。测评报告和最终修改页补充记录另存，控制台记录见同目录。

## 自动化回归与独立审查

回归脚本从仓库根执行，各脚本直接输出 PASS/FAIL，以当次输出为准：

```text
node --check docs/06-design/v2-980plus/redesign/mockups/mobile/app.js
node --check docs/06-design/v2-980plus/redesign/mockups/mobile/learning.js
node scripts/check-mobile-mockups.mjs
node scripts/verify-mobile-learning-model.cjs
node scripts/verify-mobile-audit-model.cjs
node scripts/verify-mobile-shell-audit.cjs
node scripts/verify-mobile-aux-audit.cjs
node scripts/verify-mobile-review-reconcile.cjs
git diff --check
```

模型覆盖身份/日期/任务切换、提交失败和未知、撤销、重复提交、保存恢复、模式转换和旧回调；其中累计复习脚本由独立审查 Agent 编写。开发与只读整合审查分开进行。断言组数不代表产品完成百分比或完整浏览器旅程数。

## 本轮未测边界

- 原生 iOS/Android、实际系统切后台、软键盘、读屏、所有横屏和所有按住态。
- TTS 真实出声与设备音色；本轮验证了界面状态和旧回调隔离。
