# 管理端演示入口

本目录已重做为独立桌面运营工作台。完整页面清单、六态、数据与主流程见 [README](README.md)。

登录请选择演示身份，使用任意至少 8 位演示密码。不要输入真实密码。全部动作仅保存本机合成数据，不调用正式后端。

内容链：林知夏编辑 → 王芳初审 → 赵磊终审 → 江蔚发布。
客服链：陈晨接单/指定升级 → 吴晴接收 → 明确解决后关闭。
退款链：陈晨申请 → 张三审批 → 刘敏审批 → 模拟渠道回执。

主题、切换身份、撤销、重置与存储失败演示在「身份与设置」。所有页面顶部可选择加载/空/正常/满数据/错误/无权限状态。

验证脚本 `node self-check.cjs` 只证明 VM 模板与状态机范围；浏览器终验记录见 README，不把静态演示等同正式产品验收。
