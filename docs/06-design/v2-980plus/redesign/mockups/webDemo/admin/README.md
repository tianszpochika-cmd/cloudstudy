# 语学星管理端 · 第二版静态 Demo UI/UX 重做

独立桌面运营工作台。顶部始终标注 **静态演示 · 拟真数据**，不发起真实 API、认证、支付、退款或消息请求，不改正式前后端。

## 信息架构与设计

固定侧栏按「工作空间 / 内容 / 学员与服务 / 商业与治理 / 平台」分组；顶栏保留当前位置、主题与职责。列表采用搜索、状态筛选、分页和表格；详情采用业务事实 + 时间线双栏；编辑、审核与处理采用独立表单，不用手机纵向页拉宽。

保留双审、版本快照与工作草稿分离、权限边界、客服交接、退款双审批与审计链。重做导航、页面层级、表格、详情、表单、状态反馈与数据。共同消费 `../shared/tokens.css`、`components.css`；管理端把共享 tokens 映射到布局变量，不新增另一套品牌色。浅深主题、键盘焦点、跳到工作区、原生 dialog、表单标签、错误区、Toast 已实现。

## 每页六态与表单

各页右上角可切加载/空/正常/满数据/错误/无权限。加载显示骨架与完成按钮；空态不删除原记录，可载入样例；失败显示重试；无权限解释授权身份，实际角色拒绝同时检查直接路由和动作。满数据列表每页 20 条，正常每页 6 条。正常详情/表单独立呈现具体业务。

表单采用 required 与业务错误区：标题至少 4 字、正文 20 字、处理回复 6 字；需理由的动作不可空提交。未保存表单切页确认；主题/状态重渲染保留输入；跨窗口更新不覆盖正在输入的表单，旧修订保存被拒绝。

## 数据与可靠性

- `data.js` 集中管理：20 内容、24 学员、12 工单、15 订单、7 退款、12 风险、12 举报、8 隐私、12 媒体与审计。
- 存储键 `yx.demo.admin.product.v3`。合成业务状态与主题保存；演示登录密码、本地媒体字节不保存。
- 保存前比较修订并保留快照，失败回滚业务、保留输入并提示未保存，不发成功 Toast。设置可以模拟保存失败，关闭后手动重试。
- 撤销恢复前一业务状态并保留审计，限同一会话且无后续修订；重置只影响管理端演示键。
- 下载仅为本机生成 JSON；资金/权益/消息/账号删除不会触及正式记录。

## 主流程体验路线

1. 内容：林知夏 → 新建内容 → 版权媒体核验 → 保存 → 详情送审 → 切王芳 L1 批准 → 赵磊 L2 批准 → 江蔚独立发布 → 下架/强停原因 → 合格旧快照回滚 → 审计。退回生成新草稿，不继承签核。强停版本不可恢复。
2. 客服：陈晨 → 接单 → 回复/补充，或指定吴晴与升级原因 → 待接收 → 吴晴确认 → 安全正文回复并解决 → 关闭 → 可重开。hash-only 单不允许虚构回复/关闭。
3. 商业：陈晨发起退款 → 张三批准 → 刘敏批准 → 待渠道 → 模拟提交 → 处理中 → 合成成功回执 → 订单权益读回 → 凭证 → 审计。申请人/重复审批者不能批准。
4. 平台：风险建档分诊 → 理由责任人 → 举报关联 → 观测积压 → owner 恢复任务 → 审计。隐私导出按核验/准备/领取流转；删除不可跳过 168 小时冷静期。
