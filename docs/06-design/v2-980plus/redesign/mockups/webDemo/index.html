怎样试用这份演示

学员端右下角「演示控制」可切换新用户、学习中、错题较多和已撤回同意的独立档案，也可检查六种页面状态。管理端顶栏可切换合成职责与状态。

  1. 选一个学员档案先看今日计划，或新建演示账号体验完整注册。
  2. 亲手完成一次练习错答会进入错题本，补救和报告使用实际本机记录。
  3. 试试失败与恢复数据状态可以手动切换；一键重置只清除本端拟真记录。

这是产品设计与交互蓝本。没有真实认证、收费、模型调用或后台写入。请使用合成账号与资料。
