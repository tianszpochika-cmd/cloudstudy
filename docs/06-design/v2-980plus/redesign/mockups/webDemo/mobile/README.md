# 随身学习静态原型

这是移动端业务与交互原型。页面顶部持续标注「静态演示 · 拟真数据」，仅使用浏览器中的合成档案，不连接正式 IAM、学习服务或支付系统。

## 打开与组成

- 预览地址：`http://127.0.0.1:18283/webDemo/mobile/`；需要从仓库的静态预览服务打开。
- `index.html` 提供顶栏、四项底部导航和脚本装配；`styles.css` 提供手机布局与主题适配。
- `mobile-ui.js` 提供独立移动首页：今日任务、实际记录数、到期复习、知识点与周节奏。
- `app.js` / `learning.js` 提供学习业务原型，数据来自 `../shared/data.js`。产品边界、扩展预览、目录接线和演示控制分别由共享脚本补齐。
- 「演示控制」可选择完整页面目录、六种呈现状态、合成画像和主题。目录不绕过成人及同意门槛。
- 演示档案按端、画像与账号隔离；重置用于清理当前演示画像。密码输入仅用于模拟校验，不能视为真实认证。

## 页面与主要操作

| 页面族 | 作用与实际操作 |
| --- | --- |
| 注册、登录、成人门、同意、目标 | 校验密码、确认出生年份、主动签署同意、保存目标；未满足资格时限制学习 |
| 首学、定级、定级报告、今日计划 | 提交五题测评、查看结果、生成任务与继续学习 |
| 练习、结果、详情、错题、补救、间隔复习 | 逐题提交、保存本轮事实、登记错题、匹配变式、延期验证与回顾 |
| 词汇、搜索、词卡、语法、阅读、写作、听力 | 查词、词义选择、加入复习、规则练习、草稿检查、材料理解与保存记录 |
| 书架、图书、章节 | 打开课程、目录选节、正文查词、保存笔记、完成章节 |
| 日报、周报、历史 | 读取当前档案中的学习结果，展示数量、答对率与经验 |
| 世界、小组、游戏 | 加入或退出合成小组、答题与结算；扩展能力明确为阶段预览 |
| 我的、设置、设备、隐私、客服 | 主题切换、撤销设备、撤回同意、提交本人合成工单、退出与重新登录 |

完整路由以运行时目录为准。页面可达、六态呈现与业务操作验收是不同证据，不把完整目录数量作为所有功能已通过的依据。

## 实际移动主链验证

`qa-flow.cjs` 使用 Chromium 的 390×844 触摸视口，浅色、深色各运行同一条真实点击流程。页面切换通过可见演示控制，业务事实通过实际按钮、输入与确认产生；脚本只读取业务状态作断言。

已纳入的 17 段：

1. 注册短密码拒绝，合法输入创建受限合成身份。
2. 成人状态确认，三项同意初始未勾选，逐项主动签署。
3. 学习目标预览与保存。
4. 五题定级逐题提交与最终报告。
5. 生成今日五项任务。
6. 语法三题，首题错答、其余答对，独立结果为 2/3。
7. 匹配错题变式，补救记录与延期验证，提前验证入口禁用。
8. 日报及周报读回实际学习事实。
9. 书架、图书、章节；笔记刷新保留、完成事实及记录。
10. 查词、词义答题、加入复习、完成三词任务。
11. 短写作反馈、返回修改、55 词合格稿保存。
12. 听力播放操作、字幕切换、两题理解与结果保存。
13. 撤销手机设备、刷新后保留撤销状态与当前身份。
14. 加入及退出小组，五题小游戏结算。
15. 切换主题，撤回学习同意，访问学习页面回到资格门。
16. 撤回后仍可提交本人客服工单，清空已提交草稿。
17. 退出并重新登录，撤回事实、七条学习记录及一条工单保留。

每段记录真实状态、页面横向尺寸及截图；全轮收集浏览器异常和非本机请求。来源文件记录 SHA-256，实际加载脚本另行记录，测试期间任何来源变化均标 `PARTIAL_SOURCE_DRIFT`。
