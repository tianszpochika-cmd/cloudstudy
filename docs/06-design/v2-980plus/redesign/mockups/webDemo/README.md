# 语学星 · 第二版静态 Demo UI/UX 重做

三端与演示枢纽的静态产品蓝本，目标地址：**https://learn.clyune.com/webDemo/**。全部业务操作为原创合成数据，仅保存在浏览器，不连接真实认证、学习、支付、AI 或未成年人服务。正式应用与后端不属于本次改动。

## 页面全集与信息架构

功能唯一设计源是上一级 `mobile/app.js`、`mobile/learning.js` 及 `mobile/index.html`。实际登记 **91 个唯一页面路由**，不是按“约 90 页”删减；其中包含 13 个内嵌管理预览、8 个未来阶段合成预览以及演示实验台。移动端与学员网页端保留全部 91 路由；独立管理端展开为 33 个实际工作页面，不把同一详情的多条记录算作新页面。

移动端：`首页 → 今日安排/练习 → 课程与阅读/词汇/复习 → 世界与成长 → 我的/设置/隐私/客服`。任务优先，纵向卡片与四项底部导航，390 px 可操作。

学员桌面端：`常驻侧栏 → 顶栏与 Ctrl K 搜索 → 主工作区 + 阅读目录/证据侧栏 → 报告表格与图表`。课程三栏、阅读三栏、历史筛选分页，1280/1440 px 独立桌面布局。

管理端：`工作台 → 内容资产/双人审核/发布/版本 → 学员与工单 → 订单退款/治理隐私 → 审计/观测恢复`。职责切换、列表表格、详情时间线、独立表单。完整清单与业务主链见 [管理端 README](admin/README.md)。

### 结构取舍

保留完整功能、学习规则、任务与结果身份、错题来源、章节进度与同意门槛。重做手机装饰、信息密度、标题层级、按钮层级、状态反馈、颜色与主题。桌面两端都采用独立信息架构，不把手机壳拉宽。未来阶段以显式开启的隔离合成流程演示，不接入模型、RTC 或真实未成年人信息。

## 统一设计系统与状态

[tokens 与组件规范](shared/README.md) 定义浅深语义色、字号、间距、圆角、阴影、动效、键盘焦点与减少动效。可直接操作 [组件样例](shared/index.html)：按钮、校验、表格分页、卡片、标签、dialog、抽屉、Toast、空态和骨架。

学员两端的「演示控制」支持加载、空、正常、满数据、错误、无权限六态，以及四个独立学员画像。满数据实际扩充课程、历史、错题与工单；空态清空本页适用集合并保留创建/筛选；两种场景使用隔离存储，不覆盖正常档案。管理与未来预览另有各类 30 条密集实体。切回正常恢复原事实，错误提供同页恢复，权限出口指向对应准入。

## 拟真数据与本机事实

- `shared/data.js`：原创题库、词表、课程、章节、消息、商品订单、多个成人档案，以及空/密集样例。
- `shared/product-overrides.js`：每账号隔离、受限注册、成年与同意、设备、隐私、离线与成长交互。密码从不保存。
- `shared/preview-data.js`：内嵌管理、AI/语音/K12及奖励拼读的统一原创样例、职责和空/满数据生成。
- `shared/preview-workflows.js`：消费独立数据，负责状态机、幂等动作、原因、编辑缓冲与存储回滚。
- `shared/catalog-bridge.js`：内嵌管理发布的历史快照进入两端课程；新草稿不改变旧在架正文；下架/强停使旧入口不可继续读取，个人记录保留。
- `admin/data.js`：独立运营工作台的内容、学员、工单、订单、退款、审计等合成实体。各端互相独立的一键重置。
- 存储按端/画像/账号隔离；学习撤回即刻限制学习，设置和本人客服仍可用。保存失败会恢复事实并提示未保存，不把未提交操作称为成功。写作、笔记与管理/AI输入的失败导航或重绘保留编辑器。编辑正文只渲染安全文本格式，不执行HTML或加载远程图片。
