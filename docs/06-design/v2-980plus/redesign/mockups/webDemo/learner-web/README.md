# 学员网页端 · 第二版静态演示

## 定位与信息架构

面向成人与大学生的独立桌面学习工作台。共享学习状态和拟真数据，重新组织桌面视觉与导航，不使用手机壳或纵向页拉宽。

- 左侧常驻导航：学习工作区 / 进度与成长 / 账号与服务。
- 顶栏：当前位置、消息、学员档案；顶部永久显示「静态演示 · 拟真数据」。
- 今日总览：学习目标主区 + 任务表 + 阅读/学习日历侧区。
- 内容发现：筛选工具条 + 三栏课程列表。
- 阅读：章节目录 + 正文/完成操作 + 查词/笔记三栏。
- 答题：独立答题主区 + 操作提示侧区；选择、提交、反馈保留原业务状态。
- 记录：可搜索、筛选、分页的数据表；周报按本机事实绘图，不编造成绩。
- 账号：注册/登录左右分区，设置按学习/显示/安全分组。
- Ctrl K（Mac 为 Cmd K）打开全部页面搜索，方向键移动、Enter 打开、Esc 关闭。

## 文件与边界

index.html → shared/data.js → mobile/app.js → mobile/learning.js → shared/product-overrides.js → desktop.js → shared/demo-ui.js。领域行为在两学员端一致，桌面 renderer 只负责信息架构与视图。桌面本机记录与移动端隔离；清理任一端不删除另一端记录。原桌面独立旧 app.js/styles.css 已移除，避免两份题库与状态逻辑漂移。

浅/深主题使用 shared/tokens.css，组件使用 shared/components.css；mobile/legacy.css 仅补足题卡/音标/装扮等领域控件选择器，desktop.css 显式覆盖桌面布局。
