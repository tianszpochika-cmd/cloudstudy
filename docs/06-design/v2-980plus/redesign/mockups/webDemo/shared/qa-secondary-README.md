# 学习端次要功能独立浏览器检查

## 运行

静态服务器已在 `http://127.0.0.1:18283` 提供 `webDemo/` 时，在仓库根目录执行：

```powershell
node docs/06-design/v2-980plus/redesign/mockups/webDemo/shared/qa-secondary.cjs
```

需要本机 `playwright` 与 Chromium。脚本不启停服务器，不访问真实 API，不修改业务源码，只在独立浏览器上下文里操作拟真档案。也可通过 `DEMO_QA_ORIGIN` 指定同等静态服务器源。报告与截图写入 `.git/codex-local-backups/secondary-qa-<timestamp>/`，不加入正式 Git 文件。

每端 25 个操作用例：移动端 `390×844`，桌面学习端 `1280×900`。业务动作通过真实按钮、输入框与下拉框执行，只有页面导航调用现有 `nav`。断言读取实际页面与拟真领域状态，涉及保存的操作必须刷新读回；出现任一失败或 Console/page error 时退出码为 1。每个用例保存截图，失败后继续检查其余用例。

## 路由与动作范围

| 路由 | 实际操作与断言 |
| --- | --- |
| `phonics` | 六组音标展开、符号按钮点击；不把语音调用当作发音听觉验收 |
| `search` → `vocab` | 实际输入词汇、搜索结果进入对应词；搜索历史刷新读回；无匹配不产生假结果 |
| `wordbook` / `drill` | 回忆揭示与下一词；答错后跨词形模式不改写原答案；四级/六级进度分别保存 |
| `drill` 限时 | 开始、离页停表、刷新暂停恢复、真实答题、完整结算、最佳成绩读回；不虚增学习记录 |
| `srs` | 揭示、评分、撤销恢复完整词表、重新评分与刷新读回 |
| `listening` | 未答完整拒绝保存；语速/字幕持久；换材料清答案；错答结果保存；重复查看不重复计数 |
| `speaking` | 跟读/口头翻译/角色三模式自练；重复查看保持同一结果；刷新记录不重复 |
| `league` | 关闭自己的排名后真实隐藏档案、刷新仍隐藏、重新打开 |
| `world` | 小组贡献来自实际学习记录；没有可手工虚增贡献的旧按钮 |
| `msgs` / `npref` | 无出口消息真实 focus+Enter 标读且刷新保留；有出口消息真实 focus+Enter 标读、进入原目标并刷新保留，已读仍可重进目标；消息分类与全标已读保存；通知开关互不覆盖、时间段刷新读回 |
| `a11y` | 对比/字号/动效/焦点真实开关、刷新恢复与恢复默认 |
| `devices` | 当前设备禁止撤销；取消不改状态；确认撤销与刷新状态、重复撤销禁用 |
| `tdetail` | 已回复筛选、真实工单详情、刷新保留当前详情、返回列表 |
| `placement` | 未保存不能前进；未答提交不记分；合法跳过与刷新读回 |
| `commerce` / `pay` | 分类结果；真实沙盒失败后同订单重试；未知结果不开放权益、刷新保留、查询同单完成 |
| `refund` / `subs` | 取消续订保留当前权益；电子收据与发票独立申请；退款只受理等待审核、重复申请禁用、刷新读回 |

当前没有独立 `grammar/xray/lexicon/digest/team/streak` 路由。语法为 `practice` 题组，词汇为 `vocab`，阅读为 `book/chapter`，小组贡献与连续学习为 `world/weekly` 的事实视图；不能用不存在的页面名冒充路由覆盖。主学习链、24 个阶段预览/后台样例路由、所有页面六态与布局矩阵由其他检查覆盖，本脚本不重复计入。
