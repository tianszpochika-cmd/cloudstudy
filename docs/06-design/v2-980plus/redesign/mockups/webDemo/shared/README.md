# 静态 Demo 共用设计系统

仅供 `webDemo`，不修改正式应用。HTML/JS 无需构建，所有业务事实为合成数据。

## Design tokens

| Token | 浅色 | 深色 | 使用规则 |
|---|---|---|---|
| 背景 `--bg` | `#f5f5fa` | `#15151f` | 主画布 |
| 表面 `--card` | `#ffffff` | `#20202d` | 卡片、弹窗、表单 |
| 次级表面 `--surface` | `#f0f1f7` | `#2b2b3b` | 分区、表头、骨架 |
| 正文 `--ink` | `#222337` | `#f1eff9` | 主要内容 |
| 次级正文 `--mut` | `#606277` | `#bab8cf` | 提示和元信息；仍需可读 |
| 品牌 `--brand` | `#5935b8` | `#bcabff` | 主操作、焦点、链接 |
| 成功 `--ok` | `#19714d` | `#87d6af` | 必须同时有文字/图标 |
| 错误 `--bad` | `#ac303d` | `#ffadb8` | 必须有原因与恢复动作 |
| 警告 `--warn` | `#80520c` | `#f4cc7c` | 待处理、权限或阶段提示 |

- 字体：系统中文字体；字号阶梯 12 / 14 / 16 / 20 / 28 / 36 px。英文阅读正文使用 Georgia 衬线字体。
- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 px。
- 圆角：8 / 12 / 20 px，状态标签为胶囊。
- 阴影：常规卡片低强度，弹窗提高层级，不使用阴影作为唯一边界。
- 动效：120 / 200 / 320 ms；系统减少动效时归零。
- 主题：`html[data-theme="light|dark"]`，跟随系统由演示档案设置驱动。

## 组件规范

| 组件 | 规则 |
|---|---|
| 按钮 | 主次动作分开；可操作高度至少 44 px；禁用有文字原因；危险操作先确认 |
| 表单 | 每项可见 label；错误与输入通过 `aria-describedby` 关联；密码不保存 |
| 表格 | 真实表头；筛选、分页及空结果有出口；窄宽容器内滚动 |
| 卡片 | 标题、说明、信息与动作分层；避免把按钮挤进正文 |
| 标签 | 状态同时使用文字，不能只靠颜色 |
| 弹窗 | 原生 dialog 的键盘焦点约束；Escape 关闭，关闭后回到触发控件 |
| 抽屉 | 独立详情上下文；不改变列表过滤条件；提供关闭按钮 |
| Toast | `role="status"`，说明真实已完成的操作；保存失败不能显示成功 |
| 空态 | 说明不存在何种数据，提供创建/载入样例或返回出口 |
| 骨架 | `aria-busy` 与可读加载提示，测试场景可手动完成加载 |

## 数据和状态

`data.js` 集中定义原创题库、词表、课程正文、商城订单、消息及四个合成学员画像。两学员端复用行为引擎，各用独立端/画像存储命名空间。`product-overrides.js` 补齐注册校验、同意撤回、隐私申请、设备撤销和离线/成长拟真交互。

`demo-ui.js` 提供全路由目录、加载/空/正常/满数据/错误/无权限场景、主题、独立档案与一键重置。场景检查属于静态产品验证，不代表后端验收。管理端拥有独立的运营状态机与集中合成数据文件。
