## 0. 设计约束与阶段边界

### 0.1 目标闭环

所有能力都必须落在以下闭环中：

~~~text
学习目标
  -> 合法内容与明确练习目标
  -> 听 / 读 / 说 / 音标练习
  -> 规则化反馈或用户自评
  -> 错误、收藏和生词进入统一 LearningItem / SRS
  -> 延迟复习与阶段复盘
~~~

本域的“评测”在 Phase 1 仅指文本、时间、内容标注和用户自评的确定性结果，不代表官方考试认证，也不代表 AI 发音评分。

### 0.2 Phase 1 必须实现

- 听力：毫秒级句子、token 字幕时间轴；波形；单句循环；A/B 复读；0.5x～2.0x 变速；盲听；单词/短句/段落听写；错字高亮和提示；音变雷达；Language Clips 的预制字幕交互。
- 阅读：CEFR A1～C2 分级资料；文章元数据；全英文/双语阅读；即点查词；生词和句子挖掘；段落音频；阅读进度；字号、行距、主题；预制分支故事和理解测试。
- 口语自练：单句录音、双轨波形回放、影子跟读、预编角色扮演、用户自评；录音权限、加密、上传、删除和生命周期审计。
- 音标：产品资产中 48 个图谱条目；示范音频；口型参数；Three.js 侧剖面模型；2D/SVG/帧动画降级；最小对立音辨音和点读自测。
- 数据闭环：练习会话、尝试、阅读进度、录音资产、评测事件和 SRS 事件可追踪、可重放、可去重。

### 0.3 明确不在 Phase 1 的实现

- 不接入云端 ASR、音素级发音评分、流式 AI 反馈、LLM 解释、AI 生成对话或 AI 生成阅读内容。
- 不以录音波形相似度、音量、频谱距离冒充发音正确率。波形只用于用户观察节奏、停顿和时长。
- 不把实时 AI 对话或 Barge-in 写成已存在的业务接口。商业 RTC 仅在 Phase 2 经过 Feature Flag、资质、成本和新增 ADR 后接入。
- 不在小程序强行加载 Three.js、复杂 WASM 或大型 WebGL 运行时。
- 不返回草稿、下架或无版权状态的内容；不把完整商业题库和原始媒体包作为可传播下载物。

### 0.4 术语

| 术语 | 定义 |
|---|---|
| material | 一份可学习的听力或视频内容，包含音频/视频媒体和内容版本 |
| segment | 字幕或阅读中的句子/段落时间片，时间单位统一为毫秒 |
| token | 可高亮、可点击或可判分的词级单元；token 的时间区间采用左闭右开 |
| rule annotation | 由教研标注或确定性规则引擎生成的音变标记，必须带 ruleCode |
| practice session | 一次用户在某内容、模式下的连续学习会话 |
| evaluation event | 可回放的播放、作答、录音、自评、进度和同步事件 |
| raw recording | 用户原始录音；属于个人数据，默认短期保留并支持立即删除 |
| content version | 发布后不可变的内容版本号；客户端提交必须携带版本 |

## 2. 总体架构与跨端实现

### 2.1 模块职责

| 层 | 职责 | 禁止越界 |
|---|---|---|
| 教研内容域 | 创建、校验、审核、发布 material、segment、token、音变规则、音标和口型参数 | 不在学习端临时修改已发布时间轴 |
| Core API | 鉴权、内容版本、练习会话、确定性判分、SRS 事件、媒体签名 URL、离线同步 | 不调用 LLM/ASR 作为 Phase 1 判分器 |
| 客户端 | 波形、字幕、播放器、输入、录音、自评、本地队列和降级 | 不把未经契约生成的 any 传入领域状态 |
| 对象存储/CDN | 音视频、波形 peaks、2D/3D 静态资源 | 不直接暴露私有录音永久 URL |
| Redis / Streams | 会话短缓存、幂等结果、媒体上传状态、离线同步异步任务 | 不作为唯一学习事实源 |
| SRS/学习流域 | 接收听写错误、阅读生词、句子挖掘、口语自评等 LearningItem 信号 | 不依赖某一端的本地状态结算复习日期 |

### 2.2 主链路

~~~mermaid
flowchart LR
  CMS[教研 CMS<br/>草稿/审核/版权] --> PUBLISH[发布校验<br/>版本冻结/时间轴检查]
  PUBLISH --> CONTENT[(MySQL 内容表)]
  PUBLISH --> MEDIA[(S3 + CDN)]
  CONTENT --> API[Core API<br/>鉴权/契约/规则判分]
  MEDIA --> CLIENT[uni-app 客户端<br/>播放器/波形/字幕/录音]
  API --> CLIENT
  CLIENT --> QUEUE[本地事件队列<br/>IndexedDB/SQLite]
  QUEUE --> API
  API --> SRS[SRS/学习流<br/>LearningItem]
  API --> AUDIT[(评测事件与生命周期审计)]
~~~

### 2.3 统一时间轴约定

- 所有持久化时间点使用 UTC DATETIME；界面按用户时区显示。
- 所有媒体时间使用整数毫秒 BIGINT/INT UNSIGNED；禁止在 API 中以浮点秒作为唯一事实。
- segment 和 token 使用 startMs inclusive、endMs exclusive；必须满足 0 ≤ startMs < endMs ≤ media.durationMs。
- token 必须落在所属 segment 内；允许相邻 token 之间存在静音间隙，不允许重叠。
- 客户端播放时以媒体主时钟为准，requestAnimationFrame 只负责渲染；暂停、seeked、ratechange、visibilitychange 都要重新校准。
- 字幕延迟只影响显示时间，不改变 token 的音频时间；显示时间为 max(0, startMs - subtitleDelayMs)。

### 2.4 内容发布前校验

发布流水线必须拒绝以下内容：

1. segment/token 时间越界、负数、重叠或排序错误；
2. 字幕文本与 token 字符区间无法回放；
3. 音变 annotation 引用了非本 material 的 token 或不存在的 rule；
4. 文章没有 CEFR、词数、生词率、版权状态或版本；
5. 音标不是 48 条目集合，或者 symbol、audio、mouthProfile 缺一；
6. 视频、音频没有 sha256、版权来源和下架回滚版本；
7. 分支故事存在环路、悬挂节点或 choice 指向不存在的节点。

## 3. 16 项功能逐项设计

以下每一项均固定包含目标、前置、交互、异常、验收和埋点；事件的通用字段见第 8 节。

### 3.1 FEAT-LST-001｜毫秒级字幕对齐、Wavesurfer 波形与 A/B 精听

**目标**

- 让用户在波形、句子、token 三层定位同一段声音，支持听懂、复听和断点恢复。
- 对 1 句、A/B 区间和全文提供一致的播放控制，不因切换语速或字幕模式改变事实时间轴。

**前置条件**

- material 状态为 PUBLISHED，拥有合法音频、durationMs、waveform peaks、segment 和 token 版本。
- 用户通过年龄与登录边界；内容权限、VIP/试学权益已由 Core API 校验。
- 客户端能力探测完成：AudioContext、Wavesurfer、原生 audio、离线缓存和画质档位。

**交互**

1. 进入页面先返回标题、时长、内容版本和首屏 segment；波形 peaks 懒加载，字幕 token 按可视窗口虚拟化。
2. 使用 Wavesurfer 适配器渲染 overview 波形和可选 zoom 波形；播放游标由媒体主时钟驱动，活动 segment/token 只更新状态类，不重建全文 DOM。
3. 点击句子将播放头定位到 segment.startMs；点击 token 定位到 token.startMs。点击当前句的循环按钮只循环该句，循环结束回到句前或继续下一句由用户设置。
4. A/B：第一次点击设置 A，第二次点击设置 B；B 必须大于 A，最小区间 120ms，默认 A 为当前时间、B 为当前句 endMs；播放到 B 后 seek 到 A，支持次数 1/2/3/∞。
5. 字幕模式为隐藏、英文、双语、延迟英文；英文字幕可逐 token 高亮，双语只允许中文段落跟随 segment，不伪造中文 token 时间。
6. 支持上一句、下一句、重播、拖拽 seek、播放/暂停、当前句加入表达库；恢复时读取 materialVersion、segmentId、mediaPositionMs 和播放模式。

**异常与降级**

- Peaks 失败：显示轻量 CSS 波形或空白轨道，音频播放和字幕仍可用。
- Wavesurfer/Web Audio 不可用：切换原生 audio 控件，关闭精确波形缩放并提示“当前设备使用基础播放器”。
- 时间轴校验失败：隐藏 token 级高亮，保留 segment 字幕并记录 content_timeline_invalid；不得用客户端猜时间。
- seek 超出范围：钳制到 0～durationMs 并记录一次 invalid_seek，不阻塞播放。
- 网络断开：已缓存媒体继续播放；未缓存 segment 显示离线提示，练习事件写入本地队列。
- 浏览器自动播放被拒：在用户点击后再开始播放，并记录 autoplay_blocked。

**验收**

- 在 Web/H5、iOS、Android 的目标设备上，播放、暂停、seek、单句循环和 A/B 均可用。
- 典型 10 分钟、至少 1,000 token 的 material 中，活动 token 与音频主时钟的绝对误差 P95 ≤ 80ms；seek 后 300ms 内恢复正确高亮。
- 变更播放速度、窗口缩放和字幕模式不改变 startMs/endMs；A/B 循环边界误差 ≤ 80ms。
- 关闭 WebGL、关闭动效或切换 Performance 档不影响音频、字幕和练习提交。
- 无障碍：键盘可控制播放，字幕可被读屏读取，正确/错误不只依靠颜色。

**埋点**

- listening.material_viewed
- listening.waveform_ready / listening.waveform_fallback
- listening.play_started / listening.paused / listening.seeked
- listening.segment_selected / listening.token_selected
- listening.loop_started / listening.ab_set / listening.ab_completed
- listening.subtitle_mode_changed / listening.timeline_drift_detected

### 3.2 FEAT-LST-002｜0.5x～2.0x 保持音高变速

**目标**

- 在不改变音高和字幕事实时间的前提下，帮助初学者听清细节、帮助进阶用户适应正常语速。

**前置条件**

- 已加载音频和可用播放器适配器；speed ∈ [0.50, 2.00]。
- 内容和用户设置允许变速；进入离线时有相应音频文件。

**交互**

1. 速度滑杆支持 0.05 步进，快捷档为 0.50、0.75、1.00、1.25、1.50、2.00，默认值来自用户音频设置，首次为 1.00。
2. 播放器使用 AudioWorklet/浏览器 pitch-preserving 能力；优先保证原始媒体不转码，变速只改变播放时长。
3. 播放时 UI 时间显示为内容时间；在 A/B、单句循环和影子跟读中，边界按内容时间计算，不按渲染后的墙钟时间计算。
4. 每次变速写入本地偏好和 practice event；切换 material 后沿用偏好，但超过内容支持范围时钳制。

**异常与降级**

- 设备不支持保持音高：尝试原生 preservesPitch；仍失败时仅提供 0.75/1.00/1.25/1.50，明确提示“该设备可用档位有限”。
- AudioWorklet 初始化超时：回退原生播放器，不伪造无损标记。
- CPU 持续高或出现爆音：AdaptivePerformanceEngine 降至 Performance，关闭自定义处理并保留基础播放。
- 速度值非法：返回 INVALID_ARGUMENT，客户端恢复上一个有效值。

**验收**

- 0.50、1.00、2.00 三个边界档均可播放完整媒体，源媒体 sha256 不变化。
- 同一音节在 0.50/1.00/2.00 下无可感知变调；自动化测试检查基频漂移阈值由音频 QA 维护。
- 变速时字幕高亮不漂移；连续播放 20 分钟不出现累计时间漂移超过 120ms。
- 小程序和 Performance 档不加载自定义音频处理运行时，仍能完成基础听力和听写。

**埋点**

- listening.speed_changed（speed、adapter、fallback）
- listening.pitch_preserve_failed
- listening.playback_quality_downgraded

### 3.3 FEAT-LST-003｜音变雷达：连读、弱读、失爆、同化和重音

**目标**

- 把真实语流中听不见的变化变成可定位、可解释、可复听的教学标记。
- 任何标记都能回答“哪两个 token、使用哪条规则、什么环境、标准形式如何变化”。

**前置条件**

- segment/token 带有词性、词边界、IPA、重音和方言版本；规则集状态为 PUBLISHED。
- 音频 material 的 dialect 与规则 dialect 一致；不一致时只展示教研显式标注。

**确定性规则**

| ruleCode | 现象 | 触发条件 | UI 标记 | 可解释反馈 |
|---|---|---|---|---|
| LINK_C2V | 辅音-元音连读 | token A 末音为辅音、token B 首音为元音，词边界无停顿，且两 token 同一语流 | 两 token 间弧线 | “末辅音连接到下一词首元音，两个词按一条语流听” |
| WEAK_FUNCTION_WORD | 弱读 | token 属于教研白名单功能词，处于非重读位置且有弱式 IPA | token 下方圆点 | “该功能词在非重读位置使用弱式，强式与弱式 IPA 如下” |
| UNRELEASED_STOP | 失爆 | /p/、/t/、/k/ 位于音节尾，后接辅音或停顿，且没有明确爆破释放标注 | token 末尾斜线 | “阻塞已形成但未完全释放，后续辅音/停顿遮蔽了爆破” |
| PLACE_ASSIM_N | /n/ 部位同化 | /n/ 后接双唇音 /p b m/ 或软腭音 /k g/，内容 IPA 允许同化 | 跨 token 波浪线 | “鼻音部位向后一个辅音靠拢：n→m 或 n→ŋ” |
| STRESS_SHIFT | 重音节奏 | token 带主重音/次重音，且相邻功能词弱化 | 重音竖线 | “内容词承载重音，邻近功能词弱化，形成节奏对比” |

规则引擎采用“内容显式标注优先、规则计算其次、未知不猜”的顺序。规则匹配输入为 token IPA、stress、pos、dialect、pauseMs 和相邻 token；输出必须写入 ruleCode、输入 token 范围、输出符号、解释模板和 ruleSetVersion。侵入 /r/、方言差异或无法由内容字段确定的现象默认关闭，不展示推测结论。

**交互**

1. 用户打开“听力雷达”后，句子文字上显示弧线、圆点、斜线、波浪线和重音符；颜色同时有形状和文字标签。
2. 点击标记弹出“原形 → 语流形式 → 触发环境 → 再听此处”，再听时自动将 A/B 区间设为 annotation.startMs～endMs。
3. 可按现象筛选：连读、弱读、失爆、同化、重音、数字/时间/人名地名；筛选不会改变播放时间。
4. “规则说明”展示教研来源和版本，不展示模型置信度，不把规则推断称为语音识别。

**异常与降级**

- 缺少 IPA、词性或方言：隐藏自动推导标记，展示“此处暂无教研标注”。
- 规则版本与客户端缓存不一致：使用服务端返回的 annotation 快照，禁止本地重算覆盖。
- annotation 引用失效 token：该条不渲染，记录内容质量事件并允许后台下线 material。
- 同一区间规则冲突：按显式标注 > 规则优先级 > 规则代码字典序选一条主标记，其余放入 explanation.relatedRules。

**验收**

- 相同输入 token、IPA、环境和规则版本在服务端与客户端得到相同 annotation；无随机性。
- 点击每条标记都能定位并复听对应区间，标记与字幕时间差不超过 80ms。
- 无标记时不出现空的“AI 诊断”文案；用户可以查看缺失原因。

### 3.4 FEAT-LST-004｜单词、短句、段落听写

**目标**

- 让用户从辨音到拼写建立可量化的输入训练，结果进入错题和 SRS，而不是只显示一次分数。

**前置条件**

- material 有可判分的 transcript、token、答案版本和 dictation mode 配置。
- 当前用户有练习权限；离线模式已下载加密练习包。

**交互**

1. 三种模式：单词听写、短句听写、段落听写。默认短句模式从当前 segment 开始，用户可切换范围。
2. 每条题目先播放一次；用户可按内容策略重播，输入完成后点击提交或达到段落末尾自动提交。
3. 提交请求携带 sessionId、materialVersion、segmentIds、rawAnswer、mode、attemptNo、hintCount、clientEventId。
4. 服务端采用固定 normalization 和 token diff 判分，返回 score、完全匹配/大小写差异/标点差异/单词增删改，以及关联错题和 SRS 事件。
5. 用户可在结果页重听错误 token、查看正确拼写、加入生词本或表达库；下一次复习不直接复用原题时，必须来自同知识点的已发布变式题。

**确定性判分**

~~~text
normalize(text):
  Unicode NFKC
  英文大小写折叠
  统一弯引号、连字符和撇号
  合并连续空白
  忽略规则允许的标点集合

tokenError = substitution + insertion + deletion
tokenAccuracy = max(0, 1 - tokenError / max(1, standardTokenCount))
charAccuracy = 匹配 token 内的字符正确率
score = round(100 * (0.70 * tokenAccuracy + 0.30 * charAccuracy), 2)
~~~

单词模式只对整词正确计满分；短句和段落使用上式。大小写和允许忽略的标点不计错；缩写与完整形式、英美拼写差异必须由教研 answerVariants 明确列出，不由客户端自行放宽。

**异常与降级**

- 音频未加载：允许输入草稿但不能提交完成，显示重试。
- 内容版本过期：返回 CONTENT_VERSION_MISMATCH，保留输入草稿，刷新后由用户确认重试。
- 离线：本地先生成 pending 记录，网络恢复后按 clientEventId 提交；结果未确认前显示“待同步”，不发放重复 XP。
- 重复点击：相同幂等键返回第一次判分结果，replayed=true。
- 答案包缺失或校验失败：只能播放和查看字幕，禁止本地伪造分数。

**验收**

- 三种模式均能完成输入、重播、提交、结果查看、错误入队和下一次复习。
- 同一标准答案对大小写、允许标点、空白变化给出一致结果；边界样例与教研黄金集 100% 一致。
- 字符/单词差异在提交后 200ms 内显示；错误 token 可直接定位到时间轴。
- 离线提交、恢复重试和重复提交最多产生一条 attempt、一条评测事件和一组 SRS 更新。

**埋点**

- listening.dictation_started

- listening.dictation_submitted

- listening.dictation_hint_used
- listening.dictation_offline_queued

### 3.14 FEAT-SPK-004｜单句录音、双轨波形和用户自评

**目标**

- 提供“原声 → 用户录音 → 回放 → AB 对比 → 用户自评”的自练闭环，不伪造 AI 发音分数。

**前置条件**

- 用户主动点击录音并通过系统麦克风权限；浏览器/App/小程序权限描述已配置。
- sourceSegment 有官方音频和时间轴；录音策略允许本地保存，上传由用户设置和权益决定。

**交互**

1. 首次录音先显示用途、保存位置、默认保留期和删除入口；仅在用户点击“开始录音”后申请麦克风权限。
2. 录音前倒计时 3、2、1；录音时显示时长、停止、重录；停止后生成用户波形并与原声上下对称显示。

5. 录音可仅保存在本地，也可申请上传；上传成功后只返回短期签名播放地址。

**录音安全**

- H5/App/小程序录音文件在本地使用 AES-256-GCM 加密，密钥只放系统 Keychain/Keystore；不把密钥写入 MySQL、日志或埋点。
- 远端上传使用 S3 兼容对象存储的短期预签名 URL 和 multipart upload；Core API 只保存 assetId、哈希、权限和生命周期。
- 用户删除时先标记 DELETE_PENDING，异步删除对象和本地密文；生命周期表保留最小审计信息，不保留音频内容。
- Phase 1 不把录音发送给 ASR、AI 或第三方评分服务。

**异常与降级**

- 麦克风拒绝/系统占用/无输入：提供权限设置指引和重试，不能把空文件标为完成。
- 存储空间不足：停止录音并保留已存在的加密文件，不自动上传。
- 上传中断：保留 uploadId 和已完成 part，恢复后从未完成 part 继续。
- 用户注销或删除录音：立即从列表隐藏，删除任务失败可重试并向用户显示状态。

**验收**

- Web/H5、iOS、Android 至少完成一次权限允许、拒绝、再次授权、录音、回放、删除测试；小程序使用平台 recorder manager。

- 同一录音重复 complete/delete 幂等；删除后签名 URL 失效，远端对象在策略时限内清除。
- UI 明确写出“Phase 1 无 AI 发音评分”，历史结果只包含波形、时长和用户自评。

## 4. 关键交互与确定性规则详述

### 4.1 Wavesurfer.js 与字幕 token 时间轴

客户端采用 AudioTimelineController 作为唯一时间轴适配层，Wavesurfer.js 只是波形渲染和 seek 交互组件，不直接承担业务判分。

时间轴载荷示例：

~~~json
{
  "materialId": 12001,
  "contentVersion": 7,
  "durationMs": 18420,
  "media": {
    "assetId": 90001,
    "url": "signed-url",
    "sha256": "sha256-of-source",
    "peaks": {"channels": 1, "sampleRate": 100, "values": [0.02, 0.18, 0.42]}
  },
  "segments": [
    {
      "segmentId": 700101,
      "sequence": 1,
      "startMs": 320,
      "endMs": 2840,
      "textEn": "Could you help me?",
      "textZh": "你能帮我吗？",
      "tokens": [
        {"tokenId": 7101, "sequence": 1, "text": "Could", "charStart": 0, "charEnd": 5, "startMs": 320, "endMs": 910, "ipa": "kʊd", "stress": "WEAK"},
        {"tokenId": 7102, "sequence": 2, "text": "you", "charStart": 6, "charEnd": 9, "startMs": 920, "endMs": 1290, "ipa": "juː", "stress": "WEAK"},
        {"tokenId": 7103, "sequence": 3, "text": "help", "charStart": 10, "charEnd": 14, "startMs": 1320, "endMs": 2080, "ipa": "help", "stress": "PRIMARY"},
        {"tokenId": 7104, "sequence": 4, "text": "me", "charStart": 15, "charEnd": 17, "startMs": 2140, "endMs": 2800, "ipa": "miː", "stress": "PRIMARY"}
      ],
      "soundChanges": [
        {
          "annotationId": 8101,
          "ruleCode": "WEAK_FUNCTION_WORD",
          "tokenIds": [7101, 7102],
          "startMs": 320,
          "endMs": 1290,
          "marker": "WEAK",
          "explanation": "功能词处于非重读位置，使用弱式语流"
        }
      ]
    }
  ]
}
~~~

渲染循环：

1. load：先验证 schema、版本和时间不变量，再创建 Wavesurfer 实例。
2. play：以媒体元素 currentTime 或 AudioContext 主时钟换算 contentTimeMs。
3. tick：requestAnimationFrame 内二分查找当前 segment/token，只切换 active 状态；不得每帧改写字幕全文、触发同步布局或重新计算波形。
4. seek：取消旧 loop、更新 currentTime、清空 active 状态，收到 seeked 后按新时间点重算。
5. end：优先处理 A/B 或句子循环，再处理下一句；所有状态转移写一次事件。

性能指标：High 档 1,000 token 页面活动高亮更新不超过 1 个 token DOM 树；Performance 档使用 segment 级高亮或纯文本控件；任何档位不得因为字幕动画导致全局 Layout Thrashing。

### 4.2 精听循环、A/B、盲听和变速状态机

~~~mermaid
stateDiagram-v2
  IDLE --> LOADING: 打开 material
  LOADING --> READY: 时间轴和媒体校验通过
  READY --> PLAYING: 用户点击播放
  PLAYING --> PAUSED: 暂停/切后台
  PLAYING --> LOOPING: 到达句尾且 loop=true
  PLAYING --> AB_REPLAY: 到达 B 点且 AB=true
  LOOPING --> PLAYING: seek 到句首
  AB_REPLAY --> PLAYING: seek 到 A 点
  PLAYING --> READY: 媒体结束
  READY --> OFFLINE_PENDING: 网络断开且需要未缓存资源
  OFFLINE_PENDING --> READY: 缓存命中或网络恢复
~~~

盲听模式只隐藏字幕，不删除时间轴；用户仍可播放、暂停、设置 A/B 和提交听写。字幕显示由 subtitleMode 控制，不能在服务端把盲听内容当作另一个 material。

### 4.3 音变规则引擎与可解释反馈

规则资产最小结构：

~~~json
{
  "ruleCode": "PLACE_ASSIM_N",
  "ruleSetVersion": 3,
  "dialect": "GENERAL_AMERICAN",
  "input": {
    "leftIpa": ["n"],
    "rightIpa": ["p", "b", "m"],
    "leftStress": ["ANY"],
    "pauseMaxMs": 120
  },
  "output": {"surfaceIpa": "m", "marker": "ASSIMILATION"},
  "explainTemplate": "n 在双唇音前向双唇部位同化为 m"
}
~~~

处理顺序：

1. 读取已发布 token IPA、stress、pos、pause 和 dialect；
2. 先应用教研显式 annotation；
3. 按 priority、ruleCode 对可匹配规则排序；
4. 生成 annotation，写入输入 token、输出形式、环境、规则版本和解释；
5. 运行冲突校验和时间轴校验；
6. 发布到客户端；客户端只渲染，不重新推断。

禁止使用麦克风录音、ASR 或频谱模型反推音变。用户录音只允许自评和波形对比。

### 4.4 听写与阅读的 SRS 联动

统一 LearningItem 来源：

| 触发 | LearningItem 类型 | 规则 |
|---|---|---|
| 听写错词 | VOCAB / SPELLING | 记录标准 token、错误类型、来源 segment 和 score |
| 听力雷达反复查看 | LISTENING_SKILL | 记录 ruleCode，不直接增加“听力分数” |
| 阅读点击查词 | VOCAB | 用户明确加入生词本时才进入 SRS |
| 阅读长按句子 | SENTENCE / CHUNK | 记录 article、block、tokenRange 和表达标签 |
| 音标最小对立音错误 | PHONETIC_PAIR | 记录 pairCode、题目版本和下次复习原因 |
| 口语自评 | SPEAKING_CHUNK | 记录 sourceSegment 和 selfRating，不产生 AI score |

本域只写入学习事件或调用学习流域的幂等命令；复习日期、Ease Factor、积压保护由学习流/SRS 域统一计算。

### 4.5 录音权限、加密、上传、删除与 RTC 边界

权限流程：

1. 进入页面不申请麦克风；展示用途和隐私链接。
2. 用户点击开始录音后申请平台权限；拒绝时不创建 recording asset。
3. 获得权限后创建 local recordingId 和加密文件；停止后由用户选择仅本地或上传。
4. 上传前再次显示保存期限和删除方式；上传成功后返回短期签名 URL。
5. 删除操作立即从用户列表隐藏，后台删除对象和本地密文，生命周期表保留最小审计。

RTC 边界：

- Phase 1 的单句跟读、影子跟读、角色扮演均为本地媒体 + Core API 练习事件，不创建 RTC room，不使用 HTTP 轮询模拟实时通话。
- Phase 2 若启用实时 AI 角色扮演，必须新增商业 RTC（声网或腾讯云 TRTC）接入 ADR、服务模块、数据出境/隐私评估、Barge-in 设计和 Feature Flag；本文件的 Phase 1 OpenAPI 不提供 RTC session 创建路径。
- 即使未来启用 RTC，也不能复用 Phase 1 的 raw recording 默认保留策略，需单独说明实时音频是否落盘。

### 4.6 弱网、离线音频包、断点续传和幂等提交

离线包包含：

- 已授权 material 的低码率音频、waveform peaks、字幕/token、必要的确定性答案比较包和内容版本；
- 不包含未授权原始视频、完整商业题库导出或可直接传播的永不过期源文件；
- 包清单、asset sha256、总大小、过期时间和加密密钥引用；密钥不进入日志。

下载状态：

~~~text
QUEUED -> DOWNLOADING -> PAUSED -> DOWNLOADING -> VERIFYING -> READY
                                      \-> FAILED -> RETRY
~~~

每个 asset 使用 HTTP Range 或对象存储 multipart；服务端按 packageId、assetId、partNo、sha256 去重。恢复下载必须从已验证的最后字节继续，校验失败删除当前临时分片并从最近安全点重试。

学习事件同步：

1. 客户端为每个事件生成 clientEventId、clientSeq、occurredAt 和 schemaVersion，写入本地队列。
2. 网络恢复后按 clientSeq 批量提交；服务端以 userId + clientEventId 唯一去重，并以 idempotency key 保存首次响应。
3. 服务端先落库事件，再更新练习进度/SRS；同一事件重放只返回原结果，不重复记分、XP、权益或复习排程。
4. 冲突按 contentVersion、serverUpdatedAt 和业务规则处理；不能静默覆盖用户较新的阅读进度，返回 SYNC_CONFLICT 并给客户端选择合并。

### 5.1 画质与能力矩阵

| 能力 | Ultra | High | Medium | Performance / 小程序 |
|---|---|---|---|---|
| 波形 | 高分辨率 peaks + 缩放 | 标准 peaks | 单层 peaks | CSS/静态波形或基础播放器 |

| 录音 | 本地加密、多段上传 | 同上 | 单段上传 | 平台 recorder + 本地回放 |

### 5.2 端到端测试矩阵

至少覆盖：

- Web/H5：Chrome/Safari/移动浏览器，自动播放拒绝、后台切换、键盘和读屏；
- iOS/Android：权限拒绝/恢复、耳机路由、录音中断、横竖屏、弱网；

- Windows PWA：离线缓存、Range 下载、窗口恢复；

### 5.3 性能目标

- 普通内容 API P95 < 500ms；首屏主要内容 < 2s 可交互。
- 已下载音频点击播放到有声 ≤ 500ms；已缓存字幕打开 ≤ 300ms。
- 活动 token 高亮误差 P95 ≤ 80ms；视频字幕误差 ≤ 100ms。
- 录音停止后本地波形在 1s 内可见；上传使用后台任务，不阻塞回放。
- Performance 档不创建 Three.js/WebGL/粒子上下文；任何降级都可由用户手动关闭复杂效果。

## 6. MySQL 8.x 数据模型、DDL 与数据生命周期

### 6.1 设计约束

1. 本节是本模块的落库基线；用户、词汇主表、学习项目表和租户表属于其他域，使用外部 user_id、vocab_id、learning_item_id 引用，不在本文件重复建表。
2. 内容表只保存可发布、可回放的作者/教研数据；不把 ASR 猜测结果、实时 AI 评分或原始录音直接写入内容域。
3. 毫秒时间统一使用 INT UNSIGNED，金额、统计量和事件序号不使用浮点；百分比、评分使用 DECIMAL(5,2)。
4. 所有写请求必须带 Idempotency-Key；表中的 client_*_id 或 event_id 是服务端幂等边界。客户端重试返回第一次成功的资源，不重复产生练习、判分或上传生命周期记录。
5. JSON 仅承载版本化的参数和可解释证据，不承载大音频、隐私原始录音或不可检索的核心业务字段。所有 JSON 字段需通过应用 Schema 校验。
6. 生产环境关闭级联删除；内容下线与用户删除采用状态机和异步任务，避免误删共享素材。

### 6.3 索引、事务与并发策略

- 内容浏览按 publish_status + cefr_level + kind + id 走联合索引；时间轴按 material_id + content_version + start_ms 顺序读取，禁止按 token_text 全表模糊搜索。
- 用户进度以 (user_id, article_id)、用户挖掘以 (user_id, article_id, token_id) 做唯一约束；更新进度时使用 version_no 乐观锁，较旧的离线更新返回 409 PROGRESS_VERSION_CONFLICT，客户端重新合并，不覆盖较新的阅读位置。
- 练习提交在同一事务中完成：校验会话归属与内容版本 -> 校验幂等键 -> 计算确定性结果 -> 写 attempt/submission -> 写 SRS 引用和评测事件。重复 client_*_id 只读回原结果。
- 录音上传的分片元数据与状态变化必须单独事务提交；完成上传时校验分片数、总字节数和 SHA-256 后再把 upload_status 改为 AVAILABLE。
- usr_evaluation_event 可按月分区或按归档表滚动迁移；分区键应为 created_at，不以用户可变字段分区。

### 6.4 保留与删除策略

| 数据 | 默认保留 | 到期动作 | 说明 |
|---|---:|---|---|
| 已发布素材、字幕、token、音变、IPA/口型 | 版权期内 | 下线后转只读归档；版权失效立即撤下 | 不能因用户删除而删除共享内容 |
| 用户练习会话、听写判分、阅读进度、SRS 引用 | 24 个月滚动 | 归档后聚合化；按用户注销请求删除可识别字段 | 聚合统计保留去标识结果 |
| 云端原始录音对象及元数据 | 用户主动删除或默认 30 天 | 删除请求进入队列，目标 24 小时内完成对象删除和密钥销毁 | 不能用于 Phase 1 AI 训练或隐式评测 |
| 本地原始录音 | 用户删除或默认 30 天 | App 私有目录安全删除，保留已确认的摘要状态 | 密钥存系统 Keychain/Keystore，不写日志 |
| 录音生命周期审计 | 180 天 | 脱敏归档或删除 | 不含音频内容、token、密钥 |
| 评测事件、交互事件 | 24 个月 | 聚合后删除明细 | payload_json 禁止录音、身份证件、API Key |
| 离线包及分片元数据 | 包过期后 30 天 | 服务端清理；客户端下一次启动清理过期包 | 包内容需重新校验版本和版权 |

用户删除录音必须做到：接口幂等、对象删除、加密密钥引用失效、生命周期事件落库、查询接口不再返回资产；任一异步步骤失败须可重试并告警。

## 7. REST API 与 OpenAPI 契约

### 7.1 通用约定

- Base URL 为 /api/v1；JSON 字段使用 camelCase，时间使用 RFC 3339，时长和时间轴使用整数毫秒。
- Authorization: Bearer <token> 为登录接口的默认认证；公开素材列表仍需 content:read 权限。用户写操作需 practice:write，录音需额外 recording:write 和明确同意版本。
- 所有写操作要求 Idempotency-Key，长度 1-128；事件批量使用事件内 eventId，服务端以 userId + eventId 去重。
- 列表统一使用游标分页：pageSize 默认 20、最大 100；响应包含 items、nextCursor、hasMore，不承诺跨内容版本的页码稳定性。
- 所有响应包含 requestId；错误响应固定为 errorCode、message、requestId、可选 details。错误不回传对象存储签名、密钥、原始录音或内部堆栈。
- 409 用于幂等键冲突、版本冲突和状态冲突；412 用于内容版本过期；413 用于音频超限；416 用于 Range 不可满足；429 用于限流。

### 7.2 Phase 1 明确不提供的接口

以下能力不写成“已实现”契约：实时 AI 评测、ASR 转写接口、发音自动打分、AI 角色对话、服务端 RTC 房间创建。Phase 2 若接入商业 RTC 或 AI 编排服务，必须新增 ADR、权限范围、数据处理同意和版本化 OpenAPI，不复用本阶段的本地自评字段。

### 7.4 业务错误码

| errorCode | HTTP | 触发条件 | 客户端动作 |
|---|---:|---|---|
| UNAUTHENTICATED | 401 | token 缺失或过期 | 刷新登录态后重试一次 |
| FORBIDDEN | 403 | 无内容、练习或录音权限 | 不重试，提示权限/同意 |
| RESOURCE_NOT_FOUND | 404 | 资源不存在或无权可见 | 移除本地缓存引用 |
| IDEMPOTENCY_KEY_REUSE | 409 | 同 key 请求指纹不同 | 停止重试并生成新 key |
| PROGRESS_VERSION_CONFLICT | 409 | 离线进度版本较旧 | 拉取后合并最大有效位置 |
| STATE_CONFLICT | 409 | 录音/会话状态不允许当前动作 | 刷新状态 |
| CONTENT_VERSION_EXPIRED | 412 | 旧版本不可新提交 | 使用最新内容，保留历史结果 |
| RECORDING_TOO_LARGE | 413 | 超过 50 MB 或 10 分钟 | 本地压缩或缩短录音 |
| RANGE_NOT_SATISFIABLE | 416 | 断点范围不匹配 | 重新读取 manifest |
| RATE_LIMITED | 429 | 频率过高 | 按 Retry-After 退避 |
| VALIDATION_FAILED | 422 | 参数、Schema 或规则不通过 | 修正字段，不盲目重试 |
| MEDIA_NOT_READY | 503 | 音频或离线包仍在处理 | 指数退避，保留本地任务 |
| OFFLINE_PACKAGE_EXPIRED | 410 | 离线包超过版权或缓存期限 | 删除本地包并重新申请 |
| SYNC_CONFLICT | 409 | 离线提交与服务端新版本冲突 | 按返回冲突项逐条合并 |

## 8. 事件埋点与可解释性契约

### 8.1 通用事件结构

客户端只上报行为和确定性结果所需的最小字段；事件不得包含原始录音、完整音频二进制、身份证明、访问令牌或用户自由文本原文。事件 schema：

~~~json
{
  "eventId": "uuid",
  "eventName": "listening.dictation_submitted.v1",
  "domain": "LISTENING",
  "featureCode": "FEAT-LST-004",
  "sessionId": 123456,
  "clientSeq": 17,
  "occurredAt": "2026-08-20T10:20:30.123+08:00",
  "requestId": "uuid",
  "actorId": 9001,
  "contentRef": {
    "contentType": "CAPTION_SEGMENT",
    "contentId": 456,
    "contentVersion": 3
  },
  "payload": {
    "mode": "SENTENCE",
    "score": 82.5,
    "errorCount": 2,
    "offline": true
  },
  "schemaVersion": 1
}
~~~

### 8.3 埋点验收

- 每个功能至少有进入、核心动作、成功/失败、降级或离线事件；事件可由 eventId 重试且服务端不重复计数。
- 事件时间以客户端发生时间为主、服务端接收时间为辅；时钟偏差超过 5 分钟时服务端标记 clockSkew=true，不影响练习结果。
- 规则解释必须能由 ruleCode + ruleVersion + evidence 重放；反馈页面不能只保存一段不可复核的自然语言。
- 数据看板仅使用聚合字段；录音和用户输入文本在日志、链路追踪、错误上报中一律脱敏。

### 9.2 跨端、弱网与隐私验收

- H5、iOS/Android App、iPad、Windows PWA 和微信小程序完成主链路；小程序不加载 WebGL，Performance 档不创建 Three.js 上下文。
- 模拟离线 -> 2G -> 恢复网络：音频包可断点续传，字幕/练习可离线回放，事件和提交按 clientEventId/eventId 幂等同步。
- 拔麦克风权限、切后台、锁屏、来电、Web Audio context suspended、网络断开、对象存储 5xx 均有用户可理解的状态提示和恢复动作。
- 用户删除录音后，列表、详情、回放 URL、对象存储和加密引用均不可再访问；重复删除返回同一最终状态。
- 安全测试不得发现日志中的 token、签名 URL、密钥、原始音频或完整用户答案。

### 9.3 发布门槛

1. OpenAPI lint、DDL migration dry-run、前端生成类型、后端 DTO 和 contract snapshot 一致。
2. 单元测试覆盖时间轴、音变规则、听写归一化/编辑距离、分支图合法性、SRS 映射、幂等和权限。
3. 集成测试覆盖素材版本切换、进度乐观锁、录音分片校验、删除生命周期、离线同步和 5xx 重试。
4. 端到端测试覆盖四级画质、四类平台、四种关键网络状态；波形高亮误差、首帧播放、录音本地可见时间符合 §5.3。
5. 内容发布前验证字幕无重叠、token 在 segment 内、规则 annotation 有证据、口型参数在范围内、版权允许离线。

## 10. 实现边界与后续 ADR

- Phase 1 实现：作者化内容、Wavesurfer/Web Audio 播放与时间轴、确定性听写/理解题/最小对立体判分、音变解释、Rive/Three.js 或静态口型降级、用户本地自评、可选加密上传、跨域 SRS 引用、离线包与幂等同步。
- Phase 1 不实现：实时 AI 评测、ASR 自动转写、AI 发音分数、自由对话式角色扮演、未声明同意的录音训练。
- Phase 2 若接入声网/腾讯云 TRTC，新增 ADR 说明房间生命周期、token 签发、Barge-in、录音边界、数据地域、故障降级和计费；RTC 只承载实时媒体，不改变本地练习和内容契约。
- Phase 2 若接入 Python FastAPI + LangGraph/LiteLLM，新增 AI 输入/输出 Schema、promptVersion、超时/重试/安全审核和审计表；不得把 AI 结果伪装成本文 Phase 1 的 score。
- 任何新增硬件渲染、第三方媒体服务或跨域数据共享，都必须补充 ADR、权限、版权/隐私评估和本文件映射。
