# 07 考试与成绩报告设计

> 需求溯源：PRD §2.6 考试、§6.3 VIP 权益（模拟次数分层）、mvp-scope P0。

---

## 一、功能设计

### 1.1 考试矩阵
| 类型 | 结构 | 时长 | 权益 |
| :--- | :--- | :--- | :--- |
| 词汇快测 | 50 题选择/拼写，测当前词书掌握度 | 15min | 免费每日 1 次 |
| 语法专项 | 按语法点抽题 30 题 | 20min | 免费每日 1 次 |
| 分模块计时刷题 | 阅读/翻译/听力题组（听力音频预渲染） | 自定义 | 免费每日 2 组 |
| CET-4 全真模拟 | 按真题结构：写作/听力/阅读/翻译 | 125min | 免费每周 1 次，VIP 不限 + 回看 |
| CET-6 全真模拟 | 同上（六级难度） | 130min | VIP |

- **内容来源**：公开真题语料（版权合规核查）+ 教研自命题；听力音频预录。
- **模拟卷结构配置化**：题型、题量、时间分配由后台配置，新增套卷不发版。

### 1.2 考试流程
1. **考前页**：试卷结构说明、时间分配建议、注意事项（模拟真实考场规则）。
2. **答题中**：顶部倒计时（可隐藏）、题号导航卡、未答标记；切后台自动暂停并提醒（防挂机）。
3. **交卷**：主动交卷二次确认（展示未答题数）；时间到自动交卷。
4. **分段考试支持**：全真模拟允许 24h 内分段完成（适配碎片时间），计总时长。

### 1.3 成绩报告（规则统计，无 AI）
- **总分与百分位**：按题型加权估分；百分位基于全体用户历史分布（脱敏统计）。
- **题型雷达图**：写作/听力/阅读/翻译四维。
- **薄弱点清单**：错题按知识点归类（词汇/语法点/题型技巧），一键"去练"跳转对应模块。
- **错题自动入错题本**；错词入个人词库。
- **历史对比**：与上次模拟分差、趋势曲线。

### 1.4 边界情况
| 场景 | 处理 |
| :--- | :--- |
| 断网交卷 | 本地缓存答案，联网后补交；超 24h 作废提示 |
| 免费次数用尽 | 展示升级卡片（明确 VIP 不限次权益），不隐藏成绩报告 |
| 模拟中途超时 | 自动交卷已答部分，报告标注"未完成" |
| 首次考试无历史数据 | 百分位与趋势区展示引导态 |

## 二、交互设计

### 2.1 考试中心线框

```
+----------------------------------+
| 考试中心                          |
| ┌ CET-4 全真模拟 ─────────────┐  |
| │ 125min · 真题结构 · 本周剩 1 次│ |
| │        [开始模拟]             │ |
| └─────────────────────────────┘  |
| [词汇快测 15min] [语法专项 20min] |
| [分模块刷题 →]                    |
| ── 我的成绩 ──                    |
| 上次模拟：482 分（↑13）  [报告 →] |
+----------------------------------+
```

### 2.2 答题页线框

```
+----------------------------------+
| ⏱ 28:41   阅读理解 1/3   [题卡]  |
+----------------------------------+
| (题干与选项，大字号行距)           |
| ○ A  ……                          |
| ● B  ……                          |
| ○ C  ……                          |
| ○ D  ……                          |
| [上一题]        [标记] [下一题]   |
+----------------------------------+
```

### 2.3 成绩报告线框

```
+----------------------------------+
| CET-4 模拟 · 482 分 · 超过 63% 考生|
| [雷达图：听力弱 / 阅读强]          |
| 薄弱点：                          |
| • 听力-长对话（错 4/8）[去练 →]    |
| • 词汇-形近词辨析       [去练 →]   |
| [查看错题] [分享成绩] [再战一次]   |
+----------------------------------+
```

### 2.4 关键交互细节
- **倒计时**：最后 5 分钟变橙色 + 轻提示音（可关）。
- **题号导航卡**：抽屉式弹出，已答/未答/标记三色格子直达。
- **雷达图动效**：展开动画（High+），低档直接静态。
- **分享成绩图**：仅分数与趋势、不含账号信息；带品牌水印与二维码（拉新）。
