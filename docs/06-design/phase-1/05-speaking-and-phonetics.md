# 05 口语与音标设计

> 需求溯源：PRD §2.4 口语训练（非 AI 评分形态）、mvp-scope P0；第二阶段升级为 AI 发音评测。

---

## 一、功能设计

### 1.1 跟读与影子跟读
- **内容来源**：词书例句音频、情景会话音频、演讲短文（公开素材，分难度）。
- **跟读模式**：逐句播放原声 → 用户录音 → 波形对比展示（自评）→ 下一句。
- **影子跟读**：原声连续播放，用户延迟 1–2s 跟读（高级训练），录音全程回放。
- **自评机制**（第一阶段核心）：
  - 播放控件：原声 / 我的录音 / 并排波形对比；
  - 自评打分：`流畅` `一般` `需重录`（仅记录个人趋势，不做横向排名）；
  - 重录不限次，保留最佳一次作为个人档案。
- **数据结构预留**：录音条目含 `aiScore` 空槽位，第二阶段接入评测模型直接回填。

### 1.2 48 国际音标
- **音标总表**：元音 20 + 辅音 28 网格，按发音部位分组（唇/齿/舌位）。
- **音标详情**：2D/SVG 口型剖面示意图（静态 + 分步动画）、发音要领文字（舌位/唇形/声带）、示例词 3 个 + 音频、易混音标对比（如 /iː/ vs /ɪ/）。
- **点读练习**：听音选音标四选一；按组过关（每组正确率 ≥80% 点亮徽章）。
- **3D 预留**：详情组件容器按 web-view 3D 模块尺寸设计（第二阶段替换）。

### 1.3 情景会话
- **场景库**（首发 20 个）：点餐、问路、自我介绍、电话沟通、购物、机场等。
- **会话结构**：A/B 角色对话 6–10 轮，每句配翻译与发音提示。
- **练习模式**：
  1. **听读**：逐句播放 + 文字高亮；
  2. **分角色朗读**：用户选 A 或 B 角色，App 播对方台词、用户在提示点录音自己的台词；
  3. **整段回放**：完整听自己的对话版本。
- **语速调节**：0.7x / 1.0x 两档（音频预渲染双版本或 WebAudio 变速）。

### 1.4 边界与合规
| 场景 | 处理 |
| :--- | :--- |
| 麦克风权限拒绝 | 引导开启说明（用途仅本地对比），提供"仅听读"降级模式 |
| 录音存储 | 仅本地（uni-app 文件系统），第一阶段不上传；App 卸载即清除 |
| 环境嘈杂 | 录音前提示"找个安静的地方"，提供试听后再提交 |
| 浏览器不支持录音（旧内核） | 隐藏录音入口，保留听读模式 |

## 二、交互设计

### 2.1 跟读页线框

```
+----------------------------------+
| ✕ 退出     跟读练习   3/10 句     |
+----------------------------------+
| "Where is the nearest bank?"  🔊 |
|  [原声音频波形 ▁▃▅▇▅▃▁]           |
|                                  |
|        ( ● ) 长按录音             |
|                                  |
|  我的录音 [波形 ▁▂▄▆▄▂▁]  ▶ 回放  |
|                                  |
|  自评：[流畅] [一般] [需重录]      |
|       [下一句 →]                  |
+----------------------------------+
```

### 2.2 音标实验室线框

```
+----------------------------------+
| 48 音标实验室    [元音][辅音]      |
| ┌──┬──┬──┬──┬──┐                |
| │iː│ɪ │e │æ │… │  ← 点读网格     |
| ├──┼──┼──┼──┼──┤                |
| │uː│ʊ │ɔː|ɒ │… │                |
| └──┴──┴──┴──┴──┘                |
| 选中：/iː/                        |
| [SVG 口型图] 要领：舌前部抬起…     |
| 示例：sheep / tea / key 🔊       |
| 对比：/iː/ vs /ɪ/  [听对比]       |
+----------------------------------+
```

### 2.3 关键交互细节
- **录音按钮**：长按录音、松手结束（移动端）；Web 端点击开始/停止双态按钮。
- **波形对比**：原声蓝、我的橙，纵向并排便于肉眼比对节奏断点（Wavesurfer 轻量封装）。
- **情景会话**：对话气泡聊天式布局，用户角色气泡带录音按钮；播放对方台词时气泡逐字高亮。
- **反馈动效**：完成一句跟读 → 星星小动效；整段完成 → 结算页（完成句数/重录次数/流畅自评分布）。
