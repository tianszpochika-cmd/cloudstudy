# 08 复习与错题本设计

> 需求溯源：PRD §2.1 记忆引擎、§2.8 闭环基座、§6.3 权益（错题本历史分层）、mvp-scope P0。

---

## 一、功能设计

### 1.1 记忆引擎（SuperMemo-2 规则实现）
- **调度对象**：单词（主）、语法点、句型、错句（以卡片形式统一入队）。
- **间隔策略**：基于自评质量（认识/模糊/不认识）更新 EF 因子与间隔；首次间隔 10min→1天→3天→7天→15天→30天梯度。
- **到期合并**：每日 0 点汇总到期项生成复习队列；队列上限保护（>300 项时按"最久未复习"优先并提示分批）。
- **复习不设付费门槛**：到期复习对免费用户全量开放（PRD 学习权保障）。

### 1.2 复习会话
- **卡片类型自适应渲染**：单词卡（看义忆词/听音忆词）、语法卡（规则回忆 + 1 题快答）、句子卡（翻译回忆）。
- **自评**：`记住` / `模糊` / `忘了` 三键；忘了的卡本会话末尾重现一次。
- **批量模式**：支持"极速刷"（仅认识/不认识二键）应对大复习量。

### 1.3 错题本
- **自动收录**：练习、考试、小测的全部错题，按来源/知识点/时间三维归档。
- **错题重做**：重做正确 2 次（间隔 ≥1 天）自动移入"已攻克"；免费层保留近 30 天错题，VIP 全历史。
- **错题快练**：一键组 10 题错题卷（同知识点优先）。
- **仅查看不导出**：错题本与解析仅支持应用内查看与重做，**不提供导出、下载、打印、复制接口**（内容防复制 + 数据保护，PRD §2.9）；截图不限制但不含账号水印。
- **数据保留**：会员到期后错题本只读不删（PRD §6.3 数据保留承诺）。

### 1.4 我的词库（复习视角）
- 与 03 模块个人词库同源；此处提供"词库专项复习"入口（仅复习已收录词，不推进词书）。
- 熟练度分层视图：陌生（红）/进行中（黄）/已掌握（绿）。

### 1.5 边界情况
| 场景 | 处理 |
| :--- | :--- |
| 复习队列巨大（回归用户） | 提供"重启计划"：保留掌握记录、重排 7 天补账节奏 |
| 免费层错题过期 | 过期前 3 天提示"升级保留全部错题"；过期题聚合统计仍保留 |
| 多端进度冲突 | 以服务端最后写入为准，冲突时合并较大间隔（保守防遗忘） |

## 二、交互设计

### 2.1 复习中心线框

```
+----------------------------------+
| 复习中心                          |
| ┌ 今日待复习 ────────────────┐   |
| │ 单词 58 · 语法 3 · 句子 2   │   |
| │       [开始复习]            │   |
| └────────────────────────────┘   |
| [错题本 (12)] [我的词库 364 词]   |
| [错题快练 10 题 →]                |
+----------------------------------+
```

### 2.2 复习卡片线框

```
+----------------------------------+
| ✕ 退出    复习 23/63    ▓▓░      |
+----------------------------------+
|        （正面）                   |
|      v. 放弃；抛弃                |
|   [显示答案]                      |
+----------------------------------+
|        （翻面后）                 |
|      abandon  /əˈbændən/ 🔊      |
|      例：He abandoned his car…   |
|   [忘了]   [模糊]   [记住]        |
+----------------------------------+
```

### 2.3 关键交互细节
- **翻面**：点击卡片 3D 翻转（High+）/ 淡入（低档）；空格键快捷翻面（Web）。
- **自评三键**：与背词一致的红黄绿色系，形成肌肉记忆一致性。
- **会话结算**：记住率环图 + "遗忘曲线提醒：这批词 3 天后再见"。
- **错题本列表**：按知识点分组折叠；每题展开看原题/我的答案/正确答案/解析；右上筛选器（来源/时间/状态）。
