# 02 首页与今日任务设计

> 需求溯源：PRD §2.8 学习闭环基座、§6.2 学习报告、mvp-scope P0 基座。

---

## 一、功能设计

### 1.1 首页模块（自上而下）
| 模块 | 内容 | 规则 |
| :--- | :--- | :--- |
| 顶部状态区 | 连续打卡天数、今日星星（积分）、会员角标 | 点击打卡数进入学习日历 |
| 考试倒计时卡 | 目标考试 + 剩余天数 | 未设置则展示"设定目标"引导卡 |
| 今日任务卡 | 当日任务清单与完成进度环 | 全部完成触发"今日全满"庆祝动效 |
| 快捷入口 | 背单词 / 复习 / 模考 / 小游戏 | 4 宫格直达 |
| 学习日历 | 近 30 天热力格 | 点击查看月度视图与周报入口 |
| 推荐卡 | 薄弱项提示（如"语法-时态正确率 62%，去练 5 题"） | 规则统计生成，非 AI |

### 1.2 今日任务生成规则（规则引擎，非 AI）
- **生成时机**：每日 0 点生成；用户当日首次打开时拉取。
- **任务组成**（按用户目标动态配比，每日 4–6 项）：
  1. 背新词 N 个（N 按词书进度与剩余天数推算，默认 30）；
  2. 复习到期词 M 个（记忆引擎输出，必做项）；
  3. 练习 1 组（语法/句子拆分/口语/作文轮换，覆盖弱项权重更高）；
  4. 每周 1 次模拟考试（有考试目标的用户）；
  5. 打卡（完成任意 1 项即自动打卡）。
- **完成度**：每项任务完成即得星星；全满额外奖励；未完成不惩罚、不展示负面文案。
- **补做**：昨日未完成任务合并进今日列表（标注"补"），最多保留 3 天防堆积。

### 1.3 学习日历与周报
- 日历：每日格子按学习时长着色（4 级色阶），断签日灰色不标红。
- 周报（免费层）：本周背词量、学习时长、正确率趋势、连续打卡；VIP 增加日报与薄弱题型分析。
- 周报支持生成分享图（去敏感信息、带品牌水印）。

### 1.4 提醒机制
- 站内：今日任务未开始，20:00 站内横幅一次。
- 站外：H5 浏览器通知 / App 推送（需授权）；文案正向（"今天的 30 个词在等你"），无焦虑话术。
- 免打扰：设置内可关闭全部站外提醒。

## 二、交互设计

### 2.1 首页线框

```
+----------------------------------+
| [头像] 连续打卡 12 天 ★ 86  [VIP] |
+----------------------------------+
| 考试倒计时：CET-4 还剩 47 天  >   |
+----------------------------------+
| 今日任务              进度环 3/5  |
| [✓] 复习 58 个到期词              |
| [○] 背新词 30 个        [去完成]  |
| [○] 语法练习 10 题      [去完成]  |
| [○] 跟读 5 句           [去完成]  |
| [✓] 打卡                          |
+----------------------------------+
| 快捷：[背单词][复习][模考][小游戏] |
+----------------------------------+
| 学习日历（30 天热力格）      月 > |
+----------------------------------+
| 推荐：时态正确率 62% → 去练 5 题  |
+----------------------------------+
```

### 2.2 关键交互细节
- **任务卡点击**："去完成"直达对应模块，完成返回后任务自动勾选 + 星星飞入顶部（High 档以上粒子，低档数字跳动）。
- **进度环**：全满时环变为金色 + 庆祝文案"今日星球全亮"；Performance 档仅换色。
- **日历滑动**：左右滑切换月份；点格子展示当日摘要浮层（时长/词量/任务完成）。
- **下拉刷新**：首页下拉刷新任务状态（多端同步场景）。

### 2.3 空态与异常
- 新用户首页：任务卡显示"完成设置后生成你的第一份计划"，引导补全目标。
- 离线：首页缓存上次数据，顶部提示"离线模式，数据将在联网后同步"。
