6. Phase 1 不使用 AI 生成题目、评测、敏感审核或客服结论；内容审核采用规则前置拦截、人工一审/二审和后置巡检。

## 3. 成长与游戏化原子补充

### ATOM-GAM-001 XP 资格判定、结算与回放

- **父项与缺口**：FM-GAM-001、DS06 XP 规则和账本、UIUX-09。补充“真实学习事实→资格判定→账本→聚合→回放”的边界，防止客户端把点击、重复提交或游戏动画当成 XP。
- **PRD 证据**：PRD §14 要求 XP 只来自课程、复习、阅读、听力、模考和游戏等真实学习行为，禁止点击刷 XP；§18 要求个人中心显示 XP/等级。
- **状态机**：UNQUALIFIED → QUALIFIED → SETTLEMENT_PENDING → SETTLED → RECONCILED；命中风控或规则版本不一致时为 SETTLEMENT_PENDING → REVIEW_HOLD，处理后进入 SETTLED 或 REJECTED。
- **API/数据**：读取沿用 /api/v1/gamification/profile、/ledger；结算只由冻结可信完成白名单中的服务端学习/评测事实触发，不开放“提交 XP”接口。`assessment.item.assessed.v2` 仅限已验证正确且非猜测，`learning.mastery.projected.v2` 仅限 D7 通过的真实跃迁，未来 `learning.task.completed.v2` 必须先完成专用契约；`learning.review.scheduled.v2`、`learning.task.completed.v1`、B4/B12/v1 不能结算。事实表使用 xp_ledger、account_summary、gam_idempotency_record 和统一事件信封中的 sourceEventId/ruleVersion/localDate/timezone；以上为 D2 静态约束，非 runtime 结论。
- **权限与审计**：本人可读 gamification:read:self；本人不可写 XP。系统结算使用服务端 actor，管理员仅可按 gamification:audit:read 查看，不得修改历史账本；补发或冲正必须由既有受限后台权限、幂等键和原因完成，并写 admin_audit。
- **异常恢复**：同一 sourceEventId 重放只返回原结算；规则版本过期返回 STALE_RULE_VERSION 并重新取服务端规则；网络中断先保留学习事实/本地事件队列，恢复后重放，禁止补发客户端猜测值；账本与聚合不一致由对账任务重建聚合。
- **跨端**：各端只展示服务端确认值；离线可显示“待同步”而不能显示为已入账；动画失败不影响入账；低性能档关闭 XP 飞入动画，Web/iPad/App/H5 的数值和明细一致。
- **验收**：重复点击、重复回放、跨设备并发、跨日时区和杀进程后均不重复入账；个人中心、成长页、账本明细和后台审计可由同一 sourceEventId 回放；客户端无法伪造 XP、等级或规则版本。

### ATOM-GAM-002 Streak 有效日、风险、冻结与补救

- **父项与缺口**：FM-GAM-002～004、DS06 Streak/补救/周末保护、UIUX-09。补充“有效学习日的证据、时区、状态迁移和提醒”的统一口径。
- **PRD 证据**：PRD §14 要求每天至少一个有效学习任务、7/30/100/365 里程碑、补救卡和提醒；周末可有 0～2 天休息保护；不能用羞辱式断签设计。
- **状态机**：EMPTY → ACTIVE → AT_RISK → PROTECTED/FROZEN → ACTIVE；超过有效窗口为 BROKEN；补救允许窗口内 BROKEN → RESCUE_PENDING → ACTIVE，失败为 BROKEN。
- **API/数据**：沿用 /api/v1/gamification/streak、/settings、/rescue；数据为 streak_profile、streak_day、streak_rescue、用户 IANA timezone、有效学习事件引用和规则版本。客户端只提交补救意图，补救题量/正确率按 DS06 既有规则服务端判定。
- **权限与审计**：本人读写自己的提醒和补救请求；补救消耗星星或补救卡由服务端原子扣减；管理员可审计规则、补救和人工恢复，不可直接改历史天记录；所有状态变化保留前后值、原因和 actor。
- **异常恢复**：跨午夜或时区切换以账号有效时区和结算时点确定，重复补救返回幂等结果；补救卡不足、窗口过期、重复补救分别返回既有错误；提醒发送失败不改变 Streak；Redis 锁丢失后由 MySQL 日记录重算。
- **跨端**：首页、世界、个人中心、Study Room 成员卡只显示同一服务端 Streak；离线显示上次确认并标注待同步；动画、震动和提醒可按设置关闭；小屏只保留“今天完成一个有效任务即可延续”等非羞辱提示。
- **验收**：课程/复习/阅读/听力/写作/合格游戏/Checkpoint 等有效任务能正确延续；无效点击不延续；7/30/100/365 触发一次；周末保护、补救成功/失败、跨时区和并发请求结果可审计且不重复。

### ATOM-GAM-003 星星、星尘与固定兑换

- **父项与缺口**：FM-GAM-005、FM-GAM-019、DS06 货币账本和固定兑换、UIUX-09/10。补充“学习积分、重复碎片和消耗品的非现金边界”。
- **PRD 证据**：PRD §14 规定星星只能由学习任务、Streak、成就、模考进度获得，可兑换补救卡、主题皮肤、地图装饰、头像框和学习效果；不可提现、不可交易、不可作为付费随机货币；奖励箱重复物转收藏碎片。
- **状态机**：星星/星尘为 EARNED → LEDGER_POSTED → AVAILABLE → REDEEM_PENDING → REDEEMED，失败为 REDEEM_REJECTED；兑换后不可回滚为可用余额，冲正必须产生反向账本。
- **API/数据**：沿用成长账本、/collection/catalog、/collection/redeem；数据为 currency_ledger、account_summary、固定目录、兑换订单/幂等记录和 STAR_COIN/STAR_DUST 资产类型。兑换目录必须是固定商品或明确自选，不承载概率。
- **权限与审计**：本人可读余额和兑换历史，兑换需 gamification:write:self；运营只可发布固定目录，财务无权改变学习积分；人工补发/冲正需双人或既有高风险权限、原因、前后余额和审计。
- **异常恢复**：余额不足、重复兑换、目录版本过期和商品下线返回明确错误；客户端超时可按幂等键查询；兑换扣账与发货必须同一事务或进入 REWARD_PENDING_REVIEW，由补偿任务重试，不允许只扣不发。
- **跨端**：学习端统一显示“星星/星尘”而非现金；H5/App/小程序都不能出现充值入口、提现入口或交易入口；低配设备不渲染额外粒子但兑换结果仍可查看。
- **验收**：所有来源均可追溯到真实学习事件；无法购买、提现、转赠、交易或用星星增加答题能力；固定兑换并发下余额不为负、只发一次，重复物按既有质量档换算星尘并可回放。

### ATOM-GAM-004 每日/每周任务与成就进度

- **父项与缺口**：FM-GAM-006～008、DS06 任务/成就种子规则、UIUX-09。补充任务周期切换、领取边界和成就展示授权。
- **PRD 证据**：PRD §14 要求每日/每周任务来自 15 分钟学习、复习词汇、阅读、听写、游戏等有效任务；成就覆盖 Streak、词汇、阅读、听力、写作、模考、游戏和全模块。
- **状态机**：任务 LOCKED → AVAILABLE → IN_PROGRESS → CLAIMABLE → CLAIMED/EXPIRED；成就 HIDDEN → IN_PROGRESS → UNLOCKED → SHOWCASED，撤销或数据纠错时为 SHOWCASED → HIDDEN 并留下审计，不删除历史。
- **API/数据**：沿用 /quests、/quests/{id}/claim、/achievements、/showcase；数据为 quest_definition/user_quest/quest_progress、achievement_definition/user_achievement/achievement_progress、规则版本、周期和来源事件。
- **权限与审计**：本人可读进度、领取奖励和控制展示；领取只接受服务端 CLAIMABLE；教研/运营只能发布版本化定义，不能改用户已完成事实；奖励发放、撤销、展示字段变化写审计。
- **异常恢复**：周期切换保留已完成历史，未领取奖励按既有过期规则处理；重复领取返回原结果；进度事件迟到时按事件日期重算，失败进入待处理；UI 领取消失时可从消息/成长页再次查询。
- **跨端**：每日/每周卡片、成就墙、个人中心和成员展示使用同一进度；通知深链可打开对应任务；动效、震动、彩带可关闭；无障碍读出“已完成/待领取/已过期”。
- **验收**：任务只能由有效学习事件推进，点击浏览不推进；每日/每周边界、重复领取、离线完成、成就展示关闭和后台规则版本切换均可验证；每个奖励有来源和审计。

### ATOM-GAM-005 六类游戏统一目录、会话与结算

- **父项与缺口**：PRD §14 六类游戏、FM-GAM-009～012、DS06 游戏公共会话与 UIUX-09。补充四个 feature-matrix 父项覆盖六类游戏时的公共契约。
- **PRD 证据**：候选游戏目录包含 Sentence Train、Word Match、Word Defense、Word Puzzle、Grammar Blaster、Catch the Meaning；题目必须来自用户学习进度、练习或复习；不能用付费抽题、付费复活或无关游戏刷成长。P0 初始 Gate 只允许 Sentence Train，其余不因本历史补充而进入 P0。
- **状态机**：CREATED → READY → IN_PROGRESS ↔ PAUSED → SUBMITTING → COMPLETED；用户退出为 ABORTED，超时为 EXPIRED，序列/内容/作弊校验失败为 INVALIDATED。
- **API/数据**：沿用 /games/catalog、/games/sessions、/events、/pause、/resume、/finish；数据为 game_definition/session/event/item、内容版本、题目 nonce、顺序号、完成度、正确率、来源模块和结算状态。客户端只提交事件序号和结果引用，服务端重新校验。
- **权限与审计**：本人需 games:read:self、games:play:self；管理员只能查看脱敏会话和审计；不得记录原始隐私、完整设备指纹或未必要的原题答案；无效会话保留原因和规则版本。
- **异常恢复**：断网时保留本地未提交事件，恢复后按顺序重放；乱序、重复、过期、篡改分别返回既有错误；服务端以会话状态机为准；完成但奖励待审核时显示待处理，不二次发放。
- **跨端**：移动端优先，Learner Web/iPad/H5/App 共享目录和规则；小程序按能力降级；低配关闭粒子/3D 反馈，不改变题目、计时和结算；键盘、触控和读屏都有等价操作。
- **验收**：P0 只可从目录进入 Sentence Train；任何 P1/长期候选游戏必须保持服务端 Gate 关闭，直到独立排期和验证。已开启游戏的暂停/恢复、超时/退出和完成、题目来源、游戏时间、合格条件和 XP/星星结算可审计；不能购买分数、复活、概率或装备属性。

### ATOM-GAM-006 Sentence Train 句子火车

## 5. 账号、通知、设置、隐私、同步与客服原子补充

### ATOM-INF-001 18+ 注册、登录、令牌、设备与风险冻结

- **父项与缺口**：FM-USR-001～005、DS07 auth/session/device、UIUX-12/23。补充多身份登录、令牌轮换和设备风险的统一生命周期。
- **PRD 证据**：PRD §17 要求 18+、账号密码、多设备、刷新令牌、设备管理和强制退出；Phase 1 不开放未成年人。手机号等登录标识由自有 IAM 直接校验，其他平台连接不进入默认登录链路。
- **状态机**：用户 UNVERIFIED → VERIFIED → ACTIVE → RISK_CHALLENGE → FROZEN/DELETED；设备 PENDING → TRUSTED → REVOKED；access token ISSUED → REFRESHED → EXPIRED/REVOKED。
- **API/数据**：认证使用自有 IAM 账号密码接口、短时 RS256 JWT Bearer session、JWKS、device list/kick 和 IAM refresh rotation；数据为 account、principal、device_session、session/family hash、risk_event、删除任务。登录接口只经 TLS 接收密码并只保存哈希，业务 API 不接收 Refresh Token 原文。
- **权限与审计**：登录用户只读自己的设备和会话并可踢出其他设备；管理员按用户/风控权限处理冻结，不查看 token；绑定、解绑、换号、强退、风控挑战、恢复均记录 actor、原因和时间。
- **异常恢复**：密码错误超限、Access Token 过期、Refresh Token 重放、设备被踢和认证中心异常均安全失败；保留当前有效会话不扩大权限；登录恢复需重新验证身份，不能通过客户端改状态。
- **跨端**：App/Web/PWA/H5/小程序使用同一自有 IAM 身份状态；断网不伪造登录成功；Web 使用内存 Access Token 与 HttpOnly/Secure/SameSite Refresh Cookie，原生端只使用 Keychain/Keystore；后台登录风险与用户端提示一致。
- **验收**：未确认 18+ 或身份未验证不能进入 Phase 1 社群/商业化；IAM 签发的短时 JWT Bearer、Refresh Token 轮换/重放检测、JWKS 校验、踢设备和冻结不会泄露 token 或误发权益。

### ATOM-INF-002 个人资料、账号合并、删除与匿名化

- **父项与缺口**：FM-USR-006～007、PRD §17/18、DS07 profile/merge/deletion、UIUX-12/14。补充资料域、跨身份合并和不可逆删除边界。
- **PRD 证据**：个人资料最小化，包括昵称、系统 Avatar、语言、目标、日期和强度；可多设备；支持合并、导出、删除、匿名化；真实头像上传与 Phase 1 Avatar 预设要求存在冲突，见文末。
- **状态机**：资料 ACTIVE → EDITING → SYNC_PENDING → ACTIVE/CONFLICT；合并 REQUESTED → CONFIRMING → MERGE_PENDING → MERGED/CANCELED；删除 ACTIVE → DELETE_SCHEDULED → ANONYMIZING → DELETED。
- **API/数据**：沿用 profile、identity binding/merge、delete/export 接口；数据为 user_profile、identity mapping、merge_job、deletion_job、匿名化映射、法律保留记录。合并前明确课程进度、成员、Household、SRS 的冲突和不可逆提示。

- **异常恢复**：资料冲突提示服务端版本；合并前可取消，开始不可逆阶段后只允许查询；删除任务失败可重试并保持幂等；法律保留数据隔离、到期自动清理；导出包过期后需重新申请。

- **验收**：昵称等最小资料能跨设备同步；合并不串联两人数据；删除后公开展示、Feed、通知和设备会话均撤回/匿名化；无法恢复的步骤前有二次确认和审计。

### ATOM-INF-003 通知事件、渠道、偏好与免打扰

- **父项与缺口**：FM-INF-001～003、PRD §18、DS07 notification、UIUX-12/23。补充事件、渠道和偏好之间的路由优先级。
- **PRD 证据**：支持学习、Study Room、奖励/成长、会员/交易、安全、系统分类；站内信、推送、SMS、邮件按授权使用；23:00～08:00 免打扰；安全/必要通知不能关闭，营销须可退订。

- **跨端**：站内消息为事实源，推送/SMS/邮件是渠道；App、Web、H5、小程序支持可用渠道并明示不可用原因；通知点击深链按平台 fallback；离线后已读状态可同步。

### ATOM-INF-005 隐私中心、权限同意、数据导出/清理

- **父项与缺口**：PRD §18/22、DS07 privacy、UIUX-14/23。补充隐私对象、可选权限与删除范围的可审计闭环。

### ATOM-INF-006 下载中心、离线包与文件完整性

- **父项与缺口**：FM-INF-004、PRD §18/21、DS07 offline/download、UIUX-14。补充“可离线内容”与商业原始内容保护边界。
- **PRD 证据**：支持词书、阅读、听力、片段、音频、练习、3D、衣柜、场景等包；可查看大小、状态、更新、空间、暂停/恢复/删除；弱网可使用已授权内容；不能导出完整商业原始内容。
- **状态机**：PUBLISHED → AUTHORIZED → DOWNLOADING → VERIFYING → ACTIVE_LOCAL → EXPIRED/DELETED；校验失败为 VERIFYING → CORRUPTED → REDOWNLOAD_REQUIRED。
- **API/数据**：沿用 offline package/task/list/delete/space interfaces；数据为包清单、授权引用、版本、签名/hash、分片进度、设备绑定、过期时间和本地索引；下载 API 不返回未授权原始内容。
- **权限与审计**：用户只能下载自身免费/已购/已授权包；运营发布包需内容/版权/版本权限；下载、撤销授权、删除、清理和手工补授权写审计；服务端验证 entitlement。
- **异常恢复**：暂停可续传；空间不足先提示可清理项；校验失败自动清理坏分片后重下；权益过期停止使用但保留可见状态；网络失败使用退避重试，不循环耗电。
- **跨端**：App/H5/Web/PWA/iPad 按平台能力显示可下载包；小程序按平台限制隐藏不可用包；离线学习显示“已授权/仅本地/待同步”；下载不阻塞在线主链路。
- **验收**：断点续传、hash 校验、删除/再下、版本更新、授权过期、空间不足和弱网均可恢复；不存在完整商业原始包导出、跨账号复制或绕过权益。

### ATOM-INF-007 多端同步、离线事件、Checkpoint 与冲突

- **父项与缺口**：FM-INF-005～006、PRD §18/21、DS07 sync、UIUX-14/23。补充“学习结果不可丢失”和“偏好/布局可解决冲突”的差异化策略。
- **PRD 证据**：需同步计划、SRS、进度、Checkpoint、收藏、词/短语、outfit、Room、Household、权益；Checkpoint 要保存当前课程、题目、提交答案、播放位置、计时和本地事件队列；崩溃/换设备不能丢结果。
- **状态机**：本地事件 LOCAL → QUEUED → UPLOADING → APPLIED/CONFLICT/FAILED → RETRYING/RESOLVED；学习结果冲突按服务端事实优先/事件序列合并，偏好、布局按版本提示用户选择。
- **API/数据**：沿用 sync cursor、change log、checkpoint、offline event endpoints；数据为 sync_event、cursor、entity version、idempotency key、checkpoint、change log。同步包不携带不必要的原始录音、token 或完整隐私。
- **权限与审计**：只能同步当前用户或已授权房间/Household 的域；服务端校验 userId/roomId/entitlement；冲突解决、人工修复、删除传播和数据回放写审计。
- **异常恢复**：幂等重放不重复结算；游标失效执行安全全量/分段重拉；本地队列满时保护未提交学习结果并提示；冲突不能静默丢弃；服务状态恢复后后台重试。
- **跨端**：移动端、Web、iPad、PWA、H5 都有同步状态、最后同步时间和冲突入口；小程序受平台生命周期限制仍需保存本地队列；学习结果优先于视觉布局；离线可继续已授权内容。
- **验收**：杀进程、断网、切设备、重复重放、乱序、游标失效、并发修改和删除后传播均通过；Checkpoint 恢复到课程/题目/播放位置/计时合理状态；没有重复 XP、重复奖励或丢学习结果。

### ATOM-INF-008 FAQ、客服工单、内容纠错与服务状态

- **父项与缺口**：FM-INF-007～008、PRD §18/22、DS07 support/correction、UIUX-14。补充客服、纠错、投诉和系统服务状态的隔离关系。
- **PRD 证据**：FAQ 分类含功能、支付、账号、课程、Bug、版权、隐私等；工单状态为待处理、已回复、已完成、用户补充；纠错需绑定 content/question/lesson/course/appVersion/device/language/contentVersion，并经过确认、修改、二审、发布、通知。

- **异常恢复**：网络重试不重复开票/回复；附件类型/大小不合规拒绝；服务不可用显示无堆栈错误和重试入口；工单通知失败可重试；纠错被拒需给规则化原因并允许补充证据。
- **跨端**：FAQ、工单、纠错和服务状态在 App/Web/iPad/H5 可访问；弱网可查看已缓存 FAQ；后台状态发布同步用户端；不把管理员内部备注、敏感审核或完整设备指纹展示给用户。
- **验收**：工单状态、用户补充、纠错二审、发布通知、服务降级和隐私/版权升级均可追踪；客服不能绕过双审、风控或权益权限；错误页不泄露内部信息。

## 6. 商业化与 Household 原子补充

### ATOM-COM-001 免费层、VIP/SVIP、权益中心与模块门禁

- **父项与缺口**：FM-COM-001～003/009、PRD §19、DS08 entitlement、UIUX-13。补充商品、权益和模块门禁的单一事实源。
- **PRD 证据**：免费层包括基础词书、每日基础任务、部分语法/阅读、基础游戏、基础报告、每周模考；VIP 包括全词书、高级语法/更多阅读、全部游戏、高级报告、无限模考、完整错题历史、更多主题和离线；周期为月/季/年，Phase 1 默认不自动续费。
- **状态机**：权益 NOT_ENTITLED → PENDING → ACTIVE → EXPIRING → EXPIRED/SUSPENDED；校验 REQUESTED → RESOLVED → ALLOWED/DENIED。
- **API/数据**：沿用 entitlement center、hasEntitlement 和订单查询；数据为商品版本、SKU、entitlement、有效期、来源订单/Household/恢复购买、撤销原因。前端不得根据价格页本地判断。
- **权限与审计**：用户只读自己的权益和订单；商业化服务签发/撤销权益，学习模块只调用统一门禁；运营可配置商品描述但不能手改用户权益；补权/撤权写财务与管理员审计。
- **异常恢复**：权益查询超时按安全默认处理，不把待支付当已激活；订单已付但权益待处理显示待同步并可补单；撤销、退款、恢复购买幂等；门禁故障不泄露其他用户权益。
- **跨端**：价格、权益、有效期、恢复购买和退款入口按 App/H5/Web/iOS/Android/微信/支付宝平台展示；iOS 走 StoreKit，Android/H5/微信/支付宝走既有渠道；共享订阅不共享学习数据。
- **验收**：所有模块从同一 entitlement 读取；免费边界、VIP 功能、SVIP 固定权益、过期/退款/待处理和无自动续费提示一致；任何客户端改包不能越权。

### ATOM-COM-002 SKU、结算、支付渠道与订单状态

- **父项与缺口**：FM-COM-003～006/009、PRD §19、DS08 order/payment、UIUX-13。补充价格展示、渠道路由和订单状态的端到端定位。
- **PRD 证据**：支持月/季/年、微信/支付宝合法支付码、iOS StoreKit IAP；不允许绕过 App Store；订单需显示状态、总价、有效期、退款、优惠券/码和发票能力。
- **状态机**：订单 CREATED → PAYING → PAID → ENTITLEMENT_PENDING → COMPLETED；失败/超时为 FAILED，不确定为 MANUAL_REVIEW；支付尝试 INITIATED → CALLBACK_PENDING → VERIFIED/REJECTED。
- **API/数据**：沿用商品、checkout、order/detail、coupon/code、invoice、restore purchase；数据为订单、支付尝试、金额（分）、币种、渠道、SKU/version、外部交易号、entitlement reference。回调只由服务端处理。
- **权限与审计**：用户只能创建/读自己的订单并提交支付意图；财务/商业化角色读写退款、补单和对账；运营不能改金额和外部交易号；价格、折扣、支付、发票和人工处理都有审计。
- **异常恢复**：创建订单幂等；金额、SKU、签名、商户号和订单归属校验失败拒绝；支付成功但客户端没回调可从服务端查询/被动补单；超时不自动当成功；重复回调只应用一次。
- **跨端**：客户端显示服务端订单状态；支付不可用、取消、等待回调、恢复购买和退款均有明确页面；Web/PWA 不伪造 iOS IAP；小程序按平台能力隐藏不支持渠道。
- **验收**：金额以分保存且不可被客户端改写；微信 V3、支付宝 RSA2、Apple IAP 走对应验签；订单、权益、支付失败、取消、重复回调和重装恢复均可回放。

### ATOM-COM-003 退款、补单、对账、发票与异常交易

- **父项与缺口**：FM-COM-009、PRD §18/19/22、DS08 finance/reconcile、UIUX-13。补充财务闭环和“已付未权/已权未付”状态。
- **PRD 证据**：个人中心需支持订单、付款、退款、优惠券/码、发票、IAP 恢复；后台需订单、对账、退款、异常、导出；支付和虚拟权益需可审计。
- **状态机**：对账 UNMATCHED → MATCHED → RECONCILED，异常为 EXCEPTION → MANUAL_REVIEW → RESOLVED；退款 REQUESTED → REVIEWING → APPROVED/REJECTED → REFUNDED；补单 PENDING → VERIFIED → APPLIED/REJECTED。
- **API/数据**：沿用订单/退款/补单/发票/对账 API；数据为支付尝试、外部交易、订单、退款、发票、权益变更、对账批次和导出记录；所有金额使用最小货币单位。
- **权限与审计**：用户发起退款/查看状态；客服只能提交或查询，财务执行；高风险补权/退款需要既有审批/双人规则；审计包含原状态、目标状态、金额、原因、actor、外部凭证。
- **异常恢复**：外部渠道不可用进入待处理，不重复扣款/退款；部分退款/已使用权益按既有政策阻断或人工审核；导出失败可重试；对账重跑幂等且不修改原始支付事实。
- **跨端**：订单中心显示处理中、已完成、失败、退款中、已退款和权益状态；离线不可发起支付；通知只在授权渠道发送；客服、用户、后台看到同一订单状态但字段按权限裁剪。
- **验收**：成功、取消、重复回调、已付未权、已权未付、退款、补单和对账差异均能定位到外部交易号和审计；不出现重复权益、负金额或无凭证人工改账。

### ATOM-COM-004 Household 独立数据、成员生命周期与共享权益

- **父项与缺口**：FM-COM-008、PRD §19、DS08 Household、UIUX-13。补充 Household 与 Study Room 的隔离、成员隐私和名额配置。
- **PRD 证据**：Household 成员均为 18+；个人/双人/家庭/扩展名额按方案和测试配置；成员独立学习记录、SRS、错题、表达、计划、Checkpoint、收藏和隐私；共享订阅不共享详细记录；支持邀请、移除、冷却和反欺诈；iOS Family Sharing 若适用需重新校验。
- **状态机**：关系 NONE → INVITED → ACCEPT_PENDING → ACTIVE → REMOVED/COOLDOWN → EXPIRED；家庭权益 PENDING → ACTIVE → SUSPENDED/EXPIRED。
- **API/数据**：沿用 Household 创建、invite/code/link、member/remove、entitlement 和 policy check；数据为 Household、成员关系、邀请、名额配置、冷却期、反欺诈事件、共享权益引用。Study Room 使用独立 room/group 域，不复用 Household 成员记录。
- **权限与审计**：Owner 可邀请、移除、看名额和权益状态，但默认不能看成员详细学习数据；成员可退出、控制个人展示和接受/拒绝邀请；后台商业/风控角色按需查看；成员变更、冷却、策略命中和恢复均审计。
- **异常恢复**：邀请过期、重复邀请、满员、冷却、支付退款、平台家庭资格失效和账号删除都可重试/查询；移除不删除成员个人学习事实；权限撤回及时传播到缓存和离线端。
- **跨端**：App/H5/Web/iPad 显示成员槽位、独立隐私和共享权益；iOS/Android/H5/微信按渠道展示可用的家庭能力；低配不渲染家庭动画也不影响成员操作。
- **验收**：成员上限由已批准 SKU/policy 返回，API 不硬编码冲突值；Owner 看不到未经授权的详细学习记录；Study Room 与 Household 不串数据；邀请、接受、移除、冷却、退款、删除和恢复可审计。

### ATOM-COM-005 邀请、推荐、活动与固定奖励

- **父项与缺口**：PRD §18（邀请/推荐/活动）、§19、DS08 promotion/ops、UIUX-13/15。补充商业活动与成长奖励的防滥用边界。
- **PRD 证据**：可支持邀请码/链接、Study Room/Household 邀请，奖励星星、固定物品或 VIP 试用；不得现金、多级分销或借邀请刷收益；活动和促销应为固定规则。
- **状态机**：CREATED → QUALIFIED → GRANT_PENDING → GRANTED → RECONCILED；不合格/过期/风控为 REJECTED/EXPIRED/HOLD。
- **API/数据**：沿用 invite/referral/promotion、资格查询、奖励领取接口；数据为活动版本、资格事件、邀请码/链接、设备/账号关联的必要防滥用摘要、奖励账本和审计，不记录不必要的联系人信息。

## 7. CMS、双审、运营与风控后台原子补充

### ATOM-ADM-001 内容资产、版本与版权信息

- **父项与缺口**：FM-ADM-001～004、PRD §20/22、DS08 CMS、UIUX-15。补充词书、词、音频、语法、例句、阅读、听力、写作、模考、游戏包和版本的共同元数据。
- **PRD 证据**：后台管理内容对象与内容版本；需记录来源、作者、审核人、版权、时间、版本；发布/下线可追溯。
- **状态机**：DRAFT → IN_REVIEW → APPROVED → PUBLISHED → OFFLINE/ARCHIVED；被驳回为 IN_REVIEW → REJECTED → DRAFT；发布后修订生成新版本。
- **API/数据**：沿用 CMS content/version/asset API；数据为 content、content type、source、author、copyright proof、contentVersion、locale、media hash、effective time、offline time、关联课程/题目/游戏 item。
- **权限与审计**：编辑者创建/修改草稿；一审/二审分权；运营可排期但不能替换内容；发布/下线需要既有权限和审计；版权证明不可由前端上传后直接生效。
- **异常恢复**：资源校验、版权缺失、引用断裂或版本冲突阻止发布；线上回滚到上一 approved/published 版本；下线不删除已发生的学习结果，只阻止新发题/新下载。
- **跨端**：学习端只读已发布内容版本；离线包带版本和 hash；管理员 Web 需要批量、分页、筛选和长任务状态；低配不影响内容事实。
- **验收**：所有可见内容都能追到版本、来源、版权、审核和发布记录；草稿/驳回内容不进入学习端、游戏目录、Feed 或离线包；下线和回滚能同步缓存。

### ATOM-ADM-002 导入、校验、组卷与游戏内容装配

- **父项与缺口**：FM-ADM-003～004、DS08 import/exam assembly/game pack、UIUX-15。补充批量任务和引用一致性。
- **PRD 证据**：后台支持题库导入、考试组装、内容版本、游戏包和课程/阅读/听力等内容管理。
- **状态机**：UPLOADED → VALIDATING → STAGED → ASSEMBLING → SUBMITTABLE → REJECTED/EXPIRED；长任务可 PAUSED → RESUMED。
- **API/数据**：沿用 import job、validation report、assembly、preview API；数据为批次、文件 hash、字段映射、错误行、引用关系、内容版本和任务进度；结果必须绑定操作人和导入模板版本。
- **权限与审计**：编辑者上传和预览；审核者只审通过验证的版本；发布者不能绕过审核直接上线；导入、下载原文件、重跑、废弃和覆盖均审计。
- **异常恢复**：部分行失败不覆盖已发布内容；可下载错误报告后修正重导；任务重试使用批次幂等；引用缺失、重复 ID、版权缺失和敏感命中默认 fail closed。

## 9. 统一错误、权限与审计最小集

以下不是新增功能，而是所有上述原子共用的最小验收词汇；具体模块继续使用 DS06/07/08 已有错误码和权限名。

| 场景 | 最小可观察结果 |
|---|---|
| 未登录/身份过期 | AUTH_REQUIRED；不创建业务副作用 |
| 无权限/年龄或权益不满足 | FORBIDDEN 或对应业务拒绝；不泄露其他用户数据 |
| 重复写入 | IDEMPOTENCY_CONFLICT 或返回首次结果；不重复扣款、发奖、发信、计时 |
| 版本并发 | VERSION_CONFLICT；保留服务端版本，要求显式恢复/合并 |
| 规则/内容/商品过期 | STALE_RULE_VERSION 或版本兼容提示；不按旧客户端猜测放行 |
| 资源/网络异常 | Offline/Retrying/Recovery；事实源最终可查询 |
| 风控/敏感/审核中 | REVIEW_HOLD/待处理；fail closed，不伪造成功 |
| 删除/隐私请求 | 返回请求状态和范围；异步任务幂等，法律保留项明确 |
| 后台高风险操作 | 角色校验、原因、前后状态、requestId、actor、时间、版本和审计 |
