# 04 语法与句子拆分设计

> 需求溯源：PRD §2.2 语法体系、§2.3 句子拆分、mvp-scope P0。

---

## 一、功能设计

### 1.1 语法点卡片库
- **体系结构**：三级目录（词法 → 时态语态 → 句法），约 120 个语法点（第一阶段首发 60+，持续补充）。
- **卡片结构**：语法点名称、一句话规则、3–5 个分级例句（简单→进阶）、常见错误对比（错句 vs 正确句）、随堂练习入口。
- **权益分层**：基础篇（词法 + 基础时态）免费；进阶篇（虚拟语气、独立主格等）VIP。
- **学习状态**：未学/已学/已练（练习正确率 ≥80% 标记掌握）。

### 1.2 规则化语法图谱
- 语法点间"前置依赖/关联"关系由教研预制：如"现在完成时"依赖"过去分词"。
- 展示形态：树形分层展开（Medium 档以下）/ Canvas 节点图（High 档以上）；点节点跳卡片。
- 学习路径建议：按依赖关系高亮"下一步推荐学"。

### 1.3 语法练习
- **题型**：单项选择、填空（词形变换）、句型转换（主动↔被动、合并句子）。
- **出题规则**：按语法点抽题，错题自动标记该语法点为薄弱项并进入复习队列与首页推荐。
- **解析**：每题配预制解析（规则 + 考点），答错即展示。

### 1.4 句子拆分（长难句拆解）
- **内容结构**（教研预制）：原句 → 主干提取 → 修饰成分分层标注（定语/状语/从句类型）→ 中文翻译 → 拆解要点讲解。
- **学习流程**：
  1. **看示范**：逐步动画展示拆解过程（先主干后修饰，逐层高亮）；
  2. **标注练习**：给新句，用户拖拽/点选标注主干与从句类型，系统按预制答案判定；
  3. **连词成句**：打乱词块拖拽拼合法句（语法合法性由预制答案集校验）。
- **难度分级**：简单句 → 复合句 → 长难句（四六级真题级）。

### 1.5 句型积累库
- 高频句型（如 not only...but also、It is...that 强调句）：句型公式 + 3 例句 + 仿写提示。
- 支持收藏；与作文模块联动（仿写入口）。

### 1.6 边界情况
| 场景 | 处理 |
| :--- | :--- |
| 标注练习多种合法拆法 | 预制答案集收录所有合法拆法，任一匹配即对 |
| 连词成句有剩余词块 | 允许干扰词存在，判分只看已用词块合法性 |
| 图谱节点过多卡顿 | 自动切换树形分层视图（画质引擎联动） |

## 二、交互设计

### 2.1 语法学习线框

```
+----------------------------------+
| 语法中心   [卡片库] [图谱] [练习]  |
+----------------------------------+
| 词法 ▾                           |
|  ├ 名词与冠词        ✓ 已掌握     |
|  ├ 代词              ● 学习中     |
| 时态语态 ▾                        |
|  ├ 一般现在时        ✓            |
|  ├ 现在完成时        ○ 推荐学习★  |
+----------------------------------+
```

```
+----------------------------------+
| 现在完成时                        |
| 规则：have/has + 过去分词         |
| 例：I have finished my homework. |
| ⚠ 常见错误：I have went ✗ → gone ✓|
|      [开始随堂练习 10 题]          |
+----------------------------------+
```

### 2.2 句子拆分线框

```
+----------------------------------+
| 拆解示范（逐步播放）               |
| 原句：The book [that I bought]   |
|       is useful.                 |
| 主干高亮：The book is useful.     |
| 从句标注：that I bought → 定语从句 |
|  [▶ 重播]  [我来试试 →]           |
+----------------------------------+
| 标注练习：                        |
| 请点选主干谓语：                  |
| [句子词块可点选，选中变色]         |
|  [提交判定]                       |
+----------------------------------+
```

### 2.3 关键交互细节
- **拆解动画**：主干先加粗变色 → 修饰成分逐层括注（High 档流光描边，低档分步显示）；支持手动步进。
- **连词成句**：词块磁吸到答案槽，错误位置抖动提示；整句判定通过时句子朗读一遍。
- **错题反馈**：答错展示预制解析卡（不超过 3 屏），底部"加入复习"自动勾选。
