## 3. 本地 UI 套件规则

1. 页面必须能在本地浏览器打开，不能依赖外部设计文件才能理解或演示。
2. tokens.css 是视觉令牌入口，颜色、间距、圆角、阴影和动效时序不得在页面中随意漂移。
3. 每个页面族必须覆盖 Default、Loading、Empty、Error、Offline、Completed 等基础状态。
4. Session、录音、音频、支付、同步冲突和权限流程必须补充各自的特殊状态。
5. 交互稿中的主按钮、Tab、筛选、Sheet、Dialog、播放、录音和恢复入口必须真正更新本地 UI 状态。
6. 手机稿只保留一个主滚动容器，内容不得越过 iPhone 设备壳圆角、安全区、通知岛和 Home Indicator。
7. 移动端、Pad、Web 使用同一信息架构，但按视口重排导航和内容密度。
8. 所有复杂动效提供 prefers-reduced-motion 降级；低配模式下仍能完成学习闭环。

## 4. 后续生成顺序

### P0-1：首日与每日学习闭环

欢迎/登录、18+、目标、测评、计划、首页、断点续学、SRS、错题修复、统一反馈。

### P0-2：内容与平台服务

听力、阅读、跟读、写作、Checkpoint、CET、学习报告、消息、设置、隐私、客服、下载、同步和支付状态。

### P1：成长与扩展

Avatar、衣柜、奖励箱、收藏、排行榜、Study Room、3D/地图增强和更复杂的成长动效。

每完成一组页面，先在浏览器做视觉与交互回归，再更新状态记录，最后再迁移到 Vue3/uni-app。

## 5. 验收标准

- 页面在 390×844、440×956、1024×768 和 1280×800 等视口下稳定；
- 浅色/深色切换后文本、边框、状态色和图标仍有足够对比度；
- 无横向溢出、嵌套滚动条、圆角越界或关键文字裁切；
- 主要操作满足 44pt 触控尺寸，并有可访问名称；
- 至少验证一个成功路径和一个异常恢复路径；
- Browser 截图与交互检查通过后，才把页面标记为完成；
- 本地 HTML 是可交付的 UI 稿件，不是静态截图；关键控件必须可操作。

## 6. 当前结论

本项目已经从外部设计文件同步切换为本地 HTML UI 套件优先。后续页面设计、视觉打磨、交互演示和多端响应式验证均在本地完成；生产代码仍遵循仓库规定的 Vue3 + TypeScript + uni-app 技术边界。
