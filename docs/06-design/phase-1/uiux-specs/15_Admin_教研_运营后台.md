## 2. Dashboard

关键指标：
- DAU
- 新增
- 次日/7日留存
- 学习分钟
- 完课率
- Streak分布
- VIP转化
- 崩溃率

学习质量：
- 最易错知识点
- 内容纠错量
- Checkpoint通过率

---

## 3. 内容编辑

表格：
- ID
- 标题
- 类型
- 来源
- 版权状态
- 状态
- 版本
- 修改人
- 更新时间

状态：
`草稿 → 一审 → 二审 → 发布 → 下线`

---

## 4. 3D资产管理

字段：
- Asset ID
- 名称
- 分类
- 品质
- 缩略图
- 模型包
- 性别/体型兼容
- 来源
- 状态

按钮：
- 新建
- 预览
- 发布
- 下线

---

## 5. 奖励箱配置

必须双人审核。

字段：
- 箱子版本
- 生效时间
- 获得来源
- 品质概率
- 具体物品池

UI必须实时校验：
> 概率合计 = 100%

按钮：
- `预览规则`
- `提交审核`

不允许线上未审直接改概率。

---

## 6. 消息中心后台

模板：
- Event Type
- 站内
- Push
- SMS
- Email
- Deep Link

支持灰度、频控、用户偏好过滤。

## 7. 客服

工单列表：

## 8. 运营权限

角色：
- 超级管理员
- 教研
- 一审
- 二审
- 运营
- 客服
- 财务
- 技术运维

- 概率变更
- 权益补发
- 退款
- 用户冻结
- 内容下线

必须写审计日志。
