## 2. 顶部 Global Header

移动端顶栏根据页面变化，Home 建议显示：

左：
- 用户 3D 头像快照（点击进入“我的空间”）

中：
- 当前课程 / 页面标题

右：
- Streak 火焰
- 星星余额
- 消息铃铛

避免同时显示 XP、VIP、货币、通知 5 个以上状态。

## 5. 返回逻辑

学习 Session 内：
- 左上角关闭 `×`
- 点击弹确认：
  - “暂时离开”
  - “继续学习”
- 已完成答案即时本地保存

普通页面：
- 系统返回遵循栈

支付、账号合并、注销等不可逆页面：
- 返回时明确提醒

---

## 6. Modal 使用原则

Modal 仅用于：
- 危险确认
- 关键权限说明
- 获得重大成就
- 支付结果

普通筛选、详情：
- 使用 Bottom Sheet

---

## 7. 空状态统一

每个空状态包含：
1. 图形
2. 说明
3. 一个主 CTA

例：

> 还没有收藏句子  
> 在阅读或听力中长按句子，就能加入表达库。  
> [去阅读]

---

## 8. Skeleton

首页、课程、词表、成员列表：
- 使用 Skeleton
- 禁止全页长期 Spinner

按钮提交：
- 按钮内 Loading
- 防重复提交

## 9. Feature Flag

Phase 1 P1 功能未开启时：
- 不显示灰色不可用按钮
- 直接隐藏
- 只有正式预告活动才允许显示“即将上线”

Phase 2 AI / Phase 3 K12：
- 第一阶段 UI **完全不展示**
