# 20｜三套 UI 视觉方向与跨端展示稿

> 状态：Concept Review  
> 日期：2026-08-20  
> 当前预览：../mockups/complete-ui-ux-command-center.html（Aurora UI Suite；历史方向稿仅保留作回溯参考）

## 1. 本轮目标

本轮不是冻结设计系统，而是给产品选择视觉气质：

1. 学习者第一眼感受到什么；
2. 学习任务和游戏化元素的比例如何；
3. Mobile、Pad、Web 是否共享同一套信息结构；
4. 动效应该服务于反馈、导航还是沉浸。

三套稿件都使用同一组学习内容：

    今日任务 → 继续学习 → 练习/修复 → 进度反馈 → 学习世界

因此可以直接比较视觉语言，而不会因为页面内容不同造成误判。

## 3. 三套方向

### A｜极光星图 Aurora Orbit

**关键词**：星海、路径、柔光、探索、掌握感。

- 深色底 + 蓝紫极光；
- 学习地图用轨道节点表达知识路径；
- 主任务卡使用带光晕的渐变，但正文保持高对比；
- 适合首页、学习世界、成长和阶段解锁；
- 风险是沉浸感过强时会抢走学习任务的注意力。

**建议动效**：

- 当前节点轻微呼吸；
- 任务完成时路径点亮；
- 进入页面时只做一次低幅度淡入；
- 禁止无限粒子和持续闪烁。

### B｜纸页专注 Editorial Calm

**关键词**：成年、可靠、安静、阅读、长期坚持。

- 暖白纸张色 + 深墨绿；
- 采用编辑式标题、清晰的学习进度和留白；
- 练习卡更像“学习计划页”，减少游戏化装饰；
- 适合词汇、语法、阅读、报告和个人中心；
- 风险是世界探索和奖励感偏弱，需要用少量品牌蓝/暖金补足。

**建议动效**：

- 卡片错位 4px 的轻入场；
- 任务完成后用进度线和数字变化表达反馈；
- Bottom Sheet 使用纸页上推；
- 默认不使用复杂背景动画。

### C｜任务舱 Neon Mission

**关键词**：挑战、计时、能量、关卡、即时反馈。

- 深色网格底 + 青绿色和暖橙色状态色；
- 任务卡像任务面板，强调倒计时、队列和完成条件；
- 适合 Checkpoint、CET 模拟、错题修复和阶段挑战；
- 风险是高频使用会产生疲劳，不能成为所有学习页面的默认皮肤。

**建议动效**：

- 进入挑战时显示一次扫描线；
- 答对/完成时用短促的状态脉冲；
- 计时和进度变化使用数字平滑过渡；
- Performance 画质下关闭网格流动和光晕。

## 4. 三端结构映射

| 端 | A 极光星图 | B 纸页专注 | C 任务舱 |
| --- | --- | --- | --- |
| Mobile | 单列任务流 + 底部五 Tab | 单列学习计划 + 固定主 CTA | 单列任务面板 + 进度 HUD |
| Pad | 左侧导航 + 中央任务 + 地图卡 | 左侧章节 + 中央阅读/练习 + 右侧进度 | 左侧任务队列 + 中央挑战区 + 右侧计时 |
| Web | 左导航 + 中央首页 + 右侧队列摘要 | 左导航 + 宽内容列 + 右侧学习统计 | 左导航 + 中央任务台 + 右侧事件日志 |

三种方向共享以下一级导航：

    学习 / 练习 / 世界 / 课程 / 我的

不因为换肤而改变用户已经学会的导航位置。

## 5. 动效与性能硬规则

- 核心学习页面优先 CSS/uni-app 原生动画；
- 3D、WebGL 和粒子只出现在学习世界或明确的沉浸场景；
- 每个动画必须说明“它表达了什么状态变化”；
- 所有循环动画都要响应 prefers-reduced-motion 和性能等级；
- 低配模式至少保留颜色、文字、进度和结果，不依赖动画才能理解；
- 单次进入动效建议 160–280ms，任务反馈建议 220–420ms；
- 不使用会造成眩晕的视差、快速闪烁或大面积弹跳。

## 6. 当前建议

如果产品要长期服务成人学习者，建议采用混合策略：

    B 纸页专注作为学习正文默认
      + A 极光星图作为首页/世界/成长层
      + C 任务舱作为 Checkpoint/模考/修复模式

这比让一套高刺激视觉覆盖所有页面更稳妥：

- B 负责可信、清晰和持续使用；
- A 负责品牌记忆和探索动机；
- C 负责短时挑战与完成反馈。

## 7. 评审时请重点比较

- 哪一套让“今天该做什么”最清楚；
- 哪一套最像 18+ 用户愿意长期使用的产品；
- 哪一套的动效最有帮助而不是最热闹；
- 在 Mobile 和 Web 之间切换时，哪一套最不容易迷路；
- 是否接受 B/A/C 的混合，而不是只选一套全局皮肤。
