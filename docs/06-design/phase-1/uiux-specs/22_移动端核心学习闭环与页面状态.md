## 1. 目标与设计边界

本稿把 Phase 1 的核心学习能力收束为一条可以连续完成、可以中断恢复、可以解释下一步的学习闭环：

```text
首次启动
  → 目标与时间
  → 可选规则化测评
  → Study Plan
  → Adaptive Home
  → Continue Learning
  → 词汇 / 练习答题
  → 即时反馈
  → SRS / 薄弱点复习
  → 日报 / 周报 / 月报
  → 回到下一次学习
```

### 1.1 体验目标

1. 用户打开产品后 3 秒内知道今天该做什么。
2. 每个学习页面只有一个明确的主动作，次要动作不抢主焦点。
3. 用户离开、切换设备或网络中断后，可以从最近安全检查点恢复。
4. 每次答题反馈都能解释“哪里错、为什么错、下次何时复习”。
5. 复习量过载时，系统提供可控的减负路径，不用连续打卡羞耻或惩罚式文案。
6. 结果只描述本次训练和当前状态，不把一次正确率宣称为永久掌握，也不把自研模拟结果宣称为官方成绩。

### 1.2 Phase 1 边界

- 测评、推荐、评分、复习排程使用确定性规则；不出现 AI Tutor、AI 评分、AI 实时陪练或生成式解释。
- 不展示 K12、未成年人注册或“高考提分”入口。
- 学习结果使用“暂时修复、待复测、稳固、即将遗忘”等可解释状态，不使用“永久掌握”。
- 颜色只辅助表达状态，正确/错误必须同时有文字、图标或结构变化。
- 动效、声音、触觉只表达状态变化，不制造赌场式刺激。

## 2. 通用页面模板与状态词典

所有核心页面按以下模板交付，页面路由、接口契约和埋点由实现 agent 依据此模板落地；本稿不替代 `packages/contracts/` 中的 API 契约。

```text
[页面编号]
页面名称：
用户目标：
进入入口：
主按钮：
次按钮 / 危险操作：
信息层级：
页面状态：
异常与恢复：
权限要求：
可访问性：
Mobile / Pad / Web 差异：
Deep Link：
埋点：
```

### 2.1 通用页面状态

| 状态 | 用户看到什么 | 必须提供的动作 | 说明 |
|---|---|---|---|
| `loading` | 骨架屏保留页面结构，按钮显示加载 | 等待；可安全取消时提供取消 | 禁止长时间全页 Spinner |
| `ready` | 数据完整，主按钮可用 | 完成页面主任务 | 默认状态 |
| `in_progress` | 进度、已完成量、恢复入口 | 继续 / 暂停 / 退出 | 已写入最近安全检查点 |
| `completed` | 完成结果和下一步 | 进入后续复习或回首页 | 结果必须可追溯 |
| `empty` | 图形、原因说明、一个主 CTA | 去探索 / 去创建 / 返回 | 不使用“暂无内容”结束路径 |
| `offline` | 上次同步时间、可离线内容范围 | 重试同步 / 继续离线 | 不伪装为已保存 |
| `error` | 简短原因、错误编号可折叠 | 重试 / 返回安全页 | 保留已保存进度 |
| `stale` | 内容或计划已更新的提示 | 使用最新版本 / 查看变化 | 不静默覆盖用户进度 |
| `locked` | 锁定原因和解锁条件 | 去完成前置任务 | 不展示无效主按钮 |
| `permission` | 权限用途、时机和拒绝后的替代方案 | 允许 / 稍后 | 首次启动不连续索要权限 |

### 2.2 全局交互基线

- Mobile 主内容为单列流；学习 Session 使用固定底部操作区，并为安全区预留 `env(safe-area-inset-bottom)`。
- 主按钮最小高度 48px；图标按钮点击区域至少 44×44px；关键区域不以 hover 作为唯一反馈。
- 练习或测评中点击系统返回、关闭或切换 Tab 时，先保存当前答案，再弹出“暂时离开 / 继续学习”确认。
- 普通详情、筛选、推荐原因使用 Bottom Sheet；危险操作、支付、注销使用 Dialog。
- 所有提交按钮防重复点击；Loading 在按钮内部表达，完成后短暂显示 Success 状态。
- 内容、答题、音频位置和复习结果以“最近安全检查点”为恢复边界；未到安全点的输入可提示“尚未保存”。

## 3. 三端共同信息架构

### 3.1 Mobile 五 Tab

```text
学习      练习      世界      课程      我的
Home    Practice   World    Courses     Me
```

核心学习闭环的主入口固定在“学习”和“练习”：

- **学习**：Adaptive Home、Continue Learning、Study Plan、学习地图。
- **练习**：今日优先、Quick Practice、Mistake Repair、SRS、Checkpoint、CET 训练。
- **我的**：报告、计划调整、同步状态、通知与设置。

### 3.2 Pad / Web 扩展

Pad 和 Web 不改变 Mobile 的任务优先级，只扩展空间：

| 端 | 主要布局 | 固定区域 | 不能改变的优先级 |
|---|---|---|---|
| Mobile / H5 | 单列 + 底部五 Tab + 底部主 CTA | 顶部进度、底部 CTA | 当前任务 > 复习风险 > 探索 |
| iPad | 左侧导航 + 中央主任务 + 右侧上下文 | 左侧导航、顶部状态 | 中央只保留一个主学习焦点 |
| Web | 左侧全局导航 + 中央内容 + 右侧摘要 | 左侧导航、右侧队列/历史 | 右侧不重复中央主卡 |

### 3.3 共用视觉与内容层级

1. 页面标题 / 当前阶段。
2. 当前学习目标或主问题。
3. 进度与风险状态。
4. 主按钮。
5. 解释、详情、历史等次级信息。

使用极光星图视觉语言时，品牌渐变只用于首页主任务、学习地图关键区域、关键完成态；词汇和答题正文保持低密度、高对比、少装饰。

## 4. ONB｜Onboarding 新用户入门

### ONB-01 欢迎与账号入口

**页面名称**：Welcome / Start  
**用户目标**：理解产品价值，开始建立学习计划或登录已有进度。  
**进入入口**：首次启动、退出账号后启动、未完成 onboarding 的 Deep Link。  
**主按钮**：`开始学习`  
**次按钮**：`已有账号，登录`；底部 `用户协议`、`隐私政策`。  
**信息层级**：一句价值主张 → 面向成人的服务边界 → 开始 / 登录。

**页面状态**：

| 状态 | 表现与动作 |
|---|---|
| 首次未开始 | 主按钮可用；不提前弹通知、麦克风、相册或定位权限 |
| 已有草稿 | 显示“继续设置你的学习计划”；主按钮为 `继续设置` |
| 登录加载 | 登录按钮内 Loading，其他入口暂时禁用 |
| 登录失败 | 保留输入，显示可读错误和 `重试`；提供 `稍后浏览介绍`（不创建学习进度） |
| 离线 | 允许阅读介绍；需要账号或同步的动作标注“联网后继续” |

**异常与恢复**：登录中断不得清除 onboarding 草稿；重新打开后回到最近完成步骤。  
**权限要求**：无。  
**可访问性**：价值主张为页面 H1；协议链接可顺序聚焦；真实 `button` 和 `a` 语义，不用可点击 `div`；背景动效支持减少动态效果。  
**Mobile / Pad / Web 差异**：

- Mobile：单列、底部固定主按钮，主视觉不超过首屏 40%。
- Pad：左右分栏，左侧价值说明，右侧入门卡；主按钮仍只有一个。
- Web：中央窄内容列，允许展示更完整的协议摘要和登录方式，但不增加新学习选项。

**Deep Link**：`/onboarding/welcome`。  
**埋点**：`onboarding_view`、`onboarding_start`、`login_start`、`onboarding_resume`。

### ONB-02 年龄与服务边界确认

**页面名称**：18+ Confirmation  
**用户目标**：确认符合 Phase 1 服务边界。  
**进入入口**：`开始学习` 后。  
**主按钮**：`确认并继续`  
**次按钮 / 危险操作**：`返回`；不提供绕过年龄限制的替代入口。  
**核心控件**：出生年份选择或年龄确认；勾选“我已满 18 岁”。

**页面状态**：

| 状态 | 表现与动作 |
|---|---|
| 未填写 | 主按钮 Disabled，错误说明不依赖颜色 |
| 已确认 | 写入确认时间和版本，进入学习目标 |
| 未满 18 岁 / 无法确认 | 说明当前阶段仅服务 18+；主按钮为 `返回` 或 `结束设置` |
| 年份不合理 | 输入框下说明原因，保留用户选择 |
| 保存失败 | 提供 `重试`；不进入后续页面 |

**异常与恢复**：年龄确认写入失败时不得仅在本地显示已确认；恢复后从本页继续。  
**可访问性**：年份选择有可读标签；Checkbox 可通过键盘和读屏操作；禁止只用红框表示未通过。  
**三端差异**：Mobile 使用全屏单列和底部 CTA；Pad / Web 使用中央确认卡，明确展示服务边界但不增加营销内容。

**Deep Link**：`/onboarding/age`。  
**埋点**：`age_confirmation_view`、`age_confirmation_success`、`age_confirmation_restricted`。

### ONB-03 目标、每日时间与计划偏好

**页面名称**：Goal & Routine  
**用户目标**：选择一个主要学习方向、可接受的每日时间和每周学习天数。  
**进入入口**：年龄确认后；用户在“我的 → 学习计划”重新设置时复用。  
**主按钮**：`下一步`  
**次按钮**：`跳过，稍后设置`（仅允许跳过偏好，不跳过年龄确认）。

**建议选项**：成人零基础、日常交流、CET-4、CET-6、阅读提升、听力提升、口语自练、写作提升、旅行、商务入门；每日 5 / 15 / 30 / 45 分钟；每周 3–7 天。该时长档位仅作为 v2 当前 canonical 入口的展示口径，具体配置仍以版本化契约为准。

**页面状态**：

| 状态 | 表现与动作 |
|---|---|
| 未选择 | `下一步` Disabled，并说明“先选择一个主要目标” |
| 已选择 | 卡片 Radio 有选中语义和文字状态；可继续选择时间 |
| 多目标 | 允许最多 3 个，明确一个“主要目标” |
| 保存中 | 页面选择保留，按钮 Loading，禁止重复提交 |
| 目标不可用 | 隐藏未开启的 Feature Flag，不显示灰色假入口 |

**异常与恢复**：网络失败时保留本地草稿，提示“联网后生成计划”；不得把默认目标静默写入用户档案。  
**可访问性**：目标卡使用 `radio` / `checkbox` 语义；选中态同时使用边框、勾选图标和文字；卡片与文字均可点击。  
**三端差异**：Mobile 每屏最多一组选择；Pad / Web 可分两列显示目标与时间，但主按钮固定在内容区底部或右下方。

**Deep Link**：`/onboarding/preferences`。  
**埋点**：`goal_selected`、`daily_time_selected`、`routine_saved`、`onboarding_skip_preferences`。

### ONB-04 第一课与权限延后

**页面名称**：First Lesson Handoff  
**用户目标**：在不被权限打断的情况下开始第一项可完成学习。  
**进入入口**：Study Plan 创建成功后；也可从测评跳过结果页进入。  
**主按钮**：`开始第一课`  
**次按钮**：`先看看计划`。

**页面状态**：计划生成中显示阶段性进度；计划已生成显示课程、预计时长和完成条件；首课完成后再申请通知权限。  
**异常与恢复**：课程内容加载失败保留计划，主按钮变为 `重试加载`；无可用首课时提供 `返回学习首页`。  
**可访问性**：主按钮文案包含预计时间；不以自动播放音频作为必需入口。  
**三端差异**：Mobile 进入一屏一任务；Pad / Web 可在右侧显示计划阶段，但中央仍只突出第一课。

## 5. AS｜规则化水平测评

### AS-01 测评说明与开始

**页面名称**：Assessment Intro  
**用户目标**：理解测评用途、题型、预计时间和可跳过影响。  
**进入入口**：Onboarding；`我的 → 重新测评`；计划调整时主动触发。  
**主按钮**：`开始测评`  
**次按钮**：`稍后再测`。

**信息层级**：预计 8–12 分钟 → 覆盖词汇识别、语法、阅读、听力 → 不显示即时总分 → 可稍后重测。

**页面状态**：

| 状态 | 表现与动作 |
|---|---|
| 未开始 | 显示预计题量和规则说明 |
| 已有未完成测评 | 主按钮为 `继续测评`，显示最近题号和保存时间 |
| 测评已过期 | 说明题库版本变化，提供 `使用新版本继续` 或 `重新开始` |
| 设备不支持音频 | 说明听力部分需联网/音频能力；可跳过听力并标记结果不完整 |
| 完全跳过 | 进入默认起点计划；首页提示“完成测评可优化计划”但不持续打扰 |

**异常与恢复**：测评退出前自动保存当前题和已提交答案；草稿不等同于已完成结果。  
**可访问性**：说明页可被读屏完整朗读；明确“测评不是考试”；键盘可操作开始、跳过和返回。  
**三端差异**：Mobile 单列；Pad / Web 左侧说明、中央开始卡；Web 允许使用键盘快捷键但不隐藏按钮。

**Deep Link**：`/assessment/intro`。  
**埋点**：`assessment_view`、`assessment_start`、`assessment_resume`、`assessment_skip`。

### AS-02 测评题目

**页面名称**：Assessment Question  
**用户目标**：在低压力、无即时总分干扰的条件下完成题目。  
**进入入口**：`开始测评` / `继续测评`。  
**主按钮**：`确认`；最后一题为 `完成测评`。  
**次按钮**：`退出测评`、`标记稍后检查`（仅对允许回看的题型）。

**布局规则**：顶部显示 `12 / 30` 进度、阶段名称和退出入口；中央一次只显示一个主问题；底部固定确认区。选择题整行可点，输入题有明确焦点，听力题把播放按钮放在题干附近。

**状态**：

| 状态 | 表现与动作 |
|---|---|
| 未作答 | `确认` Disabled；提示需要选择或输入，不批评用户 |
| 已作答未提交 | 允许修改；不在此时显示对错 |
| 提交中 | 锁定当前题，显示按钮内 Loading |
| 已提交 | 进度前进；只在必要时显示轻量“已记录” |
| 自动保存 | 顶部显示“已保存”或最近保存时间 |
| 音频加载中 | 播放按钮 Skeleton；提供重试，不跳过并假装完成 |
| 网络中断 | 若题目和答案已缓存，允许继续；否则进入离线提示页 |

**异常与恢复**：重复提交只计一次；切换后台回来校验当前题版本；跨设备冲突以最近安全检查点为默认，并允许查看冲突时间。  
**可访问性**：倒计时若存在必须提供“还剩多久”的可读文本，不使用闪烁；播放、重播、标记、退出均有 `aria-label`；拖拽/重排题提供点击式替代；Web 支持 Tab、Enter/Space 和可见焦点。  
**三端差异**：

- Mobile：题干与选项单列，底部 CTA 随键盘上移，不能被系统手势区遮挡。
- Pad：允许题干与辅助信息左右分栏，底部 CTA 仍固定在主内容列。
- Web：可显示题号侧栏和键盘提示；侧栏不替代顶部进度，提交逻辑保持一致。

**Deep Link**：`/assessment/session/:sessionId`。  
**埋点**：`assessment_answer_saved`、`assessment_question_submitted`、`assessment_audio_retry`、`assessment_exit_confirmed`。

### AS-03 测评结果与 Study Plan

**页面名称**：Assessment Result / Plan Proposal  
**用户目标**：理解当前起点，并选择生成一个可执行的学习计划。  
**进入入口**：完成测评；测评从历史记录打开时为只读。  
**主按钮**：`生成学习计划`  
**次按钮**：`稍后再说`、`调整计划`。

**内容**：语学星等级、参考 CEFR、预估词汇量、词汇/语法/阅读/听力能力卡；所有等级旁标注“规则化测评参考”，不制造官方认证感。

**状态**：

| 状态 | 表现与动作 |
|---|---|
| 计算中 | 显示“正在整理答题结果”，保留已完成提示 |
| 结果可用 | 展示能力卡和计划建议，主按钮可用 |
| 结果不完整 | 标出缺失维度，允许生成基础计划并提示重新测评 |
| 生成中 | 按钮 Loading；禁止重复生成 |
| 生成失败 | 保留结果，提供 `重试生成` 和 `先用默认计划` |
| 稍后处理 | 回到 Home；计划区域显示“待生成”，主 CTA 为 `生成计划` |

## 8. PRA｜练习答题 Session

### PRA-01 练习准备与队列确认

**页面名称**：Practice Session Setup  
**用户目标**：在开始前知道来源、题量、预计时长和完成条件。  
**进入入口**：Practice Hub 今日优先、Quick Practice、能力入口、Mistake Repair、Checkpoint。  
**主按钮**：`开始练习` / `开始修复`。  
**次按钮**：`为什么推荐给我？`、`调整题量`、`返回`。

**状态**：

| 状态 | 表现与动作 |
|---|---|
| 队列可用 | 显示来源、数量、预计时间、训练路径 |
| 队列不足 | 说明实际数量，提供补充模块或按现有量开始 |
| 队列为空 | 提供 `去课程` / `查看已完成内容`，不显示无效开始按钮 |
| 生成中 | 进度式 Skeleton，说明正在整理规则队列 |
| 规则服务失败 | 使用缓存队列或返回 Practice Hub，并提供重试 |
| 已完成 | 显示结果入口，不重复创建同一 session |

**可访问性**：题量和预计时间为文本；“为什么推荐”是可聚焦按钮；自定义题量用 Slider 时同时提供数值输入或步进按钮。  
**三端差异**：Mobile 用底部确认卡；Pad / Web 左侧队列来源、中间训练路径、右侧确认摘要。

### PRA-02 通用练习答题页

**页面名称**：Practice Question  
**用户目标**：完成当前题目并获得可解释的反馈。  
**进入入口**：练习准备页、Continue Learning、Checkpoint。  
**主按钮**：未提交时为 `确认答案`；需要下一题时为 `下一题`；最后一题为 `查看反馈`。  
**次按钮**：播放、重播、标记、查看提示、退出。

**题型适配**：

| 题型 | 主交互 | 必须提供的替代操作 |
|---|---|---|
| 选择题 | 整行选项 + 确认 | 键盘方向键/Tab + Enter |
| 拼写 | 输入框 + 确认 | 显示音标、重播音频 |
| 词块重排 | 点击词块组成答案 | 不依赖拖拽，支持“加入答案区 / 移回” |
| 听力 | 播放、重播、作答 | 音频文字替代或说明不可用 |
| 阅读 | 段落 + 题目 | 字号、行距、朗读顺序可调 |
| 语法 / 变式题 | 规则回顾 + 单题作答 | 解释入口在提交后展开 |

**状态**：

| 状态 | 表现与动作 |
|---|---|
| 未作答 | 主按钮 Disabled；说明下一步要求 |
| 已作答 | 可修改，显示选中态，不提前显示对错 |
| 提交中 | 当前题锁定，按钮内 Loading |
| 正确 | 进入反馈态，显示 ✓ 和“回答正确”文字 |
| 错误 | 进入反馈态，显示 ×、错因/规则入口和下一步 |
| 猜对 / 模糊 | 允许用户在反馈阶段标记信心，影响复习间隔 |
| 已标记 | 题号或顶部显示标记状态；不改变正确率 |
| 自动保存 | 顶部显示已保存时间；刷新后从安全点恢复 |
| Session 完成 | 进入反馈页，不自动跳回 Home |

**异常与恢复**：

- 双击提交只计一次，等待时禁止重复操作。
- 键盘弹出时底部 CTA 上移，输入框始终可见；关闭键盘后恢复安全区间距。
- 音频失败允许重试；若文字可替代，明确标注“本题按文字完成”。
- 网络中断时允许完成已缓存题，提交结果标为“待同步”；未缓存下一题不展示假进度。
- 内容版本变化时保存当前答案，提示使用新版本或返回安全检查点。

**可访问性**：

- 题干、选项、当前题号、保存状态、反馈状态均有语义顺序。
- 错误不只依赖红色；提供文字错因、规则回顾和下一步按钮。
- 点击区域最小 44px；焦点可见；禁用态仍可被读屏解释原因。
- Web 支持 Tab / Shift+Tab / Enter / Space；Mobile 不把拖拽作为唯一操作。
- 减少动态效果时保留题号、状态文字和进度数值；不通过震动表达唯一结果。

**三端差异**：

- Mobile：单列、一屏一个主要问题、底部固定 CTA；底部 Tab 在 Session 中隐藏，避免误离开。
- Pad：题干和上下文可左右分栏，操作区固定在中央内容底部。
- Web：可增加题号导航、答题记录和键盘提示；右侧信息不允许抢走主题目焦点。

**Deep Link**：`/practice/session/:sessionId/question/:questionId`。  
**埋点**：`practice_question_view`、`practice_answer_change`、`practice_answer_submit`、`practice_question_mark`、`practice_exit`。

### PRA-03 Checkpoint / CET 专注模式

**页面名称**：Checkpoint / Mock Practice

**用户目标**：理解本题结果和下一步，而不是只看到“对/错”。  
**进入入口**：PRA-02 提交后；词汇熟悉度提交后使用轻量版本。  
**主按钮**：`下一题`；修复流程最后一题为 `查看本次结果`。  
**次按钮**：`查看解释`、`标记为模糊`、`报告内容有误`。

**反馈内容顺序**：结果状态 → 正确答案 / 用户答案 → 一句话错因或规则 → 例句/变式 → 下次复习时间（若已计算）。

**状态**：

| 状态 | 表现与动作 |
|---|---|
| 正确 | 成功描边、✓、文字“回答正确”；不全屏庆祝 |
| 错误 | 错误描边、×、错因和正确路径；提供修复入口 |
| 猜对 / 信心低 | 显示“答对但信心较低”，建议缩短复习间隔 |
| 内容有误 | 允许报告并继续，不把用户答案标记为错误 |
| 解释加载中 | Skeleton 只占解释区，先显示结果和下一题 |
| 结果保存中 | 显示“正在保存本次结果”，下一题按钮防重复 |
| 保存失败 | 提示“结果尚未同步”，提供 `重试保存`，不伪装完成 |

**可访问性**：反馈状态用文字和图标；错误解释自动聚焦到标题但不抢走用户上下文；屏幕阅读器先读“回答错误”，再读正确答案和错因；颜色对比符合正文可读性。  
**三端差异**：Mobile 使用底部反馈面板，下一题固定；Pad / Web 右侧显示解释，中央保留题目对照；Web 可折叠规则详情。

### FB-02 Session 完成结果

**页面名称**：Practice Result / Repair Result  
**用户目标**：知道完成了什么、哪些点暂时修复、下次何时复习，以及现在最值得做的下一步。  
**进入入口**：练习、Mistake Repair、词汇 Session、Checkpoint / CET 提交后。  
**主按钮**：根据结果只保留一个：`继续今日学习`、`修复 X 个薄弱点` 或 `加入后续复习`。  
**次按钮**：`查看完整结果`、`返回首页`、`调整计划`。

**固定结果结构**：

```text
完成量 / 用时 / 正确率
  → 暂时修复数量
  → 仍需帮助的薄弱点
  → 下一次复习时间
  → 唯一推荐下一步
```

**状态**：

| 状态 | 主要文案与动作 |
|---|---|
| 正常完成 | “已完成 7 个练习点”；显示暂时修复和待复测 |
| 部分完成 | 显示已完成量与剩余量；主按钮 `继续完成` |
| 无正确答案 | 不使用“失败”；说明“这组内容仍需复习”，主按钮 `开始修复` |
| 修复完成待复测 | “将在 X 天后再次检查”；主按钮 `继续今日学习` |
| 结果保存中 | 结果骨架 + 保存状态；暂不显示最终 XP |
| 结果保存失败 | 显示本地记录状态和 `重试同步`；允许安全离开但标明未同步 |
| 结果不可计算 | 显示已完成题量，隐藏未确认的正确率，提供重试 |
| Checkpoint 通过 | 显示解锁的下一阶段；主按钮 `继续下一阶段` |
| Checkpoint 未通过 | 显示薄弱维度；主按钮 `先修复薄弱点` |

**奖励呈现**：XP、Streak、勋章放在结果的次级区域；不盖住学习结果，不使用赌博式闪烁；可关闭声音和动效。  
**考试声明**：CET 自研模拟结果必须显示“本结果为语学星自研模拟训练结果，不是官方成绩”。  
**可访问性**：图表与数字提供列表替代；结果标题包含完成状态；主 CTA 在首屏可达；动效完成后仍保留静态结果。  
**三端差异**：Mobile 先结论后详情，固定底部主 CTA；Pad / Web 使用结果总览 + 维度详情 + 复习队列三栏/两栏布局。

**Deep Link**：`/practice/result/:sessionId`、`/practice/repair/result/:sessionId`。  
**埋点**：`practice_result_view`、`repair_next_click`、`review_schedule_view`、`result_sync_retry`、`checkpoint_unlock_click`。

## 10. RV｜复习与薄弱点修复

### RV-01 今日复习队列

**页面名称**：Review Queue  
**用户目标**：按可承受的量完成到期复习，并理解每项为何被安排。  
**进入入口**：Home 到期复习卡、Practice Tab、反馈结果、通知。  
**主按钮**：`开始今日复习` 或积压时的 `完成今日可控量`。  
**次按钮**：`为什么现在复习？`、`调整复习量`、`只复习我的生词`。

**队列排序**：高风险遗忘 → 连续错误 → Checkpoint 未掌握 → 最近错题 → 普通到期内容。排序规则在解释 Sheet 中可读，不以消费、会员或活跃时长作为学习优先级。

**状态**：

| 状态 | 表现与动作 |
|---|---|
| 正常到期 | 显示数量、预计时间、来源 |
| 复习积压 | 显示总量与今日建议量；提供三种减负路径 |
| 复习中 | 显示进度和最近保存时间，可暂停 |
| 今日完成 | 显示完成量、下次复习时间、回首页入口 |
| 没有到期内容 | 提供新词或自由练习，不强迫用户继续 |
| 排程暂不可用 | 使用上次排程并标注日期，提供重试 |
| 离线 | 已下载词条可复习，结果待同步 |

**积压保护**：

1. `按今日建议量完成`：优先高风险内容，其余自动延期。
2. `增加每日量，保持目标日期`：展示预计额外分钟。
3. `减少每日量，延后目标日期`：展示新的计划日期。

确认前使用中性文案：“请选择你今天能完成的量”，不使用“你落后了”“不能放弃”等压力话术。  
**可访问性**：复习原因、数量和预计时长为可读文本；调整量控件有步进按钮；队列变化用可读状态播报，不依赖动画。  
**三端差异**：Mobile 单列卡片 + 固定 CTA；Pad 左侧复习队列、中间当前项、右侧排程解释；Web 增加按状态/来源/课程筛选和复习历史。

**Deep Link**：`/review/today`。  
**埋点**：`review_queue_view`、`review_start`、`review_load_choice`、`review_reason_open`、`review_backlog_defer`。

### RV-02 Mistake Repair 薄弱点修复

**页面名称**：Mistake Repair  
**用户目标**：针对可解释的错因完成规则回顾、变式练习和延迟复测安排。  
**进入入口**：Practice Hub、答题反馈、Home 薄弱点卡、Checkpoint 结果。  
**主按钮**：`开始修复`。  
**次按钮**：`查看错因`、`稍后处理`、`加入复习队列`。

**固定流程**：

```text
错因摘要
  → 规则回顾
  → 变式题 1
  → 变式题 2
  → 暂时修复结果
  → 延迟复测安排
```

**状态**：

| 状态 | 表现与动作 |
|---|---|
| 待修复 | 按风险和连续错误排序，显示来源和次数 |
| 修复中 | 显示当前步骤；保存到最近安全点 |
| 暂时修复 | 显示“已暂时修复”，安排下次复测 |
| 仍未修复 | 显示可执行的下一步，不把用户标记为失败 |
| 已加入复测 | 显示日期/时间和队列位置 |
| 无错因 | 进入人工可理解的题目/规则详情，不显示空白解释 |
| 内容有误 | 可报告题目并跳过该项，保留其他修复点 |

**可访问性**：错因必须是文字；规则回顾支持折叠但默认读出摘要；变式题提供点击式交互；错误状态不使用强烈震动。  
**三端差异**：Mobile 一步一屏，底部主按钮固定；Pad / Web 左侧步骤导航、中间题目、右侧错因与复测信息。

**Deep Link**：`/review/mistakes/:itemId`。  
**埋点**：`mistake_repair_view`、`mistake_repair_start`、`mistake_repair_complete`、`mistake_repair_defer`、`mistake_repair_report`。

## 11. RP｜学习报告

### RP-01 日报 / 周报 / 月报

**页面名称**：Learning Report  
**用户目标**：用可理解的数据回顾完成情况、弱点变化和下一个计划动作。  
**进入入口**：`我的 → 报告`、Home 今日完成卡、练习结果、系统通知。  
**主按钮**：默认 `调整下周计划`；若有未完成的高风险复习则为 `去完成今日复习`。  
**次按钮**：切换日报 / 周报 / 月报、查看明细、分享可见摘要（若开启）。

**内容范围**：

| 报告 | 核心指标 | 主要行动 |
|---|---|---|
| 日报 | 学习分钟、词汇/短语、正确率、XP、完成任务 | 查看今日复习或返回 Home |
| 周报 | 学习天数、各模块时间、弱点变化、计划完成率 | 调整下周计划 |
| 月报 | 能力雷达、模拟趋势、Checkpoint 变化、收藏增长 | 选择下月重点 |

**状态**：

| 状态 | 表现与动作 |
|---|---|
| 数据完整 | 显示摘要、趋势、可解释行动 |
| 数据不足 | 说明统计周期和缺少数据，提供 `继续学习` |
| 首日 / 空报告 | 不显示空图表，使用“完成一次学习后生成报告” |
| 计算中 | 显示已收集指标和生成进度 |
| 同步延迟 | 标注最后更新时间，提供 `重试同步` |
| 离线 | 显示本地缓存报告与时间，不显示未确认的最新数字 |
| 报告加载失败 | 显示历史可用报告和 `重试` |
| 计划已过期 | 主按钮 `重新安排计划`，说明原因和影响 |

**数据表达规则**：

- 报告中的“正确率”只指选定周期和题型，不等同于能力永久提升。
- 能力雷达、柱形图、趋势图必须有数字列表和文字摘要替代。
- 复习与错题使用“薄弱点减少 / 待复测增加”等具体变化，不使用排名羞辱。
- 模拟考试卡显示“语学星自研模拟训练结果，不是官方成绩”。

**可访问性**：图表支持读屏摘要、数据表或“查看数据列表”；日期范围可键盘/读屏切换；颜色、虚线、图标和文字共同表达趋势；动态数字变化有静态最终值。  
**三端差异**：

- Mobile：日报默认首屏，周报/月报用 Tab；摘要优先，明细用折叠区。
- Pad：左侧报告周期，中间摘要与图表，右侧“下一步建议”。
- Web：支持宽图表、时间范围和模块筛选；导出/分享不遮挡主学习行动。

**Deep Link**：`/me/reports?period=week`。  
**埋点**：`report_view`、`report_period_switch`、`report_detail_open`、`report_plan_adjust_click`、`report_sync_retry`。

## 12. 闭环状态转移与恢复规则

### 12.1 主流程

| 当前阶段 | 完成条件 | 下一阶段 | 中断恢复 |
|---|---|---|---|
| Onboarding | 年龄、目标、时间已确认 | 测评或默认计划 | 回到最近完成步骤 |
| 测评 | 所需题目已提交 | 结果 / Study Plan | 回到题号和已保存答案 |
| Study Plan | 计划生成或选择默认计划 | Adaptive Home | Home 显示待生成/待开始状态 |
| Adaptive Home | 用户点击主任务 | Continue Learning / Session | Home 主卡显示检查点 |
| Session | 当前题已提交 | 即时反馈 | 回到最近安全题目 |
| 反馈 | 结果已写入或待同步 | 下一题 / 复习队列 | 结果标记同步状态 |
| 复习 | 队列项完成 | 下一个复习项 / 结果 | 回到当前复习项，不重复计数 |
| 报告 | 统计周期有数据 | 调整计划 / Home | 保留上次可用报告 |

### 12.2 统一恢复优先级

```text
最近安全检查点
  > 最近一次已提交答案
  > 本地待同步结果
  > 上次同步的服务端状态
  > 默认起点
```

恢复时必须向用户说明采用了哪个时间点；不能静默覆盖较新的本地记录。对于已提交的答案，恢复后不得重复计分；对于未提交的输入，显示“尚未保存”。

### 12.3 全局异常文案基线

| 场景 | 推荐文案 | CTA |
|---|---|---|
| 网络中断 | “网络暂时不可用，已保留到最近安全检查点。” | `重试` / `继续离线学习` |
| 内容更新 | “这部分内容已更新，我们会保留你已完成的记录。” | `使用最新版本` |
| 保存失败 | “本次结果还没有同步成功。” | `重试同步` |
| 队列不足 | “当前只有 X 个内容，预计 Y 分钟完成。” | `按现有量开始` |
| 无内容 | “还没有符合条件的复习内容。” | `去课程` / `查看历史` |
| 权限拒绝 | “没有开启此权限也可以继续，相关功能将暂时不可用。” | `稍后` / `去设置` |

## 13. 可访问性与设备验收基线

### 13.1 Mobile

- 以 390×844 为核心验收视口，正文不被 Dynamic Island、状态栏、Home Indicator 或安全区遮挡。
- 关键 CTA 固定在底部安全区上方；键盘出现时自动抬升，关闭后恢复。
- 页面内容可滚动但不出现嵌套滚动；Bottom Sheet 有明确拖拽把手和关闭按钮。
- 支持系统大字号、深色模式、减少动态效果；大字号下不裁切单词、题干和按钮文案。

### 13.2 Pad

- 横屏优先但支持竖屏降级；左侧导航可折叠，中央始终保留主任务焦点。
- 触控目标不小于 44px；键盘/触控板输入时焦点清晰。
- 不把 Mobile 的卡片简单放大；利用右侧展示解释、复习原因或历史。

### 13.3 Web

- 支持 Tab 顺序、跳过导航、可见焦点、Enter/Space 操作和浏览器刷新恢复。
- 图表、音频、拖拽题均提供文字或点击式替代。
- 1280px 宽度下不需要水平滚动；窄窗口回退为单列，不隐藏唯一主 CTA。

### 13.4 状态和动效

- 成功、错误、待同步、离线、锁定都使用“图标 + 文字 + 结构/边框”表达。
- 120–180ms 微交互、200–280ms 卡片切换、250–320ms Sheet；减少动态效果时改为静态切换。
- 正确答案轻微上浮或描边即可；错误答案轻微位移并给出解释，不使用强烈震动。
- 读屏状态播报不重复；连续答题中不每题播放高刺激音效。

## 14. 设计验收清单

### 学习闭环

- [ ] 新用户可以从欢迎页完成年龄确认、目标选择、每日时间和首课进入。
- [ ] 测评可以开始、退出、恢复、跳过，并能生成结果或默认计划。
- [ ] Adaptive Home 首屏有一个明确的今日主任务和 Continue Learning 入口。
- [ ] Continue Learning 能恢复题号、音频位置和最近安全检查点。
- [ ] 词汇 SRS 支持主动回忆、释义揭示、熟悉度反馈和下次复习排程。
- [ ] 选择题、拼写、重排、听力、阅读和变式题都有统一答题状态。
- [ ] 单题反馈能解释结果，完课反馈能说明暂时修复、薄弱点和下一次复习。
- [ ] 复习积压有可控量路径，不以羞耻或惩罚驱动。
- [ ] 日报、周报、月报有数据不足、同步延迟和空报告状态。

### 状态与异常

- [ ] 所有核心页面具备 Loading、Ready、Empty、Offline、Error；涉及内容更新的页面具备 Stale。
- [ ] 提交按钮防重复点击；网络失败不丢已保存进度。
- [ ] 退出 Session 前保存并确认；刷新、切后台、跨设备后可以恢复。
- [ ] 队列不足、无任务、结果保存失败和内容有误都有可行动 CTA。

### 跨端与无障碍

- [ ] Mobile 390×844 下主 CTA 可达，底部安全区不遮挡内容。
- [ ] Pad / Web 扩展空间但不改变主任务优先级。
- [ ] 颜色不是唯一状态信号；所有图标有可读名称。
- [ ] 大字号、深色模式、减少动效、键盘和读屏路径已覆盖。
- [ ] 不展示 AI、K12、未成年人注册或官方考试成绩暗示。

## 15. 给实现 agent 的最小交接顺序

```text
1. Onboarding + 默认计划
2. Assessment Session + 恢复点
3. Adaptive Home + Continue Learning
4. SRS 词汇卡 + 熟悉度提交
5. Practice Question + 统一反馈
6. Mistake Repair + 复习排程
7. Daily / Weekly Report
```

每一步都先完成页面状态、错误恢复和可访问性，再扩展视觉动效。API、数据库、SRS 算法和埋点字段以现有契约与后端设计为准；本稿定义的是用户在各状态下“看到什么、能做什么、下一步去哪里”。
