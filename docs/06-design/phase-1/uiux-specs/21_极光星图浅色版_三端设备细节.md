# 21｜极光星图浅色版与三端设备细节

> 状态：Concept Review  
> 日期：2026-08-20  
> 配套主稿：../mockups/complete-ui-ux-command-center.html
> 关系：本规范已并入 Aurora UI Suite 主稿，不再维护独立方向稿。

## 1. 设计目标

将“极光星图”从一套偏深色的沉浸方向，扩展为适合日常学习的浅色主界面：

- 保留蓝紫极光、路径节点和探索感；
- 用浅色页面提高长时间阅读与练习的舒适度；
- 把硬件细节当作展示框架，不让设备装饰遮住学习任务；
- 三端共享内容顺序，但根据设备能力改变导航、信息密度和操作位置。

默认主主题：

    页面背景：#F5F7FF
    卡片：#FFFFFF
    主色：#596BFF
    极光第二色：#8C68FF
    掌握色：#25B88A
    奖励色：#F2A83B

主题模式：

- 浅色模式作为默认日常学习主题，白色卡片承载正文；
- 深色模式整合最初 A｜极光星图的深蓝星海、紫色极光、薄荷反馈色，不是简单降低浅色亮度；
- 主题切换即时生效，学习页面、设备外框、地图轨道和设置页保持同一套令牌。

## 2. 设备框架

### Mobile｜iPhone 16 Pro Max 风格展示框

- 390 × 844 展示画布，作为 iPhone 16 Pro Max 比例风格稿，不等同于真实物理像素；
- 深色钛金属边框、内屏圆角与屏幕裁切保持同心，内容不得越过四角边界；
- 顶部 Dynamic Island，点击后展开为通知状态；
- 左侧显示时间，右侧显示蜂窝网络、Wi‑Fi 与电量百分比；
- 页面内容避开状态栏与 Dynamic Island 安全区；内容可继续滑动，但不显示浏览器滚动条；
- 底部 Home Indicator 和五 Tab 导航固定在内屏底部；
- 主 CTA 在首屏可达，不依赖滚动到底部。

Dynamic Island 只承载轻量状态：

> 🔥 连续学习 21 天 · 今日任务还差 12 分钟

不在通知岛里塞入复杂操作，也不把它作为必须完成学习的入口。

### Pad｜iPad 横屏展示框

- 1024 × 768 逻辑尺寸；
- 横屏机身和细边框；
- 顶部中央摄像头点；
- 左侧保留一级导航；
- 主区采用两列：今日任务 + 学习世界/待办；
- 不使用手机底部 Tab，避免与侧栏重复导航。

### Web｜桌面浏览器展示框

- 1280 × 800 逻辑尺寸；
- 浏览器顶部交通灯、地址栏和标签页区域；
- 左侧为全局导航；
- 中央为主任务和学习世界；
- 右侧为队列摘要、周进度和下一次复习；
- 右侧栏不重复首页全部模块，只保留“为什么现在做这个”的证据。

## 3. 浅色版页面层级

    系统状态栏 / 浏览器栏
      → 欢迎与目标
      → 今日主任务
      → 三个关键指标
      → 学习世界轨道
      → 接下来做什么
      → 继续学习 / 练习 / 世界

首屏只保留一个品牌渐变主卡。浅色页面的其余卡片使用白底、细边框和轻微阴影，避免整页变成发光面板。

## 4. 交互细节

| 交互 | Mobile | Pad | Web |
| --- | --- | --- | --- |
| Dynamic Island/状态 | 点击展开通知摘要 | 顶部状态栏显示轻量提醒 | 浏览器内顶部显示通知点 |
| 继续学习 | 更新进度并进入 Session | 更新中央主任务 | 更新主卡和右侧队列 |
| 地图节点 | Bottom Sheet | 侧向/底部详情区 | 右侧详情区或浮层 |
| 一级导航 | 底部 Tab | 左侧栏 | 左侧栏 |
| 主题切换 | 浅/深色 | 浅/深色 | 浅/深色 |

底部五个入口均提供独立页面状态：

- 学习：今日任务首页；
- 练习：修复队列、筛选和错题本入口；
- 世界：区域地图、节点详情和区域切换；
- 课程：课程进度列表与课程探索入口；
- 我的：个人状态、主题、动效和统计设置。

指标卡的数值与说明使用垂直居中布局，保证三张卡在不同文案长度下保持视觉平衡。

## 5. 动效约束

- 极光背景只做低幅度呼吸，默认不持续漂移；
- 当前地图节点可呼吸，已完成节点不闪烁；
- Dynamic Island 展开使用 220ms 的宽度和透明度过渡；
- Bottom Sheet 使用 280ms 上推动画；
- 主题切换使用 240ms 颜色过渡；
- prefers-reduced-motion 或 Performance 画质下取消循环动画，保留状态变化和进度数值；
- 不使用模拟系统通知、真实支付提示或会误导用户的系统权限弹窗。

## 6. 评审重点

- 浅色背景是否仍有足够的品牌识别度；
- 极光主卡是否夺走了“继续学习”的注意力；
- Mobile 的 Dynamic Island 是否像设备细节，而不是额外导航；
- Pad 是否真正利用横屏空间，而不是把手机放大；
- Web 右侧信息是否帮助决策，而不是制造仪表盘噪音。
