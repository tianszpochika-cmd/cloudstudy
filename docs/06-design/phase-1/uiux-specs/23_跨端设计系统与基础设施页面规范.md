## 0.1 前端项目边界

本规范服务四个前端项目，平台输出不再拆成额外业务项目：

| 项目 | 目标平台 / 场景 | 设计约束 |
|---|---|---|
| `apps/mobile` | 移动 H5、iOS、Android、iPad；微信小程序（P1.5） | 同一 uni-app 学习端，使用条件编译、响应式布局和性能降级适配平台能力 |
| `apps/learner-web` | PC Web、平板浏览器、PWA | 独立 Web 工作台与导航壳，保持学习者信息架构但不复制移动页面 |

四个项目共享 Token、状态契约、埋点和领域规则；组件可以复用设计语义，但 UI 实现按 `uni-app` 与 Web 平台分别维护。`apps/miniapp-wechat` 仅作迁移说明或资源占位。

## 0. 文档定位与不可违背的体验原则

本文件把 Phase 1 已有的视觉、信息架构、组件、动效、基础设施和验收要求收敛为一套跨端规则。它不是重新定义产品功能，而是规定同一功能在不同设备、不同密度、不同状态下应如何被看见、理解和操作。

### 0.1 体验目标

| 关键词 | 设计含义 | 反例 |
|---|---|---|
| 清晰 | 当前任务、下一步操作、系统状态始终可见 | 让用户猜“现在发生了什么” |
| 克制 | 用具体反馈建立成就感，不用刺激和羞耻驱动学习 | 连续弹窗、赌场式开箱、过量红点 |
| 鼓励 | 错误给解释和修复路径，未完成给可恢复入口 | 只显示“错误”或“失败” |
| 可持续 | 支持暂停、离线、恢复、调整计划和关闭个性化 | 把中断当成惩罚 |
| 一致 | 颜色、间距、状态和交互语义跨端保持一致 | 同一按钮在 App 与 Web 行为不同 |

### 0.2 Phase 1 边界

- 仅面向 18 岁以上成人与大学生；不出现 K12、中高考同步、未成年人注册入口。
- AI Tutor、AI 实时陪练、AI 评分等 Phase 2 能力在 Phase 1 UI 中不展示；不能用“智能老师”伪装未开放能力。
- Study Room 只提供成员展示、排行榜和预设反应，不提供自由文本评论、私聊和群聊。
- 随机奖励只表达学习结果与收藏稀有度，不提供购买箱子、充值抽箱、付费提高掉率或排行榜数值优势。
- 所有页面服务于“学习目标 → 练习 → 反馈 → 复习 → 闭环复盘”。商业、社交和装扮不能遮挡或替代主学习任务。
- 个人学习数据、录音、设备和 Household 关系必须按隐私开关隔离；共享会员权益不等于共享学习记录。

## 1. 设计系统架构

### 1.1 五层组件模型

```text
Foundation
  └─ Primitive
      └─ Pattern
          └─ Template
              └─ Page / Flow
```

| 层级 | 内容 | 例子 | 约束 |
|---|---|---|---|
| Foundation | 颜色、字体、间距、圆角、阴影、动效、图标网格 | `color.text.primary`、`space.16` | 只定义视觉和基础行为，不包含业务文案 |
| Primitive | 原子控件 | Button、Input、Badge、IconButton、Progress | 具备完整状态和无障碍名称 |
| Pattern | 可复用业务模式 | Continue Learning、筛选栏、下载任务、同步状态 | 组合 Primitive，不复制局部规则 |
| Template | 页面骨架 | Learning、Content、Dashboard、Editor、Review | 规定布局密度、滚动和操作区 |
| Page / Flow | 真实业务页面和流程 | 学习首页、内容审核、数据导出、账号注销 | 通过路由、权限、Deep Link 和状态机接入 |

### 1.2 Token 命名和映射

采用三层 Token，避免业务页面直接依赖单一颜色值：

```text
Primitive:  color.indigo.600 / color.gray.050 / space.4
Semantic:   color.brand.primary / color.surface.card / color.text.primary
Component:  component.button.primary.background / component.table.row.height
```

Web / H5 的 CSS 变量统一采用 `--yx-` 前缀；uni-app 原生端由同一语义 Token 映射到平台变量；Admin 不得另建一套品牌蓝。

```css
:root {
  --yx-color-brand-primary: #596BFF;
  --yx-color-surface-page: #F7F8FC;
  --yx-color-text-primary: #202332;
  --yx-space-16: 16px;
  --yx-radius-card: 16px;
}

[data-theme="dark"] {
  --yx-color-brand-primary: #7785FF;
  --yx-color-surface-page: #0F1220;
  --yx-color-text-primary: #F4F6FB;
}
```

组件层只消费语义 Token；页面层只消费组件 Token。主题切换必须通过根节点主题状态完成，不能逐页写深色覆盖。

### 2.5 层级、图标和动效 Token

| 层级 | Token | 用途 |
|---:|---|---|
| 0 | `z.base` | 页面内容 |
| 10 | `z.sticky` | 顶部进度、表头、底部操作 |
| 20 | `z.nav` | TabBar、Sidebar、Global Header |
| 30 | `z.toast` | Toast、Snackbar |
| 40 | `z.mask` | Modal 遮罩 |
| 50 | `z.sheet` | Sheet、Dialog、Drawer |
| 60 | `z.system` | 权限、登录过期、全局故障 |

图标规则：

- 默认使用 2px 线宽、圆角端点、20×20 网格；Admin 密集表格可使用 16×16，但点击区域不能小于规范值。
- 图标必须有可访问名称；纯装饰图标标记为隐藏，不把装饰描述读给用户。
- 播放、暂停、重播、下载、同步、隐私、权限、删除、解绑等高风险或高频动作必须配文字或 Tooltip。
- 同一语义在不同平台只改变容器，不改变图形方向和名称。

动效规则：

| Token | 时长 | 使用 |
|---|---:|---|
| `motion.micro` | 120–180ms | Hover、Pressed、Toggle |
| `motion.card` | 200–280ms | 卡片展开、列表更新 |
| `motion.sheet` | 250–320ms | Sheet、Drawer |
| `motion.page` | 250–350ms | 页面转场 |
| `motion.reward` | 400–700ms | XP、成就；不全屏爆炸 |

系统或用户开启 Reduced Motion 时：关闭粒子、大幅位移和开箱连续动画，改为淡入、静态高亮和可跳过步骤；声音与触觉同样可以单独关闭。

## 3. 组件层级与跨端变体

### 3.1 组件命名和状态契约

组件命名使用 `YX` 前缀或产品组件库等价命名，业务名不得进入基础组件。例如使用 `YXButton` + `action="continue-learning"`，不创建 `ContinueLearningButton` 取代通用 Button。

所有可操作组件至少定义以下状态：

```text
default → hover（有指针平台）→ pressed → success / error
                         ↘ loading → disabled
focus-visible / readonly / offline / permission-denied 按场景补充
```

状态必须同时有视觉和文字或结构提示：

| 状态 | 视觉 | 必须提供 |
|---|---|---|
| `default` | 正常层级 | 可理解的名称 |
| `hover` | 轻微底色 / 边框变化 | 不改变布局尺寸 |
| `pressed` | 明度或位移小幅变化 | 不依赖声音 |
| `focus-visible` | 2px 外环，使用 `focus.ring` | 键盘可继续操作 |
| `loading` | 按钮内 Spinner 或 Skeleton | 保留动作名称，禁止重复提交 |
| `disabled` | 降低对比度但仍可读 | 必要时补充原因 |
| `success` | 成功图标、短文案 | 可恢复到下一步 |
| `error` | 错误图标、边框和解释 | 修复或重试入口 |
| `offline` | 离线标识 | 告知可继续的本地能力 |
| `conflict` | 警示标识 | 显示差异与决策入口 |

### 3.2 组件目录

| 类别 | 组件 | Mobile / H5 | Pad / Learner Web | Admin Web |
|---|---|---|---|---|
| Action | Button、IconButton、Link、Segmented Control | 触摸优先，主 CTA 固定在安全区内 | 支持键盘和 Hover | 密集尺寸，危险动作二次确认 |
| Form | Input、Textarea、Select、DateRange、Radio、Checkbox、Switch | Bottom Sheet 选择、键盘抬升 CTA | Popover 或侧栏筛选 | 表单栅格、字段级错误、批量校验 |
| Navigation | TabBar、Sidebar、Breadcrumb、PageHeader、Stepper | 5 Tab + 页面内返回 | Sidebar + 顶栏 | 240px Sidebar + 面包屑 + 工作区 |
| Content | Card、StatCard、List、Table、Timeline、Tree | 卡片和纵向列表 | 可并列卡片、横向表格 | 表格、树、分栏工作台 |
| Feedback | Badge、Chip、Banner、Toast、Snackbar、Skeleton、EmptyState、ErrorState | Toast 不遮挡 CTA | 支持键盘关闭 | 可定位到行 / 字段 / 审计记录 |
| Overlay | Bottom Sheet、Dialog、Drawer、Popover、Tooltip | Sheet 优先，Dialog 只做危险确认 | Drawer / Dialog | 右侧 Drawer、批量操作确认、审计摘要 |
| Media | AudioPlayer、Waveform、Transcript、Video、3DCanvas | 大播放区、字幕和重播 | 旁注、双栏 | 资产预览、版本对比、模型包信息 |
| Infrastructure | SyncStatus、DownloadTask、PermissionGate、PrivacyRow、DeviceSession | 状态可见、可恢复 | 顶栏小状态 + 详情页 | 队列、SLA、失败原因和审计 |

### 3.3 核心 Primitive 规则

#### Button

| 变体 | 视觉 | 适用 |
|---|---|---|
| Primary | 品牌底、白字、12–14 圆角 | 每个页面最多一个主要视觉焦点 |
| Secondary | 卡片底、品牌边框 | 调整计划、查看解释 |
| Tertiary | 文字或浅底 | 稍后、取消、次级跳转 |
| Destructive | 危险色，仅危险动作 | 删除、注销、解绑、下线 |
| Icon | 40×40 容器，命中区域 ≥44 | 重播、更多、关闭、筛选 |

提交类 Button 必须具备 loading 和幂等防重复状态；请求失败后保留用户输入，不把按钮永久置灰。

#### Input / Form

- 高度 48px（学习端）或 40–44px（Admin），焦点外环 2px，错误文案位于字段下方。
- 必须提供 label、placeholder 仅作示例，不可代替 label；密码、手机号、验证码提供读屏提示和粘贴路径。
- 表单错误按字段定位，顶部可提供摘要；不要只用红框或 Toast 报错。
- 键盘出现时，操作区使用 `env(safe-area-inset-bottom)` 抬升，不能遮挡输入内容。

#### Tabs / Chips / Filters

- Tabs 最多 5 个，超过使用横向滚动；当前项有文字、底色或下划线，不只靠颜色。
- Chip 用于难度、场景、内容类型和筛选，默认高度 32px；可删除 Chip 必须提供关闭 label。
- 筛选条件在 Mobile 使用 Bottom Sheet，在 Pad / Web 使用 Popover 或右侧筛选栏，在 Admin 使用固定筛选栏 + 高级筛选 Drawer。

#### Table / List

- 学习端默认 List，Admin 默认 Table；同一数据字段必须保持顺序、名称和状态语义一致。
- Admin 表格首列优先识别对象，末列放低频操作；批量操作栏只在选中行后出现。
- 表格提供排序、筛选、分页 / 虚拟滚动、空状态、错误状态和导出权限提示；不把大量数据一次性渲染到 DOM。
- Mobile 表格转为“主字段 + 状态 + 更多操作”卡片；关键金额、版本、审核状态不可隐藏在折叠层内。

#### Modal / Sheet / Drawer

| 场景 | Mobile | Pad / Web | Admin |
|---|---|---|---|
| 查词、筛选、节点详情 | Bottom Sheet | Bottom Sheet / Popover | 右侧 Drawer |
| 危险确认、支付结果 | Dialog | Dialog | Dialog + 审计摘要 |
| 编辑对象、详情对比 | 全屏页面或 Sheet | 右侧 Drawer | 右侧 Drawer / 分栏工作台 |
| 复杂连续流程 | 页面级 Stepper | 页面级 Stepper | 工作区 Stepper + 固定操作栏 |

Overlay 打开后必须锁定背景滚动、保留关闭入口、支持 Esc / 返回键，并把焦点移入容器；关闭后焦点回到触发控件。

### 3.4 基础设施专用组件

| 组件 | 必须展示 | 主要动作 |
|---|---|---|
| `SyncStatus` | 已同步 / 同步中 / 等待网络 / 冲突 / 失败 + 最近时间 | 重试、查看详情、解决冲突 |
| `DownloadTask` | 类型、大小、进度、剩余空间、状态 | 暂停、继续、删除、清理缓存 |
| `PermissionGate` | 为什么需要权限、数据用途、暂不开启路径 | 继续、打开系统设置、稍后 |
| `PrivacyRow` | 数据类别、用途、保存范围、共享范围 | 查看、导出、删除、关闭 |
| `DeviceSession` | 设备、平台、地区、最近时间、当前设备 | 下线、查看登录记录 |
| `ServiceStatusBanner` | 离线 / 降级 / 故障、影响范围、恢复时间（若有） | 重试、查看离线内容、联系客服 |
| `AuditBadge` | 草稿 / 一审 / 二审 / 已发布 / 已下线 | 查看版本、审核记录、回滚权限 |

## 4. 响应式规则与平台壳层

### 4.1 断点和布局宽度

| 断点 | 视口 | 默认壳层 | 设计策略 |
|---|---:|---|---|
| `xs` | 0–599 | Mobile | 单列、5 Tab、全屏学习任务 |
| `sm` | 600–767 | 大屏手机 / 小平板 | 单列或双列摘要，底部导航仍可用 |
| `md` | 768–1199 | iPad / 小型桌面 | 侧栏 + 内容；学习页可双栏 |
| `lg` | 1200–1439 | Learner Web / Admin | 固定侧栏、主内容 2–3 列 |
| `xl` | ≥1440 | 宽屏 Admin | 内容最大宽度，右侧详情或质量面板 |

页面内容最大宽度：学习端 `1200px`，Admin 工作区 `1600px`；宽屏两侧留白不能拉伸卡片到难读的长度。

### 4.2 学习端平台壳层

| 平台 | 导航 | 顶部 | 内容滚动 | 固定操作 |
|---|---|---|---|---|
| Mobile App / H5 | 底部 5 Tab：学习、练习、世界、课程、我的 | 页面标题 + 必要状态，不超过 3 个全局指标 | 单一内容滚动容器，隐藏系统滚动条但保留滑动 | 底部安全区内 CTA |
| iPad | 左侧 240px 导航 + 顶栏 | 页面标题、搜索、Streak、消息、头像 | 主内容单一滚动，详情可右栏 | 右栏或底部操作栏 |
| Learner Web | 左侧 240px 导航 + 顶栏 | 全局搜索、Streak、消息、头像 | 主内容滚动，长内容保留阅读位置 | 桌面底部不固定，操作靠近内容 |

Mobile 的屏幕内容必须裁切在设备圆角内；安全区使用 `env(safe-area-inset-top/right/bottom/left)`。Dynamic Island、刘海、状态栏只作为设备壳层，不得成为业务内容的滚动区域。手机页面只能有一个纵向滚动容器，禁止主页面与卡片内部同时滚动，除非是明确的代码 / 表格 / 时间线查看器。

### 4.3 Mobile 规则

- 页面左右边距 16px；关键卡片不超出屏幕圆角裁切区域。
- 首屏优先展示页面标题、主任务、当前进度和一个主 CTA；低频解释进入 Sheet。
- TabBar 高度包含底部安全区；主内容底部 padding 至少为 `TabBar 高度 + safe-area-inset-bottom + 16px`。
- 返回遵循系统返回栈；学习 Session 使用左上角关闭并二次确认“暂时离开 / 继续学习”。
- 软键盘出现时，输入区和 CTA 必须可见；拖拽题提供点击式替代。
- 加载优先使用局部 Skeleton；按钮提交使用按钮内 loading，不使用全屏 Spinner。

### 4.4 Pad 与 Learner Web 规则

- 768px 以上优先使用侧栏；学习任务仍然保持低密度，内容区域不因为大屏而塞入多个主问题。
- 详情页可以采用 8 / 4 或 7 / 5 栅格：左侧主内容，右侧解释、进度或操作；右侧内容可在小屏降为 Drawer。
- 横向空间增加时优先增加留白、辅助信息和可见解释，不把字号无限放大。
- 音频、阅读、语法等长内容保留阅读位置和播放位置；页面返回不重置学习状态。

### 4.5 Admin 响应式规则

- Admin 的主目标设备是 `lg` / `xl` 桌面 Web；`md` 作为审核、客服和运营值班的可用降级，不追求在手机上完整编辑复杂内容。
- `lg`：Sidebar 240px，Topbar 64px，工作区左右 padding 24px，表格保持高密度。
- `xl`：工作区最大 1600px，可显示右侧质量 / 审计 / 版本面板；不得把单行信息拉得过长。
- `md`：Sidebar 收缩为 72px 图标栏或 Drawer；表格保留关键列，其余字段进入详情 Drawer。
- `<768px`：只提供查看、处理队列、客服回复、审批等轻操作；复杂编辑提示“请在桌面端完成”，仍可保存草稿。

### 4.6 设备性能自适应

所有粒子、3D、音效和复杂图表受 `AdaptivePerformanceEngine` 控制，不得在低配机上强制加载。

| 级别 | 视觉 | 交互降级 |
|---|---|---|
| Ultra | 完整 3D、环境光、地图动效、细粒子 | 全部交互 |
| High | 3D 简化材质、有限粒子、图表动画 | 保留核心动效 |
| Medium | 2.5D / SVG、静态背景、短过渡 | 关闭非必要粒子和预览 |
| Performance | 2D 静态切片、无自动播放和大幅位移 | 所有学习和反馈功能可用 |

降级必须可解释、可恢复、可手动关闭动效；不能把低配设备用户锁在加载态。

### 5.1 学习端统一 Shell

```text
AppShell
├─ SafeArea / DeviceFrame
├─ GlobalHeader
├─ PageContent
├─ PersistentSyncStatus（轻量）
└─ PrimaryNavigation（Mobile TabBar / Pad-Web Sidebar）
```

Global Header 只保留当前页面所需信息：

- Home：头像快照、当前课程 / 页面标题、Streak、消息。
- 学习 Session：关闭、题目进度、必要的音频 / 网络状态；不展示与任务无关的会员或货币。
- 普通内容页：返回、标题、更多 / 收藏 / 内容纠错。
- 我的：头像、昵称、等级和 VIP；设置和消息作为右侧入口。

### 5.2 页面模板

| 模板 | 组成 | 适用页面 |
|---|---|---|
| `LearningTemplate` | 进度 → 单一主问题 → 解释 → 固定 CTA | 练习、Checkpoint、SRS、CET |
| `ContentTemplate` | 标题 → 正文 / 音频 → 收藏 / 纠错 → 下一内容 | 阅读、听力、语法、词汇 |
| `DashboardTemplate` | 关键指标 → 主任务 → 次级列表 → 最近活动 | 学习首页、报告、我的 |
| `ImmersiveTemplate` | 地图 / 3D → Overlay HUD → Sheet 详情 | 世界、地图、人物、学习空间 |
| `SettingsTemplate` | 分组列表 → 详情页 → 保存 / 危险操作 | 通知、隐私、下载、同步、账号安全 |

### 5.3 Deep Link 和返回

- 每条通知必须带业务 Deep Link；若目标不可用，进入对应的可解释空状态，不落到首页。
- 未登录进入受保护页面：先保存目标路由，登录成功后回到原目标。
- 权限不足进入 Admin 页面：展示“没有该操作权限”、所属角色和申请协助入口，不暴露敏感数据。
- 删除、注销、账号合并、下线、退款等不可逆路径离开时必须二次确认并说明影响范围。
- 学习答题在每个关键事件本地留存；崩溃或断电重启后显示“已恢复到第 X / Y 题”，支持继续或放弃本次恢复。

全局 Topbar：

- 右侧显示环境（生产 / 预发布）、通知、当前角色和账号菜单；生产环境必须有明确色标。
- 任何高风险操作在页面 Header、按钮和确认 Dialog 中都显示影响范围和审计要求。

### 6.3 页面模板

#### A. 运营 Dashboard

适用：DAU、留存、学习质量、VIP 转化、崩溃率、下载和同步健康度。

```text
页面标题 + 时间范围 + 导出
KPI：DAU / 新增 / D1-D7 留存 / 学习分钟 / 完课率 / 崩溃率
主图：活跃与学习时长趋势        质量图：Checkpoint / 错误率
待处理：内容纠错 / 审核队列 / 客服 SLA / 同步异常
明细：最易错知识点 / 版本影响 / 会员与退款异常
```

规则：

- KPI 卡显示数值、时间范围、同比 / 环比、数据更新时间和口径 Tooltip；没有数据时显示“暂无数据”，不得显示 0 误导。
- 图表支持键盘访问、数据表格替代、下载权限和异常点说明；颜色不是唯一编码。
- Dashboard 是查看和分流入口，不在卡片内直接执行危险操作。

#### B. 内容教研工作台

适用：词汇、短语、语法、阅读、听力、视频、题库、课程和知识点。

列表字段：

```text
ID / 标题或词条 / 类型 / 来源 / 版权状态 / 审核状态
版本 / 修改人 / 最近更新时间 / 质量指标 / 行操作
```

操作顺序：

1. 搜索或筛选定位内容。
2. 进入详情或编辑器，显示版本、引用关系、适用课程和质量风险。
3. 保存为草稿，执行字段校验和引用完整性校验。
4. 提交一审；一审通过后进入二审；二审通过才可发布。
5. 发布后显示生效版本和回滚入口；下线必须说明影响课程和用户。

编辑器布局：

- 左：内容字段和正文编辑。
- 中：实时预览，支持 Mobile / Pad / Web 断点切换。
- 右：校验、版权、引用、历史版本和审核意见。
- 底部固定操作栏：保存草稿、预览、提交审核；发布 / 下线只对具备权限的角色显示。

#### C. 审核队列

适用：内容一审 / 二审、3D 资产、奖励规则、公告和版本。

队列行必须显示：优先级、SLA、提交人、提交时间、风险标记、当前版本、上一条意见。审核详情采用“内容 + 证据 + 决策”三栏：

- 内容：可读的最终用户呈现。
- 证据：来源、版权、字段校验、影响面、历史版本。
- 决策：通过、退回修改、下线、申请协助；每个选择都要求结构化原因。

奖励箱配置额外要求：

- 概率输入实时校验，必须明确显示“合计 = 100%”。
- 小于 100%、大于 100%、空值、重复物品和版本时间冲突均阻止提交。
- 配置变更必须双人审核；提交人不能审核自己的变更。
- 线上已生效规则只允许新建版本，不允许无审计直接覆盖。

#### D. 运营与学习质量

包括活跃、留存、学习分钟、完课率、Streak 分布、最易错知识点、内容纠错量、Checkpoint 通过率和版本影响。

- 筛选按时间、平台、版本、地区、课程和人群；涉及隐私的字段默认聚合展示。
- 每个指标提供“口径说明”和“查看明细”权限；明细导出需要再次确认范围。
- 异常趋势使用说明性 Banner 和关联工单，不直接用“故障”结论替代调查。

#### E. 消息通知中心

模板字段：Event Type、站内、Push、SMS、Email、Deep Link、频控、用户偏好、灰度范围、版本。

- 预览必须分别显示通知标题、摘要、时间、未读点和落地页面。
- 发布前检查渠道合规、退订入口、频控、时区、变量缺失和 Deep Link 可达性。
- 灰度发布显示目标人数、已发送、失败、退订和投诉；支持暂停，但不能删除发送审计。

#### F. 客服与内容纠错

工单列表：类型、SLA、用户、平台、版本、状态、负责人、最近更新。详情显示用户描述、设备信息、操作历史、关联订单 / 内容 / 同步事件。

- 状态：已提交 → 处理中 → 待用户补充 → 已解决；关闭前要求解决摘要。
- 内容纠错按释义、音标、音频、答案、例句、字幕、排版分类；可以关联内容版本和审核队列。
- 客服可以处理用户问题，但不能越权编辑教研内容或直接补发敏感权益；需要转交对应角色并留下审计记录。

#### G. 权限、系统配置与审计

角色：超级管理员、教研、一审、二审、运营、客服、财务、技术运维。权限分为查看、创建、编辑、提交审核、发布、下线、导出、补发、退款、冻结和系统配置。

- 敏感操作采用最小权限、二次确认、审计摘要和可追溯操作者。
- 审计日志支持按操作者、资源、动作、时间、结果、请求 ID 筛选；不可被业务角色删除。
- 系统配置显示当前版本、生效时间、影响范围、回滚能力和变更人；生产变更前必须显示环境标识。

### 6.4 Admin 表格密度和操作规则

- 默认行高 48px；重要状态纵向居中，不使用过多 Badge 堆叠。
- 行操作最多显示 2 个高频动作，其余收进“更多”；危险操作与普通操作分组。
- 筛选条件可保存为视图；清除筛选后保留搜索关键词是否保留必须有明确规则。
- 批量操作显示“已选择 N 条”和影响范围；需要审核的批量动作逐条失败时返回失败清单，不能只显示一条总错误。
- 删除 / 下线 / 冻结不使用乐观消失；成功后显示撤销窗口或明确已生效状态。
- 导出前显示字段、时间范围、隐私字段脱敏规则和预计行数；导出任务进入下载中心。

## 7. 通知、隐私、下载、同步与异常 UX

### 7.1 通知中心与消息设置

#### 用户端

入口：我的 → 消息；全局铃铛只显示未读数量，不超过 `99+`。

Tab：全部、学习、社交、会员、安全、系统。消息卡必须包含图标、标题、摘要、时间、未读点和 Deep Link；右滑 / 长按支持标记已读和删除。

通知偏好分组：

- 学习：今日任务、复习、Streak、Checkpoint、CET。
- 社交：Study Room、排名变化、预设反应。
- 奖励：奖励箱、成就。
- 商业：会员、新课程、营销。
- 渠道：Push、Email、非必要短信。
- 勿扰：开始时间、结束时间、跨日说明。

默认不频繁打扰；学习提醒可以关闭，Email 营销必须可退订，SMS 不用于日常学习轰炸。安全通知和账号风险不能被普通营销开关隐藏。

#### Admin 端

消息模板的每次发布都产生版本和审计；频控和用户偏好在发送前计算。预览必须覆盖中文过长、变量缺失、无图标、无网络和 Deep Link 失效状态。

### 7.2 隐私与数据中心

页面分区：个人资料、学习数据、录音、登录设备、权限、SDK、Study Room 公开范围。

每条 PrivacyRow 采用固定结构：

```text
数据类别 → 收集 / 保存目的 → 保存范围和时长 → 是否共享 → 当前状态 → 管理动作
```

可用动作：

- 导出我的数据：显示申请范围、格式、预计准备时间、下载有效期和完成通知。
- 清除搜索历史：即时完成，可撤销窗口或明确不可恢复。
- 清除本地录音：说明只删除本机还是云端副本，不能用模糊“清理数据”。
- 重置学习进度：展示影响课程、复习、报告和排行榜的范围，二次确认并要求明确输入确认词。
- 注销账号：展示会员、订单、Household、学习数据、隐私义务和冷静期规则；红色文字入口，不做大红主按钮。

删除、导出、注销等长任务显示任务状态和通知入口，不能让用户停留在无限 Spinner。

### 7.3 权限与账号安全

首次跟读前先展示自定义说明：为什么需要麦克风、录音如何使用、默认是否上传、如何关闭；用户选择继续后再调用系统权限。

权限状态：未询问、已允许、仅本次允许、已拒绝、系统限制、已过期。拒绝后提供“暂不开启”和“打开系统设置”，不循环弹系统权限。

账号安全显示手机号、微信、Apple、登录设备和最近登录。设备项包含平台、浏览器 / App、地区、时间、当前设备标识和“下线”；异地或异常登录提供风险提示和保护入口。

### 7.4 下载中心

顶部展示已使用空间 / 总空间、缓存占用和可清理空间。Tab：课程、音频、视频、3D 资源。

任务状态：未开始、排队中、下载中、已暂停、已完成、失败、等待 Wi-Fi、空间不足、资源已更新。

- 每个任务显示名称、类型、大小、进度、最近更新时间和离线可用范围。
- 下载中可暂停 / 继续；失败显示原因和重试；空间不足先给清理缓存，不直接删除用户内容。
- 清理缓存与删除已下载课程分开；删除前说明是否影响离线学习。
- App 进入后台、锁屏或弱网后可恢复；进度不依赖 Toast，页面重进仍可见。
- Admin 导出、报表和批量处理也进入同一任务式下载模型，但显示任务创建人、字段范围和过期时间。

### 7.5 多端同步

全局轻量状态使用：已同步、同步中、等待网络、冲突、同步失败；不频繁弹 Toast。详情页显示最近同步时间、设备、待提交事件数和重试入口。

同步事件状态机：

```text
本地记录 → 待上传 → 上传中 → 服务端确认 → 已同步
                         ↘ 失败 → 可重试
                         ↘ 冲突 → 展示差异 → 保留本地未提交事件 / 采用服务端版本
```

- 默认采用服务器事件版本，同时保留本地未提交事件；只有不可自动合并时才打断用户。
- 学习答题、收藏、复习反馈和播放位置优先事件化；重复提交必须幂等。
- 学习计划冲突显示两个设备的修改时间、差异字段和影响范围，提供“采用服务器版本”“保留本地版本”“逐项选择”。
- 冲突未解决时不阻塞已经下载的学习内容；主 CTA 写明当前可继续的范围。

### 7.6 网络、服务和恢复

| 状态 | 用户文案 | 主操作 | 辅助行为 |
|---|---|---|---|
| 离线 | 当前离线，已下载内容仍可继续学习。 | 查看离线内容 | 重试、查看同步状态 |
| 弱网 | 网络不稳定，已保留本次操作。 | 重试 | 查看本地进度 |
| 服务暂时不可用 | 服务暂时开小差，你的学习进度已保存在本机。 | 重试 | 联系客服、查看状态 |
| 登录过期 | 为了保护账号，请重新登录。 | 重新登录 | 返回原页面 |
| 权限不足 | 你没有执行此操作的权限。 | 返回 | 查看角色 / 联系管理员 |
| 资源不存在 | 该内容已下线或暂不可用。 | 返回课程 | 查看替代内容 |
| 版本不兼容 | 需要更新后才能继续。 | 更新 App | 稍后处理 |

禁止将 `500 Internal Server Error`、堆栈、请求 URL 或内部服务名直接展示给用户；日志和 Request ID 只在“复制诊断信息”或客服工单中提供。

崩溃恢复：重启后显示恢复卡片“已恢复到第 17 / 30 题”，提供继续、重新开始和放弃本次恢复；恢复卡片不覆盖系统权限和关键安全提示。

### 7.7 帮助中心与工单

搜索默认提示“无法登录、会员、下载”；分类包括登录、学习、会员、支付、下载、Study Room、3D 人物、奖励、隐私。FAQ 不能解决时提供提交工单入口。

工单字段：类型、标题、描述、自动设备信息、可选截图、关联订单 / 内容。提交后显示已提交、处理中、待用户补充、已解决和最近更新时间；用户补充信息保留历史，不覆盖原始描述。

## 8. 无障碍与包容性规范

目标为 WCAG 2.2 AA 级别的关键路径体验，最终以各平台原生辅助功能测试结果为准。

### 8.1 视觉与颜色

- 正文与背景对比度目标至少 4.5:1，大字号和图形边界至少 3:1；品牌浅底上的次级文字必须复核对比度。
- 不用颜色作为唯一状态编码；正确 / 错误 / 同步 / 风险同时使用图标、文字、边框或形状。
- 支持 Light / Dark 和系统跟随；深色模式不直接反转图片、视频、3D 材质和品质色。
- 支持大字号和系统显示缩放；文本不裁切、不覆盖按钮、不通过省略号隐藏必须完成的说明。

### 8.2 读屏、键盘和焦点

- 每个图标按钮、播放控件、下载任务、设备操作和表格行操作都有可读 label；装饰图标 `aria-hidden`。
- Web / Admin 支持 Tab、Shift+Tab、Enter、Space、Esc、方向键和可发现的快捷键；焦点顺序与视觉顺序一致。
- Focus ring 不被卡片、圆角或 Overflow 裁掉；弹层打开后焦点进入弹层，关闭后回到触发点。
- 表格提供表头关联、排序状态、行选择状态、分页信息和数据表格替代；图表提供摘要、数据表和异常点文字说明。
- 拖拽、长按、悬停等交互必须有点击、键盘或明确按钮替代。

### 8.3 音频、视频、触觉和动效

- 所有视频有字幕；重要音频信息提供文字替代；音频有重播、进度和倍速（若场景需要）。
- 声音不是成功 / 错误的唯一提示；用户可分别关闭自动播放、音效、触觉和动效。
- 正确答案使用轻微上浮和成功描边；错误答案使用轻微位移并立即提供解释，不使用强烈震动。
- Reduced Motion 时关闭粒子、大幅位移和连续开箱动画；地图和 3D 提供静态快照或 2.5D 降级。

### 8.4 输入和触摸

- 学习端最小命中区域 44×44px；相邻操作之间保留至少 8px 间距，删除和确认不紧邻。
- 扫描、录音、拖拽、播放和下载均提供文本状态和失败恢复。
- 键盘遮挡时 CTA 自动抬升；横屏、折叠屏和安全区变化不能导致内容或按钮被裁切。

## 9. 页面状态和内容写作规范

### 9.1 状态覆盖

任何 Page / Pattern 在交付前必须设计以下状态：

```text
Default / Loading / Empty / Partial / Success / Error
Offline / Permission denied / No access / Syncing / Conflict
Disabled / Destructive confirmation / Long task / Recovery
```

空状态固定结构：图形或图标、标题、解释、一个主 CTA。示例：

> 还没有收藏句子
> 在阅读或听力中长按句子，就能加入表达库。
> [去阅读]

### 9.2 文案

- 使用“发生了什么 + 你可以做什么”的结构，避免只写“失败”“错误”“无数据”。
- 主 CTA 使用动词：继续学习、查看解释、重试、查看离线内容、导出数据。
- 错误说明不责备用户；同步冲突说明差异，不使用“数据丢失”除非已确认。
- Admin 操作明确对象、影响范围和生效时间；危险确认按钮写清“下线内容”“注销账号”，不使用模糊“确定”。
- 所有时间、金额、容量、版本和百分比显示单位；数据指标显示统计口径和更新时间。

每个新页面在进入开发前必须具备：

1. Mobile、Pad / Learner Web、Admin（若适用）的布局说明和关键断点截图或线框。
2. Light / Dark Token 对照和不低于 AA 目标的对比度检查。
3. Default、Loading、Empty、Error、Offline、Permission、Conflict / Recovery 状态。
4. 主 CTA、返回、Deep Link、键盘 / 读屏和 Reduced Motion 行为说明。
5. 事件、任务、下载、导出、同步等长操作的可恢复路径和幂等提示。
6. 涉及权限、隐私、支付、退款、注销、下线、概率、冻结或补发的审计与二次确认说明。
7. 低配设备的静态 / 2.5D / 关闭动效降级方案。

上线前 Design QA 必须通过：

- 5 个一级 Tab 职责不重叠，核心学习功能 ≤3 次点击可达。
- Home 首屏 3 秒内可看到主任务，Continue Learning 始终可恢复。
- 组件覆盖率达到 90% 以上；不出现未经登记的颜色、字号、圆角或交互状态。
- 空、加载、错误、离线、同步冲突、权限、崩溃恢复和危险操作均有可见且可操作的状态。
- 不出现 K12、AI Tutor、付费抽箱、自由文本社交等 Phase 1 禁止入口。
- 导出、删除、注销、退款、Household、设备下线、内容纠错和客服工单流程可发现、可追踪、可恢复。

## 11. 设计交付与版本管理

### 11.1 交付清单

每个页面或组件交付包应包含：

- 组件 / 页面名称、所属层级、使用场景和不适用场景。
- Token 引用、Light / Dark 变体、平台断点和密度。
- Default、Hover、Pressed、Focus、Loading、Disabled、Success、Error、Empty、Offline、Permission、Conflict 状态。
- 交互说明：点击、长按、滑动、键盘、返回、焦点、Deep Link、系统权限和错误恢复。
- 文案、读屏 label、字幕 / 文字替代和埋点事件名。
- 设备性能等级和 Reduced Motion 行为。
- 验收矩阵勾选结果、已知限制和下一步 ADR / 合同依赖。

### 11.2 版本与变更规则

- Token、组件 API、状态名和页面模板为公共契约；改变语义时需要变更记录和迁移说明。
- 新增状态先在组件层定义，再由页面使用；页面不得通过局部 CSS 覆盖破坏组件状态。
- 任何影响支付、隐私、账号、权限、审计、奖励概率、数据删除或同步冲突的设计变更，需在 `docs/10-decisions/` 记录决策。
- 设计冻结后仅允许修复可用性、无障碍、合规和阻塞性问题；视觉偏好变更进入下一版本。
