# 18｜Phase 1 设计验收清单

> **Historical / Superseded（历史 v1 设计包）**：仅用于 v1 迁移与审计追溯，不是当前实现指令。当前业务设计、任务、契约与验收以 [v2-980plus/README.md](../../v2-980plus/README.md) 为唯一入口；本文的旧数量、时间、架构、认证、事件、支付、版权和项目结构表述不得覆盖现行基线。

> **用途**：设计评审 / 开发联调 / 上线前检查

---

## A. 阶段边界

- [ ] UI中没有 K12 / 中高考同步培训入口
- [ ] 没有 AI Tutor / AI评分 / AI实时陪练入口
- [ ] 不存在未成年人注册入口
- [ ] Study Room 无自由文本评论、私聊、群聊
- [ ] 随机奖励箱不能购买
- [ ] 不存在充值货币抽箱
- [ ] 装扮不可交易、提现
- [ ] SVIP为固定可预览权益，不送付费关联随机抽取次数

---

## B. 导航

- [ ] 5个一级Tab职责不重叠
- [ ] 任意核心学习功能 ≤ 3 次点击可达
- [ ] Home 3秒内看到主任务
- [ ] Continue Learning 始终可恢复
- [ ] 通知 Deep Link 正确

---

## C. 学习交互

- [ ] 一屏一个主要学习任务
- [ ] 正确/错误不只依赖颜色
- [ ] 所有错误有解释路径
- [ ] SRS反馈按钮清晰
- [ ] 音频有重播
- [ ] 拖拽题有无障碍替代

---

## D. 个性化

- [ ] Adaptive Home可关闭
- [ ] 可查看推荐原因
- [ ] 可恢复默认布局
- [ ] 不使用消费能力进行学习内容排序

---

## E. 3D

- [ ] 低端设备有静态快照模式
- [ ] 学习Session不强制加载3D
- [ ] 装扮品质不影响学习数值
- [ ] 成员展示遵循隐私开关

---

## F. 奖励

- [ ] 奖池可查看
- [ ] 概率可查看
- [ ] 有规则版本
- [ ] 有开箱历史
- [ ] 重复物品可转碎片
- [ ] 有确定性兑换通道
- [ ] 动效无赌场意象

---

## G. 商业

- [ ] 价格明示
- [ ] 退款入口可发现
- [ ] iOS数字权益使用合规购买流程
- [ ] Household共享权益但不共享学习数据
- [ ] 订单状态完整

---

## H. 基础设施

- [ ] 消息分类完整
- [ ] Push可关闭
- [ ] Email营销可退订
- [ ] SMS不用于日常学习轰炸
- [ ] 勿扰时间生效
- [ ] 账号绑定/合并有冲突确认
- [ ] 设备可下线
- [ ] 用户可删除/导出数据
- [ ] FAQ/工单可用
- [ ] 内容纠错入口可用

---

## I. 弱网

- [ ] 断网学习进度不丢
- [ ] 崩溃后可恢复
- [ ] 重复提交幂等
- [ ] 下载可暂停/恢复
- [ ] 用户能看懂错误文案

---

## J. 视觉

- [ ] Light/Dark均完成
- [ ] 字号符合Token
- [ ] 颜色符合Token
- [ ] 重要CTA层级一致
- [ ] 红点不过载
- [ ] 阅读页不过度游戏化
- [ ] 成人视觉不幼稚

---

## K. 上线设计冻结条件

满足以下条件可进行 Phase 1 UI Freeze：

1. 核心 P0 页面全部有高保真稿；
2. 组件库覆盖 ≥ 90% 页面；
3. Empty / Loading / Error / Offline 状态齐全；
4. Deep Link 矩阵完成；
5. 3D低配降级方案完成；
6. 随机奖励规则页完成；
7. 隐私/权限/注销流程完成；
8. 支付/退款/Household流程完成；
9. Design QA 无 P0 阻塞问题。
