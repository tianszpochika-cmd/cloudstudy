# 01 账号与入学引导设计

> 需求溯源：PRD §6.1 账号与注册登录、§6.2 用户信息与档案、mvp-scope P0。

---

## 一、功能设计

### 1.1 注册与登录
| 功能点 | 规则 |
| :--- | :--- |
| 手机验证码登录 | 未注册手机号首次验证即自动注册；验证码 60s 防频刷、每日上限；无密码体系（减少遗忘成本） |
| 微信授权登录 | App/H5 调起授权；未绑定手机号时强制补绑（实名合规）；同手机号自动合并账号，学习记录归并 |
| 登录态 | JWT + 静默刷新；多端同时在线；"我的-设备管理"可下线其他设备 |
| 账号注销 | 自助发起 → 7 天冷静期可撤回 → 15 日内完成；数据按用户选择匿名化或删除 |
| 未成年人标识 | 注册时选填出生年份；<18 岁自动进入未成年人模式（可绑定监护人） |

### 1.2 入学引导（Onboarding）
1. **双协议确认**：首次启动弹出《用户协议》《隐私政策》摘要，勾选同意后进入（合规留痕）。
2. **学习目标选择**：四级 / 六级 / 日常提升 / 零基础（四选一卡片，可后续修改）；选择后推荐默认词书。
3. **目标考试日期**（可选）：用于首页倒计时与今日任务权重。
4. **水平快速自测**（可选、可跳过）：20 题自适应出题（答对升难度、答错降难度），产出预估词汇量与起始词书位置建议；题目来自公开题库。
5. **昵称与头像**：昵称必填（默认生成"星星+随机名"），头像从预设头像库选择（第一阶段不开放上传）。
6. **提醒设置**：引导开启学习提醒（默认 20:00），H5 引导浏览器通知授权、App 引导推送授权。

### 1.3 监护人模式
- 孩子账号"我的-监护人"发起绑定 → 监护人手机收到绑定码 → 监护人注册/登录后确认。
- 监护人权限：查看学习报告（只读）、设置每日使用时长提醒、排行榜匿名强制、支付确认。

### 1.4 边界情况
| 场景 | 处理 |
| :--- | :--- |
| 微信已绑手机号 A，再用手机号 B 登录 | 提示账号已存在，引导切换而非重复注册 |
| 验证码超频 | 冷却 10 分钟并提示，防刷接口风控记录 |
| 自测中途退出 | 进度保留 24h，可从"我的"继续 |
| 注销冷静期内登录 | 提示"账号注销中"，可一键恢复 |

## 二、交互设计

### 2.1 主流程线框（首次启动）

```
+----------------------------------+
|  启动屏：星空 + 品牌 Logo          |
+----------------------------------+
        ↓
+----------------------------------+
|  协议弹窗（摘要 + 勾选 + 全文链接） |
|  [同意并继续]  [不同意→退出]       |
+----------------------------------+
        ↓
+----------------------------------+
|  登录页：                         |
|  [手机号输入] [验证码] [获取]      |
|  [本机号码一键登录]                |
|  ─── 或 ───  [微信图标] 微信登录   |
+----------------------------------+
        ↓（新用户）
+----------------------------------+
|  目标选择：四张卡片                |
|  [四级] [六级] [日常提升] [零基础] |
|  目标考试日期（可选）              |
+----------------------------------+
        ↓
+----------------------------------+
|  水平自测？ [开始 20 题] [跳过]    |
+----------------------------------+
        ↓
+----------------------------------+
|  设置昵称 + 选头像 → 进入首页      |
|  （撒星动效欢迎，Performance 档静态）|
+----------------------------------+
```

### 2.2 关键交互细节
- **目标卡片**：选中态放大 + 描边高亮，附一句人群描述（"冲刺 CET-4，核心 4500 词"）。
- **验证码按钮**：点击后 60s 倒计时禁用；错误 3 次触发图形验证。
- **水平自测**：单题一页、无返回修改（保证自适应准确）、顶部进度点；结束页展示预估词汇量 + 推荐起点 + "进入首页"。
- **头像选择**：3×4 预设头像网格，选中加描边；底部"换一批"。
- **失败与空态**：网络错误统一弹"星空信号弱"提示卡 + 重试按钮，不出现技术错误码。

### 2.3 动效与反馈
- 欢迎进入首页：星星汇聚成星座 Logo（High 档以上，≤1.5s 可跳过）。
- 所有引导步骤支持"跳过"，不强制；跳过的可选项在"我的"保留补全入口（红点提示一次）。
