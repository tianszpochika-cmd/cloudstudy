# 09 游戏化与排行榜设计

> 需求溯源：PRD §2.7 趣味学习与游戏化、§6.2 隐私设置（榜单匿名）、mvp-scope P0。
> 设计原则（design-system.md）：**不制造羞耻感**——排行榜可关可匿名，不用连续打卡制造压力。

---

## 一、功能设计

### 1.1 排行榜
| 榜单 | 口径 | 规则 |
| :--- | :--- | :--- |
| 背词周榜 | 本周新学 + 复习词量 | 每周一 0 点重置归档 |
| 打卡周榜 | 本周打卡天数 | 同上 |
| 模考分榜 | 本周最高模拟分 | 仅参与者可见自己排名 |

- **范围**：全站榜 + 战队内榜（战队内更强调互助：展示"队友今日完成"而非纯名次）。
- **隐私控制**：设置内三选一——显示昵称 / 匿名（"某颗星"）/ 不上榜；未成年人账号默认匿名且监护人可强制。
- **防刷**：同一词重复复习不计入背词榜；模拟分榜需完整交卷。
- **奖励**：周榜前 10% 发徽章与星星奖励（只奖头部不踩尾部，榜单不展示"倒数"）。

### 1.2 徽章与成就体系
- **阶梯设计**（示例）：
  - 打卡系：3 天/7 天/30 天/100 天（断签重计但保留历史最高，文案不指责）；
  - 词汇系：100/1000/4500 词里程碑；
  - 考试系：首次模考/及格/500+；
  - 探索系：首次跟读、首次战队、全音标过关。
- **展示**：徽章墙（点亮/未点亮灰色剪影）；新徽章弹窗仪式感动效（可跳过）。
- 徽章可设为资料卡展示（最多 3 枚）。

### 1.3 学习战队与能量树
- **组队**：3–6 人，好友邀请码/分享链接加入；无匹配池（避免陌生人社交合规风险）。
- **能量树**：队员每日完成任务浇水（自动），树按总积分生长（幼苗→小树→大树→开花 4 形态）；周日结算"本周战队之星"。
- **战队看板**：队友今日完成情况（完成/未完成两态，不展示分数比较）、战队累计天数。
- **退出与解散**：随时退出（冷却 24h 再加入他队）；队长解散需全员确认。

### 1.4 趣味小游戏：六类游戏矩阵（首期上线 4 款）

> 所有游戏均为 Vue 组件简单版（无 Phaser 依赖），共用统一规则：**题目包从用户当前词书/语法进度抽取（玩即复习）**；每日限局防沉迷（免费 3 局/VIP 5 局，跨游戏共享额度）；画质引擎低档降级为静态点选玩法。每题结算即时写回复习队列（答错的词/句自动进入今日复习）。

| # | 游戏 | 类型 | 核心机制 | 首期状态 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 拼句火车 Sentence Train | 句型·拖拽 | 词块车厢拼合法句，陈述→疑问→复合句三难度 | ✅ 首发 |
| 2 | 单词消消乐 Word Match | 配对·记忆 | 8×4 翻牌配对（单词-释义/音标），连击加速 | ✅ 首发 |
| 3 | 单词保卫战 Word Defense | 拼写·生存 | 怪兽逼近，限时拼写单词攻击；拼错扣血，血量耗尽结算 | ✅ 首发 |
| 4 | 拼图解谜 Word Puzzle | 拼写·解谜 | 字母重排/缺字补全还原单词，含音标提示道具 | ✅ 首发 |
| 5 | 语法射击 Grammar Blaster | 语法·速答 | 语法选择题限时连击闯关，答错展示解析卡 | 🔒 预留 |
| 6 | 词义捕手 Catch the Meaning | 反应·选择 | 释义下落，移动接住目标单词的正确释义 | 🔒 预留 |

- **难度适配**：每局题目按用户当前词书与复习队列成熟度抽取（待复习词占 70%、新词占 30%）。
- **结算口径**：每局产出星星（可兑换补签卡/头像装饰）+ 复习数据写回；同词重复答对不重复计星星。
- **预留款节奏**：5/6 两款在数据表现验证后于第一阶段内排期追加，不阻塞首发。

#### 拼句火车（Sentence Train）细节
- 词块车厢拖入轨道拼出目标中文对应的英文句；判定合法后火车开走 + 星星。
- 每局 5 题限时 3 分钟，含 1–2 个干扰词块。
#### 单词消消乐（Word Match）细节
- 错配翻回，全消结算（用时/步数评星）。
#### 单词保卫战（Word Defense）细节
- 单词按音节分段提示；每词限时 15s，答对播攻击动效，5 词一波。
#### 拼图解谜（Word Puzzle）细节
- 两种模式：字母重排（乱序字母块拼词）与缺字补全（挖 1–3 空）；提示道具消耗星星。

### 1.5 打卡补签卡
- **定位**：断签救济道具，保住连续打卡与打卡周榜进度，不制造补签焦虑。
- **获取**：星星兑换（100 星/张，库存上限 3 张）；VIP 每月 1 日赠送 2 张。
- **使用规则**：断签后 **3 天内**可补签前一日；每日限用 1 张；不可跨周补签（周榜重置后失效）；补签日在日历上显示特殊标记（与正常打卡视觉区分）。
- **文案基调**："昨天差一点，用补签卡接上吧"——不指责、不倒计时催迫。

### 1.6 分享海报
- **三类模板**：
  | 模板 | 触发入口 | 内容要素 |
  | :--- | :--- | :--- |
  | 打卡海报 | 完成任务结算页/日历页 | 连续天数、今日数据、鼓励文案 |
  | 周报海报 | 周报页 | 本周学习概览、徽章、战队 |
  | 成绩海报 | 模考报告页 | 模拟分、提升幅度（分数可选隐藏） |
- **生成与分享**：canvas 客户端生成图片（无服务端依赖）→ 保存到相册/分享（小程序/微信 SDK）；海报含品牌 Logo 水印与个人邀请码（可关闭）。
- **隐私边界**：不含真实姓名、手机号、头像照片（仅预设头像图形）；未成年人账号默认不带邀请码。

### 1.7 边界情况
| 场景 | 处理 |
| :--- | :--- |
| 战队不足 3 人 | 允许 2 人队，能量树生长速度按人数折算 |
| 榜单数据敏感（低参与） | 参与人数 <50 时只展示自己排名不展示他人 |
| 未成年人游戏时长 | 小游戏计入每日使用时长提醒 |
| 补签卡库存不足 | 兑换入口展示星星进度，不弹付费推销 |
| 海报生成失败（低端机） | 降级为纯文案分享（不生成图片） |

### 2.4 关键交互细节
- **拖拽**：移动端长按拖拽 + 磁吸入槽；Web 端支持点击选择再点槽位（无障碍替代）。
- **连击反馈**：消消乐连击 ≥3 触发音效升调 + 粒子（High+，低档仅数字）。
- **新徽章仪式**：全屏暗场 + 徽章旋转点亮（≤2s，可跳过，Performance 档直接弹窗）。
- **榜单展示**：自己的行高亮固定可见（即使排名靠后也锚定显示），他人仅前 20 名 + "超过 xx% 用户"汇总条。
- **补签动效**：断签日格子点击 → 弹补签卡使用确认（展示剩余张数）→ 补签成功格子点亮为"补签"色 + 连续天数重新连上。
- **海报生成**：生成耗时 >1.5s 显示进度；生成后先预览再保存/分享，避免直接外发。
