## 规范执行要点

- 品牌渐变仅用于规范 5 用途：首页核心 CTA / 地图关键区域 / XP 卡 / 3D 展示背景 / 计划结果卡。
- 答题反馈颜色只辅助（文字说明始终存在，01 §5）。
- 奖励箱明示"免费获得、不可购买"，开箱为卡片揭示式，无轮盘/拉杆/爆大奖视觉（10 §5/§6）。
- 呼吸动效等动画均带 `prefers-reduced-motion` 降级（17 动效无障碍规范）。
- 推荐卡带"为什么推荐给我？"可解释入口，规则不含消费因子（03 §3）。
