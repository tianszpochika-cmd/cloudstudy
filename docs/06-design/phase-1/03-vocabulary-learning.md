# 03 单词学习设计（核心模块）

> 需求溯源：PRD §2.1 单词学习、§6.3 VIP 权益（词书/背词量分层）、mvp-scope P0。

---

## 一、功能设计

### 1.1 词书库
| 词书 | 说明 | 权益 |
| :--- | :--- | :--- |
| 四级核心词汇 | 首发词书，按高频排序 + 教材顺序双索引 | 免费 |
| 六级核心词汇 | 含四级已学标记（去重提示） | VIP |
| 中学基础词汇 | 面向零基础用户 | VIP |
| 日常高频会话词 | 场景分组（餐饮/出行/社交） | VIP |

- 词书详情页：词量、预计完成天数（按每日背词量）、音频覆盖率、"开始学习/继续"。
- 同时只能主学 1 本词书（保证复习队列稳定），可切换但旧书进度保留。

### 1.2 词条数据结构（内容侧）
每个词条：单词、音标（IPA）、原声音频、中文释义（分层：核心义/扩展义）、英文例句 + 翻译、助记（词根词缀/谐音/图像联想）、词形变化、考点标记（四六级高频）。

### 1.3 背词会话（核心流程）
- **分组**：以 10 词为一组（Group），一次会话学 1–3 组（用户设置）。
- **三步流程**（每组内循环）：
  1. **识记**：词卡展示单词 + 音标 + 释义 + 例句，自动播放发音，可点击助记展开；
  2. **回忆测试**：看中文释义 + 首字母提示 → 自评按钮：`认识` / `模糊` / `不认识`；或拼写测试（听音拼写/看义拼写，按词难度选择）；
  3. **组末小测**：本组 10 词四选一快测，错题即时重学。
- **自评入队规则**（SuperMemo-2 简化映射）：认识→间隔拉长入复习队列；模糊→当日会话内重现 1 次 + 短间隔；不认识→本组内立即重学 + 次日复习。
- **免费层限流**：每日新词上限 N 个（如 50），到期复习**不限量**（复习不设门槛，保护学习效果）；触限展示升级卡片。

### 1.4 单词详情页
- 内容：全部词条信息 + 发音慢速开关 + 收藏/加入词库 + 我的学习记录（见过几次、正确率）。
- 从任何模块（阅读例句、错题、搜索）点词进入，统一组件。

### 1.5 个人词库
- 自动收录：背词标"不认识"、练习/考试错题词、查词记录。
- 手动管理：添加、移出、按熟练度分层（陌生/进行中/已掌握）；VIP 支持自建词书（如"我的易错词书"）并纳入背词计划。

### 1.6 词根词缀专题课
- **内容结构**：100+ 常用前缀/后缀/词根，每词根一课：
  1. **讲解卡片**：词根含义 + 记忆口诀 + 构词规则（前缀改义/后缀改性）；
  2. **派生词族**：围绕该词根的 6–12 个高频派生词（均关联到现有词书词条，可一键进入详情）；
  3. **快测**：词根含义选择 + 派生词义猜词（5 题），通过后点亮图谱节点。
- **串记联动**：词条详情的助记字段展示所属词根（如 un- + like），点击跳转专题课；专题课派生词学完自动进入背词队列。
- **入口**：学习页"词根词缀"二级页（按前缀/后缀/词根三栏 + 进度图谱）；VIP 全部解锁，免费层试学 10 课。

### 1.7 边界情况
| 场景 | 处理 |
| :--- | :--- |
| 当日新词学完 | 提示"今日新词已完成，复习队列还有 M 个"，引导复习 |
| 会话中途退出 | 组内进度本地保存，下次从断点继续 |
| 音频加载失败 | 自动重试 1 次，失败则该词跳过发音不阻塞流程，后台告警 |
| 切换词书 | 二次确认；旧书复习队列并入总队列不清空 |

## 二、交互设计

### 2.1 背词会话线框

```
+----------------------------------+
| ✕ 退出   第 2 组 / 共 3 组  ▓▓░  |
+----------------------------------+
|                                  |
|        abandon  /əˈbændən/  🔊   |
|        v. 放弃；抛弃              |
|  ┌────────────────────────────┐  |
|  │ He abandoned his car in    │  |
|  │ the snow. 他把车弃在雪中。  │  |
|  └────────────────────────────┘  |
|        [助记：ab-离开+band绑→解开走] |
|                                  |
|   [认识]    [模糊]    [不认识]     |
+----------------------------------+
```

### 2.2 关键交互细节
- **发音**：进入词卡自动播放一次；点击单词或喇叭重播；长按喇叭播慢速。
- **自评按钮**：三键大按钮（绿/黄/珊瑚红描边），支持键盘 1/2/3 快捷（Web 端）。
- **拼写测试**：软键盘输入，提交即判；错字母位红色标记，展示正确答案后可"再试一次"。
- **组末小测**：四选一卡片快闪节奏（每题限时 8s 进度条），答对绿色✓过、答错震动 + 展示词卡 3s。
- **会话结算页**：本组认识/模糊/不认识分布环图 + 获得星星 + "下一组 / 结束"。

### 2.3 动效与画质降级
- 答对：星星迸发粒子（High+）→ 绿色对勾（Medium）→ 仅文字"正确"（Performance）。
- 词卡切换：左右滑卡片飞出（High+）→ 淡入淡出（Medium/Performance）。
- 所有动效 ≤300ms，受四级画质引擎统一管控。
