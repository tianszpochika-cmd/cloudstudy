# 11 管理后台设计（work.clyune.com）

> 需求溯源：mvp-scope P0 内容与后台、PRD §2.9 安全与商用合规（双审留痕）、§6.4 票据与对账。
> 技术栈：Vue 3 + Element Plus；角色权限 RBAC。

---

## 一、功能设计

### 1.1 角色与权限
| 角色 | 权限范围 |
| :--- | :--- |
| 超级管理员 | 全部 + 角色分配 |
| 教研编辑 | 内容创建/编辑/提交审核 |
| 审核员 | 内容审核（一审/终审）、驳回 |
| 运营 | 会员运营、激活码、推荐位、公告 |
| 客服 | 用户查询、补单、工单 |

- 全操作审计日志（谁/何时/改了什么/前后值）。

### 1.2 内容管理
| 内容类型 | 管理功能 |
| :--- | :--- |
| 词书与词条 | 词书 CRUD、词条批量导入（CSV 校验）、音频上传与校验、免费/VIP 标记 |
| 题库 | 语法/词汇/阅读/翻译题 CRUD、知识点标签、难度标定、批量导入 |
| 模拟卷 | 卷结构编排（题型/题量/时间配置化）、发布与下线 |
| 语法点与图谱 | 语法点 CRUD、依赖关系编辑（图谱可视化编辑）、例句管理 |
| 句子拆分库 | 原句/拆解标注/多合法答案集管理 |
| 情景会话 | 场景 CRUD、对话轮次编辑、音频管理 |
| 作文素材 | 汉译英句库、模板范文、病句库 |
| 游戏题包 | 拼句/消消乐题目包管理与投放 |

### 1.3 内容双审流（合规核心）
```
草稿 → 提交审核 → 一审（审核员A） → 终审（审核员B） → 已发布
                ↘ 驳回（注明原因）→ 回到草稿
已发布 → 下线（留痕）→ 可重新提交
```
- 一审与终审不可同人；每次状态变更留痕（人/时间/意见）。
- 已发布内容修改需重走审核（版本管理，可回滚到上一版本）。

### 1.4 会员与商业化运营
- **权益配置**：VIP 矩阵数值在线调整（带生效时间，改前预览）。
- **激活码管理**：批次生成（数量/面值/有效期）、导出 CSV、核销记录查询、作废。
- **订单与对账**：订单台账（状态/渠道/金额）、退款操作、日对账报表导出。
- **试用与优惠**：试用资格管理、优惠位配置。

### 1.5 用户与客服
- 用户查询：脱敏手机号搜索、学习概况、会员状态、设备；**不可导出明文个人信息**（合规）。
- 工单：用户反馈/投诉列表、处理状态流、补单操作（双人复核）。
- 未成年人保护操作：监护人绑定核验、排行榜匿名强制。

### 1.6 数据看板（埋点）
- 核心指标：DAU、新增、次留/7 留、背词完成率、复习完成率、考试参与率、付费转化。
- 漏斗：注册→选目标→首次背词→次日回访；各环节流失定位。
- 内容质量：各词书/题组错误反馈率（用户报错入口汇总）。

## 二、交互设计要点

### 2.1 布局

```
+------------------------------------------------------+
| Logo 语学星运营台      [环境:生产] [角色:审核员] [头像] |
+--------+---------------------------------------------+
| 内容管理 |  词书管理                                  |
| 审核中心 |  [搜索词书] [+新建] [批量导入]             |
| 会员运营 |  ┌──────────────────────────────┐        |
| 用户客服 |  │ 四级核心词书  4523词 已发布 ●  │        |
| 数据看板 |  │ 六级核心词书  5800词 一审中 ◐  │        |
| 系统设置 |  └──────────────────────────────┘        |
+--------+---------------------------------------------+
```

### 2.2 关键交互
- **审核中心工作台**：待审队列 + 并排预览（左内容右审核单），一键通过/驳回（驳回必填原因）。
- **批量导入**：CSV 上传 → 校验报告（行级错误定位）→ 确认入库。
- **危险操作**（下线已发布内容、作废激活码批次）：二次确认 + 原因必填 + 审计留痕。
- **看板**：默认近 7 天，指标卡 + 趋势线 + 漏斗三段式；支持按渠道/平台下钻。
