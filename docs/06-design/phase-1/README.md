# 第一阶段设计总览：标准语言学习 App「语学星」（无 AI 完全商用版）

> **需求溯源**：`requirements/product-requirements.md` §2（十大功能块）与 §6（用户基础与商业化）、`requirements/mvp-scope.md` P0、`docs/09-roadmap/roadmap.md` 第一阶段。
> **设计目标**：做一个**涵盖所有主流学习功能、零 AI 依赖、安全可直接商用**的标准语言学习产品，额外以游戏性形成差异化；"完善美丽"是验收项。Web + H5 先行（uni-app），App 端随后。

---

## 1. 用户角色

| 角色 | 说明 | 设计影响 |
| :--- | :--- | :--- |
| 免费用户 | 注册即用，权益受限（见 VIP 矩阵） | 限制点外露且可一键升级，限制不伤核心体验 |
| VIP 会员 | 月/季/年卡或激活码开通 | 权益标识统一用金色皇冠角标 |
| 未成年人 | 可绑定监护人 | 排行榜可匿名/关闭，支付需监护人确认 |
| 监护人 | 绑定孩子账号 | 只读报告 + 时长管理，不代答练习 |
| 教研/运营/客服 | 后台角色 | 见 11-admin-console.md |

## 3. 全局导航设计

- **底部 TabBar 五项**：`首页` `学习` `复习` `成长` `我的`（H5/Web 大屏转为左侧边栏）。
- **学习场景沉浸原则**：进入背词会话/考试/游戏后隐藏 TabBar，顶部仅保留「退出 + 进度」；考试中退出需二次确认并保存进度。
- **触控与无障碍**：主按钮高度 ≥48px，热区 ≥44×44px；所有语音内容提供文字对照；所有手势提供按钮替代路径。
- **核心手势**：背词卡左右滑切换自评、复习卡右滑"记住/模糊"、听力句左滑循环复读。

## 4. 视觉基调（"完善美丽"验收标准）

| 维度 | 规范 |
| :--- | :--- |
| 主色 | 星云蓝（信任/学习）+ 活力橙（行动/奖励），薄荷绿=正确反馈，珊瑚红仅用于错误提示不制造惩罚氛围；VIP 权益用金色点缀 |
| 卡片与质感 | 大圆角（16-24px）、柔和阴影、低饱和插画背景；禁用刺眼高饱和撞色 |
| 主题 | 星空探索贯穿：学习=收集星星点亮星座；吉祥物静态立绘 + CSS 表情切换（第二阶段升级 Rive 数字人，容器尺寸预留） |
| 字体 | 中文思源黑体/系统字体；英文单词卡用大号无衬线（含音标字体支持 IPA 字符） |
| 动效 | 一律走四级画质引擎；核心反馈动效 ≤300ms；Performance 档退化为色块变化 |
| 深色模式 | 基础深色模式（护眼），跟随系统 + 手动切换 |

## 6. 关键全局规则

1. **免费/付费边界**：所有 VIP 限制点在触达时展示"升级卡片"（说明限制原因与权益），不静默失败；每日限流类限制（背词量）次日 0 点重置。
2. **数据保留承诺**：会员到期仅回收功能权益，学习记录、词库、错题本永久保留（PRD §6.3）。
3. **未成年人保护**：排行榜默认匿名可选、无陌生人私聊、支付需监护人确认（PRD §6.4）。
4. **录音类功能**：首次使用申请麦克风权限并说明用途；录音仅本地对比播放，第一阶段不上传服务器。
5. **内容防复制**：错题本、题库解析仅支持应用内查看与重做，不提供导出/下载/打印接口（PRD §2.9）。
6. **画质降级**：所有动效与粒子受 AdaptivePerformanceEngine 管控，低配档退化为静态反馈。
