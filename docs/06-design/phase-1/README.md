# 第一阶段设计总览：K12 传统型学习 App「语学星」

> ⚠️ **待重建**：第一阶段目标已调整为“标准多语言学习软件（无 AI 完全商用版）”（单词/语法/句子拆分/口语/作文/考试/排行榜/趣味学习，不再以 K12 教材同步为主线，见 PRD §2）。本文档及以下各模块文档基于旧 K12 口径，即将按新需求重建；可复用的通用部分：导航结构、视觉基调、四级画质约束、第二阶段预留思路。

> **需求溯源**：`requirements/product-requirements.md` §2（K12 体系，剔除数字人/AI 评测）、`requirements/mvp-scope.md` P0、`docs/09-roadmap/roadmap.md` 第一阶段。
> **设计目标**：面向中小学生（小学一年级 ~ 初中三年级），做一个**不依赖 AI 也完整好用、界面完善美丽**的传统英语学习 App。Web + H5 先行（uni-app），App 端随后。

## 1. 用户角色

| 角色 | 说明 | 设计影响 |
| :--- | :--- | :--- |
| 学生（主用户） | 小学一年级 ~ 初中三年级 | 低龄段（1-3 年级）大字号、语音引导为主；高龄段信息密度适度提升 |

| 教研/运营 | 后台角色，见 07-admin-console.md | 不进入学习端设计 |

## 2. 信息架构（IA）

```
语学星（学习端）
├── 首页（今日任务 + 学习进度 + 打卡）
├── 教材（教材同步学习区）
│   ├── 教材/年级选择与切换
│   ├── 单元(Unit) → 课时(Lesson) 列表
│   └── 课时四维闭环：单词预习 / 课文跟读 / 语法拆解 / 自测小考
├── 实验室（专项训练区）
│   ├── 48 音标实验室
│   └── 自然拼读法则树（Phonics）
├── 复习（记忆中心）
│   ├── 今日复习队列（间隔重复）
│   ├── 错题本
│   └── 我的词库
└── 成长（激励与社交区）
    ├── 徽章与成就
    ├── 学习战队与能量树
    └── 趣味小游戏（拼句火车、拼读消消乐）
全局浮层：家长报告入口、设置（含画质与音效开关）、提醒授权引导
```

## 3. 全局导航设计

- **底部 TabBar 四项**（H5/Web 大屏时转为左侧边栏）：`首页` `教材` `复习` `成长`。实验室从首页与教材页入口进入，避免 Tab 超过 4 项。
- **学习场景沉浸原则**：进入课时学习/游戏后隐藏 TabBar，顶部仅保留「退出 + 进度」，防止中途跳出打断心流；退出需二次确认（已产生进度时）。
- **儿童友好触控**：主按钮高度 ≥ 48px，点击热区 ≥ 44×44px；低年级界面文字配语音播报按钮（TTS 朗读界面提示语，第一阶段用浏览器/系统 TTS）。
- **手势**：跟读页左滑下一条、复习卡片右滑"记住了/模糊"（Web 端提供按钮替代路径，遵循无障碍原则）。

```
+--------------------------------------------------+
| 首页 | 教材 | 复习 | 成长        ← 底部 TabBar    |
+--------------------------------------------------+
```

## 4. 视觉基调（"完善美丽"的验收标准）

| 维度 | 规范 |
| :--- | :--- |
| 主色 | 星云蓝（信任/学习）+ 活力橙（行动/奖励），辅以薄荷绿（正确反馈）、珊瑚红（错误，仅用于提示不用于惩罚氛围） |
| 圆角与质感 | 大圆角卡片（16-24px）、柔和阴影、低饱和插画背景；禁用刺眼高饱和撞色 |
| 插画 | 星空探索主题贯穿：学习 = 收集星星点亮星座；吉祥物（第二阶段升级为数字人，第一阶段为静态立绘 + CSS 表情切换） |
| 字体 | 中文思源黑体/系统字体；英文采用 Comic 风格少儿字体（低年级）与清晰衬线（高年级朗读材料） |
| 动效 | 一律走四级画质引擎；核心反馈动效 ≤300ms；Performance 档退化为色块变化 |
| 暗黑模式 | 第一阶段提供基础深色模式（护眼），不做复杂沉浸暗色（第二阶段高中场景再做） |
