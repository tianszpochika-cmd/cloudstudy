# 10 VIP 与商业化设计

> 需求溯源：PRD §6.3 VIP 与权益机制、§6.4 订阅与支付、mvp-scope P0 用户基础与商业化。

---

## 一、功能设计

### 1.1 权益矩阵（前端呈现口径）
| 功能 | 免费层 | VIP |
| :--- | :--- | :--- |
| 词书 | 四级核心 | 全部词书 |
| 每日新词 | 50 个 | 不限 |
| 语法卡片 | 基础篇 | 全部 + 进阶 |
| 模拟考试 | 每周 1 次 | 不限 + 回看 |
| 错题本 | 近 30 天 | 全历史 |
| 游戏局数 | 每日 3 局 | 每日 5 局 |
| 学习报告 | 周报 | 日报 + 薄弱分析 |
| 打卡补签卡 | 仅星星兑换 | 每月赠 2 张 + 星星兑换 |
| 自建词书 | ✕ | ✓ |

- 数值全部后台配置化，不发版可调。
- **到期复习永不设限**（学习权保障，PRD §6.3）。

### 1.2 会员中心页
- 当前权益状态卡（VIP 剩余天数/免费层 + 已用额度）。
- 权益对比表（上表可视化，免费项打灰勾、VIP 项金勾）。
- 规格选择：月卡/季卡/年卡（默认高亮年卡"最划算"角标）；新用户试用位（3 天，每账号限一次）。
- 支付方式：微信支付/支付宝（H5/App）；激活码兑换入口。
- 购买记录与到期提醒设置。

### 1.3 购买与激活流程
1. **在线支付**：选规格 → 下单（服务端创建订单）→ 调起支付 → 回调核验 → 权益生效 + 成功页（撒星动效）。
2. **激活码**：我的-激活码输入 16 位码 → 校验（有效/已用/过期/格式错四态）→ 权益生效；激活码批次由后台生成与核销留痕。
3. **掉单处理**：支付成功但回调失败 → 客户端主动查询补偿（3 次轮询）+ 客服补单通道。
4. **退款**：客服后台发起，权益即时回收，订单台账记录。

### 1.4 到期与续费
- 到期前 7/3/1 天站内提醒（设置可关）；到期当日权益降级。
- **降级体验设计**：降级不弹窗轰炸，仅在首次触达受限功能时展示温和升级卡片；数据全部保留（词库/错题/记录只读可用）。
- 续费优惠位（仅展示一次/周，不做倒计时焦虑营销）。

### 1.5 未成年人支付保护
- 未成年人账号：支付按钮点击 → "需监护人确认"流程（监护人账号收到确认请求）→ 可设月度支付限额。

### 1.6 升级卡片触达规则（全局组件）
| 触发点 | 文案基调 |
| :--- | :--- |
| 新词达每日上限 | "今日新词已完成 50 个，升级解锁不限量" |
| 点击 VIP 词书 | "《六级核心》是 VIP 词书，免费试看 10 词" |
| 模考次数用尽 | "本周模拟已用完，升级不限次 + 历次回看" |
| 30 天前错题 | "升级保留全部错题历史" |
- 规则：同一触发点每日最多弹 1 次；VIP 试看（词书 10 词）降低决策门槛。

## 二、交互设计

### 2.1 会员中心线框

```
+----------------------------------+
| 会员中心                          |
| ┌ 当前：免费用户 ─────────────┐   |
| │ 今日新词 32/50 · 六级词书未解锁│ |
| └────────────────────────────┘   |
| [月卡 ¥18] [季卡 ¥45] [年卡 ¥128★]|
| 新用户专享：3 天 VIP 免费试用     |
| [立即开通]   [激活码兑换]         |
| ── 权益对比 ──                    |
| 词书      免费:1本  VIP:全部      |
| 模拟考    免费:周1次 VIP:不限     |
+----------------------------------+
```

### 2.2 升级卡片线框（全局浮层）

```
+----------------------------------+
| 🔒 六级核心词书是 VIP 专属         |
| 先免费试看 10 词？                 |
| [试看 10 词]  [开通 VIP ¥128/年]  |
|               （今日不再提示）     |
+----------------------------------+
```

### 2.3 关键交互细节
- **支付成功页**：皇冠点亮 + 权益清单逐条勾选动画（≤2s）+ "开始体验 VIP 词书"直达。
- **激活码输入**：4 位一组自动分段，粘贴自动拆分；错误态抖动 + 明确原因。
- **价格展示**：明码标价含"约 ¥x/天"换算；无隐藏自动续费勾选（第一阶段无自动续费）。
