# 沉浸式前端与动效渲染架构

> 适用于语学星 uni-app 前端。Phase 1 只实现学习地图、游戏化、音频、阅读和可选 3D Avatar 等非 AI 沉浸能力；实时 AI、数字人和流式反馈属于 Phase 2。

## 1. 分层渲染

- 原生页面层：uni-app 页面、表单、列表、任务、练习、报告和设置。
- 轻动效层：CSS、uni-app 动画、VueUse Motion，用于状态切换、进度和答题反馈。
- 增强媒体层：Wavesurfer、视频、音频逐句播放和轻量 Canvas，仅按页面懒加载。
- 重渲染层：Three.js、Rive、Phaser 通过 H5/App web-view 隔离承载；小程序使用 2D 或静态方案。

## 2. Phase 1 实现边界

- 可以实现学习地图、XP、连击、轻游戏、阅读器、音频波形、3D Avatar 快照和可选实时 3D 展示。
- 不实现生成式 AI 流式回答、AI 数字人、AI 语音陪练、AI 发音评分或模型驱动状态机。
- 任何复杂动画都必须服从 AdaptivePerformanceEngine 四档策略。

## 3. Phase 2 预留

- 结构化 AI 反馈采用局部响应式更新、分段渲染和可取消请求，避免整页重排。
- 数字人使用 Rive 状态机，状态只能由经过校验的会话事件驱动。
- 实时语音和 Lip-Sync 在商业 RTC、音频权限、成本和安全闸门通过后启用。

## 4. 性能与可访问性

- 首屏不加载非当前任务需要的 3D、游戏或大媒体资源。
- 页面卸载时释放音频、动画和 web-view 上下文。
- Performance 档仅保留文本、色彩、静态图和基础音频控件。
- 动效、声音和触觉都必须允许用户关闭，并提供非颜色单一反馈。

## 5. 验收

- 学习任务在 Web/H5/iOS/Android 的 Performance 档可完整完成。
- 复杂模块加载失败不阻塞背词、练习、提交和复习。
- 动画、媒体和 3D 资源均有加载、空、失败和降级状态。
