# 本地开发

## 目标

任何新成员或编码 Agent 都能在不接触生产数据的情况下启动基础服务、运行测试和查看样例内容。

## 本地依赖

- Node.js 与 pnpm。
- MySQL。
- Redis。
- 可选对象存储模拟服务。
- 可选的模型 mock provider。

## 本地环境原则

- 使用 .env.example 复制出的本地环境文件。
- 默认关闭实时语音、支付和社区功能。
- 使用合成用户和课程种子。
- 日志中隐藏手机号、邮箱、音频原文和模型密钥。
- 端口以 `config/local-ports.json` 为唯一事实源；Gateway 和新服务必须先登记固定端口，禁止自动递增。

## 启动顺序

1. 准备本地依赖。
2. 执行数据库迁移和种子。
3. 启动 v2 Gateway/IAM/领域服务模板；迁移期可启动 `core-api` 兼容入口和 Worker。
4. 启动四个冻结前端项目；微信小程序只通过 `apps/mobile` 条件编译输出。
5. 用测试账号完成测评到复习的完整路径。
