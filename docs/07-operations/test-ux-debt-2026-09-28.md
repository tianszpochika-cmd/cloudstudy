## D1. 冷启动黑洞（业务链：首访无引导）

* 现象：新号进首页/今日/书架全空，无下一步指引；定级入口需人工拼 `/assessment`。
* 复现：新注册 → 过门 → 存目标 → 落首页，无计划横幅、无“去定级”按钮。
* 要求：首访向导（门→同意→目标→定级四步，带进度），空态页配 CTA 按钮。
* 验收：新号 3 次点击内到达定级第一题。关联 `PAGE-P1-LEARN-HOME`、`PAGE-P1-TODAY`。

## D2. 门禁铁板，无等待态（交互：403/503/409 直出）

* 现象：成人门未过整页 403（`trusted_age_required`），无文书 503，无版本 409，前端原文展示错误码，用户视为服务器挂了。
* 复现：新号点成人门（未批）→ 整页 403 卡死，无人话、无返回。
* 要求：提交后放行进系统，学习能力置灰 + “身份确认中”；错误码翻人话；token 资格静默刷新，不要求退出重登。
* 验收：5 种门禁错误均有中文提示 + 明确下一步。关联 `PAGE-P1-ADULT-CONSENT`、`PAGE-P1-AUTH-REGISTER-RESET`。

## D3. 定级双轨断链（业务链：B25/P1 接缝）

* 现象：前端调旧 B25 开题口（2 道），计划编排只认新 P1 报告，答完出分后首页依然空，最高潮接空气。
* 复现：干净库 → B25 答完 100 分 → `learning_plan` 0 行 → 首页无横幅（test 机 2026-09-28 实证）。
* 要求（正道）：前端切 P1 新口（`/placement/sessions`，10 道密封题）→ 报告 → 自动 ensure；B25 退役。test 机 2 条 B25 规则为临时快修，world 种子修好后由种子接管。
* 验收：新号定级 10 题 → 报告 → 首页横幅 → 今日任务，一气呵成。关联 `PAGE-P1-ASSESSMENT`、`PAGE-P1-PLAN-MAP`、`PAGE-P1-TODAY`。

## D4. 同意版本写死（交互 + 契约：前端硬编码）

* 现象：`apps/learner-web/src/api/learner-content.ts` 的 `saveOnboarding` 把三同意 `version` 写死为 `b30-consent-v1`；换环境直接 409。
* 复现：只发布 `test-doc-v1` 的库上点“保存并开始测评”→ 3 个 409（test 机 2026-09-28 实证）。
* 要求：前端先读已发布版本再提交；test 机已追加 `b30-consent-v1`（test 档）解围。
* 验收：只发布新版本文档时，前端无需改代码即可通过。关联 `PAGE-P1-ONB-GOAL`。

## D5. 空态无动作（交互：诚实但无助）

* 现象：今日/书架/社交/商城空态只有一句话，无按钮；用户不知道去哪。
* 要求：每个空态配一个主动作按钮（去定级/去书架/去目标）。
* 验收：5 个空页截屏复核。关联 `PAGE-P1-TODAY`、`PAGE-P1-COURSE-SHELF`、`PAGE-P1-SOCIAL`、`PAGE-P1-COMMERCE`。
