# 产品愿景与文档治理

本目录保存产品方向、目标用户、仓库结构与**文档治理规则**，是整个文档体系的元层。

## 文档清单

- [product-vision.md](product-vision.md)：产品愿景、目标人群与差异化定位。
- [personas.md](personas.md)：用户画像与典型使用场景。
- [repository-tree.md](repository-tree.md)：仓库目录结构与各目录职责。
- [document-governance.md](document-governance.md)：**文档治理规则**，定义事实源优先级、Phase 1 范围冻结、跨域所有权与交付检查流程。
- [document-audit-2026-09-10.md](document-audit-2026-09-10.md)：2026-09-10 文档体系审计记录（9 项问题与修复口径）。

## 须知

`document-governance.md` 是判断文档合格性的唯一标准。任何文档之间出现语义冲突时，按其中定义的优先级顺序解释，低层文档不得静默覆盖高层基线。
