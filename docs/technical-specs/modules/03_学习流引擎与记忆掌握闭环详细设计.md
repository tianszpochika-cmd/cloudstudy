# 03｜学习流引擎与记忆掌握闭环详细设计 (Learning Stream & Memory Engine Domain)

> **设计基线**：PRD v3.3 第 20、21、25、26、36 章  
> **所属业务域**：com.englishflow.modules.learning  
> **目标服务承载**：`learning-service`；外部请求经 `api-gateway`，学习事实和 SRS 由本服务拥有。  
> **迁移兼容**：`services/core-api`，仅作为 v1 兼容承载。  
> **面向端**：apps/learner-web (Vue 3 + Vite), apps/mobile (Vue 3 + uni-app)

---

## 1. 业务目标与阶段边界

学习流引擎是语学星的核心教学中枢，摒弃传统“刷完即忘”的线性模式，落地**“记忆 -> 错误 -> 修复 -> 延迟验证 -> 掌握”**的全闭环科学记忆机制。

- **Phase 1 (确定性规则引擎)**：
  - 基于经典的 **改进型 SuperMemo SM-2 间隔重复算法** 动态计算遗忘曲线与最佳复习排程。
  - 建设“今日任务流 (Daily Learning Stream)”动态组装引擎：每日智能交织“新学内容 (40%) + 到期复习 (40%) + 错题重练 (20%)”。
  - 建立四阶掌握度状态机 (生疏 New -> 熟悉 Learning -> 掌握 Mastered -> 牢固 Consolidated)。
  - 严格执行**延迟验证机制**：错题在当天订正后不标记为掌握，必须在第 2 天与第 7 天的复习流中再次通过，方可转入掌握态。
- **Phase 2 (AI 动态强化)**：
  - 引入弱项薄弱度向量聚类，AI 自适应生成“个性化辨析补丁包”与易混淆变式题。
- **Phase 3 (教材进度同步)**：
  - 支持按 K12 学校周历、考试节点自动调整冲刺复习权重与单元周清排程。

## 2. 完整功能树与子功能矩阵

```text
学习流引擎与记忆掌握闭环 (Learning Stream & Memory Engine)
├── 1. 学习计划与目标排程 (Study Plan Scheduler)
│   ├── 学习词库/课程切换 (CET4 冲刺 / 考研核心 5500 / 零基础日常 1000 / 雅思高频)
│   ├── 每日配额与节奏设定 (新词 10/20/30/50 词/天，复习比例自适应弹性伸缩)
│   └── 预计完成时间倒计时与动态进度追赶机制
├── 2. SM-2 记忆曲线与调度引擎 (SRS Memory Engine)
│   ├── 遗忘度与难度系数动态衰减计算 (Ease Factor 弹性修正)
│   ├── 间隔天数梯度计算 (Interval: 1天 -> 3天 -> 7天 -> 15天 -> 30天 -> 90天)
│   ├── 闪卡记忆反馈评定 (0-完全遗忘 / 1-困难模糊 / 2-顺利想起 / 3-轻而易举)
│   └── 逾期复习智能平滑算法 (防止断签后复习堆积崩溃)
├── 3. 错题本与掌握度闭环 (Mistake Loop & Mastery Lifecycle)
│   ├── 错题智能捕获与归类 (词义辨析错、拼写拼错、长难句结构混淆、听力连读误判)
│   ├── 错题即时攻坚 (即时微解析 -> 结构变式再次校验)
│   ├── 延迟验证防线 (24小时首轮验证 -> 7日二次复验 -> 未通过重新降级打回)
│   └── 四阶掌握度生命周期流转 (生词池 -> 学习中 -> 已掌握 -> 永久归档)
└── 4. 每日学习流流水线 (Daily Stream Pipeline)
    ├── 今日任务包动态构建 (混合新学、复习、错题，形成 15~20 题一组的沉浸流)
    ├── 学习会话暂存与断点续学 (本地 SQLite/Pinia 暂存 + 服务端心跳同步)
    └── 每日学习报告与雷达图生成 (掌握量、遗忘率、专注时长、专注力波形)
```

## 3. 详细交互流程 (UX Flow)

### 3.1 今日沉浸学习流 (Daily Stream) 端到端交互
1. **主页“继续学习”触发**：
   - 客户端调用 `/api/v1/learning/stream/today` 拉取今日待学批次（默认 15 项）。
   - 顶部呈现进度指示条（已完成/总计）、当前 Streak 连续打卡火苗动效。
2. **卡片流转交互循环**：
   - **Step 1 (新词呈现)**：正面看词听音 -> 用户思考 -> 点击翻面 -> 浏览中文释义与 3D 嘴型 -> 点击“认识/不认识”。
   - **Step 2 (穿插交互检测)**：学完 3 个词后，立即穿插 1 道 4 选 1 听音选义题或选词填空题。
   - **Step 3 (即时判分)**：
     - 若正确：播放清脆动效音，触发 +5 XP 浮动动效，自动滑向下一题。
     - 若错误：屏幕轻微震动反馈，卡片变红，立即展开“权威解析与易错陷阱”，同时后端将该项写入今日待重练队列（尾部重排）。
3. **节点冲刺与阶段结算**：
   - 15 项完成后，触发彩带粒子特效与“阶段达成”弹窗，展示本组用时、正确率、掌握新词数；
   - 提供“休息 1 分钟”或“开始下一组复习”按钮。

### 3.2 错题闭环解决交互流 (Mistake Verification Flow)
```text
[做题出错] 
    │
    ▼
[写入错题库] ──► 状态: PENDING_RETRY (待重练)
    │
    ▼
[当日流末尾即时重练]
    │
    ├── 未通过 ──► 留在今日错题队列，反复巩固
    │
    └── 通过 ──► 状态转为: PENDING_DELAY_VERIFY_D1 (待 24h 延迟验证)
                   │
                   ▼
       [第二天复习流暗度抽检]
                   │
                   ├── 抽检失败 ──► 惩罚打回，易忘因子衰减，重新回到待学池
                   │
                   └── 抽检成功 ──► 状态转为: PENDING_DELAY_VERIFY_D7 (待 7天复验)
                                       │
                                       ▼
                             [第 7 天复验通过] ──► 标记为: RESOLVED (真正攻克掌握)
```

## 5. 接口契约规范 (API Contracts)

- `GET  /api/v1/learning/plan/current`：获取用户当前激活的计划及总体进度大盘。
- `POST /api/v1/learning/plan/switch`：切换学习计划（如从 CET-4 切换到 考研英语）。
- `GET  /api/v1/learning/stream/today`：拉取今日待学流列表（按新学/复习/错题配比动态打包，单次返回 15~20 题）。
- `POST /api/v1/learning/stream/action`：提交单题学习反馈（传入 response_quality: 0~3，服务端原子更新 SM-2 进度并返回即时结算）。
- `GET  /api/v1/learning/mistakes/queue`：获取当前待攻坚的错题列表。
- `POST /api/v1/learning/mistakes/verify`：提交错题验证作答。
- `GET  /api/v1/learning/stats/daily-summary`：获取今日学习成果统计与掌握度雷达图。
