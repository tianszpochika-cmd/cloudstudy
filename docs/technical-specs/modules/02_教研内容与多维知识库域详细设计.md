# 02｜教研内容与多维知识库域详细设计 (Content & Knowledge Base Domain)

> **设计基线**：PRD v3.3 第 10、11、12、13、14、22、23、37 章  
> **所属业务域**：com.englishflow.modules.content  
> **目标服务承载**：`content-service` + `media-service`；外部请求经 `api-gateway`，内容发布和版权权限由服务侧 PEP 校验。  
> **迁移兼容**：`services/core-api`，仅作为 v1 兼容承载。  
> **面向端**：apps/learner-web (Vue 3 + Vite), apps/mobile (Vue 3 + uni-app), apps/admin-web (教研后台)

---

## 1. 业务目标与阶段边界

本域负责语学星全生命周期教研内容资产（词汇、语法、长难句、听力语料、阅读材料、题库及多媒体资源）的建模、分级、组织与发布。

- **Phase 1 (成人核心体系)**：
  - 构建严谨的 CEFR (A1-C2) 词汇库与分级标签体系。
  - 构建系统化语法树与 100+ 核心语法点（含结构化长难句 X 光机解析树）。
  - 建设大学英语四六级 (CET-4/6)、考研英语、职场通用词库与真题题库。
  - 静态多模态媒体资源挂载（美音/英音标准 MP3、3D 发音器官关键帧标注数据）。
- **Phase 2 (AI 与高阶拓展)**：
  - 引入雅思 (IELTS 4.5-8.5)、托福 (TOEFL 60-115) 专项真题语料与高频口语机经库。
  - 挂载 AI 动态例句生成元数据与语义向量索引（pgvector/Milvus）。
- **Phase 3 (全龄段与 K12 同步)**：
  - 引入全国主流中小学教材版本（人教版、外研版、牛津上海版、北师大版、翼教版等）的册次、单元、课文、核心词句映射库。
  - 严格版权隔离与合规审核机制。

## 3. 详细交互流程 (UX Flow)

### 3.1 词汇深度学习交互链路
1. **词卡正反面翻转 (Flashcard Mode)**：
   - 正面：呈现目标单词、标准音标、发音按钮（点击触发美/英原声音频播放）、例句填空（挖空词汇）。
   - 交互：用户点击“查看释义”或滑动卡片翻转至背面。
   - 背面：展开词性、中文精准释义、词根词缀图解、3D 口腔舌位剖面入口、完整双语例句。
2. **3D 发音解剖透视交互**：
   - 用户点击发音图标旁的“3D 嘴型”按钮。
   - 客户端唤起 Three.js 渲染的口腔侧剖面 3D 动画，展示发音时舌体隆起位置、软腭升降及气流路线；低配设备自动降级为 2D 骨骼关键帧分解图。
3. **知识网联动**：
   - 点击同义词/派生词胶囊标签，支持通过底部抽屉 (Bottom Sheet) 快速预览该词释义，支持一键“加入待学队列”。

### 3.2 长难句 X 光机 (Sentence X-Ray) 拆解交互链路
1. **初始状态**：呈现未拆解的复杂英文原句，提供原声朗读。
2. **一键透视 (X-Ray 激活)**：
   - 句子根据语法成分自动进行彩色语义切块（主语：蓝色，谓语：橙色，宾语：绿色，定语从句：紫色虚线框，状语从句：黄色底纹）。
3. **树状层级下钻**：
   - 界面下方呈现基于 `Vue Flow` 的交互式语法树。
   - 用户点击任意从句节点，主句高亮对应从句区间，并展开从句内部的主谓宾二次拆解。
4. **互动校验模式**：
   - 系统将句子打散为语法成分卡片，要求用户按“主干 -> 修饰成分”进行顺序拖拽拼装，拼装正确后触发粒子动效并解锁金币奖励。

## 5. 接口契约规范 (API Contracts)

- `GET  /api/v1/content/vocab/detail/{word}`：查询单个单词完整知识档案（释义、音频、例句、3D发音参数、派生词）。
- `GET  /api/v1/content/vocab/batch`：批量获取一组词汇简要信息（用于词卡列表与流式做题）。
- `GET  /api/v1/content/grammar/tree`：获取全量语法分类知识树结构。
- `GET  /api/v1/content/grammar/detail/{code}`：获取指定语法点深度讲义与易错点。
- `GET  /api/v1/content/sentence-xray/{id}`：获取长难句及 X 光机语法切片结构 JSON。
- `POST /api/v1/content/question/query-by-ids`：根据题目 ID 集合批量拉取渲染元数据（去除了标准答案字段，防止客户端逆向抄袭）。
