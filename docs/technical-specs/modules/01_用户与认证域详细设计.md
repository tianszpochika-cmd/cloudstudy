# 01｜用户画像、认证与未成年人合规域 (User & Auth Domain)

> **设计基线**：PRD v3.3 第 17、39 章  
> **所属业务域**：com.englishflow.modules.auth & com.englishflow.modules.user  
> **目标服务承载**：`iam-service`（身份、租户、设备、会话、RBAC/ABAC）+ `learner-service`（学习档案/偏好）；外部请求经 `api-gateway`。  
> **迁移兼容**：`services/core-api`，仅作为 v1 兼容承载。

---

## 1. 业务目标与价值
构建覆盖多端（App/H5/Web/小程序）的统一用户与账户中心。
- **Phase 1**：实现 18+ 成人与大学生快捷登录、多设备会话管理、学习档案与偏好配置，强制实名认证防线。
- **Phase 2**：引入 AI 学习人格画像、职场/留学定制档案。
- **Phase 3**：引入未成年人身份证校验、家长锁与监护人绑定机制。

---

## 2. 核心功能拆解与子功能矩阵

用户与认证域 (User & Auth)
├── 1. 多端认证与登录
│   ├── 手机号一键登录 / 验证码登录 (SMS)
│   ├── 微信开放平台 / 小程序授权登录
│   ├── Apple ID 授权登录 (iOS 原生)
│   └── 密码/验证码双因子重置
├── 2. 会话与多设备管理
│   ├── JWT Token 双令牌刷新机制 (Access Token + Refresh Token)
│   ├── 多端设备指纹采集与设备列表
│   └── 异地登录告警与单端/多端踢出下线
├── 3. 学员画像与学习档案
│   ├── 基础信息 (昵称、头像、性别、生日、所在地)
│   ├── 语言水平基线 (CEFR A1-C2 / 四六级 / 雅思预估分)
│   ├── 每日学习目标设定 (5/15/30/45分钟，目标掌握词汇量)
│   └── 学习偏好与无障碍设置 (音效开关、发音偏好 美音/英音)
└── 4. 合规与未成年人保护 (Phase 3 预留字段)
    ├── 实名认证与年龄鉴权拦截 (18+ 准入)
    ├── 未成年人家长锁密码与使用时长限制
    └── 账户注销与个人数据脱敏导出

## 3. 详细交互流程 (UX Flow)

### 3.1 手机验证码与一键登录流程
1. **客户端发起**：用户输入 11 位大陆手机号，点击“获取验证码”。
2. **频率限制与防刷**：服务端校验 IP 频率与手机号频率（同手机号 60s 内仅发 1 次，单 IP 每日上限 20 次）。
3. **短信触达**：notification-worker 发送 6 位数字验证码，Redis 缓存有效期 5 分钟。
4. **校验与登录**：用户提交验证码，后端原子校验并核销。
   - 若用户不存在：自动注册，生成默认昵称（语学星_XXXX）、默认头像与初始 A1 档案，写入 usr_user 表。
   - 若用户已存在：更新 last_login_at 与 last_login_ip。
5. **Token 签发**：生成 accessToken (有效期 2 小时) 与 refreshToken (有效期 30 天)，写入 Redis 白名单。

### 3.2 首次进入水平测评与画像定制交互
1. **引导页**：展示 3 选 1 目标卡片（A. 零基础入门 / B. 大学四六级与日常口语 / C. 职场进阶与雅思托福）。
2. **5 分钟快速定级**：提供 10 道自适应测试题（词汇、语法、听力各 3~4 题）。
3. **生成定制计划**：计算初始 CEFR 等级，生成初始星图地图与每日任务队列。

## 4. 数据实体与核心字段设计 (Data Schema)

### 4.1 用户主表 (usr_user)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | PK, 自增 | 用户唯一主键 ID |
| uuid | VARCHAR(64) | UK, 非空 | 对外业务唯一标识 (UUID) |
| phone | VARCHAR(20) | UK, 可空 | 绑定手机号 (加密存储) |
| nickname | VARCHAR(50) | 非空 | 用户昵称 |
| avatar_url | VARCHAR(255) | 可空 | 头像 OSS 地址 |
| cefr_level | VARCHAR(10) | 非空, 默认 'A1' | 当前评估等级 (A1, A2, B1, B2, C1, C2) |
| daily_target_mins | INT | 非空, 默认 15 | 每日目标学习时长 (分钟) |
| accent_pref | VARCHAR(10) | 非空, 默认 'US' | 发音偏好：'US' 美音, 'UK' 英音 |
| age_group | VARCHAR(20) | 非空, 默认 'ADULT' | 年龄段：'ADULT'(18+), 'TEEN', 'CHILD' |
| status | TINYINT | 非空, 默认 1 | 状态：1 正常, 0 封禁, 2 注销待删除 |
| created_at | DATETIME | 非空 | 注册时间 |
| updated_at | DATETIME | 非空 | 更新时间 |

### 4.2 第三方账号绑定表 (usr_oauth_binding)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | PK, 自增 | 主键 |

| unionid | VARCHAR(128) | 可空 | 微信开放平台联合 ID |
| created_at | DATETIME | 非空 | 绑定时间 |

### 4.3 用户设备登录会话表 (usr_device_session)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | PK, 自增 | 主键 |
| user_id | BIGINT UNSIGNED | FK, 非空 | 关联用户 ID |
| device_id | VARCHAR(128) | 非空 | 客户端设备唯一指纹 |
| device_type | VARCHAR(20) | 非空 | 设备类型：'IOS', 'ANDROID', 'WEB', 'MP' |
| client_version | VARCHAR(20) | 非空 | 客户端版本号 (如 1.0.0) |
| refresh_token | VARCHAR(255) | 非空 | 刷新令牌 Hash |
| is_active | TINYINT | 非空, 默认 1 | 是否有效 (0 已被顶号/退出) |
| last_active_at | DATETIME | 非空 | 最后活跃时间 |

## 5. 接口契约规范 (API Contracts)
- POST /api/v1/auth/sms/send-code：发送手机验证码
- POST /api/v1/auth/login/phone：手机验证码登录/注册
- POST /api/v1/auth/login/oauth：微信/Apple 快捷登录
- POST /api/v1/auth/token/refresh：无感刷新 Access Token
- GET  /api/v1/user/profile：获取当前学员画像与学习目标
- PUT  /api/v1/user/profile：更新学员昵称、头像、每日学习目标与偏好
- GET  /api/v1/user/devices：获取多端在线设备列表
- POST /api/v1/user/devices/kickout：强制踢出指定设备
