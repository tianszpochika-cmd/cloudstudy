# 06｜自习室与班级社群域详细设计 (Study Room & Social Domain)

> **设计基线**：PRD v3.3 第 31、32、33 章  
> **所属业务域**：com.englishflow.modules.social  
> **服务承载**：services/core-api  
> **面向端**：apps/learner-web, apps/mobile (uni-app)

---

## 1. 业务目标与阶段边界

为缓解独自学习英语的孤单感与拖延症，构建**低干扰、高陪伴、沉浸式**的虚拟自习室与学习小组体系。

- **Phase 1 (无压力陪伴与合规社群)**：
  - 虚拟番茄钟自习室 (Virtual Study Room)：支持“入座”、“静音专注”、“番茄钟倒计时”、“状态展示 (如：正在背四级/正在刷考研阅读)”。
  - 低 UGC 互动机制：严禁开放无监管自由聊天室（防违规与防早恋/诈骗），仅允许预设正向快捷鼓励语（如“加油！”、“一起冲刺四级！”）与表情互动。
  - 排行榜体系：每日/每周专注榜、学词榜（支持隐私隐身模式）。
- **Phase 2 (跨国与职场交流沙龙)**：
  - 引入受控的职场外企 Mock 交流小组（基于 Phase 2 AI 审查把关）。
- **Phase 3 (学校班级与师生互动)**：
  - 引入学校班级群组、教师作业布置与一键学情监督。

## 2. 完整功能树与子功能矩阵

```text
自习室与班级社群域 (Study Room & Social)
├── 1. 虚拟自习室 (Virtual Study Room)
│   ├── 主题自习室大厅 (CET-4 冲刺室、考研早起室、雅思静音室、深夜自律室)
│   ├── 虚拟座位表渲染 (座位网格、同桌学员头像、当前专注时长展示)
│   ├── 番茄钟与沉浸白噪音 (雨声、咖啡馆、壁炉、林间，支持音频混音)
│   └── 离座与挂机检测 (超过 5 分钟无学习行为自动释出座位，转为离线)
├── 2. 排行榜与榜单激励 (Leaderboards)
│   ├── 榜单维度 (日榜、周榜、月度总榜、好友榜)
│   ├── 榜单结算与段位升降级 (每周一凌晨结算，前 10 名晋升更高星区)
│   └── 隐私保护机制 (允许用户开启“排行榜匿名显示”或“完全隐藏”)
└── 3. 学习小组与班级挑战 (Study Groups & Teams)
    ├── 小组创建与加入 (3~10人微型小组，设定共同目标：如全员 21 天不打烊)
    ├── 小组里程碑资金池/星币奖池 (全员达标平分星币奖励)
    └── 预置快捷打气与点赞 (轻量互动，0 文本输入风险)
```

## 3. 详细交互流程 (UX Flow)

### 3.1 自习室入座与专注交互
1. **进入自习室**：用户在“发现/社群”页选择“晨读专注室 (20人/房)”。
2. **选择空座**：点击空位“立即入座”，系统分配 Seat 号，本地开启番茄钟（默认 25 分钟）。
3. **沉浸学习界面**：
   - 界面切换为深色极简模式，中间显示大号番茄钟倒计时，背景播放白噪音；
   - 底部以小气泡展示同桌状态（如“广州的 @Lily 刚背完了 20 个单词”）；
4. **结伴鼓励**：
   - 用户可点击同桌头像，弹出 3 个预设鼓励气泡：“✨ 保持专注！”、“🔥 一起上岸！”、“👏 太强了！”；
   - 被鼓励者收到静默动效浮层，不中断当前做题。

## 4. 数据实体与核心字段设计 (Data Schema)

### 4.1 自习室房间表 (soc_study_room)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | PK, 自增 | 自习室 ID |
| room_name | VARCHAR(64) | 非空 | 房间名称 (如 'CET4 晨光突击室') |
| category | VARCHAR(32) | 非空 | 分类：'CET4', 'CET6', 'KAOYAN', 'IELTS', 'QUIET' |
| max_seats | INT | 非空, 默认 30 | 最大容纳座位数 |
| current_online_count| INT | 非空, 默认 0 | 当前在线入座人数 |
| background_audio | VARCHAR(255) | 可空 | 默认白噪音 OSS 音频 |
| is_active | TINYINT | 非空, 默认 1 | 是否开放 |

### 4.2 自习室在座状态表 (soc_room_seat_presence)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | PK, 自增 | 主键 |
| room_id | BIGINT UNSIGNED | FK, 非空 | 关联房间 ID |
| user_id | BIGINT UNSIGNED | FK, 非空 | 关联用户 ID |
| seat_index | INT | 非空 | 座位序号 (1-30) |
| focus_content | VARCHAR(64) | 非空 | 当前学习标签 (如 '正在背核心词汇') |
| seated_at | DATETIME | 非空 | 入座时间 |
| last_heartbeat_at| DATETIME | 非空 | 最近心跳时间 (Redis 辅助 15s 维持，超时踢出) |

## 5. 接口契约规范 (API Contracts)

- `GET  /api/v1/social/rooms`：获取当前开放的自习室列表及在座人数。
- `POST /api/v1/social/room/enter`：加入自习室并分配空座。
- `POST /api/v1/social/room/heartbeat`：自习室在座心跳（维持在线与同步专注时长）。
- `POST /api/v1/social/room/leave`：离开自习室并释出座位。
- `POST /api/v1/social/room/cheer`：向指定同桌发送预设鼓励气泡。
- `GET  /api/v1/social/leaderboard/{type}`：拉取指定榜单（日榜/周榜/好友榜）。
