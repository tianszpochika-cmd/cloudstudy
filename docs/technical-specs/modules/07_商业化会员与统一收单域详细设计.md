# 07｜商业化会员与统一收单域详细设计 (Commerce & VIP Subscription Domain)

> **设计基线**：PRD v3.3 第 34、35、39 章  
> **所属业务域**：com.englishflow.modules.commerce  
> **目标服务承载**：`commerce-service`；外部请求经 `api-gateway`，订单、权益、退款和对账由本服务拥有。  
> **迁移兼容**：`services/core-api`，仅作为 v1 兼容承载。  
> **面向端**：apps/learner-web (Vue 3 + Vite), apps/mobile (Vue 3 + uni-app)

---

## 1. 业务目标与阶段边界

本域负责语学星全端多渠道收单、会员权益鉴权与订阅状态机流转。

- **Phase 1 (多渠道合规收单)**：
  - 支持 **微信支付 (Native/JSAPI/H5/App)** 与 **支付宝 (App/网页)**。
  - 支持 **iOS 原生 Apple In-App Purchase (IAP)** 订阅与 App Store Server Notifications v2 服务端票据校验。
  - 核心权益梯度：**免费基础版 (Free)**、**连续包月/季/年 VIP (Pro)**、**家庭多端畅享卡 (Household)**。
  - 严格的权益网关防越权拦截与订单幂等防刷。
- **Phase 2 (AI 算力与高阶权益包)**：
  - 引入“AI 算力能量包”与专属雅思/托福名师私教诊断权益加购。
- **Phase 3 (K12 校园包与多子女绑定)**：
  - 支持家庭组 1 个主账号绑定 2~3 个子女独立学习档案。

## 2. 完整功能树与子功能矩阵

```text
商业化会员与统一收单域 (Commerce & Subscription)
├── 1. 商品与权益矩阵 (SKU & Entitlements)
│   ├── 会员 SKU 管理 (连续包月 ¥28/月、季卡 ¥68、年度畅学卡 ¥198、终身卡)
│   ├── 权益细粒度网关 (无限次长难句 X 光机、高阶考研/四六级真题库、3D 口腔全开、去广告)
│   └── 促销与优惠券 (新客首月 ¥9.9 特惠、满减券、老带新拼团)
├── 2. 统一收单聚合收银台 (Cashier & Payment Gateway)
│   ├── 微信支付适配器 (WeChat Pay V3 - 下单、验签、回调通知、主动查单)
│   ├── 支付宝适配器 (Alipay SDK - 唤起收银台、RSA2 验签、异步通知)
│   └── Apple IAP 深度接入 (StoreKit 2 事务流、JWS 验签、丢单被动补单机制)
├── 3. 订单与订阅状态机 (Order & Subscription State Machine)
│   ├── 订单全生命周期 (Created -> Paid -> Fulfilled -> Refunded / Closed)
│   ├── 自动续费与扣费宽限期 (Active -> InGracePeriod -> Expired -> Cancelled)
│   └── 订单防重复支付与分布式锁拦截
└── 4. 履约发票与售后 (Invoicing & Refund)
    ├── 会员权益秒级原子发放与 Redis 缓存同步
    └── 电子发票开具申请与合规退款审批流
```

## 3. 详细交互流程 (UX Flow)

### 3.1 Apple IAP 购买与防丢单履约流程
```text
[iOS 客户端点击购买 VIP] ──► 调用 uni.requestPayment / StoreKit 2
    │
    ▼
[Apple 弹窗指纹/FaceID 扣费成功]
    │
    ▼
[客户端获取 Signed Transaction JWS] ──► 立即提交至 /api/v1/commerce/iap/verify
    │
    ▼
[服务端双重校验]
    ├── 1. 解密 JWS 校验 Bundle ID, Product ID, Transaction ID (防伪造)
    ├── 2. 查询 pay_order 是否已存在相同 transaction_id (防重放攻击)
    └── 3. 向 Apple 官方验证接口二次背靠背确认
    │
    ▼
[原子写入订单并开通权益] ──► 更新 usr_user_vip 表，刷新 Redis 缓存
    │
    ▼
[返回客户端成功状态] ──► 触发烟花全屏庆祝弹窗，立即解锁所有 VIP 专属关卡
```

## 4. 数据实体与核心字段设计 (Data Schema)

### 4.1 支付订单表 (pay_order)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | PK, 自增 | 订单 ID |
| order_no | VARCHAR(64) | UK, 非空 | 平台唯一订单号 (如 'ORD20260820XXXX') |
| user_id | BIGINT UNSIGNED | FK, 非空 | 下单用户 ID |
| sku_id | VARCHAR(64) | 非空 | 商品 SKU 编码 |
| pay_channel | VARCHAR(20) | 非空 | 支付渠道：'WECHAT', 'ALIPAY', 'APPLE_IAP' |
| original_amount | DECIMAL(10, 2) | 非空 | 原价金额 (元) |
| pay_amount | DECIMAL(10, 2) | 非空 | 实际支付金额 (元) |
| order_status | VARCHAR(20) | 非空, 默认 'PENDING' | 'PENDING', 'PAID', 'CLOSED', 'REFUNDED' |
| channel_trade_no | VARCHAR(128) | 可空 | 第三方交易流水号 |
| paid_at | DATETIME | 可空 | 支付完成时间 |
| created_at | DATETIME | 非空 | 下单时间 |

### 4.2 用户 VIP 权益主表 (usr_user_vip)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |

| last_order_no | VARCHAR(64) | 可空 | 最近续费订单号 |
| updated_at | DATETIME | 非空 | 更新时间 |

## 5. 接口契约规范 (API Contracts)

- `GET  /api/v1/commerce/products`：获取当前生效的 VIP 会员价格与促销列表。
- `POST /api/v1/commerce/order/create`：创建收单订单（返回微信/支付宝调起支付参数）。
- `POST /api/v1/commerce/iap/verify`：iOS Apple IAP 票据服务端验证与履约。
- `POST /api/v1/commerce/callback/{channel}`：第三方支付渠道异步 Webhook 回调通知。
- `GET  /api/v1/commerce/vip/status`：获取当前用户的 VIP 权益详情与到期倒计时。
