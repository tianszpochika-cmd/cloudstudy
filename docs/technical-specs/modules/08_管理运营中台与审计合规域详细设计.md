# 08｜管理运营中台与审计合规域详细设计 (Admin, Operations & Compliance Domain)

> **设计基线**：PRD v3.3 第 35、37、39 章  
> **所属业务域**：com.englishflow.modules.admin  
> **目标服务承载**：`admin-ops-service` + 各领域服务；外部请求经 `api-gateway`，IAM/RBAC 和高风险审计由服务端执行。  
> **迁移兼容**：`services/core-api`，仅作为 v1 兼容承载。  
> **面向端**：apps/admin-web (教研运营后台)

---

## 1. 业务目标与阶段边界

本域为语学星的运营、教研、风控合规团队提供一站式中台支撑。

- **Phase 1 (教研与合规基础中台)**：
  - 教研资产录入流：可视化词汇编辑、语法树节点管理、题库录入与多媒体资产管理。
  - 双审合规流 (Two-Tier Review Workflow)：初审 (Reviewer) -> 终审 (Approver) -> 发布上线。
  - 用户与风控管理：用户档案检索、违规封禁、注销数据脱敏。
  - 核心业务看板：日活 (DAU)、付费转化率、各关卡平均完成率与留存漏斗。
- **Phase 2 (AI 评测监控与题库辅助扩充)**：
  - AI 判分质量抽检看板、提示词 Prompt 灰度发布中台。
- **Phase 3 (教材版本映射与未成年人防沉迷监管)**：
  - K12 教材课文与考试真题版权审核档案、未成年人监护人申诉工单处理。

## 2. 完整功能树与子功能矩阵

```text
管理运营中台与审计合规域 (Admin & Governance)
├── 1. 教研资产内容管理系统 (Curriculum CMS)
│   ├── 词汇与例句编辑器 (支持音标输入法、音视频 OSS 关联、3D 嘴型关键帧绑定)
│   ├── 语法知识树编排器 (拖拽式调整层级、语法点富文本 Markdown 编辑)
│   ├── 题库管理中台 (批量题目导入 Excel/JSON、题目预览、查重去重)
│   └── 试卷组卷向导 (按 CEFR 难度分布、题型比例自动/手动组卷)
├── 2. 双审内容合规流 (Content Safety & Dual Approval)
│   ├── 敏感词与涉政涉暴文本机器初筛 (前置敏感词库正则比对)
│   ├── 人工双审工单流 (教研初审提交 -> 审核主管终审签发)
│   └── 线上内容一键紧急下架与回滚
├── 3. 用户与风控中心 (User CRM & Risk Control)
│   ├── 学员全景画像看板 (学习总时长、VIP 到期日、错题堆积量、登录设备列表)
│   ├── 作弊与异常监控 (刷 XP/脚本批量提交异常封号、设备黑名单)
│   └── 账号注销审核 (个人隐私数据按国家合规规范完全脱敏)
└── 4. 运营与数据大盘 (Analytics Dashboard)
    ├── 核心指标总览 (DAU/MAU、次日/7日留存率、今日新增注册、付费 GMV)
    ├── 学习流漏斗分析 (从 Onboarding -> 第1课 -> 达成每日目标各环节转化)
    └── 财务与对账中心 (微信/支付宝/Apple IAP 统一对账单下载)
```

## 3. 详细交互流程 (UX Flow)

### 3.1 教研内容双审发布流程
```text
[教研员录入 20 道长难句题目] ──► 点击“提交审核” ──► 状态: IN_REVIEW
    │
    ▼
[教研组长待办工作台接收任务]
    │
    ├── 驳回：填写驳回原因（如：“第 3 题中文释义不精准”）──► 状态打回: REJECTED (退回修改)
    │
    └── 审批通过 ──► 状态: APPROVED
                       │
                       ▼
             [发布至生产环境] ──► 状态: PUBLISHED ──► 同步刷新全网 CDN 缓存
```

## 4. 数据实体与核心字段设计 (Data Schema)

### 4.1 管理员账户与角色表 (adm_manager_user)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | PK, 自增 | 管理员 ID |
| username | VARCHAR(50) | UK, 非空 | 登录账号 |
| password_hash | VARCHAR(255) | 非空 | 加密密码 |
| real_name | VARCHAR(50) | 非空 | 真实姓名 |
| role_code | VARCHAR(32) | 非空 | 角色：'SUPER_ADMIN', 'CURRICULUM_EDITOR', 'AUDITOR', 'OPERATOR' |
| is_active | TINYINT | 非空, 默认 1 | 是否启用 |
| created_at | DATETIME | 非空 | 创建时间 |

### 4.2 内容审核工单表 (adm_content_audit_log)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | PK, 自增 | 工单 ID |
| content_type | VARCHAR(32) | 非空 | 审核对象：'VOCAB', 'GRAMMAR', 'QUESTION', 'PAPER' |
| content_id | BIGINT UNSIGNED | 非空 | 目标内容 ID |
| submitter_id | BIGINT UNSIGNED | FK, 非空 | 提交审核人 ID |
| auditor_id | BIGINT UNSIGNED | FK, 可空 | 审批人 ID |
| audit_status | VARCHAR(20) | 非空, 默认 'PENDING' | 'PENDING', 'APPROVED', 'REJECTED' |
| reject_reason | VARCHAR(255) | 可空 | 驳回原因说明 |
| created_at | DATETIME | 非空 | 提交时间 |
| audited_at | DATETIME | 可空 | 审核完成时间 |

## 5. 接口契约规范 (API Contracts)

- `POST /api/v1/admin/auth/login`：管理员账号密码登录与获取管理后台 JWT。
- `GET  /api/v1/admin/content/questions`：分页检索题目列表（支持按题型、难度、状态筛选）。
- `POST /api/v1/admin/content/question/save`：创建或更新题目内容。
- `POST /api/v1/admin/content/audit/action`：执行审核通过或驳回操作。
- `GET  /api/v1/admin/dashboard/overview`：获取运营大盘实时统计核心指标数据。
- `POST /api/v1/admin/user/ban`：封禁违规用户。
