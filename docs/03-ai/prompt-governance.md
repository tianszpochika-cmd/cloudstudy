# 提示词治理

## 版本结构

每个提示词至少记录：

- prompt_id 与 semver 版本。
- 适用任务、模型和语言。
- 输入 schema、输出 schema 和示例。
- 安全边界、禁止事项和降级策略。
- 评测集版本、上线人和变更原因。

## 运行时要求

- 生产请求携带 prompt version 和 experiment id。
- 提示词与业务代码分离，支持回滚。
- 不把用户原始隐私直接拼接进系统提示词。
- 对长上下文设置预算，优先传递当前目标、错误和必要历史。

## 变更流程

草稿 -> 离线评测 -> 小流量 -> 线上指标观察 -> 发布或回滚。

## 禁止事项

- 让模型自行改变课程目标或用户等级。
- 让模型输出未经验证的医疗、法律、财务或职业承诺。
- 把模型输出直接当作支付、封禁或升降级的唯一依据。
