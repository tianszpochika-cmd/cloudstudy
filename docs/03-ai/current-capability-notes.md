# 当前 AI 能力落地笔记

基线日期：2026-08-19。这里记录架构假设，不把任何单一供应商或模型名称写死。

## 可以直接利用的能力形态

1. 结构化文本输出：让反馈、评分证据、改写和复习项符合 JSON Schema，再由应用渲染。
2. 流式文本：在反馈较长时先展示可用字段，减少等待感。
3. 实时语音：把语音角色扮演做成独立会话服务，支持低延迟音频、转写、打断和工具/上下文控制。
4. 评测与数据集：用固定样例、规则评分、人工抽检和线上回归持续比较提示词与模型版本。
5. 多供应商适配：文本、转写、语音生成和实时会话可以来自不同 provider，业务层只依赖内部接口。

## 对本项目的取舍

- P0：结构化文字反馈 + 复习推荐 + mock provider。
- P1：实时语音角色扮演；客户端实时链路和服务器编排链路分开。
- P1：把真实错误沉淀为脱敏评测集，而不是只看平均满意度。
- P2：再考虑个性化声音、离线语音和更复杂的多模态教具。

## 不能忽略的限制

- 结构化输出不等于内容正确，仍需 schema 校验、规则检查和教研抽检。
- 实时语音成本、并发、网络、权限和跨端音频兼容性必须单独压测。
- 模型、价格、地区可用性和供应商条款会变化，所有配置要可切换。
- 面向中国大陆公众提供 AI 生成文本、音频等功能时，要把内容安全、投诉、数据处理、备案/平台要求和 AI 标识纳入上线闸门。
