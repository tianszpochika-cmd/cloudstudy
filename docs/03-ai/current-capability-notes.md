# AI 能力状态说明

> 基线日期：2026-08-20。Phase 1 不启用任何生成式 AI、AI 发音评分、AI 实时陪练或 AI 数字人。本文件只定义 Phase 2 启动后的能力边界。

## Phase 1

- 使用规则化测评、SRS、错题统计、内容推荐和学习报告。
- 不调用 LLM、ASR 评分、TTS 对话或实时 AI 服务。
- 前端不展示尚未启用的 AI 入口，不把 mock 结果包装成 AI 功能。

## Phase 2 可启用能力

1. 结构化文字反馈：输出必须符合 JSON Schema。
2. 课程上下文约束的文字角色练习。
3. 发音评测、作文批改、长难句分析和 RAG。
4. 商业 RTC 实时语音与数字人。
5. 多供应商适配、成本限额、评测集和人工抽检。

## 必要闸门

- Python FastAPI AI 编排服务、Pydantic Schema、prompt_version 和失败降级就绪。
- 内容安全、投诉处理、AI 标识、数据处理和适用备案/平台要求完成复核。
- 每项能力有离线评测、线上灰度、成本预算和一键关闭开关。
- 客户端永不持有模型供应商密钥。

## 禁止事项

- 在 Phase 1 需求、UI、营销或验收中将 AI 能力列为已交付。
- 将模型判断直接作为付费、封禁、等级或其他用户权益的唯一依据。
- 在没有授权和审核的情况下批量发布 AI 生成学习内容。
