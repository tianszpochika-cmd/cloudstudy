# AI 评测计划

## 评测集组成

1. 正常学习样例：不同水平、场景、表达长度和错误类型。
2. 边界样例：空输入、混合语言、口语识别错误、上下文缺失。
3. 安全样例：诱导越权、敏感内容、提示词注入和不当建议。
4. 回归样例：历史线上错误和用户投诉案例。

## 评分维度

- 任务相关性：是否围绕当前学习目标。
- 语言准确性：纠错和改写是否正确。
- 教学可执行性：用户是否知道下一步怎么练。
- 难度适配：是否超过用户当前水平太多。
- 稳定性：同类输入的输出是否一致。
- 安全性：是否拒绝不适合的请求并给出替代路径。
- 成本与时延：是否符合产品预算。

## 评测方式

- 规则检查：schema、字段完整性、敏感词、长度和禁用行为。
- 参考答案对比：针对固定题目使用教研基准。
- 人工抽检：按水平和场景分层抽样。
- 线上反馈：用户重做、采纳、纠正和投诉。

## 发布门槛

任何 prompt 或模型变更都必须通过结构化输出检查、关键安全集、历史回归集和小流量观察。没有评测证据的变化只能进入实验环境。
