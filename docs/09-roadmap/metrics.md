# 指标与口径

> **文档分类：当前执行指标口径**。Phase 1 指标只衡量 18+ 成人的规则化学习闭环；Phase 2 AI 指标必须在单独的阶段开关和版本范围下统计，不能把 AI 能力写入 Phase 1 完成条件。

## 北极星指标

完成目标场景产出并在复习中再次正确调用的活跃学习者数。

## 漏斗

访问 -> 注册 -> 完成测评 -> 完成首课 -> 完成首次规则化练习 -> 完成首次复习 -> 七日留存 -> 付费/续费。

## 质量指标

- 反馈后重做率。
- 重做后的错误减少率。
- 复习到期完成率。
- 规则反馈采纳/纠正率。
- 内容投诉和下线率。
- 每位活跃用户的媒体与基础设施成本。

Phase 2 启用后，另行增加 AI 反馈采纳/纠正率、模型成本和语音分钟成本，并标注 `phase`、`prompt_version` 与模型版本；这些指标不回写 Phase 1。

所有指标必须写明事件来源、过滤条件、时间窗口和版本范围。
