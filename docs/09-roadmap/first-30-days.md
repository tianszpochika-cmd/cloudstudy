# 首 30 天执行清单（Historical / Superseded）

> **文档分类：Historical / Superseded（v1 首 30 天计划快照）**。下方周计划和“初始化/上线/实现”等动作只记录当时的计划，不得直接作为当前开发命令或完成证据。当前执行见 [`roadmap.md`](./roadmap.md)、[`../../requirements/mvp-scope.md`](../../requirements/mvp-scope.md) 和 [`../../requirements/backlog/README.md`](../../requirements/backlog/README.md)；其中 9A 冻结的四项目、930+50、184/486/310、游戏、SRS、音频、支付和内容口径优先。
> 原 v1 计划目标是验证 18+ 成人 Phase 1 规则化学习闭环；它不改变当前 v2 Platform 0 / Phase 1 的任务拆分和 Gate。

## 第 1 周：冻结基线

- 确认 PRD、MVP、用户故事和验收标准为唯一需求源。
- 锁定首发目标：成人零基础、日常交流、CET-4 或 CET-6 中的两个方向。
- 确定首发词书、题目、音频和阅读素材的来源、版权和审核责任人。
- 完成首日路径、背词、复习、练习和报告的高保真稿确认。
- 定义 OpenAPI、MySQL 核心实体、事件字典和隐私最小化规则。

## 第 2 周：可运行骨架

- 初始化四个前端项目、Java 25 服务模板、`api-gateway`、提供账号密码登录和自有 JWT/JWKS 的 `iam-service`、MySQL/Redis 本地环境；旧 `core-api` 只作为兼容入口。
- 跑通账号、目标选择、非 AI 测评、今日任务、词汇学习和练习提交。
- 接入 Flyway 迁移、OpenAPI 生成、内容种子和基础鉴权。
- 用合成数据完成：选目标 -> 背词 -> 提交 -> 复习入队 -> 报告。

## 第 3 周：内容与复习闭环

- 上线首发词书、10-20 个语法点、首批阅读/听力/句子练习。
- 实现 SRS、错题队列、今日任务、打卡、阶段报告和基础排行榜。
- 建立内容后台草稿 -> 审核 -> 发布 -> 下线流程。
- 接入设计令牌和四级性能开关，优先保证 Performance 档可用。

## 第 4 周：封闭试学

- 邀请 20-50 名 18+ 用户进行 7 天试学。
- 观察激活、首课完成、复习完成、连续学习、错误率和中断点。
- 修复影响学习闭环、内容质量、隐私和性能的问题。
- 根据数据决定 Phase 1 P1 内容与 iOS/Android 上架节奏；不提前启动 AI 功能。
