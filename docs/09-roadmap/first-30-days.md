# 首 30 天执行清单

> 面向第一阶段目标：标准语言学习 App（无 AI 依赖、完全商用），Web + H5 先行。

## 第 1 周：定方向

- 访谈 5–10 名目标用户（四六级考生 + 日常提升人群）。
- 确定首发词书（四级核心词汇）与首发考试目标，敲定语料来源与版权合规清单。
- 完成背词流程、考试页、排行榜的线框与视觉基调（“完善美丽”标准）。
- 确认数据字段、事件字典与隐私最小化原则。

## 第 2 周：跑通骨架

- 初始化 uni-app 学习端、Spring Boot core-api、MySQL/Redis 本地容器。
- 建立登录、学习目标选择、背词流程、练习提交和学习记录。
- 定义内容 schema 与 OpenAPI 契约（packages/contracts），生成 Java DTO 与 TS 类型。
- 用合成数据跑通首日路径：选目标 -> 背词 -> 练习 -> 复习入队。

## 第 3 周：做真实闭环

- 完成首发词书（四级核心词汇）的完整数据与音频。
- 上线语法卡片（10–20 个语法点）与句子拆分练习首批内容。
- 接入记忆引擎复习队列（SuperMemo-2）、今日任务与打卡。
- 落地设计令牌、插画风格与四级画质引擎开关；搭建管理后台内容双审流。

## 第 4 周：小范围试学

- 邀请第一批 20–50 名用户完成 7 天试学（Web/H5）。
- 观察背词完成率、复习完成率、考试参与率与中断点。
- 修复最影响学习闭环与视觉体验的问题。
- 决定是否进入 8 周 MVP 试验，以及 iOS/Android 包体送审节奏。
