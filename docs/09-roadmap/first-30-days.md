# 首 30 天执行清单

> 目标：验证 18+ 成人 Phase 1 的规则化学习闭环。技术路线固定为 Vue 3 + uni-app + Spring Boot 3 + MySQL + Redis；不引入生成式 AI。

## 第 1 周：冻结基线

- 确认 PRD、MVP、用户故事和验收标准为唯一需求源。
- 锁定首发目标：成人零基础、日常交流、CET-4 或 CET-6 中的两个方向。
- 确定首发词书、题目、音频和阅读素材的来源、版权和审核责任人。
- 完成首日路径、背词、复习、练习和报告的高保真稿确认。
- 定义 OpenAPI、MySQL 核心实体、事件字典和隐私最小化规则。

## 第 2 周：可运行骨架

- 初始化 uni-app 学习端、Vue 管理后台、Spring Boot Core API、MySQL/Redis 本地环境。
- 跑通账号、目标选择、非 AI 测评、今日任务、词汇学习和练习提交。
- 接入 Flyway 迁移、OpenAPI 生成、内容种子和基础鉴权。
- 用合成数据完成：选目标 -> 背词 -> 提交 -> 复习入队 -> 报告。

## 第 3 周：内容与复习闭环

- 上线首发词书、10-20 个语法点、首批阅读/听力/句子练习。
- 实现 SRS、错题队列、今日任务、打卡、阶段报告和基础排行榜。
- 建立内容后台草稿 -> 审核 -> 发布 -> 下线流程。
- 接入设计令牌和四级性能开关，优先保证 Performance 档可用。

## 第 4 周：封闭试学

- 邀请 20-50 名 18+ 用户进行 7 天试学。
- 观察激活、首课完成、复习完成、连续学习、错误率和中断点。
- 修复影响学习闭环、内容质量、隐私和性能的问题。
- 根据数据决定 Phase 1 P1 内容与 iOS/Android 上架节奏；不提前启动 AI 功能。
