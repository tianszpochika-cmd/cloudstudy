# 首 30 天执行清单

> 面向第一阶段目标：中小学生传统型学习 App（无 LLM 依赖），Web + H5 先行。

## 第 1 周：定方向

- 访谈 5–10 名目标用户（学生 + 家长）与 1–2 名教研老师。
- 确定首发的年级段与教材版本（如小学三四年级 + 人教版 PEP）。
- 完成教材同步课、音标实验室、复习页的线框与视觉基调（"完善美丽"标准）。
- 确认数据字段、事件字典、未成年人保护与隐私最小化原则。

## 第 2 周：跑通骨架

- 初始化 uni-app 学习端、Spring Boot core-api、PostgreSQL/Redis 本地容器。
- 建立登录、年级教材选择、课节读取、练习提交和学习记录。
- 定义内容 schema 与 OpenAPI 契约（packages/contracts），生成 Java DTO 与 TS 类型。
- 用合成数据跑通首日路径：选课 -> 预习 -> 跟读 -> 自测。

## 第 3 周：做真实闭环

- 完成 2–3 个单元（10–20 课时）的教研内容与配套练习。
- 接入记忆引擎复习队列（SuperMemo-2）和基础提醒。
- 落地设计令牌、插画风格与四级画质引擎开关。
- 搭建管理后台的课程 CRUD 与内容审核状态流。

## 第 4 周：小范围试学

- 邀请第一个班级/20 名用户完成 7 天试学（Web/H5）。
- 观察课节完成率、跟录制音率、复习完成与中断点。
- 修复最影响学习闭环与视觉体验的问题。
- 决定是否进入 8 周 MVP 试验，以及 iOS/Android 包体送审节奏。
