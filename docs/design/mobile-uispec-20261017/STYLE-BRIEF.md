# 移动端全量交互 UI 稿 · STYLE-BRIEF（2026-10-17）

来源：apps/mobile/src/theme/v2-tokens.scss、docs/takeover/ui-audit-20261013/DESIGN-DIRECTION.md、已重设计的正式页面（登录 / 注册 / 找回密码 / 新手引导 / 访问权限，提交 fe6e027c…758dc0fb）。本稿只做设计原型，不改 apps/*。

## 1. 设计原则
- 简约、开放排版：按页面的真实主任务组织内容，避免框里套框、重复状态卡、装饰性图标/标签/大渐变/艺术字。
- 先主任务，再辅助出口。反馈只在真正发生操作时出现。
- 全部 UI 文案中文、简短具体；不夸大、不泄露账号是否存在、不显示内部错误码和原始版本号字符串。

## 3. 外框与导航
- 原型框 390×844，含 44px 状态栏区和自定义导航栏（返回 44×44 命中区 + 标题居中 17px/600）。
- 一级页（学习 home、练习 b2-practice、成长 world、课程 learn、我的 profile）带底部 TabBar（5 项，选中 brand，未选中 mut，图标 24px + 文字 11px，高 56 + 安全区）。
- 每页右上角（原型工具条，在手机框外）提供：浅色/深色切换、状态切换（正常 / 加载 / 空 / 错误 / 无权限等本页实际存在的状态）。

## 4. 组件规范（shared.css / shared.js 统一实现，页面只复用）
- 按钮：主按钮高 48、16px/600、brand 底 inverse 字；次按钮 surface 底 ink 字；文字按钮 brand 字。命中区≥44×44。
  - 禁用态（真实可辨）：背景 surface、文字 mut、无阴影、cursor:not-allowed，不能只靠降低透明度。
  - 提交中：按钮内 16px 转圈 + 文案「正在登录…」类，按钮保持宽度、不可重复点击。
- 输入框：高 48、圆角 12、1px line 边框；聚焦 brand 边框 + 焦点环；错误 bad 边框 + 字段下方 13px bad 色错误文案（逐字段报错，首个错误自动聚焦）；密码眼睛图标 19px，命中区 44。
- 列表行 / 卡片 / chip / 分段控件 / 进度条 / 头像 / 徽标 / 开关 / 底部弹层（ActionSheet，带拖拽条，遮罩可点关闭）/ 对话框（标题+说明+最多两个按钮，危险操作 bad 色）/ Toast（顶部居中，2s 自动消失，成功/错误/普通三种）/ 骨架屏。
- 图标：统一线性 24px 描边 1.75，使用内联 SVG，在 shared.js 中提供图标集合。

## 5. 状态规范（每页必须覆盖本页存在的全部状态）
- 加载：骨架屏（首屏）或局部转圈（操作内），不出现「等待登录」类静态状态框。
- 空：一句说明 + 一个可执行动作（如「还没有错题」+「去练习」），不放大插画。
- 错误：一句中文原因 + 「重试」；网络错误、服务不可用分别说清楚。
- 无权限 / 功能未开放：明确中文原因 + 下一步（如「该功能需开通学习权益」+「查看权益」）。
- 成功：Toast 或行内确认，必要时页面跳转。

## 6. 文案规则
- 全站统一用「忘记密码？」作为找回入口（带全角问号），放在密码字段右下；找回页标题统一「找回密码」。
- 登录/注册互相切换放在主动作之后：「还没有账号？注册」/「已有账号？登录」。
- 不显示 v2.x.x、build 号、错误码等原始字符串；版本信息只在「设置 › 关于」以「当前版本 2.0」这类人话出现。
- 数字与单位之间留空格的规则同中文排版习惯；英文专有名词（Language Clips、Avatar）保留。

## 7. 深色模式
- 每个组件、每种状态都必须在深色下复验：文字对比 ≥4.5:1，边框可见，图片/插画不出现白底块，阴影改为更深更淡。

## 8. 交付契约
- 每页一个 `pages/<route-id>.html`（route-id 见 PAGES.md），只引用 `../shared.css` 与 `../shared.js`，使用 mock 数据，所有交互可点击：点击、跳转（链接到对应原型页）、弹层、对话框、Toast、表单校验、加载/空/错误态切换。
- 每页末尾（手机框外）放「交互说明」区块，并同步追加到 INTERACTIONS.md：列出每个交互 → 触发 → 状态变化 → 反馈。
- `gallery.html`：组件总览，所有组件与状态，浅深色均可切换。
- 自检：用 Playwright 在 390×844 下截浅色与深色两张图，存 `shots/<route-id>-light.png`、`shots/<route-id>-dark.png`，确认无溢出、无白底块、文字可读。
