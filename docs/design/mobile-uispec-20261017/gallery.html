交互说明（gallery）

  • 主题切换 → 顶部工具条「浅色 / 深色」 → html[data-theme] 切换，写入 localStorage['uispec-theme']，并响应 ?theme=dark。
  • 按钮提交中 → 点击「主按钮」 → 按钮保持宽度、显示 16px 转圈与「正在登录…」、禁用重复点击，1.5s 后恢复并弹出成功 Toast。
  • 表单校验 → 点击「提交」 → 逐字段标红并显示中文错误，焦点落到首个错误；输入后该字段错误自动清除。
  • 密码可见 → 点击眼睛图标 → 切换 type=password/text，图标与 aria-label 同步。
  • chip / 分段 → 点击 → 同组单选互斥或多选切换，反馈为选中态变化（uispec:toggle）。
  • 开关 → 点击或空格/回车 → aria-checked 切换；禁用开关不可操作。
  • 底部弹层 → 点击「打开底部弹层」 → 遮罩淡入、面板上滑；点击遮罩/取消/Esc 关闭；选择项关闭并 Toast。
  • 对话框 → 点击「打开对话框」或「危险操作」 → 居中弹入，两个按钮；危险按钮使用 bad 色，确认后关闭并 Toast。
  • Toast → 点击任意 Toast 按钮 → 顶部居中显示 2s，成功/错误/普通三种图标与颜色。
  • 重试 → 点击「重试」 → 状态块内切换加载占位，1.2s 后恢复并 Toast。
