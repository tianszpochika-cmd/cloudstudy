交互说明（b4-offline）

  • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?theme=light|dark 固定主题；?state=normal|loading|empty|error|forbidden|offline 直达页面状态；?mock=packages|no-queue|sync-rejected|sync-error|partial|authorize-error|download-error|cleanup-error 演示内容包管理、同步与失败分支。截图（每项 ?theme=light|dark 各一张）：b4-offline-{light,dark}.png；b4-offline-{loading,empty,error,forbidden,offline}-{light,dark}.png；b4-offline-{packages,no-queue,sync-rejected,sync-error,partial,authorize-error,download-error,cleanup-error}-{light,dark}.png。
  • 页面状态 → 工具条「正常 / 加载 / 空 / 错误 / 无权限 / 离线」，文案对齐 B4StatusPanel 与 stores/b4.ts 的 loadWorld / fail：加载为「网络可用 · 正在加载成长记录」+ 两张卡骨架屏（aria-busy）；空为「暂无可用的离线内容。」+「回到可用学习」→ today.html（设计新增，需同步实现：真实页没有整页空态，只在内容包卡内显示「即将开放」说明）；错误为「网络可用 · 学习同步状态 / 学习世界暂时无法读取。」+「重试」；无权限为「网络可用 · 学习同步状态 / 当前没有读取学习世界的权限。」+ 单个「去登录」→ login.html?returnTo=%2Fpages%2Fb4-offline%2Fb4-offline；离线为「网络不可用 · 学习同步状态 / 学习世界暂时无法读取。」+「重试」，有队列时同时显示「待同步 N」与「同步」。
  • 状态恢复 → 错误与离线「重试」转圈「正在重试…」→ 1.1s 后回到正常态，不弹成功 Toast；空态只保留「回到可用学习」；无权限只保留「去登录」。切换离开正常态会关闭画质与清理确认、取消未完成的授权 / 下载 / 清理 / 同步计时并恢复按钮；切回正常态保留已选画质、内容包与待同步记录。
  • 页头与导航 → 导航栏「离线包」（pages.json 标题）+ 返回 world.html（backMobile：返回上一页，无历史时回 home.html），右上角设置 → settings.html；页内 kicker「随身学」（ZH_KICKERS）、标题「把学习，带在身边。」、说明「管理离线内容与待同步记录，联网后继续前进。」（pages.b4-offline）；不显示底部 TabBar。
  • 状态条 → 等价 B4StatusPanel：标题「网络可用 · 学习同步状态」；无自定义说明时，队列为空显示「成长记录会随学习进度更新。」，有队列显示「本机有 N 条待同步记录，联网后可继续同步。」；状态为 error / offline 时边框转 bad 色并出现「重试」；有队列时显示 warn 徽标「待同步 N」与「同步」；右侧画质 chip 恒显示当前档位。
  • 同步 → 状态条「同步」或卡内「立即同步」转圈「正在同步…」，记录先标记为「同步中」→ 0.9s 后队列清空，说明「服务端已接受 N 条事件。」，不弹 Toast；?mock=sync-rejected 以 2 条队列打开，说明「服务端未接受事件，队列已保留。」，点击同步仍被拒绝且记录转为「同步失败」；?mock=sync-error 打开即显示「待同步事件提交失败，队列仍保留。」，状态条为错误变体。
  • 内容包（默认）→ 对齐真实页：离线包接口尚未上线时列表为空，卡内显示虚线说明「离线内容包 即将开放」+「离线下载服务尚未上线，目前学习内容需联网读取。」，右侧显示「在线 / 离线」，不虚构已下载内容。
  • 内容包（?mock=packages）→ 显示四行状态：可获取（请求授权）、下载中（暂停 / 清理）、已暂停（继续 / 清理）、可离线使用（无操作）；每行显示名称、「大小 · 已完成 / 总部分 部分」与中文状态徽标，状态徽标同时带文字，不只靠颜色区分。
  • 请求授权 → 「请求授权」转圈「正在授权…」→ 0.8s 后状态变「已授权」、出现「暂停 / 清理」，说明「离线包授权已由服务端确认；资源下载仍需真实清单和校验。」（stores/b4.ts 原文），不显示为已下载；?mock=authorize-error 说明「离线包授权失败，未显示为已下载。」且状态条转错误变体，不虚构授权结果。
  • 暂停 / 继续 → 转圈「正在暂停…」/「正在继续…」→ 0.8s 后状态徽标与按钮切换为「已暂停」/「下载中」，说明「离线包下载状态已由服务端确认。」；?mock=download-error 说明「离线包下载状态更新失败，未在本地标记为成功。」并保留原状态。
  • 清理 → 「清理」打开危险确认框「清理本机分片？」，说明「只清理本机临时分片；之后需要重新获取，才能离线使用这个内容包。」；取消关闭；「清理」转圈「正在清理…」→ 0.8s 后状态变「已清理」、进度归零，说明「离线包临时分片已由服务端确认清理。」；已清理行显示「重新获取」（设计新增，需同步实现：真实页清理后仍显示「清理」，会留下无效按钮）；?mock=cleanup-error 说明「离线包清理失败，未在本地删除未确认资源。」，内容包保持原状。
  • 待同步列表 → 卡内每行显示「自习室互动」与中文状态徽标（待同步 / 同步中 / 同步失败），失败行追加服务端返回的中文原因，如「服务端未接受该事件。」；无记录时显示「没有待同步操作。」，右侧仍显示「N 条」且「立即同步」隐藏；有记录时底部显示主按钮「立即同步」。不显示事件编号、账号标识或原始事件类型。
  • 画质 → 状态条右侧 chip（aria-label="画质：舒适"）打开底部弹层「画质」，四档「精致 / 舒适 / 轻量 / 省资源」（B4_PERFORMANCE_LEVELS），当前档带 brand 对勾与 aria-pressed；选择后更新 chip 文案并关闭弹层，焦点回到画质按钮；遮罩、取消与 Esc 均可关闭。画质只影响本机显示。
  • 登录门禁 → 对齐真实页 onShow：先 session.restore()，未登录直接跳转登录页，不渲染离线页；原型以无权限态承载该分支，登录页回跳地址为 /pages/b4-offline/b4-offline。
  • 文案边界 → 不显示 packageId、downloadId、sha256、签名、内部错误码或原始状态枚举；离线能力未上线时明确写「即将开放」，不把授权或部分下载说成可离线使用；同步失败只描述中文原因，不在本地伪造已同步。
