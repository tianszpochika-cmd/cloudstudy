交互说明（register）

  • 主题切换 → 工具条「浅色 / 深色」 → 整页 token 切换并记住选择。
  • 状态切换 → 工具条「正常 / 加载 / 错误 / 离线」 → 只显示该状态：正常为注册表单，加载为入口骨架屏，错误为注册服务不可用，离线为网络不可用。
  • 状态「加载」 → 品牌行与表单位显示骨架屏，页面标记 aria-busy，不出现「等待注册」类静态框。
  • 状态「错误」重试 → 点击「重试」 → 按钮转圈并变「正在重试…」→ 1.1s 后回到正常态并 Toast「注册服务已恢复」；「去登录」跳转 login.html。
  • 状态「离线」重新连接 → 点击「重新连接」 → 按钮转圈「正在重新连接…」→ 1.1s 后回到正常态并 Toast「网络连接已恢复」。
  • 字段输入 → 聚焦时 brand 边框 + soft 焦点环；首次提交后，输入时仅在本字段已合法时清除该字段错误，错误行保留高度（visibility:hidden）不引起布局跳动；表单级错误在输入时清除。
  • 失焦校验 → 首次提交后，字段失焦时按当前值重新校验并显示当前错误；密码失焦时若确认密码已填，同步复核「两次输入的密码不一致。」。
  • 提交校验 → 点击「创建账号」或按回车 → 逐字段标红并聚焦首个错误：账号为空「请输入账号。」、长度不在 3–128 位（含少于 3 位与超过 128 位）「账号长度需为 3 至 128 位。」；密码为空「请输入密码。」、少于 12 位「密码至少 12 位。」、超过 128 位「密码最多 128 位。」；确认密码为空「请再输入一次密码。」、不一致「两次输入的密码不一致。」。
  • 密码可见 → 点击两个眼睛按钮 → 分别切换密码 / 确认密码的明文与密文，图标与 aria-label（显示密码 / 隐藏密码、显示确认密码 / 隐藏确认密码）同步；提交中不可切换。
  • 登录 → 点击底部「登录」 → 跳转 login.html；提交中链接置灰不可点。真实页会把当前 returnTo 带在登录链接上；原型链接保持 login.html。
  • 提交中 → 校验通过后 → 按钮保持宽度、显示 16px 转圈与「正在创建账号…」，三个字段 / 眼睛 / 登录链接全部不可操作，防止重复提交。
  • 注册失败（Mock） → 账号填 exists@yuxuexing.com → 1.4s 后表单内 bad 色提示「注册没有完成。请尝试登录或找回密码。」；rate@yuxuexing.com → 「操作过于频繁，请稍后再试。」；closed@yuxuexing.com → 「注册暂未开放，请查看服务公告。」（auth.register.temporarilyUnavailable，iam.consent.version_unavailable）；fail@yuxuexing.com → 「注册没有完成，请稍后再试。」（auth.register.failed，UNKNOWN_AUTH_ERROR）。失败保留已填内容，不跳转。
  • 注册成功（Mock） → 其他任意账号 + 至少 12 位且两次一致的密码 → 1.4s 后清空密码、顶部 Toast「账号已创建，正在完成设置」，1.2s 后跳转 onboarding.html。真实页注册成功后走 continueAfterLogin(returnTo)：新账号进入开始引导，原型以 onboarding.html 表示。
