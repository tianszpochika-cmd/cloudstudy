  • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?theme=light|dark 固定主题；?state=normal|loading|empty|error|forbidden|offline 直达页面状态；?mock=risk|broken|no-chest|chest-error 演示连续学习将中断 / 已中断、奖励箱为空与奖励读取失败。
  • 页面状态 → 工具条「正常 / 加载 / 空 / 错误 / 无权限 / 离线」：正常为成长概览与各区块；加载为 role=status「正在读取成长记录…」+ 骨架屏（aria-busy）；空为「还没有成长记录 / 完成今天的学习，就会点亮第一颗星。」+「去学习」；错误为「成长记录暂时无法读取 / 请检查网络后重试。」+「重试」；无权限为「登录后查看成长记录 / 成长记录与你的学习进度一起保存。」+「去登录」→ login.html；离线保留已读取的成长记录，并在最上方显示 warn 色 role=status「网络暂时不可用 / 本机有 2 条待同步记录，联网后可继续同步。」+「重试」。
  • 状态恢复 → 错误与离线「重试」转圈「正在重试…」→ 1.1s 后回到正常态，不弹成功 Toast；无权限只保留「去登录」。
  • 切换状态副作用 → 离开正常态会取消未完成的破冰 / 领取 / 开启奖励箱 / 重试计时并恢复按钮，不出现延迟 Toast 或跳转；切回正常态保留已领取的任务与已开启的奖励箱状态。
  • 概览 → 等级 Lv.4 · 稳步成长、总 XP 1 280、星币 320；等级进度条 role=progressbar 为 64%，说明「距离下一级还需 220 XP。」。
