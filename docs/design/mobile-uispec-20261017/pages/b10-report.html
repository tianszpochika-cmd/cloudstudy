      • 页头与导航 → 导航栏「错题与报告」（pages.json 标题）+ 返回（backMobile：返回上一页；无历史时回 home.html，原型 data-back="home.html"），右上角设置 → settings.html；页内 kicker「看看你的进步」（ZH_KICKERS）、标题「看见进步，找到下一步。」、说明「回顾学习记录，订正错题，让薄弱处慢慢变强。」（pages.b10-report）；不显示底部 TabBar。
      • 状态条 → 等价 B10StatusPanel：idle「准备开始」、loading「正在加载学习内容」、ready「已准备好，可以开始 / 错题记录与报告已读取。」、empty「当前没有可用内容」、offline「网络暂时不可用 / 待同步不等于已结算。」、stale「内容版本已失效 / 当前版本已下线或发生变化，请重新读取。」、error「服务暂时不可用」；error / offline / stale 右侧出现「重试」，其余状态只保留画质按钮。状态条下方始终显示「错题本只保留整次答错的练习。」（ZERO_ONLY_COPY）。
