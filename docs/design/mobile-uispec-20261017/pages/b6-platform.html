交互说明（b6-platform）

  • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?theme=light|dark 固定主题；?state=normal|loading|error|forbidden 直达页面状态；?mock=load-error|refresh-error|degrade|empty-data 演示首次读取失败、刷新失败、自动降级与三份数据全空；?level=ultra|high|medium|performance 指定初始画质。截图全集（每项 ?theme=light|dark 各一张，共 16 张）：b6-platform-light.png / b6-platform-dark.png；b6-platform-loading-{light,dark}.png；b6-platform-error-{light,dark}.png；b6-platform-forbidden-{light,dark}.png；b6-platform-load-error-{light,dark}.png；b6-platform-refresh-error-{light,dark}.png；b6-platform-degrade-{light,dark}.png；b6-platform-empty-data-{light,dark}.png。
  • 页头与导航 → 导航栏「画质与设备」（pages.json）+ 返回 settings.html（真实入口「设置 › 性能帮助与设备适配说明」，「我的」也有同名入口）；MobilePageHeader 的 kicker「设备适配」（ZH_KICKERS）、标题「让学习，流畅又舒适。」、说明「选择适合设备的画质，了解无障碍与兼容支持。」（pages.b6-platform）；不显示底部 TabBar。
  • 页级标题行 → 对齐 vue 的 b6-mobile-heading：eyebrow「原生与多端」（grid 图标）+ 说明「设备支持情况与画质选项，可在这里查看。」+ 右侧唯一的页面级次按钮「刷新」（文字在前、refresh 图标在后；:loading 时显示转圈并保留「刷新」文字）。矩阵卡头不再有「刷新」。
  • 内容顺序 → 与 b6-platform.vue 一致：目标端矩阵 → 画质与降级 → 无障碍替代路径；撤销上一稿把画质提前的「设计调整」。
  • 刷新 → 页面级「刷新」重新读取三份数据（矩阵 / 预算 / 无障碍），转圈期间按钮禁用、文案保持「刷新」；成功时不显示任何提示、不弹 Toast，卡内沿用最新数据。失败时标题行下方显示 role="alert" 单行「网络不可用，当前使用本地性能设置。」，卡片继续渲染已有数据（对齐 vue load() 只改 errorMessage、不重置三个 ref）；提示条内没有「重试」，页面「刷新」本身就是重试（设计明确）。?mock=load-error 打开即首次读取失败（提示条 + 三张卡的默认空数据），点「刷新」即成功恢复；?mock=refresh-error 打开即处于一次刷新失败后的状态（提示条 + 卡片保留完整数据），再点「刷新」仍失败一次，之后成功（便于反复演示同一分支）。
  • 目标端矩阵卡 → eyebrow「壳矩阵」（grid）、标题「目标端矩阵」、说明 = statusLabel(codeLayerStatus)「待测试阶段验证」、右上徽标 = statusLabel(realDeviceEvidenceStatus)「等待测试阶段」；不显示 matrixVersion（设计调整，STYLE-BRIEF 不显示原始版本串）。七行 mock 覆盖全部 B6PlatformCode：WEB 网页版 / H5 移动网页 / ANDROID Android App / IOS iOS App / IPAD iPad / WECHAT_MINI_PROGRAM 微信小程序 / WINDOWS_PWA Windows 桌面版（中文名映射为设计调整）；每行保留优先级与实现方式一行（如「P0 · 移动端 uni-app」）+ 状态徽标（实现方式的中文译法与英文原值 learner-web / mobile uni-app / uni-app conditional build 的对应关系为设计调整）。徽标文案只取本页 STATUS_LABELS：已就绪 / 已构建 / 代码已就绪 / 待测试阶段验证 / 等待测试阶段 / 需测试阶段验证 / 已通过 / 未通过；mock 为代码层证据 CODE_READY →「代码已就绪」；未知值一律显示「待确认」，不出现原始枚举（设计调整，vue 会回退显示原始值）。
  • 画质与降级卡 → eyebrow 图标取 V2_ICONS.gear 精确路径（非 sparkles），标题「画质与降级」，说明原文「低帧率、内存压力或离线时自动降级」。档位文案取本页 QUALITY_LEVEL_LABELS：极致 / 高清 / 标准 / 省电，徽标与四个按钮一致，默认「高清」；不重命名、不增加每档效果说明。选择只通过选中按钮样式与卡头徽标表达（role="radiogroup" + role="radio" / aria-checked），不显示「画质已切换为…」类反馈、不弹 Toast；点击当前档位是无操作。选择写入 localStorage['uispec-quality-level']，方向键 / Home / End 切换并把焦点留在新档位。文案说明：设置页同一 PerformanceLevel 使用「超高 / 高 / 均衡 / 省资源」，本页保留 vue 的「极致 / 高清 / 标准 / 省电」，跨页差异如实保留、不统一。
  • 画质预算行 → 按 vue 渲染 budget.levels：每行「档位名」+「{textureBudgetMb}MB · 粒子 {particleBudget} · 3D|SVG/静态」。mock 四行：极致 512MB · 粒子 100 · 3D；高清 256MB · 粒子 64 · 3D；标准 128MB · 粒子 24 · 3D；省电 64MB · 粒子 0 · SVG/静态（真实 apps/mobile/src/api/b6.ts 不返回 levels，因此为 mock 数据）。
  • 自动降级 → ?mock=degrade 在初始档位上下调一档（默认「高清」→「标准」）并显示 warn 行「检测到设备压力，画质已自动降为「标准」。」；?mock=degrade&level=performance 保持「省电」。真实页由 AdaptivePerformanceEngine 在低帧率、内存压力、离线或存储压力时自动降级，结果只体现在选中档位；该 warn 行不在 vue 中，属设计新增。
  • 无障碍替代路径卡 → eyebrow 图标取 V2_ICONS.check 精确路径（非 check-circle），标题「无障碍替代路径」，说明 = releaseBlocking ? '上线阻断检查' : '建议检查'（mock 为「上线阻断检查」），右上徽标「{n} 项」。每行都是 ✓ 成功图标 + 标题 + fallbackRule（vue 对所有项统一渲染 ✓，API 无逐项状态）；mock 五行对齐 api 条目：文字缩放至 200% 不裁切 / 键盘可完成关键流程 / 读屏可理解状态 / 动效可关闭 / 权限拒绝仍可继续。取消上一稿的 warn 图标与「待验证」徽标。
  • 读取失败 → 对齐 vue load() 的 catch：标题行下方显示单行 role="alert"「网络不可用，当前使用本地性能设置。」；三张卡继续按默认值渲染（矩阵说明「待测试阶段验证」、徽标「等待测试阶段」、列表为空；画质按钮仍可用；无障碍「0 项」「上线阻断检查」）；不显示卡内「…暂时无法读取」说明，也没有提示条内的「重试」。
  • 空数据 → ?mock=empty-data 模拟当前 apps/mobile/src/api/b6.ts 的真实回退：三份列表全部为空，页内不显示读取失败提示；各卡只显示单行「暂无目标端数据。」/「暂无画质预算数据。」/「暂无无障碍检查项。」（单行、不写成读取失败，设计新增）。
  • 页面状态 → 加载：页面级「刷新」转圈（文案保留）+ 三张卡骨架屏（aria-busy，骨架为设计新增，不显示「正在读取…」文案）；错误：单行「网络不可用，当前使用本地性能设置。」+「重试」，不再有标题、正文与「继续调整画质」；无权限：「登录后查看设备适配与画质设置。」+「去登录」→ login.html?returnTo=%2Fpages%2Fb6-platform%2Fb6-platform（真实页 ensureMobilePageAccess 未登录直接跳转，本态为设计新增）。document.title 同步：正常「画质与设备」、加载「正在读取设备适配信息…」、错误「网络不可用，当前使用本地性能设置。」、无权限「登录后查看设备适配与画质设置。」。
  • 状态恢复 → 工具条切换离开正常态会取消未完成的刷新计时并恢复按钮；错误态「重试」转圈 1.0s 后回到正常态，不弹成功 Toast；切回正常态按 ?mock 重新预置失败提示、空数据与降级结果。
  • 登录门禁 → 对齐真实页 onShow：先 ensureMobilePageAccess，未登录直接跳转登录页，不渲染本页；原型以无权限态承载该分支。
  • 文案边界 → 不显示 platformCode、matrixVersion、原始状态枚举或内部错误码；平台名与实现方式使用中文 mock；未知状态显示「待确认」；纹理 MB 与粒子数按 vue 如实显示，不隐藏。
