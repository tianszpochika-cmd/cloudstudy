交互说明（assessment）

  • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?view=guide|held|question|report|skipped 直达对应视图，缺省为「开始定级」。
  • 页面状态 → 工具条「正常 / 加载 / 空 / 错误 / 无权限 / 离线」→ 正常为测评流程；加载为读取测评进度的骨架屏（aria-busy）；空为「目前没有可用的题目」；错误为测评服务不可用；无权限为没有测评权限；离线为网络不可用。切换离开正常态会取消未完成的模拟请求与提交，结束提交中状态。
  • 开始定级 → 点击「开始定级」→ 显示「正在准备测评 / 请稍候。」→ 1s 后进入第 1 题。
  • 选择选项 → 点击任一项 → 该项边框与底色变为选中态、左侧字母变为 brand 实心并显示对勾，「提交答案」由禁用变为可用；再次点击同项保持选中，不可清空。
  • 提交答案 → 点击，或聚焦选项按回车（未选中时先选中、已选中时提交）→ 按钮保持宽度显示 16px 转圈与「正在记录…」，四个选项不可操作 → 0.9s 后显示本次反馈「刚才提交的这题答对了。」或「刚才提交的这题没有答对。」，进度前进并显示下一题；第 10 题提交后进入报告。服务端已接收题数在进度条下方以「服务端已接收 n 题。」显示。
  • 报告 → 显示等级与分数（如 B1 · 70 分）、答对题数与答对比例；「查看今日状态」跳转 today.html，「重测」按钮转圈「正在准备…」1.2s 后从第 1 题重新开始。
  • 已跳过测评 → ?view=skipped → 显示「已跳过测评 / 水平尚未验证」，明确「这次跳过不是正式测评分数」「这不是测评等级」；「查看今日状态」跳转 today.html。
  • 断点继续 → ?view=held → 显示「继续上次测评」与「重新读取」；点击后转圈 1.1s，回到题目视图并保留已接收题数。
  • 页面状态恢复 → 空 / 错误态「重新读取」、错误态「重试」、离线态「重新连接」→ 按钮转圈 1.1s 后回到正常态并 Toast「已重新读取测评内容 / 测评服务已恢复 / 网络连接已恢复」；错误与离线态均说明「不会新开一套题」。
  • 无权限 → 「查看学习权益」跳转 b5-commerce.html，「返回学习首页」跳转 home.html。
  • 返回 → 导航栏返回跳转 home.html；各视图的「返回学习首页」同样跳转 home.html。
