交互说明（b2-vocabulary）

  • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?theme=light|dark 固定主题；?state=normal|loading|empty|error|forbidden|offline 直达页面状态；?mock=idle|revealed|rating|rate-error|done|stale|stale-recovery|queued|sync-partial|sync-done|no-audio|back-error 演示空闲、已揭晓背面、评分中、评分失败、今日完成、版本失效、待核验、待同步、同步部分失败、同步完成提示、没有发音与背面读取失败。截图为 b2-vocabulary-{light,dark}.png、b2-vocabulary-{loading,empty,error,forbidden,offline,revealed,rating,done,stale,queued,no-audio,back-error,rate-error,idle,sync-partial,sync-done}-{light,dark}.png。
  • 页面状态 → 工具条「正常 / 加载 / 空 / 错误 / 无权限 / 离线」：正常为复习词卡、空闲或今日完成；加载为 role=status「正在加载学习内容…」+ 骨架屏（aria-busy）；空对齐 b10.vocab.empty「今天没有到期词卡」+ b10.status.noSample「内容准备好后会在这里显示。」+ 单个「重试」；错误为「词汇批次暂时不可用 / 请根据上方状态重试；未确认的复习不会被显示为已完成。」+「重试」；无权限为「当前会话没有访问权限 / 登录后可以继续复习。」+ 单个「去登录」；离线为「网络暂时不可用 / 待同步不等于已结算。」+「重试」，有队列时队列行显示「n · 待同步不等于已结算。」+「同步待处理记录」。所有状态下页面下方「基础练习 / 错题与报告」两个出口照常保留。
  • 状态恢复 → 空、错误与离线「重试」转圈 → 1.1s 后回到正常态，不弹成功 Toast；无权限不提供重试。
  • 空闲 → ?mock=idle（对齐 store.status === 'idle'）：显示「等待读取词汇批次 / 身份与页面初始化完成后，将从学习服务读取当前复习队列。」，无按钮、无骨架屏。
  • 批内进度 → 顶部「已完成 2 / 5」与细进度条同步更新，评为一张后前进一位；今日完成与空闲时进度区隐藏。
  • 播放发音 → 仅在服务端返回音频地址时显示「播放发音」；点击后按钮短暂变为「正在播放…」并禁用 1.2s，随后恢复；没有音频时改为说明「没有发音，不能播放。」，不提供空按钮。?mock=no-audio 演示该分支。
  • 显示答案 → 正面只显示单词、音标与提示，并说明「正面不展示释义、例句或标准答案。」；点击主按钮转圈「正在读取答案…」→ 0.8s 后在同一张卡内展开释义、英文释义、例句与「下次复习」日期，评分按钮出现。?mock=revealed 直接显示背面与四档记忆信心；?mock=rating 显示评分中的真实禁用态（surface 底、mut 字、虚线边框、not-allowed）与「正在记录…」。
  • 背面读取失败 → ?mock=back-error 在卡内显示 bad 色 role=alert「词卡背面暂时无法加载，答案未被伪造。可以再试一次。」（带参数打开即显示，便于核对），不伪造释义；再次点击「显示答案」可正常展开。
  • 记忆信心 → 背面四档「忘了 / 模糊 / 记得 / 很熟」以 bad / warn / ok / ok 柔和底色区分，同时用文字表达；选择后四档立即进入真实禁用态，转圈「正在记录…」→ 0.7s 后前进到下一张，并在卡下显示 role=status「复习已记录。」2.4s 后自动消失。
  • 评分失败 → ?mock=rate-error（对齐 rateCard 未获确认分支）：选择记忆信心后卡片不前进，卡内显示 bad 色 role=alert「服务端未确认本次复习，当前卡片未推进。」，四档按钮恢复可点，可再次评分；错误在下一次评分开始时清除。
  • 版本失效 → ?mock=stale 显示 warn 色横幅「内容版本已失效 / 当前版本已下线或发生变化，请重新读取。」+「重试」，评分按钮禁用；点击转圈「正在读取…」1s 后横幅消失、评分恢复可用。?mock=stale-recovery 演示同一面板的第二种来源（RECOVERY_REQUIRED）：说明改为「复习记录待核验，暂不可结算。」。
  • 待同步 → ?mock=queued 显示 warn 色横幅「网络暂时不可用 / 本次复习已排队待同步，服务端尚未确认掌握变化。」+ 队列行「1 · 待同步不等于已结算。」+ 横幅按钮「同步待处理记录 / 重试」（对齐 B10StatusPanel 在 offline 下的 status.retry 与 status.sync）。「重试」转圈「正在重试…」1.1s 后回到 ready 态（横幅改为 surface 底「已准备好，可以开始」、队列保留、不再显示重试），不弹 Toast。「同步待处理记录」转圈「正在同步…」0.9s 后横幅消失，进度区上方显示 ok 色 role=status 提示「已准备好，可以开始 / 待同步复习已提交。」（对齐 syncSrs 成功后的 status='ready' + message），2.4s 后淡出，不弹 Toast。离线态内的「同步待处理记录」走同一流程并回到正常态。?mock=sync-partial 演示部分失败：同步后仍保留队列，说明改为「部分复习未获服务端确认，队列仍保留。」。?mock=sync-done 直达同步成功后的页内提示。
  • 今日复习已完成 → 全部评完后或 ?mock=done：隐藏进度与词卡，显示 ok 图标、「今日复习已完成」与服务端确认说明 +「刷新复习队列」；点击转圈「正在刷新…」0.9s 后重新读取：先回到加载态，再回到正常 / 完成态，不弹 Toast。
  • 画质 → 顶部「画质 · 舒适」打开底部弹层，四档「精致 / 舒适 / 轻量 / 省资源」；当前档带 brand 对勾与 aria-pressed，选择后更新顶部文案并关闭，焦点回到画质按钮；遮罩、取消与 Esc 均可关闭。
  • 出口 → 卡下两个次按钮：基础练习 → assessment.html、错题与报告 → b10-report.html，所有状态下保留；真实页没有页脚说明，原型同样不显示。
  • 导航 → 二级页：导航栏标题「单词复习」+ 返回（backMobile：返回上一页；无历史时回首页，原型 data-back="home.html"）；右上角设置 → settings.html；不显示底部 TabBar。
