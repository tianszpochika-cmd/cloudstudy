交互说明（b2-vocabulary）

  • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?theme=light|dark 固定主题；?state=normal|loading|empty|error|forbidden|offline 直达页面状态；?mock=done|stale|queued|no-audio|back-error 演示今日完成、版本失效、待同步、没有发音与背面读取失败。
  • 页面状态 → 工具条「正常 / 加载 / 空 / 错误 / 无权限 / 离线」：正常为复习词卡或今日完成；加载为 role=status「正在加载学习内容…」+ 骨架屏（aria-busy）；空为「今天没有到期词卡 / 完成今天的练习后，新的词卡会在到期时出现。」+「重新读取 / 去练习」；错误为「词汇批次暂时不可用 / 未确认的复习不会被显示为已完成。」+「重试 / 返回学习首页」；无权限为「当前会话没有访问权限 / 登录后可以继续复习。」+ 单个「去登录」；离线为「网络暂时不可用 / 待同步不等于已结算。」+ 待同步队列 +「重试 / 返回学习首页」。
  • 状态恢复 → 空「重新读取」、错误与离线「重试」转圈 → 1.1s 后回到正常态，不弹成功 Toast；无权限不提供重试。
  • 批内进度 → 顶部「已完成 2 / 5」与细进度条同步更新，评为一张后前进一位；今日完成后进度区隐藏。
  • 播放发音 → 仅在服务端返回音频地址时显示「播放发音」；点击后按钮短暂变为「正在播放…」并禁用 1.2s，随后恢复；没有音频时改为说明「没有发音，不能播放。」，不提供空按钮。?mock=no-audio 演示该分支。
  • 显示答案 → 正面只显示单词、音标与提示，并说明「正面不展示释义、例句或标准答案。」；点击主按钮转圈「正在读取答案…」→ 0.8s 后在同一张卡内展开释义、英文释义、例句与「下次复习」日期，评分按钮出现。
  • 背面读取失败 → ?mock=back-error 时首次「显示答案」在卡内显示 bad 色 role=alert「词卡背面暂时无法加载，答案未被伪造。可以再试一次。」，不伪造释义；再次点击可正常展开。
  • 记忆信心 → 背面四档「忘了 / 模糊 / 记得 / 很熟」以 bad / warn / ok / ok 柔和底色区分，同时用文字表达；选择后四档立即进入真实禁用态（surface 底、mut 字、虚线边框、not-allowed），转圈「正在记录…」→ 0.7s 后前进到下一张，并在卡下显示 role=status「复习已记录。」2.4s 后自动消失。
  • 版本失效 → ?mock=stale 显示 warn 色横幅「内容版本已失效 / 当前版本已下线或发生变化，请重新读取。」+「重新读取」，评分按钮禁用；点击转圈「正在读取…」1s 后横幅消失、评分恢复可用。
  • 待同步 → ?mock=queued 显示 warn 色横幅「本次复习已排队待同步 / 服务端尚未确认掌握变化，联网后继续同步。」+「同步」；点击转圈「正在同步…」0.9s 后横幅消失并弹成功 Toast「待同步复习已提交。」。离线态内的「同步」走同一流程并回到正常态。
  • 今日复习已完成 → 全部评完后或 ?mock=done：隐藏进度与词卡，显示 ok 图标、「今日复习已完成」与服务端确认说明 +「刷新复习队列」→ 转圈 0.9s 后弹 Toast「复习队列已更新。」并保持完成态。
  • 画质 → 顶部「画质 · 舒适」打开底部弹层，四档「精致 / 舒适 / 轻量 / 省资源」；当前档带 brand 对勾与 aria-pressed，选择后更新顶部文案并关闭，焦点回到画质按钮；遮罩、取消与 Esc 均可关闭。
  • 出口 → 卡下两个次按钮：基础练习 → assessment.html、错题与报告 → b10-report.html；页脚说明「复习记录以服务端确认为准；待同步不等于已结算。」。
  • 导航 → 二级页：导航栏标题「单词复习」+ 返回（b2-practice.html）；右上角设置 → settings.html；不显示底部 TabBar。
  • 文案边界 → 不显示内部错误码、算法版本或原始题型枚举；来源与掌握度用「复习 / 新学 / 学习中 / 新词」中文徽标表达，不只依赖颜色。
