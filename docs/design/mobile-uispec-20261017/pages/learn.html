交互说明（learn）

  • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?theme=light|dark 固定主题；?state=normal|loading|empty|error|forbidden|offline 直达页面状态。
  • 课程直达 → ?contentCode=b2-grammar-present|b1-daily-greetings|b1-listening-campus|b1-reading-city（兼容 ?content=）直接打开课程内容；&taskId=… 与真实页一致，显示「可浏览课程，完成记录暂不可用。」。
  • Mock 参数 → ?mock=content-loading|content-error|content-empty 演示课程读取中、读取失败与无学习单元；?mock=review-loading|review-empty|review-error|review-offline|review-permission|review-illegal 演示复习安排的各分支；?mock=no-courses 等同工具条「空」。
  • 页面状态 → 正常为课程选择、练习入口与复习；加载为读取课程的骨架屏（aria-busy）；空为课程书架为空 + 暂无待复习；错误 / 无权限 / 离线分别说明原因并提供重试或权益入口。切换离开正常态会取消未完成的读取、复习完成与重试计时。
  • 状态恢复 → 错误 / 无权限 / 离线「重试」转圈「正在重试…」「正在重新连接…」→ 1.1s 后回到正常态，不弹成功 Toast；无权限另有「查看学习权益」跳转 b5-commerce.html。
  • 练习灵感 → 三张入口卡：单词复习 → b2-vocabulary.html、分级阅读 → b11-reading.html、语法结构 → b3-grammar.html；卡片有 44px 以上命中区与键盘焦点环。
  • 选择课程 → 课程卡列出 4 门课程（标题 + 语言 / 类型 / 单元数），点击任一行 → 卡片切换为「正在读取课程…」+ 骨架屏 → 0.9s 后显示课程内容；读取结束将焦点移到课程标题。
  • 课程内容 → 显示课程标题、语言与类型、简介、学习单元（题干 + 四个选项），下方「换一门课程」返回课程列表；无学习单元时显示「暂无可展示的学习单元。」。
  • 内容读取失败 → 课程卡内 bad 色 role=alert「课程暂时无法读取，请检查网络后重试。」+「重试」与「换一门课程」；重试转圈后恢复当前课程，不弹 Toast。
  • 练习入口 → 基础练习 → assessment.html（真实页将 b2-practice 入口指向测评），分级阅读 → b11-reading.html，语法练习 → b3-grammar.html；「更多练习与学习报告」→ b10-report.html。
  • 复习列表 → 标题「待复习 n 项」与「按最近的练习记录整理。」；每行显示来源与阶段（如「错题 · 待复习」）；可完成项点击「开始复习」→ 转圈「正在复习…」→ 0.9s 后该行移除、计数递减、历史增加并 Toast「复习已记录」；不可完成项显示「去学习」/「去练习」与原因（新内容需先学一遍 / 复习需要一次可核验的作答）。
  • 复习空态 → ?mock=review-empty：标题「待复习 0 项」、「暂无到期复习。」（reviewEmpty → NO_DUE_COPY）、「薄弱点尚不能判断。」（weaknessView(0)）与「最近已完成 3 项复习。」，不显示复习行；全部复习完成时同样回到该空态。
  • 复习读取失败 / 无权限 / 离线 → ?mock=review-error 显示「复习安排暂时无法读取。」+「重试」，重试转圈后恢复 4 项复习；?mock=review-offline 追加「请检查网络后重试。」；?mock=review-permission 显示「当前账号无法查看复习安排。」且不提供重试。
  • 复习不可用操作 → ?mock=review-illegal 在列表上方显示 warn 行「这个操作现在不能用」，点击「开始复习」只弹错误 Toast，不改变列表。
  • 工具条「空」 → 复用正常态框架：课程卡改为「书架里还没有可学习的课程 / 可以先从练习入口开始，或回到首页看看。」+「去首页看课程」，复习卡为「暂无到期复习。」与「薄弱点尚不能判断。」；练习入口与练习灵感保持可用，切回正常态恢复原课程与复习状态。
  • TabBar → 底部 5 项，「课程」选中并带 aria-current="page"；其余跳转 home.html / b2-practice.html / world.html / profile.html。右上角设置入口跳转 settings.html。
  • 文案边界 → 不显示内部投影版本、错误码或「等待加载」类静态占位；加载使用骨架屏，计数与状态同时用文字表达，不只依赖颜色。
