交互说明（settings）

  • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?theme=light|dark 固定主题；?state=normal|loading|error|forbidden 直达页面状态；?mock=account-error|notif-error|notif-save-error|save-error|withdraw-failed|dnd-conflict|dnd-save-error|locale-error 演示账户偏好读取失败、通知偏好读取 / 保存失败、保存到账户失败、撤回失败、免打扰时段不一致、免打扰统一保存失败与学习内容语言未保存；?view=withdraw-confirm 直接进入学习同意的行内确认态。截图（每项 ?theme=light|dark 各一张）：settings-{light,dark}.png；settings-{loading,error,forbidden}-{light,dark}.png；settings-{account-error,notif-error,notif-save-error,save-error,withdraw-failed,dnd-conflict,dnd-save-error,withdraw-confirm,locale-error}-{light,dark}.png。
  • 页面状态 → 真实页没有整页错误 / 离线页，卡片始终渲染，失败都显示在卡内：加载为偏好卡「正在读取账户偏好…」+ 通知卡「正在读取…」（不显示通知列表与免打扰区）；错误为偏好卡 warn 条「账户偏好暂时无法读取；本机设置仍可使用。」+「重试读取」，同时通知卡「通知偏好暂时无法读取。」+「重试」；离线不设整页态，已从工具条移除。无权限只保留标题「登录后管理设置。」+「去登录」→ login.html?returnTo=%2Fpages%2Fsettings%2Fsettings（真实页 ensureMobilePageAccess 未登录直接跳转，本态为设计新增）。
  • 状态恢复 → 错误态「重试读取 / 重试」转圈后恢复卡内内容，不弹成功 Toast；无权限只保留「去登录」。切换离开正常态会关闭全部弹层、取消未完成的保存 / 撤回 / 读取计时并恢复按钮与开关；切回正常态保留已预览的主题、动效与通知开关。
  • 页头与导航 → 导航栏「设置」（pages.json 标题）+ 返回 profile.html（真实页由「我的」进入）；页内 kicker「舒适设置」（ZH_KICKERS）、标题「舒服的节奏，才走得更远。」、说明「调整学习目标、外观与动效，让这里更适合你。」（pages.settings）；不显示底部 TabBar。
  • 卡片顺序与 eyebrow 图标 → 按 settings.vue：学习目标（target）→ 偏好设置（gear）→ 隐私与数据（lock）→ 设备与会话（grid）→ 站内通知偏好（inbox）；图标路径取自 apps/mobile/src/theme/v2-icons.ts 同名图标；不显示「关于语学星」卡。
  • 学习目标卡 → 只读两行「当前目标 / 四六级备考」「每日目标 / 15 分钟」，底部「修改目标」→ onboarding.html（真实页 /pages/onboarding/onboarding）。
  • 主题 → 分段控件「跟随系统 / 浅色 / 深色」默认跟随系统；选择后在当前原型内立即预览对应主题（真实页 watch(themeMode) 调用 mobileThemeController.setTheme），并标记为待保存。工具条主题与页内主题是两套控制：工具条只切换设计稿预览，页内选择模拟用户的真实偏好。
  • 动效 → 分段控件「完整动效 / 减少动效 / 关闭动效」，切换后把本页过渡时长改为较短或 0（对齐 setMobileMotion 的预览语义），并标记为待保存；系统「减少动效」仍优先。
  • 高对比度 → 开关只有标题、没有附加说明（真实页无说明文案）；打开后本页卡片边框、说明文字和控件边框立即加强（模拟高对比主题预览），并标记为待保存。
  • 画质 → 四个 chip「超高 / 高 / 均衡 / 省资源」默认「高」，选择立即生效；说明固定为「低帧率或内存不足时，画质可能自动降低。」，不随选择变化；画质不进入保存按钮（真实页 setMobileQuality 本机生效），不显示帧率或内存数值。
  • 保存偏好 → 修改主题、动效或高对比度后主按钮才可点击；未修改时为真实禁用态（surface 底、mut 字、not-allowed）并显示提示「修改上面的主题、对比度或动效后即可保存。」。点击后转圈「保存中…」→ 0.9s 后按钮恢复禁用态、显示成功条「主题、对比度与动效已同步到账户。」；?mock=save-error 打开即预置一个已改动的偏好（「减少动效」已选、保存按钮可点）并显示失败条「本机设置已立即生效，但未同步到账户，请检查网络后重试。」（真实页原文），点击保存得到同样结果。
  • 恢复显示默认 → 一键回到「跟随系统 / 完整动效 / 高对比度关闭 / 高画质」，立即预览并标记为待保存；不自动提交，仍需点保存同步到账户。
  • 界面语言 → 只读行「简体中文」（真实页本机只读）；学习内容语言默认「英语」，点击打开底部弹层选择「英语 / 简体中文」，当前值带 brand 对勾；选择后按钮转圈「保存中…」→ 0.9s 后更新值并显示成功条「学习内容语言已同步到账户。」（真实页原文）；?mock=locale-error 打开即在语言行下方预置 bad 条「学习内容语言未保存，请重试。」（真实页原文），再次选择同样得到该提示。
  • 账户偏好读取失败 → ?mock=account-error 在偏好卡顶部显示 warn 条「账户偏好暂时无法读取；本机设置仍可使用。」+「重试读取」，其余控件保持可操作；点重试转圈「正在读取…」→ 0.9s 后隐藏并保留当前本机选择。
  • 站内通知 → 14 类通知逐行开关（学习进度 / 复习提醒 / 连续学习 / 考试安排 / 学习检查点 / 自习室互动 / 奖励动态 / 课程更新 / 会员服务 / 活动资讯 / 安全提醒 / 账户通知 / 支付与订单 / 系统消息），默认仅「学习进度 / 复习提醒 / 安全提醒」开启（真实页「未设置的类型默认关闭」）；「课程更新」行下方显示「摘要投递暂不可用」（真实页 unsupportedCadence）。切换时该行显示「保存中…」、所有开关暂时禁用 → 0.7s 后保存完成并显示「设置已保存。」。
  • 通知保存失败 → 通知卡底部 error 条「保存失败，已更新最新设置，请确认后重试。」（真实页原文），列表与免打扰区保留，开关回退；?mock=notif-save-error 打开即预置该条，点击任意开关得到同样结果。不复用「通知偏好暂时无法读取。」读取失败条。
  • 通知读取失败 → ?mock=notif-error 隐藏通知列表与免打扰区，只显示 bad 条「通知偏好暂时无法读取。」+「重试」；点重试转圈「正在读取…」→ 0.9s 后恢复列表与免打扰区，不弹 Toast。
  • 站内免打扰 → 通知读取成功后，开始 / 结束时间始终显示（DEFAULT_NOTIFICATION_DND_WINDOW：22:00 / 07:00），不随开关隐藏；开关说明为「已关闭 / 开启中；只影响站内提醒」。「保存时段」只在改过时间后出现，保存时按开启提交（enabled=true），0.7s 后说明更新并显示「设置已保存。」。开始与结束相同则拒绝并把「开始和结束时间不能相同。」显示在通知卡底部 error 条。?mock=dnd-conflict 额外显示「各类型的免打扰时段不一致；保存后会统一。」；?mock=dnd-save-error 打开即显示底部 error 条「12 项已保存，2 项未保存。已更新最新版本，可重试统一时段。」+「重试统一设置」，点击重试 0.9s 后完成并显示「设置已保存。」。
  • 隐私与数据 → 五行说明来自 privacyNotices() 默认回退（删除申请、音频保留、退出与登录、跨服务导出、全部完成结果），不显示内部编号或完成百分比。
  • 撤回学习同意（行内确认）→ 点「撤回学习同意」后该按钮隐藏，原位显示 role="alert" 文案「确认撤回后，学习能力会收回。账号仍会保留。」+「取消」「确认撤回」两个按钮；确认中「确认撤回」显示「正在撤回…」且两个按钮都禁用；成功后退出确认态、按钮恢复为可点的「撤回学习同意」，下方显示成功条「学习同意已撤回。学习能力已收回，账号仍保留。」（WITHDRAW_DONE_COPY）；失败时保持确认态并显示「撤回没有完成。学习同意仍在。」（WITHDRAW_FAILED_COPY）。?mock=withdraw-failed 打开即预置确认态与失败文案；?view=withdraw-confirm 直接进入行内确认态。
  • 设备与会话 / 出口 → 「管理设备与会话」→ devices.html；「性能帮助与设备适配说明」→ b6-platform.html；「查看消息」带 chevron → b4-social.html。
  • 文案边界 → 不显示账户 ID、策略版本、内部错误码、原始枚举或设备指纹；所有保存结果以服务端确认为准，失败时明确说明「本机已生效但未同步」，不把本机预览说成已保存到账户。
