交互说明（b11-reading）

  • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?theme=light|dark 固定主题；?state=normal|loading|empty|error|forbidden|offline 直达页面状态；?mock=queued|save-error|expired|answered-ok|answered-bad|submit-error|submit-offline|revoked|motion-off 演示待同步、保存失败、版本失效、已答对 / 已记录、提交失败、离线提交、授权撤回与关闭动效。截图：b11-reading-{light,dark}.png 与 b11-reading-{loading,empty,error,forbidden,offline,queued,save-error,expired,answered-ok,answered-bad,submit-error,submit-offline}-{light,dark}.png（revoked 复用无权限截图）。
  • 页面状态 → 工具条「正常 / 加载 / 空 / 错误 / 无权限 / 离线」：加载为「正在加载内容」+ 骨架屏（aria-busy）；空为「当前没有可用内容 / 暂时没有可用的授权文章。内容准备好后会在这里显示。」+「重试」（对齐 b11.status.empty、b11.reading.noArticle 与 b11.common.noSample）；错误为「服务暂时不可用 / 阅读服务暂时不可用；最后位置仍保留。」+「重试」；无权限为「当前会话没有访问权限 / 当前文章版权状态不允许阅读。」+「去登录」→ login.html?returnTo=%2Fpages%2Fb11-reading%2Fb11-reading；离线为「暂时无法连接服务 / 网络暂时不可用；当前页面和待同步队列仍保留。」+「重试」+ 待同步队列行与「恢复同步」。
  • 状态恢复 → 空、错误与离线「重试」转圈「正在读取…／正在重试…」→ 1.1s 后回到正常态，不弹成功 Toast；离线队列「恢复同步」转圈「正在同步…」→ 1.1s 后回到正常态并显示页内提示「待同步阅读记录已提交。」；无权限只保留「去登录」。
  • 登录门禁 → 对齐真实页 onMounted：先 session.restore()，未登录跳转登录页；loadReading 在无会话时把状态置为 forbidden。原型以无权限态承载未登录分支，回跳地址与真实页一致。
  • 切换状态副作用 → 离开正常态会关闭画质弹层、取消未完成的保存 / 同步 / 提交计时并恢复按钮，不出现延迟反馈；切回正常态保留当前段落、作答与待同步记录。
  • 页头与导航 → 导航栏「分级阅读」（pages.json 标题）+ 返回（无历史时回 home.html），右上角设置 → settings.html；页内 kicker「阅读角」、标题「翻开属于你的新一页。」、说明「选择适合的阅读难度，把好表达收入日常。」；不显示底部 TabBar。
  • 文章信息与段落 → 顶部「授权文章 · 1 篇」与「画质 · 舒适」「动效」同排；文章卡显示 CEFR 级别、词数、预计时长与标题（不显示文章 ID 或内容版本号）；正文逐段呈现，每段英文下方固定显示「译文」与中文翻译（对齐真实页 blockTranslation 有值即显示）；下方「第 n 段 · 共 3 段」。
  • 上一段 / 下一段 → 切换段落时进度条与「33% · 第 1 / 3 段」同步更新，并隐藏已保存提示；第一段的「上一段」、最后一段的「下一段」进入真实禁用态（surface 底、mut 字、虚线边框、not-allowed）。切换后可继续阅读并在任意段落保存位置。
  • 保存进度 → 主按钮「保存进度」（b11.reading.save）转圈「正在保存…」（段落切换按钮同时禁用，防止重复提交）→ 1s 后显示 ok 色 role=status「阅读位置已保存 / 阅读进度已由服务端确认。」（对齐 readingMessage），提示保留到下一次切换段落或刷新；不弹 Toast。`?mock=save-error` 首次保存失败：提示改为 warn 横幅「阅读位置未确认，最后位置已保留。」+「待同步 1」+「恢复同步」，阅读内容仍可查看。
  • 恢复同步 → 待同步横幅的「恢复同步」转圈「正在同步…」0.9s 后清除横幅并显示 ok 提示「待同步阅读记录已提交。」（对齐 syncOffline 成功文案）；失败时队列保留、不静默覆盖本地位置。
  • 版本失效 → ?mock=expired（对齐 404 / 410 → status='expired'）：显示 warn 横幅「内容版本已失效 / 内容版本或阅读授权已失效，请重新读取。」；段落切换、保存、选项与「提交答案」全部真实禁用；「重试」转圈「正在读取…」0.9s 后横幅消失、功能恢复，并显示 ok 提示「阅读内容已更新。」。
  • 理解检查 → 题干 + 三个选项，选项为单选：点击后 brand 描边、soft 底、圆形标记填充，aria-checked 同步；未选择时「提交答案」为真实禁用态（surface 底、mut 字、虚线边框）；已作答的题目选项与提交按钮进入禁用态并保留已选标记。
  • 提交答案 → 转圈「正在提交…」→ 0.9s 后卡内出现 role=status 反馈块：答对为 ok 底「已保存 / 回答正确」，答错为 surface 底「已保存 / 服务端已记录本次练习」（对齐真实页文案，不使用反馈代码），焦点移到反馈块；`?mock=answered-ok|answered-bad` 直接演示两种结果。
  • 提交失败 / 离线提交 → ?mock=submit-error：第 1 题卡内显示 bad 色 role=alert「理解题提交失败，答案仍保留。」，再次提交可成功；?mock=submit-offline（对齐 isB11OfflineError 分支）：显示 warn 色「理解题答案已保留，服务端尚未判定。」并出现待同步横幅「待同步 1」，答案与当前段落不变。
  • 动效开关 → 顶部「动效」开关切换 aria-checked；关闭后本页提示与进度过渡立即停止（.is-motion-off），并弹普通 Toast「已关闭动效」/「已开启动效」；`?mock=motion-off` 直接以关闭状态打开；不改动全局主题。
  • 画质 → 顶部「画质 · 舒适」打开底部弹层，四档「精致 / 舒适 / 轻量 / 省资源」，当前档带 brand 对勾与 aria-pressed；选择后更新顶部文案并关闭弹层，焦点回到画质按钮；遮罩、取消与 Esc 均可关闭（对齐 B11StatusPanel 的 picker）。
  • 出口 → 页尾两个次按钮：学习报告 → b10-report.html、单词复习 → b2-vocabulary.html；正常态下始终保留。
  • 文案边界 → 不显示反馈代码、内容版本号、文章 ID 或原始状态枚举；待同步与失效状态同时用文字说明，不只依赖颜色。
