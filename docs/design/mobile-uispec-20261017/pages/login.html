交互说明（login）

  • 主题切换 → 工具条「浅色 / 深色」 → 整页 token 切换并记住选择。
  • 状态切换 → 工具条「正常 / 加载 / 错误 / 离线」 → 只显示该状态：正常为登录表单，加载为恢复会话骨架屏，错误为登录服务不可用，离线为网络不可用。
  • 状态「加载」 → 品牌行与表单位显示骨架屏，页面标记 aria-busy，不出现「等待登录」类静态框。
  • 状态「错误」重试 → 点击「重试」 → 按钮转圈并变「正在重试…」→ 1.1s 后回到正常态并 Toast「登录服务已恢复」；「帮助中心」跳转 support.html。
  • 状态「离线」重新连接 → 点击「重新连接」 → 按钮转圈「正在重新连接…」→ 1.1s 后回到正常态并 Toast「网络连接已恢复」。
  • 账号 / 密码输入 → 聚焦时 brand 边框 + soft 焦点环；输入即清除本字段错误与表单级错误。
  • 提交校验 → 点击「登录」或按回车 → 账号为空标红「请输入账号」、密码为空标红「请输入密码」，并聚焦首个错误；修正后错误自动消失。
  • 密码可见 → 点击眼睛 → 切换明文 / 密文，图标与 aria-label（显示密码 / 隐藏密码）同步；提交中不可切换。
  • 忘记密码？ → 点击 → 跳转 reset-password.html；提交中链接置灰不可点。
  • 注册 → 点击底部「注册」 → 跳转 register.html；提交中链接置灰不可点。
  • 提交中 → 表单通过校验后 → 按钮保持宽度、显示 16px 转圈与「正在登录…」，账号 / 密码 / 眼睛 / 忘记密码 / 注册全部不可操作，防止重复提交。
  • 登录失败（Mock） → 账号填 error@yuxuexing.com → 1.4s 后表单内 bad 色提示「账号或密码不正确，请重试。」；locked@yuxuexing.com → 「账号暂时锁定，请稍后重试。」；rate@yuxuexing.com → 「请求过于频繁，请稍后再试。」。失败时保留已填内容，不跳转。
  • 登录成功（Mock） → 其他任意账号 + 任意密码 → 1.4s 后清空密码、顶部 Toast「登录成功，正在进入学习首页」，1.2s 后跳转 home.html。
