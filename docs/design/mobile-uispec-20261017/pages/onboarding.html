交互说明（onboarding）

  • 主题与页面状态 → 工具条「浅色 / 深色」「正常 / 加载 / 错误 / 离线」 → 整页 token 切换；状态块分别为引导流程、读取设置骨架屏、读取失败、网络不可用。切换离开正常态会取消未完成的模拟请求并关闭对话框。
  • 步骤指示 → 确认身份 / 必要同意 / 学习目标 → 已完成显示对勾，当前步骤为 brand 实心数字并带 aria-current="step"，待完成为描边数字，同时保留屏幕阅读器状态文字。原型按「确认身份 → 必要同意 → 学习目标 → 设置已完成」线性演示；真实页在必要同意已完整时会跳过该步直接进入学习目标。
  • 步骤一 · 出生年份 → 输入仅保留 4 位数字 → 失焦或提交时校验：为空或不在 1900–2026 时字段下方标红「请输入 1900 至 2026 的整数年份。」并聚焦；修正后错误文字隐藏并保留行高。
  • 步骤一 · 成人确认 → 勾选「我确认自己已满 18 周岁」 → 方框变为 brand 实心对勾；未勾选时提交显示「请确认自己已满 18 周岁。」。
  • 步骤一 · 主动作 → 年份合法且已勾选前，按钮为禁用外观（surface 底、mut 字、not-allowed）；点击禁用按钮只显示两条校验错误，不进入下一步。通过后点击「确认并继续」→ 转圈「正在确认…」→ 1s 后进入「查看同意事项」并聚焦新标题。
  • 步骤一 · 未满 18（Mock） → 出生年份晚于 2008（当前年份减 18）→「正在确认…」1.1s 后 Toast「暂不能向你开放学习」并跳转 forbidden.html。
  • 步骤二 · 同意记录 → 展示 5 条记录（3 条必要 + 2 条可选），已记录为 ok 徽标、已撤回为 mut 徽标；「展开来源记录」展开 IAM 来源、记录时间与文档版本，按钮文案变「收起来源记录」并同步 aria-expanded。
  • 步骤二 · 继续 / 重新读取 → 「按已有同意继续」→「正在继续…」0.9s 后进入学习目标；「重新读取」→「正在读取…」1s 后 Toast「同意记录已更新」。
  • 步骤三 · 学习目标 → 四张单选卡（成人零基础 / 四六级备考 / 考研英语 / 职场与日常）→ 单选互斥，选中为 brand 边框 + soft 底 + 实心对勾，aria-checked 同步。
  • 步骤三 · 每日时长 → 5 / 15 / 30 / 45 分钟四选一，默认 15 分钟；选中项带对勾与 brand 文字。
  • 步骤三 · 保存 → 未选目标时点击主按钮 → 行内 bad 色「请选择学习目标和每日时长。」并聚焦首张卡片；已选目标 → 转圈「正在保存…」1.2s 后进入「设置已完成」、更新摘要并 Toast「学习目标已保存」。保存后「重新读取」会恢复最近一次保存的目标与时长。
  • 步骤四 · 开始定级 → 点击「开始定级」→ 转圈「正在打开…」0.7s 后跳转 assessment.html。
  • 步骤四 · 调整目标 → 点击「调整目标」→ 回到学习目标步骤，保留已选目标与时长。
  • 账号设置 → 点击 → 跳转 settings.html。
  • 退出登录 → 点击 → 对话框「退出登录？」（说明「退出后，本次设置需要重新登录才能继续。」）→「退出登录」为 bad 色；确认后 Toast「已退出登录」，0.8s 后跳转 login.html；取消 / 遮罩 / Esc 关闭。
  • 提交中 → 主按钮保持宽度并显示 16px 转圈；输入、勾选、选项卡、重新读取、账号设置与退出登录全部不可操作，防止重复提交。
  • 加载 / 错误 / 离线 → 加载为品牌行与步骤区骨架屏；错误为「设置读取未完成」+「重新读取」+「退出登录」；离线为「网络连接不可用」+「重新连接」。重试按钮转圈 1.1s 后回到正常态并 Toast。
