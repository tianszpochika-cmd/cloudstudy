    交互说明（b4-games）

    • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?theme=light|dark 固定主题；?state=normal|loading|empty|error|forbidden|offline 直达页面状态；?mock=queue|partial|ready|active|paused|result|passed|empty 演示状态条、游戏会话与结果分支。截图：b4-games-{light,dark}.png。
    • 页面状态 → 工具条「正常 / 加载 / 空 / 错误 / 无权限 / 离线」：加载为「正在加载游戏目录」+ 目录骨架屏（aria-busy）；空为「暂无可用游戏」+「去练习」→ b2-practice.html；错误为「游戏目录暂时没有读出来 / 游戏服务暂时不可用，请稍后重试。」+「重试」；无权限为「当前会话没有访问权限 / 登录后可以继续查看游戏大厅。」+ 单个「去登录」→ login.html?returnTo=%2Fpages%2Fb4-games%2Fb4-games；离线为「网络暂时不可用 / 游戏需要联网；待同步记录会保留在本机。」+「重试」。
    • 状态恢复 → 错误与离线「重试」转圈「正在重试…」→ 1.1s 后回到正常态，不弹成功 Toast；空态只保留「去练习」；无权限只保留「去登录」。
    • 切换状态副作用 → 离开正常态会关闭游戏详情、画质与结束确认弹层，取消未完成的同步 / 暂停 / 刷新 / 结算计时并恢复按钮；切回正常态保留已选画质、游戏会话与最近一局结果。
    • 页头与导航 → 导航栏「游戏大厅」（pages.json 标题）+ 返回 world.html（backMobile：返回上一页，无历史时回 home.html），右上角设置 → settings.html；页内 kicker「边玩边学」、标题「换个方式，练出好状态。」、说明「在轻松的小挑战里，巩固单词与句子。」（pages.b4-games）；不显示底部 TabBar。
    • 状态条 → 等价 B4StatusPanel：标题固定「网络可用 · 学习同步状态」，默认说明「成长记录会随学习进度更新。」；有本机待同步记录时说明变为「本机有 2 条待同步记录，联网后可继续同步。」，右侧出现 warn 徽标「待同步 2」与「同步」。
    • 同步 → 点「同步」转圈「正在同步…」→ 0.9s 后待同步计数与「同步」按钮消失，说明更新为「待同步记录已全部同步。」，Toast「待同步记录已同步」。
    • 画质 → 状态条「画质 · 舒适」打开底部弹层，四档「精致 / 舒适 / 轻量 / 省资源」（B4_PERFORMANCE_LEVELS），当前档带 brand 对勾与 aria-pressed；选择后更新文案并关闭弹层，焦点回到画质按钮；遮罩、取消与 Esc 均可关闭。
    • 游戏目录 → 卡片「小游戏」+ 右侧数量「6 项」；玩法卡片对齐 gameLabel：拼句小火车 / 单词消消乐 / 单词保卫战 / 拼图解谜 / 语法射击 / 词义捕手。每项显示图标、名称、「即将开放」徽标、每次时长上限与关闭原因；玩法未开放时不提供开始入口，点击整行打开详情弹层而不是假装开局。
    • 游戏详情 → 点击任一玩法打开底部弹层：名称、「每次最多 N 分钟」、「即将开放」徽标与原因（已登记的玩法为「关卡还在开发中，暂时只能查看目录。」，其余为「这个玩法还没有上线，开放后会出现在这里。」），「知道了」/ 遮罩 / Esc 关闭，焦点回到该行。
    • 游戏会话 → 服务端返回进行中的会话时显示「游戏进度」卡（?mock=active|paused|ready）：玩法名、状态徽标（准备中 / 进行中 / 已暂停）、已进行回合数、warn 提示「当前还没有可操作的题目。」与「暂停 / 恢复 / 刷新 / 结束」。
    • 暂停 / 恢复 → 「暂停」转圈「正在暂停…」→ 0.8s 后徽标变「已暂停」，按钮变「恢复」，Toast「已暂停，进度已保存」；「恢复」转圈「正在恢复…」→ 徽标回到「进行中」，按钮变「暂停」，Toast「已恢复，继续挑战」。
    • 刷新 → 「刷新」转圈「正在刷新…」→ 0.7s 后 Toast「游戏进度已刷新」，不回退回合数。
    • 结束 → 「结束」打开确认对话框「结束这局游戏？ / 结束后会返回本局结果，这一局不能继续。」，默认「继续游戏」为次按钮，「结束游戏」为 bad 危险按钮；确认后转圈「正在结算…」→ 0.9s 后关闭对话框、隐藏进度卡、显示最近一局结果并 Toast「本局已结束，结果已返回」。Esc / 遮罩 / 继续游戏均不结束。
    • 最近一局结果 → 对齐 lastGameResult：通过为「挑战通过」+「符合奖励条件」（?mock=passed），未通过为「再练习一次」+「暂不符合奖励条件」（?mock=result）；显示正确率、完成度与服务端得分，不显示会话 ID、规则版本或内部状态枚举。
    • 目录为空 → ?mock=empty 目录卡内显示「暂无可用游戏 / 新玩法准备好后会出现在这里。」，数量显示 0 项；工具条「空」是整页空态，两者不重复叠加。
    • 部分可用 → ?mock=partial 状态条说明为「部分功能暂不可用，已显示可读取的内容。」，目录与结果继续可用。
    • 登录门禁 → 对齐真实页 onShow：先 session.restore()，未登录直接跳转登录页，不渲染游戏目录；原型以无权限态承载该分支。
    • 文案边界 → 不显示 P0 / P1 / 发布阶段、服务端错误码、会话 ID 或原始状态枚举；未开放玩法明确写成「即将开放」，不提供可点击的伪开始按钮。
