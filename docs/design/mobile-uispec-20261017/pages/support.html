交互说明（support）

  • 主题与直达参数 → 工具条「浅色 / 深色」切换整页 token 并写入 localStorage['uispec-theme']；?theme=light|dark 固定主题；?state=normal|loading|empty|error|forbidden 直达页面状态；?mock=no-tickets|load-error|refresh-error|board 演示无工单、首次读取失败、刷新失败后的结果、显示支持编号。截图（每项 ?theme=light|dark 各一张）：support-{light,dark}.png；support-{loading,empty,error,forbidden}-{light,dark}.png；support-{no-tickets,load-error,refresh-error,board}-{light,dark}.png。
  • 页头与导航 → 导航栏「客服与帮助」（pages.json 标题）+ 返回 profile.html（真实入口「我的 › 帮助中心」）；MobilePageHeader 的 kicker「我们来帮你」（ZH_KICKERS）、标题「有疑问，我们一起解决。」；support.vue 用 .mobile-page-description{display:none} 隐藏说明行，本稿不渲染说明「选择问题类型，查看与跟进你的帮助请求。」；不显示底部 TabBar。
  • 客服与帮助卡 → 只有 eyebrow：help 图标 +「客服与帮助」，没有标题「提交问题」；正文三行依次为「暂不能提交新工单，可查看已有工单。」（support.vue 原文）、ticketNotice(closure)、supportNotice(closure)（有编号时才显示）。默认 mock 的 board 为 null，第二行逐字显示 ticketNotice 的兜底文案「受控正文尚未批准。这里不能提交一份客服能够理解并闭环处理的工单。只有摘要的记录会标成信息不足。」；不提供「新建工单」按钮与「提交入口暂未开放。」。
  • 支持编号 → ?mock=board 时第二行显示 mock 的 ticketCopy「工单提交暂未开放。你可以在这里查看已有工单的编号与处理状态。」，第三行显示「支持编号 YS-2026-1042」（supportNotice(closure)，纯文本无图标）；默认 mock 无编号，该行隐藏。
  • 我的工单卡 → 只有 eyebrow：ticket 图标 +「我的工单」，没有「工单记录」、标题「我的工单」、说明「按类型筛选，点开查看详情。」与数量徽标；没有类型筛选 chip，也不读取 ?filter=。卡片底部是唯一的整宽 opt 按钮：文字在前、refresh 图标在后；出错时文字为「重试」，其余为「刷新」；忙碌时只转圈并禁用，文字不变。
  • 工单行 → 两行纯文本：「工单 {ticketId}」+「{categoryNames} · {stateNames}」，分类与状态中文名对齐 support.vue；未知分类回落「历史分类」、未知状态回落「历史状态」。没有状态徽标、预计处理时间、chevron、整行点击或「工单详情」弹层（vue 没有详情入口）。
  • 读取失败 → 对齐 vue load() 的 catch：清空列表，卡内显示 danger 色单行「工单暂不可用，请重试。」（role="alert"），底部按钮文字改为「重试」，点击后重新读取；成功时不弹 Toast。卡内不再有第二个「重试」。?mock=load-error 打开即为该结果，点「重试」恢复列表；?mock=refresh-error 打开即处于首次刷新失败后的结果（列表清空、按钮为「重试」），点「重试」成功恢复。
  • 空态 → 正常页面，卡内一行虚线框「暂无可见工单。」（support.vue 原文），底部保留「刷新」；不显示整页空态或「提交问题后，可以在这里查看处理进度。」。刷新成功后若仍无工单保持该行。
  • 页面状态 → 加载：正常页面 + 卡内「正在读取工单…」（role="status"），按钮禁用且文字保持「刷新」并转圈；错误：正常页面（第一张卡照常），只在「我的工单」卡内显示错误行与「重试」，没有整页错误块；空：正常页面 + 卡内虚线空态与「刷新」；无权限：仅「登录后查看你的帮助请求。」+「去登录」→ login.html?returnTo=%2Fpages%2Fsupport%2Fsupport（真实页 ensureMobilePageAccess 未登录直接跳转，本态为设计新增）。document.title 同步：正常「客服与帮助」、加载「正在读取工单…」、空「暂无可见工单」、错误「工单暂不可用，请重试。」、无权限「登录后查看你的帮助请求。」。
  • 状态恢复 → 切换状态会取消未完成的读取计时并恢复按钮；错误与空态「重试 / 刷新」转圈后回到可读结果，不弹成功 Toast；切回正常态按 ?mock 重新预置列表与支持编号。
  • 登录门禁 → 对齐真实页 onShow：先 ensureMobilePageAccess，未登录直接跳转登录页，不渲染本页；原型以无权限态承载该分支。
  • 文案边界 → 不显示原始分类 / 状态枚举、内部错误码、工单正文或受控流程说明；工单编号与支持编号为用户可读的 mock；状态只用文字表达，不使用颜色徽标。
