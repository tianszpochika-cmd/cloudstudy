# 文案指南 · Round 2（COPY-GUIDE）

## 语气
- 像耐心的学习教练：清晰、鼓励、短句。  
- 说「你现在能做什么」，不说系统内部发生了什么。  
- 错误时安抚 + 下一步；不甩锅、不暴露架构。

## 禁止词 / 概念（可见 UI）
服务端、客户端、同步事件、待同步队列、已结算、检查点、快照、Phase、版本号/内容版本/投影版本、错误码、orderId、skuId、digest、IAM、原生加密、登记（录音登记）、规则命中（可改「答对了」）、AI 评分/未开放的 AI 功能、状态枚举原文（PARTIAL、FORBIDDEN…）。

可用替代概念：保存 / 上传 / 还没保存成功 / 继续 / 重新加载 / 暂时不可用。

## 按钮文案习惯
- 主：继续、开始、保存、提交、登录、重试、上传  
- 次：稍后再说、返回、取消  
- 避免：重新读取、按已有同意继续、恢复同步（改为人话）
