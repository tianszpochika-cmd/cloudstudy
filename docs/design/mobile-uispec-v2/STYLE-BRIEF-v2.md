# 移动端 UI 稿 · STYLE-BRIEF v2（2026-10-19）

Round 2。功能范围与页面清单不变（见 PAGES.md），**布局与文案可改**。目标：消费级学习 App 质感（Duolingo / Speak / Headspace 级清晰），不是后台控制台。

产出目录：`docs/design/mobile-uispec-v2/`。相对 Vue 改过的文案必须在页面交互说明标「文案相对 Vue 已改，需同步 i18n」。

## 1. 设计原则

1. **一屏一主任务、一个主动作**（Primary）。次要出口用文字链或「⋯」；禁止双主按钮并排/堆叠。
2. **先内容，后系统**。正常态不展示同步条、就绪条、画质条；这些进设置、溢出菜单或出错时再出现。
3. **人话**。用户只关心「能不能学 / 下一步做什么」；禁止服务端、队列、检查点、结算、版本号、Phase、ID 等内部词（详见 COPY-GUIDE）。
4. **少装饰、强层级**。去掉重复 eyebrow；标题即场景；副文案 ≤ 1 句。
5. **反馈克制**。成功用短 Toast 或行内一句；错误优先字段下/卡片内；全屏错误仅在整页不可用时。
6. **深色同等用心**：对比 ≥4.5:1，无白底块。

## 3. 外框与导航

- 原型框 390×844；状态栏 44；自定义顶栏：返回 44×44 + 标题 17/600 居中。  
- 一级 Tab（home / learn / b2-practice / world / profile）：底栏 5 项，选中 brand，高 56+安全区。  
- **顶栏右侧**：默认不放齿轮。需要设置时进 profile/settings；画质/动效仅出现在「设置 › 画质与设备」或学习页溢出「⋯」。  
- 框外工具条（浅/深色、状态切换）仅设计调试用，不计入产品 UI。

## 4. 组件

### 按钮
- **Primary**：高 48，brand 底 inverse 字，每屏最多 1 个实心主按钮。  
- **Secondary**：surface 底；用于并列次要（少用）。  
- **Text**：brand 字，用于「注册」「稍后再说」「重新加载」。  
- 禁用：surface + mut，不可只靠透明度。  
- 忙碌：保留原文字 + 16px 转圈（或极短「正在…」），防双击。

### 卡片 / 列表
- 一页 1–2 张内容卡为宜；列表优先「单卡 + 行」而非每行一卡。  
- 行高命中 ≥44；右滑/次要操作不要做成第二颗实心钮。

### Sheet / Dialog / Toast
- Sheet：拖拽条，遮罩可关。  
- Dialog：标题 + ≤2 句说明 + 最多两钮（危险用 bad）。  
- Toast：顶中，≤2s；成功/普通/错误三色；**不承载解释性长句**。

### 空态
- 插画位（可选 64–96 简图）+ 一句人话 + **一个**主动作。  
- 禁止「服务端未返回…」类句子。

### 行内错误 / 离线
- 表单：字段下 13px bad。  
- 列表页：卡顶或内容区一条 soft/warn 提示 +「重试」文字钮或小按钮。  
- 离线：保留只读内容；提示「网络断开了，连上后会自动继续。」；待上传动作用「有 N 项未上传 · 上传」人话，不说「待同步队列」。

## 5. 入口 / 启动模式

- **Login / Register / Reset**：单列表单 + 一个主按钮；切换账号类用文字链。  
- **Onboarding**：步进器可保留，但每步只有一个主 CTA；「账号设置 / 退出」收到顶栏「⋯」或页脚单文字「退出」。同意步去掉「IAM / 摘要 / 版本」展示，改成可读条款列表 +「同意并继续」。  
- **断点恢复（assessment held 等）**：标题「继续上次测评」+ 人话「还差几题就完成了」+ 主按钮「继续」；次要「稍后再说」文字链。  
- **Forbidden**：一个说明 + 一个主出口（如「返回登录」）；其余进文字链。

## 6. 状态规范

| 状态 | v2 表现 |
|---|---|
| 加载 | 骨架或内容区转圈，无「正在加载学习内容」大横幅 |
| 空 | 人话 + 一个动作 |
| 错误 | 人话原因 + 重试 |
| 无权限 | 原因 + 去登录 / 查看权益 |
| 离线 | 轻提示；能读缓存就读 |
| 成功 | Toast 或行内一句 |

# v2B 视觉升级（2026-10-19，覆盖上文冲突处）

质量参照：Duolingo / Speak / Headspace / Apple Fitness。目标是**一眼看出**和 Round 1 不同。

## 字体层级
- Display 40/1.1/800，字距 -0.02em（启动页、首页问候）
- Title 28/1.2/750，字距 -0.01em
- Headline 20/1.3/700；Body 16/1.5；Caption 13/1.4
- 数字（连续天数、百分比）用 tabular 数字，48–56/800

## 品牌色运用
- 品牌紫保留（#5935b8 / 深色 #bcabff），**不要所有表面都是淡紫**。
- Hero 面：渐变 `linear-gradient(135deg,#6a3fe0 0%,#8b5cf6 55%,#f472b6 120%)`，上面用白字；深色模式降低亮度（#3b2a7a→#5b3fb0）。
- 辅助色块：薄荷 #d9f5e8 / 杏 #ffe9d6 / 天蓝 #dcecff / 柠檬 #fff4c2，用于图标瓦片和插画底，深色模式用 20% 透明版。
- 页面底色：浅 #f7f6fb，卡片纯白；深 #0f0e17，卡片 #1b1a26。

## 形状与层次
- 圆角：卡片 24，Hero 28，按钮 pill 999（高 56），图标瓦片 14，Sheet 顶角 28。
- 阴影：柔和大扩散 `0 8px 24px rgba(40,20,90,.08)`；不用描边分隔卡片。
- 留白：页边 24，区块间距 28–32。

## 插画 / 吉祥物位
- 用简洁 SVG 几何形（圆、星、斑点、书本轮廓）组合成占位插画，标注「插画位」于交互说明；吉祥物位 = 圆角星形角色占位（品牌紫+眼睛两点）。

## 组件
- 列表行：左侧 44×44 彩色图标瓦片 + 标题/副标题 + 右侧状态（对勾/时长/箭头）；行间无线，用 12 间距。
- 分段控件：pill 轨道，选中项白底浮起（深色为卡片色）。
- 进度环：首页目标环 120px，描边 12，渐变描边。
- Bottom sheet：拖拽条、28 顶角、大标题、主按钮置底。
- 主按钮：pill 56 高，品牌实色或白色（在渐变上）；一屏一个。

## 动效备注（写在交互说明）
- 页面进入 320ms ease-out 上移 12px 渐显；轮播 swipe + 指示点伸缩；进度环 600ms 绘制；按下 scale .97。尊重 reduced-motion。

## 启动流程
splash（渐变全屏 + 品牌星 + 名字）→ 2–3 屏价值轮播（大插画位 + Display 标题 + 一句说明 + 指示点）→ 底部固定：主按钮「开始学习」+ 文字链「我已有账号」。之后才进入成人确认/同意/目标（每步一主按钮，退出放「⋯」）。
