## onboarding
- 启动流程：闪屏（渐变全屏 + 小星 + 「语学星 / 每天一点点，学会一门语言」）→ 3 屏价值轮播 → 成人确认 → 条款同意 → 学习目标。每步一个主按钮；退出收进顶栏「⋯」。【文案相对 Vue 已改，需同步 i18n】
- 状态：`?state=splash|carousel-1|carousel-2|carousel-3|adult|adult-invalid|adult-underage|consent|goal|goal-selected|goal-saving|goal-error|sheet|loading|error|offline` 直达，工具条同名切换（新增子状态已在 shared.js 登记）。【文案相对 Vue 已改，需同步 i18n】
- 成人确认：标题「先确认你的年龄」+「仅限 18 岁以上用户使用。」，出生年份 +「我确认自己已满 18 周岁」，主按钮「继续」；年份为空或不足四位提示「请填写四位出生年份」，未满 18 提示「仅限 18 岁以上用户使用」，未勾选提示「请先确认你已满 18 周岁」，均为字段下 13px 红字。【文案相对 Vue 已改，需同步 i18n】
- 条款同意：标题「开始学习前，先看这几条」+ 三行可读条款（用户协议 / 隐私政策 / 成人学习资格，标「必要」并带对勾）+「这些条款之后可以在设置里随时查看。」+ 主按钮「同意并继续」；只展示可读条款，不展示内部记录、摘要或文档版本。【文案相对 Vue 已改，需同步 i18n】
- 学习目标：标题「你想先达成什么？」+ 四行目标 + 每日时长分段（默认 15 分钟）；未选目标时「保存，开始学习」真实禁用；保存中转圈，失败行内「学习目标没保存成功，再试一次就好。」；成功后进入 home。Vue 保存后的「设置已完成 / 开始定级」步不在此页重画，由 assessment 页承载。【文案相对 Vue 已改，需同步 i18n】
- 加载 / 错误 / 离线：加载为骨架屏（`aria-busy`）；错误「设置没读出来」+「重新加载」；离线「网络断开了」+「重试」；重试 1.1s 后回成人确认并轻 Toast。【文案相对 Vue 已改，需同步 i18n】
- 设计新增：闪屏、三屏价值轮播与卡片堆叠、条款同意的可读条款行、加载骨架、错误 / 离线整页态，以及上述演示直达状态；无新业务、奖励或规则。
- 动效与触感：轮播 4.5s 自动前进 + 跟手拖拽（1.0x / 0.4x 视差）、指示点 320ms 伸缩、按钮 / 目标行 scale(.96) 弹簧回弹、sheet 380ms 弹簧上滑；全部尊重 prefers-reduced-motion。
