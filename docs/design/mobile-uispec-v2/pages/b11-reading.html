交互说明（b11-reading · v2 试点）

  • 主题 → 工具条「浅色 / 深色」切换整页 token 并记住选择。
  • 状态 → 工具条「正常 / 加载 / 空 / 错误 / 离线」：加载为骨架屏（aria-busy）；空为「暂时没有可读的文章 / 换个时间再来，或先做一组词汇复习。」+ 唯一主按钮「重新加载」；错误为「文章没加载出来 / 阅读位置还留着，重新加载就能接着读。」+「重新加载」；离线保留正文只读，并在顶部显示轻提示。【文案相对 Vue 已改，需同步 i18n】
  • 去除常驻状态条 → Round 1 的「阅读位置未确认」「待同步 N」「恢复同步」「播放授权已过期」横幅与顶部「画质 · 舒适 / 关闭动效」不再常驻；画质与动效收进导航栏「⋯ → 阅读设置」。
  • 页头 → 导航栏「分级阅读」+ 返回；页面标题同为「分级阅读」，仅一句说明，无紫色 kicker、无「授权文章 · 1 篇」计数。
  • 阅读 → 文章卡显示级别、词数、预计时长与标题；正文逐段显示英文与译文。进度条与「33% · 第 1 / 3 段」文字同步。
  • 上一段 / 下一段 → 降级为文字链，避免与主按钮并排；第一段 / 最后一段进入真实禁用态。
  • 保存进度 → 每屏唯一实心主按钮。点击后按钮转圈，1s 后下方出现一行绿色「进度已保存」，不弹横幅、不写「已由服务端确认」；切换段落时该行自动收起。
  • 离线 → 顶部浅色提示「网络断开了，已读内容仍可查看，连网后进度会自动保存。」+「重试」文字链；正文保持可读。?state=offline 直达；正常态 ?offline=1 也可预览同一提示。
  • 理解检查 → 题干 + 三个单选；未选择时「提交答案」为次按钮禁用态。提交后答对显示「回答正确」，答错显示「记下了，再看一遍这一段」，不再出现「服务端已记录本次练习」。
  • 提交失败（演示） → ?mock=submit-error：卡内提示「没提交成功，答案还留着，再试一次」，答案保留可重提。
  • 阅读设置 → 导航栏「⋯」打开底部弹层，四档画质「精致 / 舒适 / 轻量 / 省资源」，当前档带对勾与 aria-pressed；选择后关闭弹层，不弹 Toast。遮罩、完成、Esc 均可关闭。
  • 文案边界 → 无「服务端」「待同步」「已确认」「版本」「授权」等词；不显示文章 ID、内容版本或状态枚举。
