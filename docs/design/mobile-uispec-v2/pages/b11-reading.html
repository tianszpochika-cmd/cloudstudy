交互说明（b11-reading · v2B 试点）

  • 主题 → 工具条「浅色 / 深色」切换整页 token 并记住选择。
  • 状态 → 工具条「正常 / 加载 / 空 / 错误 / 离线」，也可用 ?state= 直达。加载为骨架屏（aria-busy）；空/错/离线均为「插画位 + 一句人话 + 一个按钮」。【文案相对 Vue 已改，需同步 i18n】
  • 文章卡 → 28px 大圆角、24px 内边距；顶部为级别 chip（B1，淡紫胶囊）与词数/时长；标题 25px Display 字重。正文 17px / 行高 1.7，提升长文舒适度；不再有整块浅灰底。
  • 译文折叠 → 默认收起，点击胶囊「显示译文 / 收起译文」展开当前段译文（aria-expanded + 箭头旋转 220ms）；切换段落时保持当前展开状态，不重复朗读。
  • 阅读进度 → 进度条与「33% · 第 1 / 3 段」同步；段落切换时进度 600ms 过渡。
  • 上一段 / 下一段 → 底部文字链，中间显示「1 / 3」；第一段/最后一段真实禁用。
  • 保存进度 → 固定在手机框底部的唯一实心主按钮；点击后转圈，900ms 后按钮上方出现一行绿色「进度已保存」，2.4s 自动收起；不弹横幅、不说「已由服务端确认」。切换段落时该行收起。
  • 离线 → 顶部轻提示 + 正文保持只读；此时主按钮仍可用，保存后提示「进度已保存在本机，连网后自动上传」。
  • 理解检查 → 题干 + 三个单选（软底圆角行）；未选择时「提交答案」为次按钮禁用态。答对显示「回答正确」，答错显示「记下了，再看一遍这一段」。【文案相对 Vue 已改，需同步 i18n】
  • 提交失败（演示） → ?mock=submit-error：卡内提示「没提交成功，答案还留着，再试一次」，答案保留可重提。
  • 阅读设置 → 导航栏「⋯」打开 28px 顶角底部弹层，四档画质「精致 / 舒适 / 轻量 / 省资源」；当前档带对勾与 aria-pressed。遮罩、完成、Esc 均可关闭。
  • 动效 → 页面进入 320ms 上移渐显；译文展开/收起 220ms；进度条 600ms；按钮按下 scale .97；尊重 prefers-reduced-motion。
  • 文案边界 → 无「服务端」「待同步」「已确认」「版本」「授权」等词；不显示文章 ID、内容版本或状态枚举。
