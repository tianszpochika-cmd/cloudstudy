交互说明（login · v2 试点）

  • 主题 → 工具条「浅色 / 深色」切换整页 token 并记住选择；页面无其他主题入口。
  • 状态 → 工具条「正常 / 加载 / 错误 / 离线」：正常为单列表单；加载为恢复登录的骨架屏（aria-busy）；错误为「暂时登录不了 / 可能是网络波动，请稍后重试。」+ 一个「重试」；离线为「网络断开了 / 连上网络后就能登录。」+ 一个「重试」。错误与离线均用文字说明，不只靠颜色。
  • 页面结构 → 品牌行 + 标题「欢迎回来」+ 一句说明 + 账号 / 密码 + 唯一实心主按钮「登录」；注册与忘记密码？都是文字链，不与主按钮争夺注意力。【文案相对 Vue 已改，需同步 i18n】
  • 加载态 → 品牌行与表单位置显示骨架屏；不出现「等待登录」类静态占位，也不显示工程状态说明。
  • 错误 / 离线重试 → 点击「重试」→ 按钮转圈并变「正在重试…／正在重连…」→ 1.1s 后回到正常态并弹成功 Toast；失败重试不改变页面。
  • 字段校验 → 点击「登录」或按回车：账号为空标红「请输入账号」、密码为空标红「请输入密码」，焦点落到第一个错误字段；输入后错误自动消失。
  • 密码可见 → 点击眼睛切换明文 / 密文，aria-label 与图标同步；提交中不可切换。
  • 提交中 → 按钮保持「登录」原文 + 16px 转圈，整宽不变；账号、密码、眼睛、文字链全部不可操作，防止重复提交。
  • 登录失败（演示） → error@yuxuexing.com → 「账号或密码不正确，请再试一次。」【文案相对 Vue 已改，需同步 i18n】；locked@yuxuexing.com → 「尝试次数有点多，请稍后再试。」；rate@yuxuexing.com → 「操作有点频繁，请稍后再试。」。失败时保留已填内容，密码框重新聚焦，不跳转。
  • 登录成功（演示） → 其他任意账号 + 任意密码 → 1.2s 后顶部 Toast「已登录」→ 1s 后进入 home.html；不展示账号、令牌或跳转参数。
  • 忘记密码？ / 注册 → 分别跳转 reset-password.html 与 register.html；提交中置灰不可点。
  • 大字与深色 → 输入框 16px、行高 48px；深色下卡片底与输入框底均使用 token，无白底块。
