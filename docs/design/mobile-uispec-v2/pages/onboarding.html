  • 指示点 → 选中项拉长为 28px 胶囊，320ms 弹簧伸缩；计数「1 / 3」在右上角 chip 中同步。
  • 图标 → 全站统一 Phosphor Icons v2.1.1（MIT）：TabBar 选中 fill + 渐变；功能瓦片白色 duotone；本页目标行瓦片用 duotone 图标。
  • 底部固定 → 轮播与后续步骤共用固定操作条，每屏只有一个实心主按钮；轮播底部为「开始学习」+ 文字链「我已有账号」→ login.html。文字链不与主按钮并排。
  • 成人确认 → 标题「先确认你的年龄」+ 出生年份 + 「我确认自己已满 18 周岁」；主按钮「继续」。年份为空 / 非四位 / 未满 18 时在字段下用 13px 红字说明；勾选未选时在勾选行下提示。不展示年龄校验的实现细节。工具条「年龄校验 / 未满 18」两个演示态对应「请填写四位出生年份 / 请先确认你已满 18 周岁」与「仅限 18 岁以上用户使用」；未满 18 只停在字段提示，不进入下一步。【文案相对 Vue 已改，需同步 i18n】
