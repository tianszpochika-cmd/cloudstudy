交互说明（onboarding · v2B 试点）

  • 主题 → 工具条「浅色 / 深色」切换整页 token 并记住选择；页面无其他主题入口。
  • 状态 → 工具条「闪屏 / 轮播 1–3 / 成人确认 / 学习目标」直接切换流程步骤；也可用 ?state=carousel-1|carousel-2|carousel-3|adult|goal 直达。【文案相对 Vue 已改，需同步 i18n】
  • 闪屏 → 渐变全屏 + 品牌星标 + 「语学星」+ 一句品牌说明；轻触、回车或空格进入轮播第 1 屏。仅展示品牌，不出现加载百分比或版本号。
  • 轮播 → 3 屏价值说明（每天 10 分钟，稳稳进步 / 听说读写，一个 App 练全 / 错题会自己回来找你），每屏 = 大插画位（紫 / 薄荷 / 杏三色几何组合，待替换最终插画）+ Display 40/800 标题 + 一句说明；可左右滑、点指示点，指示点选中时拉长。【文案相对 Vue 已改，需同步 i18n】
  • 底部固定 → 轮播与后续步骤共用固定操作条，每屏只有一个实心主按钮；轮播底部为「开始学习」+ 文字链「我已有账号」→ login.html。文字链不与主按钮并排。
  • 成人确认 → 标题「先确认一下你的年龄」+ 出生年份 + 「我确认自己已满 18 周岁」；主按钮「继续」。年份为空 / 非四位 / 未满 18 时在字段下用 13px 红字说明；勾选未选时在勾选行下提示。不展示年龄校验的实现细节。
  • 学习目标 → 四个带彩色图标瓦片的目标行 + 每日时长分段控件（默认 15 分钟）；未选目标时主按钮「保存，开始学习」为真实禁用态；选择后可用，保存成功进入 home.html。
  • 退出 → 页内不再并排「账号设置 / 退出登录」；成人确认与学习目标步骤的右上角「⋯」打开底部弹层，提供「退出登录」与「继续设置」，遮罩 / Esc 可关闭。
  • 动效 → 闪屏圆点 1.6s 呼吸；轮播切换 420ms ease-out 横移，指示点宽度 320ms 伸缩；按下按钮 scale .97；主按钮高 56、全圆角。尊重 prefers-reduced-motion。
  • 无障碍 → 轮播滑动区支持左右方向键；指示点有 role="tab" 与「第 N 屏」标签；步骤标题使用 tabindex="-1" 便于切换后聚焦。
