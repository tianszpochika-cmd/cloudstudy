交互说明（home · v2B 试点）

  • 主题 → 工具条「浅色 / 深色」切换整页 token 并记住选择。
  • 状态 → 工具条「正常 / 加载 / 空 / 错误 / 离线」，也可用 ?state=empty|error|offline 直达。加载为整块骨架屏（aria-busy）；空/错/离线均为「插画位 + 一句人话 + 一个按钮」。【文案相对 Vue 已改，需同步 i18n】
  • Hero 卡 → 品牌渐变底，左侧问候 + 54px 连续天数（tabular 数字），右侧 120px 渐变进度环（描边 12）；环下为白色 pill 主按钮「继续学习」，是首屏唯一实心按钮。副信息「今日 15 分钟 · 已完成 2 / 5」作为一行小字，不做第二颗按钮。【文案相对 Vue 已改，需同步 i18n】
  • 进度环 → 600ms 绘制动画（stroke-dasharray 过渡），中心显示 40% 与「今日目标」；环形进度与文字同步，不只靠颜色。
  • 今日任务 → 单张白卡 + 带 44×44 彩色图标瓦片的行（薄荷 / 紫 / 杏 / 天蓝 / 柠檬），行间不再画分割线，改用 8px 间距；已完成行瓦片为薄荷对勾、标题降为次要色、右侧对勾常显。整行可点，行尾只有一个箭头，无第二颗实心钮。
  • TabBar → 选中项图标带 pill 背景、文字加粗；其他项为普通图标 + 文字。高度 68 + 安全区，顶部用柔和阴影替代描边。
  • 离线轻提示 → 正常态下若设备离线，仅在 Hero 上方出现一条 warn 轻提示，不遮蔽内容；恢复后自动消失。离线整页态保留「重试」。
  • 重试 → 错误/离线点「重试」→ 转圈并变「正在重试…／正在重连…」→ 1.1s 后回到正常态，不弹成功提示。
  • 动效 → 页面进入 320ms ease-out 上移 12px 渐显；Hero 进度环 600ms 绘制；行按下 scale .99；按钮按下 scale .97；TabBar 选中 pill 140ms 渐变。尊重 prefers-reduced-motion。
  • 文案边界 → 无「服务端」「已结算」「版本」等工程词；无常驻同步条或画质条；头像入口去「我的」，设置留在「我的」页。
