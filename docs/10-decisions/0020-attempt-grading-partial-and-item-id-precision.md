# ADR-0020：判分提交的部分提交与题 ID 精度（P1-LIVE-010）

- 状态：已接受（人类负责人全权委托执行，2026-09-16）
- 日期：2026-09-16
- 相关任务：`P1R-M4-005/006`（定级引擎与报告）、`P1R-M5-002`（判分入口）
- 缺陷：P1-LIVE-010（本地全栈活链路 W5 实测发现，两项）
- 合约事实源：本次无契约变更（见"有意不做的事"）

## 背景

| # | 现象（活实测） | 根因 |
|---|---|---|
| 1 | 交 1/2 题直接 500 NPE（`selected.isBlank()` on null） | `allMistakes` 对未答题 `answerMap.get()` 取空；部分提交本应计错 |
| 2 | JS 客户端交卷 404（Python 同形状 200） | FNV-64 题 ID（~2e18）超 JS 安全整数，转发即失真；服务端按失真 ID 查规则 → 404 |

## 决策

1. `isCorrect` 空指针改计错：未答题按错题计入 `mistakes`，scoreBucket 照常 PARTIAL/ZERO（活验证：故意交错得 ZERO）。
2. 提交侧同时接受字符串 `itemCode`（仓内 `rules()` 过滤已有双匹配惯例）；客户端传字符串 ID（`positiveLong` 精确解析）或 `itemCode` 均可。
3. 不动契约富模型：`B10AttemptSubmission`（digests/sequences）是 M5-002 的完整目标，服务端当前实现为简化形；两者差异记为已知缺口，不在本轮用"纸面契约扩张"掩盖。

## 后果

- assessment 57/0/0；W5 14/14（游戏/判分/词汇/媒体/avatar）。
- 已知缺口：定级种子仅 2 题（manifest 十题待补种）；富模型判分待 M5-002 后续轮次。
