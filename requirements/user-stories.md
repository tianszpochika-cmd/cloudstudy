# 用户故事

> 用户故事按最终产品阶段标注，避免把 Phase 2/3 能力误当作 Phase 1 必须交付。

## Phase 1 学习者（18+、无生成式 AI）

| 编号 | 用户故事 | 优先级 |
| --- | --- | --- |
| US-P1-001 | 作为新用户，我想选择学习目标并完成规则化测评，以便获得适合自己的起点。 | P0 |
| US-P1-002 | 作为忙碌的成人，我想在 5-20 分钟内完成今日任务，以便持续学习。 | P0 |
| US-P1-003 | 作为学习者，我想按遗忘风险复习词汇、短语和句型，以便长期记住。 | P0 |
| US-P1-004 | 作为学习者，我想知道错误属于词汇、语法、听力或表达哪一类，以便针对性复习。 | P0 |
| US-P1-005 | 作为学习者，我想进行跟读、听写、阅读和写作自练，以便建立完整能力。 | P0 |
| US-P1-006 | 作为学习者，我想参加计时训练并看到阶段报告，以便知道下一步练什么。 | P0 |
| US-P1-007 | 作为学习者，我想调整学习时长、提醒、首页排序和隐私设置，以便控制自己的学习方式。 | P0 |
| US-P1-008 | 作为学习者，我想在弱网下完成已下载的基础练习，以便不中断学习。 | P1 |
| US-P1-009 | 作为学习者，我想通过任务、成就和轻游戏保持动力，但不希望奖励变成付费抽奖。 | P1 |
