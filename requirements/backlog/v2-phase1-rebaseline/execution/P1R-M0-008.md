# P1R-M0-008 — 任务状态、Evidence 与计划校验

## 交付

- 计划校验器支持 `PLANNED/READY/IN_PROGRESS/REVIEW/ACCEPTED/BLOCKED/REWORK`，继续校验 108 个任务、里程碑计数、运行层 ID 与 GAP 覆盖。
- `scripts/audit/p1r-evidence-gate.mjs` 校验完整范围依赖、合法状态轨迹、依赖是否已接受、canonical manifest 是否存在且已提交、提交是否可追溯、SHA-256 是否匹配、终态评审是否独立，以及 BLOCKED/REWORK 是否包含 blocker 与 next step。
- `tests/p1r/p1r-evidence-gate.test.mjs` 覆盖合法接受、范围展开、非法状态跳转、跨平台 Git blob 摘要、摘要篡改、自审/空白绕过、路径逃逸、未提交或漏 Evidence、漏 blocker 和未满足依赖等失败关闭场景。
- CI 已接入计划、Evidence、夹具与 M0 测试检查。

## 验证

`pnpm plan:p1r:check` 保持 108 项与全部范围/GAP 覆盖；`pnpm test:p1r` 13/13；`pnpm p1r:evidence:check` 只在 ledger、状态轨迹与 manifest 已提交且一致时通过，在构造的非法场景中失败。

集成结论：`ACCEPTED`。任何后续状态变更都必须同时提交 ledger、当前源提交 Evidence 和可复核结果。
