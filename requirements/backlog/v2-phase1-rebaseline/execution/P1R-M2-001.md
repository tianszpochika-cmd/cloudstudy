## 本轮目标

- 让 Security、JWT public-path、CORS/CSRF、限流和审计共用一个与 canonical Gateway contract 对齐的 route/auth-class policy。
- 对 credentialed browser unsafe request 执行 Origin 优先、Origin 缺失才回退 Referer 的来源校验；official-site 不获得业务会话来源权限。
- 按 auth class 执行限流，非 local 配置默认走 Redis；补齐 429 `Retry-After` 与 Redis 不可用时的 503 fail-closed 语义。
- 使用 Java 25 执行进程内安全边界测试，覆盖 public/protected/internal、authority header 清洗、requestId/traceId 及 401/403/429/503。
- 使用当前提交的真实 Gateway 进程验证 IAM/JWKS、Redis、多进程额度、受保护 upstream、全量 route/controller/owner projection 与真实浏览器 CORS/CSRF；生成严格限长、脱敏的 audit envelope，并验证应用层 `/internal/v1` 拒绝。
