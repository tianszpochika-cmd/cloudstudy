## 目标与退出条件

冻结 Phase 1 成人公开注册、账号密码登录、刷新、退出、设备会话撤销、密码重置及 RS256/JWKS 的 D2 契约。退出前必须同时满足：

1. Web/H5 只通过 `HttpOnly + Secure + SameSite` Cookie 接收 Refresh Token，响应体永不返回该凭据；
2. iOS/Android 原生端通过显式原生请求/响应契约接收 Refresh Token，并注明只能进入 Keychain/Keystore，不允许普通 storage fallback；
3. 登录、注册和刷新不能继续共用混合响应；Web Cookie 刷新与原生 body 刷新输入可由生成客户端静态区分；
4. Access Token 保持短时 RS256，JWKS 只发布 RSA 公钥材料；算法、`kid`、轮换和缓存语义不可漂移到 ES256/OIDC/OAuth；
5. Refresh Token rotation、reuse/replay detection、family/session revoke、logout 与 password reset 的成功/失败响应和审计关联语义固定；
6. merge、validate、generate、Git baseline compatibility、类型检查、P1R/B8 专项测试和独立终验通过。
