## 前置工作 A：legacy B 套件清理（33 → 0 失败）

**为何是「建立真实 CI」的前置**：`P1R-M2-009` 的交付物是把真实 CI 建起来 —— contract / build / unit / integration / security / SBOM / plan-evidence 各道门禁。而本仓库的 `ci.yml` 当时**只运行 `pnpm test:p1r`**，全部 `tests/`（1924 项）**不在 CI 内**，其中 **33 项长期失败**。

在这 33 项失败存在的前提下建 CI 只有两种结果：把它接进流水线即**红**，或继续只跑子集 —— 后者正是"CI 不真实"的定义。因此**先把全量套件恢复为可接入的绿色基线**，是本任务的前置。
