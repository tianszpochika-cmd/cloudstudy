### Phase 1 遇到并解决的两个真实缺陷

1. **`pnpm.overrides` 静默失效**：根 `package.json` 的 5 条安全 override 自工作区使用 pnpm 10 起被忽略（`The "pnpm" field in package.json is no longer read by pnpm`）。已迁至 `pnpm-workspace.yaml`。**注意**：仅新增 workspace override 不足以生效——lock 内残留的旧 `overrides` 段会阻止重新解析，必须同时从 `package.json` 删除该字段。
2. **Rolldown + `preserveSymlinks: true` 的解析失败**：`@dcloudio/vite-plugin-uni/dist/config/resolve.js:128` 强制 `preserveSymlinks: true`，于是 vite 8 的 Rolldown 按符号链接路径解析，在 pnpm 隔离布局下找不到 pinia 的私有依赖（`vue-demi`、`@vue/devtools-api`）。用定向 `publicHoistPattern` 解决，其余包保持隔离。

过程中的一次 `pnpm install --force` 因前端 dev server 占用 `esbuild.exe` 而 EPERM 中断，留下不完整的 `node_modules`（表现为 rollup 原生包目录为空）；已用「删除 `node_modules` + 重装」彻底修复。
