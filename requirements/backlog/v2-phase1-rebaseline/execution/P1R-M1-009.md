## 已确认的 owner 边界

- `content-service`：内容版本与媒体语义关联、官方字幕文本、版权/许可和发布资格。
- `media-service`：媒体/录音资产元数据、对象引用、完整性、处理任务、rendition、字幕 artifact metadata、manifest、短时授权 URL 和 delete/purge receipt。
- `assessment-service`：规则化口语/跟读 session、attempt、自评与结果摘要；不得读取或传播原始录音 bytes。
- `learning-service`：只消费 assessment 的可信结果；不拥有录音资产、媒体处理或口语评分事实，也不接收录音/Shadowing 的直接写入。

## D2 生命周期、失败与兼容决议

1. 管理媒体：短时 upload intent → 上传完成校验 → `QUEUED/PROCESSING` → `READY/CLEAN` 或 `FAILED/QUARANTINED`；rendition、字幕 artifact 与文本替代各有可查询状态。超时先按幂等键/任务 ID 查询；失败按 M1-007 的预算、退避、DLQ/replay 和人工恢复处理，不能发布不完整版本。
2. 学习播放：只对已发布、rights 有效、设备/阶段/同意满足的版本签发短时 grant；manifest 的内容时间轴固定毫秒，播放器仅在 `[0.5, 2.0]` 内连续变速并保持音高。字幕/音频/下载不可用时给出文本或练习替代，而不是空白成功。
3. 个人录音：`LOCAL_ENCRYPTED_DRAFT`、`UPLOAD_PENDING`、`REMOTE_READY`、`DELETE_PENDING`、`DELETED` 为不同事实；本地草稿不伪造远端成功。远端资源只归已验证本人，回放/签名、删除和导出都经过服务端 PEP 与 retention policy。
4. 口语完成：media 只返回录音资源安全引用；assessment 创建固定 0.5 秒 target-gap 的 shadowing session/attempt/self-rating 并决定是否形成可信规则结果；只有该结果可沿 INT-P1-006 进入 workflow/learning。录音保存、麦克风权限、播放进度等旧历史事件不作为本任务自动晋升的 canonical Kafka 事件。
5. 兼容：B1/B3/B11 的历史入口必须标识 legacy/deprecated 与迁移窗口；canonical 录音对象归 media，shadowing completion/attempt 归 assessment。任何客户端 `actor/requester/tenant/owner/rights` 字段都不能成为授权事实。
