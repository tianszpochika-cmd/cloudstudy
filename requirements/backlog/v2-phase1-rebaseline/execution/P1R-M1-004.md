# P1R-M1-004 — Gateway 边界与浏览器安全契约

状态：`IN_PROGRESS`

不可变来源基线：`dev@e5110f29d73724fd518fd6d4a6a7cbcdb08ece28`

依赖：`P1R-M1-001/002/003=ACCEPTED`

## 目标与退出条件

冻结 Phase 1 Gateway 路由、安全边界和浏览器凭据 D2 契约。退出前必须同时满足：

1. 每个 active `/api/v1` operation 能由有序、无歧义的 route rule 映射到唯一 service owner；`/internal/v1`、未知版本和未登记路径在外部边界失败关闭；
2. learner-web、admin-web、mobile H5、official-site 和原生 Bearer 的 Origin/Cookie 能力分离，credentialed CORS 禁止 wildcard，官网不能获得业务 Cookie/Token 权限；
3. Web Cookie 认证写请求具备明确的 CSRF、Origin/Referer、SameSite、Path、凭据 transport 和失败语义；原生无 Cookie 路径只能由可信 transport/device context 选择；
4. JWT 预检固定 RS256/JWKS、issuer/audience/time/token type/scope 校验，不能以 Bearer header 存在或客户端 authority 头建立身份；Gateway 预检不能替代服务 PEP；
5. 登录/刷新/密码重置、公开读、普通读写、高风险后台等 route class 有具名 rate-limit policy，429 必带 Retry-After，限流后端异常默认 fail closed；
6. requestId/traceId、401/403/429/5xx、边界审计字段/脱敏和 direct-connect blocking 可机器检查；合同测试、生成/校验/兼容、类型检查与独立终验通过。
