# P1R-M0-001 — 当前资产清单

## 交付

- 机器可读清单：`config/p1r-current-asset-inventory.json`。
- 盘点范围覆盖模块、页面注册、契约、服务、数据、测试、部署和历史 Evidence 候选。
- 每个条目包含 owner、路径、版本、风险和 `REUSE-VERIFY/REPAIR/REWRITE/NEW/HISTORICAL/PHASE-GATED` 标签。

## 结果边界

清单用于决定后续任务“复用、修正、重写或新增”，不把目录存在、旧代码存在或旧运行报告等同于当前完成。运行、契约、数据 owner、浏览器和发布证据仍由后续 P1R 任务重新生成。

## 验证

- 解析 JSON 并检查必填字段与标签集合。
