## 1. 产品全景与系统架构

### 1.1 产品矩阵
- **终端矩阵**：微信小程序 (Miniapp)、App (iOS / Android / iPad，uni-app 一套代码编译见 ADR-0004)、Learner Web (PC 沉浸学习)、Official Site (官网与 SEO)、Admin Web (教研与运营中台)。
- **核心理念**：将大语言模型 (LLM)、实时语音交互 (Realtime ASR/TTS/RTC)、数字人渲染技术与传统阶梯式教学法、认知记忆算法（改进版 SuperMemo-2）深度融合。

### 1.2 阶段定位一览表
| 阶段 | 核心受众 | 痛点诉求 | 核心驱动功能 |
| :--- | :--- | :--- | :--- |
| **Phase 1** | 标准语言学习者（四六级考生、日常提升人群、零基础） | 单词记不牢、学习碎片化、缺反馈与动力、AI 产品合规顾虑 | 单词与记忆引擎、语法体系、句子拆分、考试模拟、口语跟读、作文练习、排行榜与趣味游戏（全程无 AI，完全商用） |
| **Phase 2** | 高中生、大学生、考研党 | 升学压力大、长难句读不懂、读后续写提分难、四六级/考研听说弱 | 动态语法树、高考读后续写 AI 逐句升格、各省听说机考模考、考研手译本与复试面试 |
| **Phase 3** | 白领、外企员工、出海业务、雅思托福考生 | 职场哑巴英语、跨国谈判阻滞、海外生活不适、留学机考高分难 | 商务开会/邮件即时润色、出海实战谈判模拟、海外生存沙盒、雅思托福换题模考 |

## 2. 第一阶段：标准多语言学习（无 AI 完全商用版）

> **第一阶段目标**：做一个**涵盖所有主流学习功能的标准语言学习软件**，零生成式 AI 依赖，无需生成式 AI 算法备案，内容全部教研预制，**安全、可直接商用的完美产品**；在标准功能之上额外增加游戏性作为差异化亮点。以英语为主，架构预留多语言。
> **范围边界**：K12 中小学教材逐课同步涉及教材商业许可，第一阶段**不纳入**（取得许可后再行引入）；AI 相关能力（陪练、数字人、知识库 RAG、发音评测、实时语音）统一在第二阶段交付（见 `docs/09-roadmap/roadmap.md`）。

### 2.1 单词学习（核心主线）
- **多词书库**：四级核心词汇、六级核心词汇、中学基础词汇、日常高频会话词；词书数据采用公开教研语料与自编整理，不含存在版权争议的商业词书。
- **词条四维信息**：原声发音（预录/合成音频）+ 音标 + 中英释义 + 例句与助记。
- **词根词缀专题课**：100+ 常用前缀/后缀/词根课程，每词根 = 讲解卡片 + 派生词族 + 快测，与词条助记字段联动（学一个词根串起一族词）。
- **记忆引擎**：SuperMemo-2 间隔重复调度；背词流程采用“回忆式测试”（先看中文回忆英文 → 自评 → 按熟悉度入队），错题自动回流。
- **个人词库**：学习、练习、考试中遇生词自动收录，支持手动添加与移出；按熟练度分层展示。

### 2.2 语法体系
- **语法点卡片库**：从词性、时态、语态到复合句，每个语法点 = 讲解卡片 + 例句 + 随堂练习。
- **语法练习题型**：选择、填空、句型转换；错题自动进入复习队列。
- **规则化语法图谱**：语法点间的前置/关联关系由教研预制（第一阶段不做语义检索，第二阶段入 pgvector）。

### 2.3 句子拆分（字句拆分）
- **长难句拆解**：教研预制的句子拆解数据（主干/修饰成分切分与标注），用户先看示范、后做标注练习。
- **句子成分练习**：找主谓宾、辨认从句类型、连词成句（拖拽词块拼合法句）。
- **句型积累**：高频句型库，每句型配例句与仿写提示。

### 2.4 口语训练（非 AI 评分形态）
- **跟读与影子跟读**：原声逐句播放 → 用户录音 → 自评对比（听自己 vs 原声，不做 AI 打分；评分槽位预留第二阶段）。
- **48 国际音标**：音标卡片 + 2D/SVG 口型示意图 + 发音要领文字说明 + 点读练习（3D 口腔实验室属第二阶段）。
- **情景会话**：预编写情景对话（点餐、问路、自我介绍、电话沟通等），分角色朗读与录音。

### 2.5 作文训练
- **句式写作**：汉译英练习 + 参考答案逐句对照（教研预制评分要点，不做 AI 批改）。
- **模板仿写**：范文模板挖空 → 用户填充仿写。
- **病句改错**：教研预制的常见错误句，用户改错并查看规则解析。

### 2.6 考试
- **计时刷题**：分模块计时题组（词汇、语法、阅读）。
- **四六级模拟**：按真实考试题型结构与时间分配的全真模拟卷。
- **成绩报告**：正确率、耗时、题型薄弱点统计（规则统计，无 AI）；错题自动入错题本。

### 2.7 趣味学习与游戏化（额外增加的差异化亮点）
- **六类游戏矩阵**（简单版用 Vue 组件实现，首期上线 4 款、预留 2 款；Phaser 完整版属第二阶段）：

| 游戏类型 | 玩法 | 首期状态 |
| :--- | :--- | :--- |
| 拼句火车 Sentence Train | 拖拽词块车厢拼合法句 | 首发 |
| 单词消消乐 Word Match | 单词-释义/音标翻牌配对消除 | 首发 |
| 单词保卫战 Word Defense | 限时拼写生存：拼对攻击怪兽、拼错扣血 | 首发 |
| 拼图解谜 Word Puzzle | 字母重排/缺字补全还原单词 | 首发 |
| 语法射击 Grammar Blaster | 语法选择限时速答闯关 | 预留 |
| 词义捕手 Catch the Meaning | 移动接住目标单词的正确释义 | 预留 |

  统一规则：题目包从用户当前词书/语法进度抽取（玩即复习）；每日限局防沉迷；画质引擎低档降级为静态点选玩法。
- **成就徽章与打卡**：连续打卡、单词里程碑、考试达标等徽章阶梯。
- **打卡补签卡**：断签后 3 天内可补签前一日（星星兑换或 VIP 每月赠送），保住连续打卡记录；每日限用 1 张，不可跨周补签。
- **分享海报**：打卡海报、周报海报、成绩海报（canvas 生成，含品牌水印与邀请码，不含个人敏感信息）。
- **学习战队与能量树**：3–6 人小队共享打卡积分，浇灌战队能量树。
- **排行榜**：周榜（打卡天数、背词量、模拟考分），每周重置、支持匿名、遵循设计系统“不制造羞耻感”原则展示。

### 2.8 学习闭环基座
- **今日任务**：按词书进度 + 复习队列 + 考试计划自动生成每日任务清单。
- **学习报告**：日/周维度统计报告（背词量、正确率、时长、连续打卡），支持家长/监护人查看。
- **提醒与习惯**：定时学习提醒（H5 用站内/浏览器通知，App 用推送）、深色模式、字号调节。

### 2.9 安全与商用合规（第一阶段零 AI 的保障）
- **无生成式 AI 功能** → 无需生成式 AI 算法备案；全部内容教研制作、双审留痕。
- **未成年人保护**：排行榜可关闭/可匿名、无陌生人私聊、家长绑定查看报告。
- **版权安全**：不含 K12 教材同步与教材版权内容；词书与真题语料采用公开可商用来源并留采购凭证。
- **内容防复制**：错题本、题库解析仅支持应用内查看与重做，不提供导出、下载、打印接口。

### 2.10 多语言预留
- 架构以英语为主，词书/题型/语音资源按“语言 + 语种资源包”建模，后续扩展日语、韩语等语种无需重构数据模型。

## 3. 第二阶段：高中与大学学术/升学突破体系

### 3.1 减压与抗焦虑学习体验
- **番茄微课系统**：将沉重的高考考点拆解为 5-8 分钟的高能量微模块。
- **暗黑沉浸极简模式**：无广告、零多余通知，专注护眼夜间刷题。
- **剧情式逆袭挑战**：通过分支剧情将高考真题转化为侦探破案等趣味任务。
- **AI 考前心理疏导**：温和英语陪练与正向心理暗示，疏导考前焦虑。

### 3.2 动态语法图谱与长难句 X 光机
- **长难句即时结构拆解**：自动分解长复合句为句法树并高亮从句与修饰成分。
- **个性化语法弱点图谱**：根据错题动态标红薄弱节点，推送强化变式题。

### 3.3 高考提分与真题模考引擎
- **读后续写 AI 升格导师**：诊断情节逻辑，提供三阶词句升格（基础->进阶->满分地道），注入高级句式。
- **高考听说各省机考模考**：覆盖广东、北京、上海等各省机考评分规则与全真题型。

### 3.4 大学学术与考研突破
- **四六级真题倍速听力**：0.8x-1.5x 无损变速单句精听与听写挖空。
- **考研英语手译本**：历年真题逐句英汉对照与采分点智能比对。
- **考研复试英语面试模拟**：中英文多专业方向全真问答实战。
- **学术论文/SCI 润色助手**：优化学术词汇、语态与逻辑转折。
- **外企 STAR 法则面试官**：针对 Situation/Task/Action/Result 追问式实战模拟。
- **AI 辩论竞技场**：回合制正反方英语思辨攻防。

## 4. 第三阶段：职场商务、出海实战与留学考培

### 4.1 职场与跨国商务实战
- **全场景商务会议模拟**：多口音（美/英/印/新等）国际会议主持、提问与总结。
- **跨境谈判沙盒**：价格博弈、交期延误、索赔条款实战，实时输出说服力评分。
- **商务邮件与通讯润色插件**：一键切换正式、委婉、坚定、简短四种语气。
- **行业垂直术语库**：跨境电商、外贸制造、科技金融、跨国物流等领域词库。

### 4.2 海外生存与文化沉浸沙盒
- **全真海外生存场景**：海关盘问、租房签约、就医急诊、银行开户等突发状况。
- **跨文化交际避坑指南**：解析 Small Talk 边界、地道俚语与文化禁忌。

### 4.3 雅思/托福留学高分冲刺
- **当季口语换题库实时更新**：每周同步全球最新口语高频新题。
- **官方评分标准多维诊断**：流利连贯(FC)、词汇多样(LR)、语法广度(GRA)、发音语调(PR)。
- **大小作文智能批改**：逻辑连贯性诊断、论据充实度评分与中式英语重写。
- **全真模考计时系统**：全真还原机考考场倒计时与答题节奏。

## 5. 跨阶段通用底层核心模块

> 交付分期：第一阶段仅交付非 LLM 的传统能力（记忆引擎、规则化知识图谱、教材内容体系）；AI 对话、数字人、知识库 RAG、发音评测等 AI 能力统一在第二阶段分批交付，具体批次见 `docs/09-roadmap/roadmap.md`。

- **记忆引擎**（第一阶段）：结合答题耗时与遗忘曲线，自适应规划复习时机。
- **知识图谱**（第一阶段规则化 / 第二阶段语义化）：12,000+ 词汇与 800+ 语法点关联网络，精准定位盲区；第二阶段入 pgvector 支持语义检索与相似题推荐。
- **教材知识库 (RAG)**（第二阶段）：教材、词库、语法点、真题结构化入库，AI 回答严格锚定权威教材，防止幻觉；含入库管线、引用溯源与版本管理。
- **AI 安全与风控**（第二阶段随 AI 能力上线）：前置敏感词拦截，语法解析严格锚定权威教材规则，少儿对话词汇表约束。

## 6. 用户基础与商业化体系

> 贯穿全阶段的基座体系。第一阶段即交付注册登录、用户信息、VIP 权益结构与激活码变现；支付渠道与自动续费随商户资质就绪开启（公司主体：深圳云澜深境科技有限公司）。

### 6.1 账号与注册登录
- **手机号验证码注册/登录**（中国大陆实名制基础，主登录方式）。
- **微信授权登录**（App/H5/小程序），绑定手机号后自动合并重复账号。
- 多端登录态同步（uni-app 全端共享 token，JWT + 刷新机制）；设备管理与下线。
- **账号注销**：用户自助发起，15 日内完成（个人信息保护法合规）；学习数据按用户选择匿名化或删除。
- **监护人模式**：未成年人账号可绑定监护人手机号，监护人可查学习报告、设置每日使用时长提醒。

### 6.2 用户信息与档案
- **基础资料**：昵称、头像（第一阶段用预设头像库，不开放自定义上传以降低审核风险）、学习目标（四级/六级/日常提升）、目标考试日期。
- **学习档案**：初始水平快速自测（可选）、预估词汇量、薄弱题型标签；全部用户可见可改。
- **隐私设置**：榜单显示名（昵称/匿名）、资料对战队成员可见性；个人信息最小化收集清单与权限说明页。
- **合规**：《个人信息保护法》最小收集原则；首次启动双协议（隐私政策 + 用户协议）确认；未成年人个人信息保护规则单独声明。

### 6.3 VIP 与权益机制（会员体系）

免费层 + VIP 会员双层结构，权益矩阵（第一阶段口径，具体数值后台配置化）：

| 功能 | 免费层 | VIP 会员 |
| :--- | :--- | :--- |
| 词书 | 四级核心词书 | 全部词书（六级/日常高频/中学基础） |
| 每日背词量 | 限量 N 个 | 不限 |
| 语法卡片 | 基础篇 | 全部 + 进阶篇 |
| 模拟考试 | 每周 1 次 | 不限次 + 历次回看 |
| 错题本 | 近 30 天 | 全历史 |
| 游戏与战队 | 基础游戏 | 全部游戏包 + 创建战队 |
| 学习报告 | 周报 | 日报 + 薄弱分析 |

- **会员规格**：月卡/季卡/年卡；新用户试用策略（如 3 天 VIP 试用）。
- **激活码/兑换码体系**：第一阶段变现冷启动方式（自营渠道/第三方电商售卡，应用内兑换），不依赖支付资质即可商用。
- **到期策略**：到期降为免费层，**学习记录与词库完整保留**（不以删除数据为续费惩罚）；到期前 7/3/1 天续费提醒（可在设置关闭）。

### 6.4 订阅与支付
- **支付渠道**：微信支付（App/H5）与支付宝；商户资质以公司主体申请。
- **自动续费**：严格遵循“显著提示、到期前提醒、随时可取消”监管要求；第一阶段默认不开自动续费，仅提供手动续费。
- **票据与对账**：订单台账、退款流程、客服查询接口；价格与权益明码标价。
- **未成年人支付保护**：未成年人账号支付需监护人确认，可设支付限额。

### 6.5 使用数据与学习记录
- 全部学习行为入事件埋点（analytics/events/core-events.yml 事件字典），用户可查看自己的学习历史。
- 数据使用边界：仅用于学习推荐与报告统计，不对外提供；第二阶段 AI 功能使用数据时遵循 docs/03-ai/safety-and-privacy.md 的脱敏与授权规范。
