# 语学星全栈语言学习系统 —— 产品需求规格说明书（PRD）

> **文档版本**：v3.3（三阶段全量功能 + 产品基础设施 + 3D成长系统 + 记忆与掌握闭环增强版）  
> **产品正式名称**：语学星  
> **研发/运营主体**：深圳云澜深境科技有限公司  
> **第一阶段核心原则**：在既定低成本创业预算、备案要求和许可边界内，做一款**功能全面、沉浸、重交互、可商业化的 18+ 成人语言学习软件**。  
> **第一阶段明确不做**：K12/高中同步学科培训、教材同步、生成式 AI、AI 实时陪练、AI 批改、AI 数字人、未成年人运营体系、开放式 UGC 社交。  
> **三阶段目标**：三期内覆盖原始规划中的标准学习、AI 智能学习、大学/考研/留学/职场、高中/K12 等全部设想；涉及监管资质的能力只在满足前置条件后开放。

# 0. 产品战略与合规总原则

## 0.1 产品长期愿景

语学星长期建设为覆盖：

- 成人零基础语言学习
- 大学英语 / CET-4 / CET-6
- 考研英语
- 日常生活语言
- 职场商务语言
- 出海与海外生活
- 雅思 / 托福等留学语言能力训练
- AI 个性化学习
- AI 实时口语与数字人
- 在取得相应资质、授权并完成专项合规评估后，再扩展高中 / K12 学习场景

的多语言学习平台。

**第一阶段不追求一次覆盖所有年龄，而是优先把“成人自主语言学习”做深、做完整、做出沉浸感。**

- “同步教材”
- “同步课堂”
- “名师授课”

### 第一阶段推荐对外定位

> **语学星是一款面向18岁以上成人与大学生的多语言自主学习工具，通过间隔重复、互动训练、沉浸式场景、游戏化任务与规则化学习路径，帮助用户进行词汇、语法、听力、阅读、写作和口语自练。**

# 2. Phase 1 —— 市场开拓版（18+、无生成式AI）

## 2.1 Phase 1目标

第一阶段不是“小MVP”，而是**功能完整的商业化语言学习产品**。

目标：

1. 在不进入K12学科培训和生成式AI监管高成本区域的前提下，形成明显产品竞争力。
2. 做到“打开就能学、每天愿意回来、学习过程有沉浸感、进步看得见”。
3. 支撑约 **1万注册用户 / 1,000～2,000 DAU**。
4. 云资源保持在既定低成本范围。
5. AI API费用为0。
6. 为Phase 2保留AI能力槽位，但Phase 1代码和UI中不虚假展示AI功能。
7. 第一阶段即可形成会员付费闭环。

## 4.3 间隔重复记忆引擎

Phase 1实现确定性算法，不依赖AI。底层以SM-2 / 改进间隔重复为主，并使用“艾宾浩斯遗忘规律”作为用户可理解的记忆曲线展示模型，而不是机械采用固定的5分钟、30分钟、1天、2天等统一复习间隔。

输入信号：

- SM-2 / 改进间隔重复参数
- 正确率
- 反应时间
- 连续错误次数
- 最近一次正确时间
- 复习次数
- 熟练度
- 遗忘风险
- 用户答题信心
- 错题与错因记录
- 延迟复测结果

生成：

- 今日新词
- 今日复习
- 高频错词
- 长期未复习词
- “即将遗忘”列表
- 推荐下次复习时间
- 预计记忆强度
- 当前掌握阶段

### 4.3.1 Memory Curve —— 艾宾浩斯记忆曲线

对单词、短语、句型、语法模式等LearningItem展示可解释的个人记忆曲线。

用户可看到：

- 当前记忆强度；
- 最近学习/复习时间；
- 已复习次数；
- 预计遗忘风险；
- 推荐下次复习时间；
- 当前掌握状态；
- 历次复习后记忆强度变化。

建议状态：

`未学习 -> 新学 -> 短期记忆 -> 巩固中 -> 长期掌握 -> 即将遗忘 -> 重新巩固`

记忆曲线只作为可解释的展示层，实际排程由确定性SRS算法根据个人学习记录动态计算。

### 4.3.2 Active Recall —— 主动回忆与信心输入

在适合的学习对象上优先提供“先回忆、后揭晓”的训练方式。

支持：

- 中文先回忆英文；
- 英文先回忆中文；
- 听音后回忆拼写；
- 句块关键词回忆完整表达；
- 语法结构根据提示主动补全；
- 用户主动点击“显示答案”。

揭晓答案后可记录信心：

- 确定会；
- 有点模糊；
- 猜对/蒙对；
- 完全不会。

信心结果作为SRS排程的辅助信号。即使客观答对，如果用户标记为“猜对/模糊”，仍可缩短下次复习间隔。

“当场答对”不直接等于长期掌握。

系统可对重要LearningItem安排：

`首次学习 -> 当天巩固 -> 延迟复测 -> 再次延迟复测 -> 长期掌握`

建议根据SRS动态计算复测时间，不强制所有内容使用完全相同的1天/3天/7天/30天周期。

长期掌握判定可综合：

- 多次延迟复测正确；
- 反应时间稳定；
- 信心不为“猜对”；
- 一段时间内无重复错误；
- 对应知识点在不同题型中仍能正确使用。

如果延迟复测失败：

`长期掌握候选 -> 降级为巩固中/即将遗忘 -> Mistake Repair -> SRS重新排程`

### 13.9.5 Global Mastery Map —— 全局知识掌握图谱

将原有语法弱点图谱扩展为全局学习图谱。

覆盖：

- 单词；
- 短语 / Collocation；
- 句型；
- 语法节点；
- 听力技能点；
- 阅读技能点；
- 拼写；
- 场景课程能力点；
- CET训练能力点。

每个节点可处于：

- 未学习；
- 学习中；
- 薄弱；
- 短期掌握；
- 长期掌握；
- 即将遗忘。

图谱可按模块、课程、时间和学习目标查看，并允许从薄弱节点直接进入专项练习或Mistake Repair。

### 13.9.6 错题与记忆联动

错题不作为孤立数据存放。任何错误都可触发：

`记录错题 -> 标记错因 -> 更新掌握图谱 -> 调整SRS -> 生成变式复习 -> 延迟复测 -> 恢复长期掌握`

同一个LearningItem在不同模块出现错误时应合并学习信号。例如某个单词在阅读、听力和拼写中连续出错，应提高整体遗忘风险和复习优先级。

### 13.9.7 复习积压保护

为了避免用户中断几天后出现大量待复习任务，记忆中心支持：

- 正常复习；
- 快速追赶；
- 分2～7天清理积压；
- 优先处理高遗忘风险内容；
- 暂时降低新内容数量。

目标是不因为复习债务过高而让用户放弃学习。

### 13.9.8 Phase 1实现原则

- 不使用生成式AI；
- 不需要向量模型；
- 所有判断来自结构化学习事件和确定性规则；
- 记忆曲线是可解释展示，不伪装为医学/脑科学精确预测；
- 用户可以手动调整每日复习量；
- 用户可以查看为什么某个内容被安排复习；
- Phase 2可在不改变数据模型的前提下加入AI解释、AI变式题和更复杂的个性化调度。

## 16.7 Learning Reward Chest —— 学习奖励箱

第一阶段可以加入**随机学习奖励箱**，但采取保守合规设计：

### 核心规则

**随机奖励箱只能通过真实学习行为免费获得，不直接出售。**

不得：

- 使用人民币直接购买随机箱；
- 使用充值获得的虚拟货币开启随机箱；
- 购买SVIP后直接赠送“10个付费关联随机箱”；
- 付费提高随机品质概率；
- 出售“抽奖次数”；
- 装备提现；
- 装备换现金；
- 用户之间买卖装备；
- 建立玩家交易市场。

### 推荐获得方式

- 完成每日核心任务：1个基础学习奖励箱；
- 连续学习7天：1个进阶奖励箱；
- 完成周目标：1个进阶奖励箱；
- 通过Checkpoint：按阶段固定奖励 + 可附带学习奖励箱；
- 完成30天课程：主题纪念奖励；
- 达成重大Streak：专属固定装扮；
- Study Room完成团队挑战：每名成员获得团队奖励。

### SVIP替代方案

为了避免“付费 -> 随机结果”的关联，SVIP首开建议赠送：

- **10张装扮自选券**；或
- **10个内容可预览、结果固定的欢迎礼盒**；或
- 一套固定SVIP主题服饰 + 背景 + 动作；
- 专属衣柜页、额外装扮方案保存位等非随机权益。

> 不采用“开SVIP直接送10个随机宝箱”的原方案。

- 个人版：1个账号
- 双人版：2个成人账号
- 家庭/好友版：最多4个成人账号
- 扩展版：最多6个成人账号（是否上线视渠道规则与商业测试）

### 权益原则

每个成员拥有独立：

- 学习记录
- SRS
- 错题
- 表达库
- 学习计划
- Checkpoint
- 收藏
- 隐私设置

订阅共享**不等于数据共享**。

默认情况下，主订阅人不能查看其他成年成员的详细学习记录。

### 加入方式

- 主订阅人创建家庭/共享组
- 邀请码或受控邀请链接
- 成员登录自己的账号加入
- 主订阅人可移除成员
- 防止频繁换人滥用：设置合理冷却期和设备/账号风控

### 与学习室关系

Household是**付费权益组**，Study Room是**学习互动组**，两者分离：

- Household负责会员权益共享
- Study Room负责共同学习

用户可以共享会员但不加入同一学习室。

### iOS策略

iOS优先使用App Store支持的Family Sharing能力来共享符合条件的自动续期订阅/非消耗型购买。

若未来设计自有的跨平台“家庭会员”，上线前必须再次按当期App Store审核规则核验其购买、恢复购买、权益同步与共享方式。

### Android / H5

可由公司账户体系维护共享组与权益，但：

- 购买入口遵守所在平台支付规则；
- 防止账号倒卖；
- 不得把“共享会员”做成公开拼车交易市场。

- 成人账号
- 邀请制小组
- 系统学习动态

- 无私聊

33. **Active Recall**：主动回忆模式，支持先回忆后揭晓；
34. **Confidence Rating**：记录“确定 / 模糊 / 猜对 / 不会”，辅助SRS调度；
35. **Interleaving Practice**：跨词汇、短语、语法、听力、阅读、句型的交错练习；
36. **Mistake Notebook**：独立“我的错题本”入口，与Mistake Repair共用数据；
37. **Error Cause Analysis**：规则化错因分类和趋势统计；
38. **Delayed Mastery Test**：通过延迟复测区分当场答对与长期掌握；
39. **Global Mastery Map**：全局知识掌握图谱，统一展示薄弱、短期掌握、长期掌握和即将遗忘状态；
40. **Memory & Mastery Center**：统一承载今日复习、即将遗忘、错题和长期掌握；
41. **Review Backlog Protection**：复习积压保护和分日追赶机制。

### 付费随机机制调整

原设想“开SVIP送10个随机宝箱”**没有直接加入**。

v3.3继续采用：

- SVIP赠10张装扮自选券；或
- 10个内容固定且可预览的欢迎礼盒；或
- 固定SVIP主题套装。

随机奖励箱只通过学习行为免费获得，避免把“付费”和“随机结果”绑定。

### v3.3仍明确没有加入Phase 1的能力

- 自由文本留言板
- 陌生人私聊
- 开放论坛
- 用户公开视频社区
- AI Conversation
- AI作文批改
- AI发音评分
- 真人教师直播
- 未成年人/K12入口
- 人民币/充值货币购买随机宝箱
- SVIP购买后直接获得随机抽取次数
- 用户间装扮交易市场
- 虚拟物品提现

这些能力继续按照Phase 2 / Phase 3门控执行。

# 50. 参考依据与产品研究说明


本版PRD在原v2.1全部长期设想基础上重新分期，并参考以下公开机制进行产品边界设计：

- 教育部《义务教育阶段校外培训项目分类鉴别指南》：学科类培训按培训目的、内容、方式、评价综合判断；外语属于学科范围之一。
- 教育部《教育移动互联网应用程序备案管理办法》：教育移动应用提供者备案及相关基础要求。
- Apple App Review Guidelines：App内数字功能、会员等支付遵循In-App Purchase规则。
- 国家网信办生成式人工智能备案/登记公告：调用已备案模型提供生成式AI应用/功能时，按现行规则由地方网信部门开展相应登记；上线后按要求公示。
- 《人工智能生成合成内容标识办法》：Phase 2生成式AI文本、音频、图片等按要求实施标识。
- Duolingo公开产品资料：路径、Streak、XP、Quest、Leaderboard、个性化复习等机制。
- GitHub OpenLingo / FreeLingo / LibreLingo / LinguaCafe等公开项目：SRS、分级学习、互动阅读、学习路径等产品机制。
- 《互联网用户账号信息管理规定》：为用户提供信息发布、即时通讯等服务时的真实身份信息认证与账号治理要求。
- 《网络信息内容生态治理规定》：平台信息发布、评论、巡查、处置等内容治理责任。
- 《互联网信息服务算法推荐管理规定》：个性化推送、排序精选等算法推荐服务的透明度、用户选择与治理要求。
- Apple Developer / App Store Connect关于Family Sharing的官方说明：符合条件的自动续期订阅和非消耗型内购可启用家庭共享。
- Apple App Review Guidelines：提供可购买的随机虚拟物品机制时，需要在购买前披露各类物品的获取几率。
- Google Play Payments / Developer Program Policy：购买关联的随机虚拟物品需要在购买前显著披露概率；非游戏App中的随机奖励/忠诚计划也存在规则披露要求。
- 文化部《关于规范网络游戏运营加强事中事后监管工作的通知》：对于网络游戏随机抽取虚拟道具，要求概率公示并限制直接以法定货币/游戏虚拟货币参与随机抽取；本产品Phase 1据此采取更保守的“学习免费随机奖励 + 付费固定权益”设计。
