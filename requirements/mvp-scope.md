# MVP 范围与优先级

> 分期基调（与 docs/09-roadmap/roadmap.md 一致）：第一阶段做**面向中小学生的传统型学习 App**，不依赖大模型，内容与规则由教研预制；AI 相关功能（对话陪练、数字人、知识库 RAG、发音评测、实时语音）统一放第二阶段。

## MVP 成功条件

在 8 周试验周期内，中小学生用户能够完成：选年级教材 -> 每日短课（预习/跟读/语法/自测）-> 错题进入间隔复习 -> 打卡与战队激励，并且产品团队能够看到每一步的转化和失败原因。**全程不依赖 LLM 可用性。**

## P0：必须有（第一阶段，传统型）

### 学习者

- 手机号或微信登录；年级与教材版本选择（人教版 PEP 等）。
- 教材逐课同步：单词预习、课文跟读（录音对比，非 AI 打分）、教研预制语法拆解、同步自测小考。
- 48 音标实验室（2D/SVG 版）。
- 今日任务、学习进度与提醒。
- 记忆引擎：SuperMemo-2 间隔重复、错题回流、个人词库。
- 打卡、徽章成就、学习战队与能量树（规则化积分）。
- 轻游戏化：拼句火车、拼读消消乐（Vue 组件简单版）。

### 内容与后台

- 课程、课节和练习 CRUD；教材版本管理。
- 内容审核状态：草稿、审核中、已发布、已下线。
- 核心学习事件埋点；基础用户、订阅和客服查询能力。
- 未成年人模式与内容留痕。

### 平台

- 学习端 Web + H5（uni-app 一套代码）。
- iOS/Android 包体就绪（上架视备案进度）。
- 官网落地页与免费测评入口。
- 管理后台（Vue 3 + Element Plus）。

### 视觉验收

- 设计令牌落地、插画风格统一、动效受四级画质引擎管控——"完善美丽"是 P0 验收项。

## P1：第二阶段第一批（AI 基座，留存验证后加入）

- FastAPI AI 编排服务（LiteLLM + Pydantic 校验 + 超时降级）。
- 教材知识库 RAG 入库（pgvector）与 AI 回答锚定权威教材。
- 受课程上下文约束的文字陪练与结构化反馈。
- prompt_version 治理与最小离线评测集。

## P2：第二阶段后续批次

- 音素级发音评测；读后续写升格与作文批改；长难句 AI 拆解。
- 商业 RTC AI 对话接入；数字人 Rive 情绪状态机与 Lip-Sync；3D 口腔实验室（视美术资产）。
- 会员订阅、优惠券和支付对账；多渠道提醒。
- Phaser 完整版游戏矩阵。

## P3：规模化后加入

- 高中/升学与职场出海人群功能。
- 行业词库、企业团队版与岗位模板。
- 离线包与系统级语音体验；教研市场或认证课程；真人老师服务。

## 明确暂缓

- 无边界的 AI 自由聊天大厅。
- 以排行榜为主的强竞争机制。
- 没有教研审核的批量课程自动发布。
- 首期同时维护多套完全不同的原生 UI。
- 第一阶段内任何依赖 LLM 的功能提前上线。
