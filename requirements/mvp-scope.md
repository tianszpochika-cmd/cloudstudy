# MVP 范围与优先级

> 本文件是 Phase 1 的执行范围，不覆盖全部 PRD 长期能力。v2 技术基线：Vue 3 四项目、Java 25 LTS + Spring Boot 4.1 微服务/Gateway/IAM/RBAC、MySQL 8.x、Redis 7.x；现有 Spring Boot 3 `core-api` 仅作迁移兼容；Phase 1 不启用生成式 AI。

> **文档分类：当前 Phase 1 执行范围**。本文件只定义首发与 P1 的交付边界；全量登记和成熟度以 v2-980plus 为准：`V2-980-0001..0980` = 930 个业务单元 + 50 个跨域扩展登记位，184 个显式设计、486 个原子映射、310 个待细化单元，不等于 980 份可实施详细设计或已完成实现。

## MVP 成功条件

在 8 周验证周期内，18 岁以上用户能够完成：注册与目标选择 -> 非 AI 水平测评 -> 今日任务 -> 词汇 SRS -> 规则化练习 -> 错题复习 -> 阶段报告，并能通过免费版或激活码完成首次商业化体验。

## P0：首发必须交付

### 学习者主链路

- IAM 自有账号密码登录/注册、短时 JWT 会话、Refresh Token 轮换、设备会话撤销、账号注销和隐私设置；手机号/第三方账号连接不进入 Phase 1 正式登录方案。
- 目标选择：成人零基础、日常交流、CET-4、CET-6、听力、阅读、写作、口语自练。
- 规则化水平测评：词汇、语法、阅读、听力；输出参考等级与学习建议。
- 今日任务：新词、到期复习、语法练习、短听力或阅读任务。
- 单词学习：词条详情、发音、释义、例句、个人词库、版本化改进型 SM-2 间隔重复（每条 SRS 状态记录 `algorithmVersion`；FSRS 仅作为后续升级候选）。
- 语法与句子：语法卡片、选择/填空/句型转换、预制长难句拆分、句子重组。
- 听力与阅读：分段播放、`0.5x~2.0x` 变速（快捷档 `0.5 / 0.75 / 1 / 1.25 / 1.5 / 2`，音高保持）、听写、分级阅读、生词收藏。
- 口语自练：跟读、影子跟读、录音回放、48 音标 2D 图示、预编情景会话；不提供 AI 打分。
- 写作自练：汉译英、模板仿写、病句改错、参考答案对照。
- 练习与考试：原创 CET 风格训练、计时模块、阶段 Checkpoint、成绩与薄弱点报告。
- 复习闭环：错题入队列、来源追踪、到期复习、重做和下一次复习时间。

### 轻量激励

- 今日/每周任务、XP、连续学习、成就徽章。
- 首发 1 款轻游戏：拼句小火车 (Sentence Train)；P1 扩展至共 4 款，长期目标为 6~8 款学习游戏。
- 周排行榜支持匿名、关闭和每周重置。
- 学习分享海报仅包含用户主动选择的学习数据。

### 商业化与后台

- 免费/VIP 权益、激活码、SKU、订单和权益查询。
- P0 完成支付 provider 适配、回调验签和沙盒验证；微信、支付宝与 Apple IAP 的生产开关默认关闭，且首发不启用自动续费。只有商户/渠道资质、沙盒、验签、退款、对账、回滚与审计证据齐全后才能开启生产支付。
- 词书、语法、练习、音频和课程包 CRUD；所有内容只可使用自有、开放许可或合法授权来源，第三方品牌、词库/释义、教材和真题须绑定有效授权凭证后才可展示或发布。
- 内容状态：草稿 -> 审核中 -> 发布 -> 下线；双人审核和版本回滚。
- 用户、订阅、客服、埋点和基础运营看板。

### 平台范围

- 首发优先：`apps/mobile` 的移动 H5 / Android / iOS / iPad 学习链路，以及独立的 `apps/learner-web` 浏览器学习链路。
- 管理后台：独立的 `apps/admin-web`（Vue 3 + Element Plus）。
- 官网：独立的 `apps/official-site`，负责公开内容、下载引导、价格与合规公示，不承载登录后的学习业务。
- 微信小程序作为 P1.5：由 `apps/mobile` 通过 uni-app 条件编译输出，不能阻塞 Web/H5 主链路，也不单独建立第二套业务项目。

#### 前端项目冻结

Phase 1 前端只维护以下四个独立项目；“平台”是项目的交付目标，不是额外的代码仓库或业务应用：

| 项目 | 负责平台 / 场景 | 不负责 |
|---|---|---|
| `apps/mobile` | 移动 H5、iOS、Android、iPad；后续微信小程序 | PC Web 学习工作台、管理后台、官网公开页 |
| `apps/learner-web` | PC Web、平板浏览器、PWA 学习工作台 | 移动 H5 的第二套页面、管理后台、官网公开页 |
| `apps/admin-web` | 教研、审核、运营、商业化、客服和审计后台 | 学习者五 Tab、移动端业务页面 |
| `apps/official-site` | 品牌官网、课程介绍、价格、下载、SEO 和合规公示 | 登录后的学习业务 |

四个项目可共享契约、API 客户端、领域规则、设计 Token、埋点和国际化资源；页面 DOM、导航壳和平台交互按项目分别实现。

## P1：Phase 1 增强

- 扩展至共 4 款轻游戏矩阵；6~8 款仅作为长期目标，不纳入 P1 交付承诺。
- 3D Avatar、学习空间、衣柜和非付费随机学习奖励箱。
- Study Room 低 UGC、学习动态和成员展示。
- 离线下载、断点恢复、同步冲突处理。
- Language Clips 视频课程、家庭共享和更多场景课程包。

## Phase 2：AI 能力，不得提前混入 Phase 1

- Python FastAPI AI 编排服务。
- AI Tutor、结构化文字反馈、RAG、发音评测、作文批改、实时语音和数字人。
- 具体启用必须满足 PRD 前置条件、内容安全、数据治理和成本闸门。

## Phase 3：受监管扩展

- 未成年人账号、K12/高中课程、教材同步和教师/机构生态。
- 必须先完成资质、版权、未成年人保护和专项合规评估。

## 明确暂缓

- 未授权教材、商业题库、真题答案和解析。
- Phase 1 的 LLM、AI 评分、AI 数字人、开放式自由聊天。
- 面向未成年人的注册入口、学科培训宣传和家长运营体系。
- 付费抽奖、现金兑换、用户自由发帖和陌生人私聊。
