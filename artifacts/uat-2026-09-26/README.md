## 三、最新明确故障

1. **首页 503**：登录后 `GET /api/v1/learner/home` 返回 `STORE_FAILURE`，消息为 `first-day planning projection is not available for the confirmed target`。学习 Web 和移动 H5 都显示任务不可用。[浏览器与响应证据](local-latest-runtime/login-smoke/summary.md)中有 requestId、traceId 和截图。需要沿目标确认 → learning owner 计划引用 → learner 首页投影追踪；不得补假任务让首页显示成功。
2. **阅读与同域技能路由断路**：真实登录态 `/reading` 显示“网络暂时不可用”，重试仍失败。阅读列表预检被 Gateway 以 `403 The CORS route is not available.` 拒绝，普通 GET 为 `404 The API route is not available.`；语法练习/掌握度、写作提示、听力素材等也出现同类预检拒绝。[阅读诊断](local-latest-runtime/reading-diagnosis/summary.md)核对了 9 条路径与源码 owner 冲突。页面将预检失败归为离线，不能据此判断用户网络断了。先按契约/真实 owner 拆分精确路由，再重建 Gateway 并在登录态复测；不要以重启健康进程代替修复。
3. **管理与视觉边界**：本轮没有授权管理员会话；学习 Web、管理 Web、移动 H5 的 `/favicon.ico` 为 404。Batch24 独立截图还发现两端重置密码页未继承指定的英文/深色偏好、学习 Web 390px 注册页隐藏品牌字标；需在当前源码复现后再判是否仍存在。

## 四、接手测试顺序与判定

1. 先读[本机运行交接](local-latest-runtime/operational-handoff.md)、[登录冒烟](local-latest-runtime/login-smoke/summary.md)、[阅读诊断](local-latest-runtime/reading-diagnosis/summary.md)、[覆盖台账](../uat-2026-09-23/coverage-ledger.md)，核对固定端口、版本、进程和数据源。现有源码未绑定一个干净提交，不要把旧镜像与当前源码混为一轮。
2. 从可复现的 **首页 503** 与 **阅读/技能路由 403/404** 入手，记录浏览器页面、请求/响应、Gateway 路由、owner 事实和恢复操作。修复必须遵循 OpenAPI、Gateway/owner 分工、服务侧鉴权与现有设计；每个改动做适用的局部及运行验证。
3. 修复后用合法本地合成成人账号按注册/登录 → Gate/同意 → 目标 → canonical 定级 → 计划/今日任务 → 已发布且有权利的内容 → 练习判分 → 复习/报告的顺序测试。缺正式题源、版权、同意文书或独立审核材料时保留明确阻断，不能造正式发布事实或用旧两题流程代替 Phase 1 定级。
4. 再测管理端角色/权限、内容双审与发布、官网真实投影及移动 H5 同一事实的读回；原生 App、iPad、小程序、麦克风、离线和媒体字节另列环境。每条 PAGE-P1 只有在关键操作、owner 持久化、错误恢复及相关跨端表现均有证据时才可改判 PASS。
5. 将新证据写入对应日期的报告，并回填[56 项覆盖台账](../uat-2026-09-23/coverage-ledger.md)的具体行、环境、时间和判定。先保留原始失败，再记录修复与复测，不用成功计数冲抵仍失败的业务链。若需要对外部署或复用旧私有数据卷，先独立核对迁移、法律/内容准入和回滚条件。
