# Batch18 私有库数据真实性核查（2026-09-25）

本次只读核查私有隔离项目的 owner 数据表与种子来源，没有修改数据库或容器。结论只适用于该隔离库，不外推到共享环境或正式部署。业务主表大多为空，**不能称为真实数据已齐备**；仍有错误标为 `PUBLISHED` 的旧样例。

| 数据族 | 私有库事实 | 四端可见性与风险 |
| --- | --- | --- |
| B3 旧学习素材 | `b3_content_experience` 的 `platform` 记录 113 条 `PUBLISHED`，均标为版本 301，来自 V7/V11/V20 种子；无可核验的 canonical `content_version` 绑定。 | 当前 Gateway 只开放精确语法点 GET，owner 查询仍含 `AND 1 = 0`，这些行不会从该入口返回；其余 B3 路由未获当前 Gateway 执行投影。但库内发布状态不真实。 |
| B25 词条 | `b25_content_vocabulary` 中 `b25-item-001`（`hello`）为 `PUBLISHED`，其课程单元不存在，表缺版权字段。 | Gateway 有按 ID 读取，owner 仅检查认证与发布状态；已认证 learner 知道 ID 时可能直取。因本批无合法新会话，仅判“潜在可直达”，未声称浏览器实际展示。 |
| B2 词块 | `b2_content_chunk` 的 32001（`build a habit`）为 `PUBLISHED`，缺 canonical 版本/权利关联。 | 内部 owner 可按 ID 读，但当前 Gateway 未映射其 OpenAPI 路径，四端经现行 Gateway 不可达。 |

私有库未见两条 orphan 的外键、SRS/复习/收藏、学习任务或评估回执引用。课程/单元/题目、公开投影、canonical 内容定义/版本、有效同意文书与 grant、社群房间/榜单、商品/订单/权益、客服/管理/分析投影、学习计划/任务和评估会话均为 0。这是正向业务验收缺数据的证据；空数据、匿名安全拒绝和页面渲染均不能计为对应功能 PASS。

现有 `local-real-10x` 种子使用 `platform` 租户，且会发布面向 LEARNER 的夹具投影，不符合“明确 UAT 标记、版权安全、隔离在非正式租户、不进公开投影”的条件。不能用它替代正式内容审核或同意文书。

下一步只对精确识别的旧种子行做前向补偿迁移：先保存目标行的主键、版本、状态和散列快照，再将上述 113+2 行标为 `UNPUBLISHED` 并回读数量与非目标行不变；保留行，不改已应用的历史迁移。回退仅凭对应快照执行。B3 owner 的 `AND 1 = 0` 门禁继续保持，直到获版权/原创来源、许可范围与期限、独立编辑/双审/发布、canonical 版本绑定和读取时校验证据。IAM 的正式生效同意文书也仍需独立批准。
