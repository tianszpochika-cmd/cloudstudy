# Batch 21 官网公开流程抽查

## 范围与结果

- 检查的是当前工作区 `apps/official-site` 源码，使用本机 Nuxt 开发服务 `127.0.0.1:18182`；未访问公网部署、未触碰 Docker 或共享服务。检查结束后已停止本次启动的开发服务。
- 官网静态、公开投影、路由入口测试：25/25 通过。
- 浏览器完成 11 组交互/状态检查，包括首页词卡练习、课程搜索与清空、FAQ 搜索与展开、学习世界玩法、主题和画质档位、移动导航与学习入口、减少动态效果、投影失败重试、旧路径跳转、404、SSR 主题隔离、触屏滚动和房间旋转。
- 19 个公开路由在 320、390、768、1440 像素视口及亮/暗主题下共检查 152 组；所有断言通过：没有横向溢出，每页恰有一个 H1，canonical 路径正确，页面没有翻译键占位符。
- 官网公开投影在该本地环境返回 `empty-fallback / error / PUBLIC_PROJECTION_UNAVAILABLE`；页面呈现受控错误状态，点击重试后仍可用。该环境没有本地 Gateway 公开投影事实，不能据此判定生产数据或服务状态。

## 浏览器运行限制

路由矩阵与交互断言全部完成。脚本最终的“浏览器 Console 必须无错误”断言未通过：本机 Nuxt 开发模式的 Vite HMR WebSocket 出现 `ERR_NO_BUFFER_SPACE`，随后尝试连接 `localhost:5173` 被拒绝。错误指向本次开发服务热更新通道；未观察到页面脚本异常或上述功能断言失败。因而本次本地开发态结果不作为“Console 零错误”证据。已有 Batch 20 私有 Docker 官网抽样记录是 390/1280 像素入口页无页面错误和横向溢出，但覆盖面小于本次本地源码矩阵。

## 结论

本次没有发现可确认的官网产品缺陷，因此没有修改官网源码。全页面的课程投影、内容真实性和后端联动仍需结合可用的合法公开内容数据验收。
