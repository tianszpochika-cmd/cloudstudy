## 本批修正与源码检查

- 学习 Web 与移动 H5 在已知登录、注册失败时保留白名单错误标记，并显示简短的中英文提示。缺正式同意文书时说明账号暂不可用；未知服务端诊断不会直接展示。通用 409 不再误称账号已占用。
- 官网公开入口改为先查看开放情况和无需登录的学习示例，不再把当前不可用的注册、登录当作可操作入口；静态学习规划标明示意性质，公告链接靠近开放状态说明。官网、学习 Web、管理 Web、移动 H5 的可见品牌统一为“语学星”。
- Web 注册页英文链接间距、移动注册页重复密码长度提示、重置页冗余说明作了整理。本批 IAM 源码中三类必需同意文书与可选分析/语音文书的准入边界也已修正并通过局部测试，但 **IAM 新源码尚未部署到本私有环境**，不能以本批运行结果认定其生效。

## 私有 HTTPS 浏览器复测

[逐项证据](docker-isolated-browser-batch24/evidence.json)、[汇总](docker-isolated-browser-batch24/summary.json)与同目录截图来自私有网络内的 Chromium 容器。官网首页、开放页、课程和帮助入口，三套公开认证页面及 390/1280px 布局经浏览器实测；官网首页到开放页、再到免登录示例的两种视口导航均通过。结果为 **24/24 HTTP 200**、**18/18 浏览器内 JWKS CORS 200**，页面错误、失败请求、横向溢出及已加载破图均为 **0**。官网检查页无直达当前不可用的注册/登录链接，8 个受检页面显示账号未开放状态。

学习 Web、移动 H5 各两项失败提示以浏览器拦截并合成已知 503 响应验证，**4/4** 显示预期提示；请求没有到达 IAM，也没有写账号或同意记录。这只证明客户端在该响应下的界面行为，不证明真实服务会返回相同响应。独立截图复核未见明显裁切、重叠或破图，**但发现两端重置密码页在指定英文/深色入口后仍显示中文/浅色**；学习 Web 390px 注册页品牌字标也被隐藏。这些视觉与偏好问题纳入下一批修正，不能被本批的零页面错误或零溢出覆盖。原生 App、iPad、小程序及登录后页面不在这轮浏览器覆盖内。
