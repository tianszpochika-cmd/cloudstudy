# 第十六批：四端页面边界与账号状态修复

## 本批发现及修复

- 官网公开商业目录中，字段不完整或金额不合法的方案曾可能被拼成误导性价格。BFF 现在仅接收完整的公开方案字段，按币种格式化金额；无效方案直接不展示，商业目录空态也会清除旧内容投影里的价格。前端请求失败时立即清空旧课程与价格，BFF 遇公开读取撤回后也拒绝并发旧成功请求回填缓存。
- 管理端学员详情在快速 A→B 切换、权限变更或重新检索时，迟到请求曾可能覆盖当前表单或列表。详情、检索和“加载更多”均校验请求代次、管理员会话及当前选择；写操作在提交前重新核对所选学员和权限。旧学员的确认框不能向新学员发出 SRS 重置。
- 管理端审计列表原先把缺少 `redacted: true` 的行一律标为“已脱敏”。现在仅在该标记明确为 `true` 时显示动作及资源/命令/追踪引用，否则隐藏这些字段并标为“待核验”。刷新、筛选、切号以及“加载更多”均隔离迟到响应。审计后端改为按租户和递减序号做游标分页，每页最多 100 条；游标加密并绑定租户，新增索引 V5。前后端与数据库迁移必须同批部署，审计导出仍不可用。
- 学习 Web 的 B1 本地快照绑定 IAM 已确认的主体；注销、切号、无 owner 断点和失败的断点写入都不再复活旧账号进度。会话代次校验也挡住同账号重新登录后的旧请求，以及注销后迟到的刷新结果。详见[学习 Web 专项](batch16-learner-b1-subject-isolation.md)。
- 移动首日、B1、B10、B11 缓存及 B11 离线队列均绑定已验证主体；切号和退出清除内存、旧回包不能落入新账号。口语页切号停止录音与音频并丢弃晚完成的受保护录音；听力页切号停止音频和定时器。移动本地 H5、App、小程序三目标编译通过，真实设备媒体操作仍待验收。
- 移动 B3 写作、阅读、语法页的本地草稿改为只恢复同账号、同内容版本数据；身份变化清空页面中的答案、反馈和位置，异步响应落地前复核身份。旧无主体草稿不能恢复。正式 App、iPad 和小程序的运行效果仍待真机验收。
- 移动 B3 阅读保存使用每次编辑对应的事件标识，重试复用待同步标识；同账号内重复读取、切换题目或编辑答案时，旧请求也不再覆盖新页面反馈。写作提示压短，阅读题反馈不再回显内部规则码。
- 两端学习世界 B4 的个人状态和离线交互队列已绑定 IAM 确认的主体和会话代次；切号/退出清除旧状态，迟到请求不能覆盖新账号，旧无主体离线记录不会恢复，存储失败不再误报“已排队”。两端 13 路读取遇权限拒绝或全部失败会清除旧个人投影并报真实错误，部分成功只展示新取得的内容。详见[学习 Web 专项](batch16-learner-b4-account-isolation.md)和[移动专项](batch16-mobile-b4-account-isolation.md)。游戏、离线页隐藏内部挑战令牌、会话编号、原始事件码和下载状态码，改用简短说明。由于缺可操作题目与正式玩法，两端“开始”暂不可操作，游戏仍按阻断处理。
- C02 设置页回归断言改为核对现行国际化 key 与中文资源，保留“暂不可修改”和“目标保存成功”的实际文案检查。
