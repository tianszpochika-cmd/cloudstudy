# 首日页面 UI 小批验收（2026-09-23）

范围：`apps/learner-web` 与 `apps/mobile` 的入学引导、测评、首页和今日任务页面。对照 `PAGE-P1-ONB-GOAL`、`PAGE-P1-ASSESSMENT`、`PAGE-P1-LEARN-HOME`、`PAGE-P1-TODAY`，仅修用户可见状态、入口和窄屏布局，不改变 IAM、合同或领域写入。

| 问题 | 本轮处理 | 证据边界 |
| --- | --- | --- |
| 测评错误/空态提示重复且夹杂“内容投影”“Gate”等术语 | Web 测评保留单条错误与重试；题目提交状态不明时先重新读取。移动测评区分加载、无题、失败，提交状态不明时暂停再次提交。入学引导文字缩短。 | 页面行为和构建通过；没有可用 canonical 定级题包，真实定级未验。 |
| 首日无数据或网络失败仍显示 `0%`、默认 `15` 分钟 | 移动首页/今日只在收到 home 事实后显示进度，失败时显示重试；Web 首页离线不把旧快照当当前进度。 | 浏览器夹具渲染通过；真实账号计划/任务仍缺失。 |
| 任务缺课程引用、锁定或内容未发布时仍可点击；进行中任务反而被禁用 | 两端只为有 `contentCode` 的可用任务打开课程；移动允许 `IN_PROGRESS` 继续，锁定/未发布内容禁用；空任务回到课程或首页。 | 仅修入口真实性；课程浏览不等于完成任务。 |
| 390px 首页任务说明被按钮挤出孤字 | 移动首页与今日任务在窄屏让说明占整行、按钮另行右对齐。 | [390px 首页截图](screenshots/mobile/first-day-ui-390/home-light.png) 为合成夹具；不能替代原生设备。 |

验证：Web 与 Mobile typecheck 通过；Web production build 与 Mobile H5 build 通过；相关页面/链路测试 11/11；浏览器夹具 31 页面 × 5 组视口/主题 = 155 次，错误 0。390px 的首页、入学、测评、今日页面 `scrollWidth=390`，无横向溢出；[夹具明细](screenshots/mobile/first-day-ui-390/results.json)。截图和 155 次浏览器渲染只验证 H5 合成响应，不是新账号端到端验收。

仍未闭合：移动测评没有跳过/自选起点 API 与 UI；canonical 四维定级、首日计划、真实今日任务和课程授权仍需领域链路及人工操作证据。没有服务重启或 Docker 打包。
