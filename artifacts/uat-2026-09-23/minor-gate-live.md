# 未成年人准入本地实测

2026-09-23，运行 `node tests/uat/minor-gate-live.e2e.mjs`，经本地 Gateway 与当前 Java owner，使用一次性 `@local.invalid` 账号。输入出生年 2010；账号先注册并接受三项文档同意，以便把成人 Gate 与同意缺失分开测试。未输出凭证或令牌；结束后精确匹配账号已 `DISABLED`，活跃会话为 0。

| 操作 | HTTP |
| --- | ---: |
| 注册 | 201 |
| 三项必要同意 | 200 × 3 |
| 成人 Gate（2010 出生年） | 403 |
| 重新登录 | 200 |
| 学习计划、定级读取、学习内容目录 | 403 × 3 |
| 本人账号资料读取 | 200 |

本人资料读取与学习准入分属不同边界，故不把资料 200 判为学习权限绕过。此测试只说明本地配置下上述三条 owner 学习入口拒绝未成年声明；它不验证出生年真实性、生产可信年龄证据、全部课程/活动入口、原生客户端或正式法律版本。生产成人准入仍受 [生产 Gate 缺口](iam-production-gate-gap.md) 阻断。
