# Canonical P1 定级五路由本地实测

执行 `node tests/uat/p1-placement-owner-live.e2e.mjs`，经本地 Gateway `127.0.0.1:18070` 和当前 IAM/assessment Java 进程。一次性成人学习者从注册、成人 Gate、三项同意到新登录，随后仅在该合成账号上撤销五个定级权限，再新登录检查权限边界。没有打印或保存密码、JWT。详细状态码与数据库计数见 [evidence.json](evidence.json)。

| 条件 | 创建会话 | 读取会话 | 提交响应 | 跳过定级 | 读取报告 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 匿名 | 401 | 401 | 401 | 401 | 401 |
| 未过成人 Gate，携带伪造角色/租户头 | 403 | 403 | 403 | 403 | 403 |
| 成人 Gate 已过，必要同意未齐 | 403 | 403 | 403 | 403 | 403 |
| 成人 Gate 与三项同意均齐，当前缺正式授权题源 | 503 | 404¹ | 404¹ | 503 | 404¹ |
| 精确撤销五个定级权限后重新登录 | 403 | 403 | 403 | 403 | 403 |

¹ 使用不存在的会话/报告 ID；404 只证明该请求没有伪造读取结果。不能据此认定真实资源的跨用户访问已验收。

创建和跳过返回 503 时，该合成 principal 的 P1 session、response、checkpoint、result、idempotency 五表及定级完成 outbox 事件均为 **0**，前后计数一致；没有生成假的定级结果。伪造 `X-Role`、`X-B5-Role`、`X-Tenant-Id` 未绕开成人 Gate 或题源门槛。合成账号精确停用，活跃会话 0，停用后的重新登录为 401。

本轮边界结论为 **PARTIAL**：正式 10 题、四维评分、会话续答、报告、跨用户真实资源访问仍需可信内容来源、版权与目标 pin 就绪后再测。当前 503 是失败关闭证据，不是定级功能可用证明。
