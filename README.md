# EnglishFlow：AI 职场英语成长平台

> 工作名：EnglishFlow。面向中国大陆的小资、白领和需要在真实场景中使用英语的成年人。

这是一个多端全站项目骨架，目标不是做一个“只会聊天的 AI”，而是做一个 15 分钟可完成、目标导向、能复习、能量化进步的英语学习系统。

## 产品建议

### 核心闭环

1. 入学测评：确定大致水平、目标和可用时间。
2. 结构化课程：按 CEFR 能力层级和真实场景组织内容。
3. AI 陪练：文字、语音、角色扮演和即时反馈。
4. 记忆复习：间隔重复、错题回流和个人词库。
5. 每周复盘：展示能力变化，重新安排下一周计划。

### 首发定位

- 人群：工作 1–10 年、时间碎片化、需要提升职场沟通的成年人。
- 高频场景：会议发言、汇报、邮件、面试、社交寒暄、出差旅行。
- 首个承诺：每天 15 分钟，连续 8 周，完成一条可验证的职场英语能力路径。
- 差异化：课程老师设计学习路径，AI 负责个性化练习，人类规则负责质量和边界。

## 平台分期

- P0：学习 Web、微信小程序、运营后台、官网落地页。
- P1：React Native/Expo 移动端，复用领域逻辑和 API。
- P2：只有在原生能力确有需要时，再增加独立 iOS/Android 原生模块。

## 技术分层

- apps/：各端产品与后台。
- services/：核心 API、AI 编排、语音实时会话、异步任务。
- packages/：跨端共享的类型、契约、领域逻辑、设计令牌和埋点。
- database/：数据库结构、迁移、种子和测试夹具。
- content/：课程、对话、练习、词汇和媒体素材。
- ai/：提示词、评测集、策略、实验和模型适配资料。
- requirements/：需求、用户故事、MVP 范围和验收标准。
- docs/：产品、架构、设计、运营和合规文档。
- infra/：本地开发、部署、监控和安全配置。
- tests/：端到端、集成、契约、AI 评测、性能和安全测试。
- agent/：供编码 Agent 使用的项目上下文、工作流和决策记录。

## 推荐的第一条开发路线

1. 先完成 requirements/mvp-scope.md 和 3 个核心场景。
2. 先做 Web + 小程序 + 核心 API，不要一开始拆成十几个微服务。
3. AI 先做文字陪练、结构化反馈和复习推荐，再接入实时语音。
4. 用真实用户完成 8 周闭环后，再决定原生 App 和更多课程线。

## 开始开发前

复制 .env.example 为 .env.local；确认数据库、缓存和对象存储方案；选择 Web、微信小程序和移动端的具体框架版本；补充产品名、品牌、付费方案和隐私条款。
