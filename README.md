# 语学星：全年龄段 AI 自适应英语学习平台

> **产品名：语学星**（研发工作名 EnglishFlow）｜**公司：深圳云澜深境科技有限公司**
> 面向中国大陆的全年龄段英语学习平台：K12 中小学启蒙（第一阶段主线）、高中/大学升学突破、职场与出海实战。

这是一个多端全站项目骨架，目标不是做一个“只会聊天的 AI”，而是做一个“学习目标 -> 练习 -> 实时反馈 -> 复习 -> 闭环复盘”的英语学习系统。

## 交付分期

- **第一阶段（约 8 周）**：标准语言学习 App——单词/语法/句子拆分/口语/作文/考试 + 排行榜与趣味游戏，零 AI 依赖、安全可直接商用；含账号/VIP 权益/激活码变现等商业化基座（K12 教材同步待商业许可），Web + H5 先行，“完善美丽”为验收项。
- **第二阶段**：AI 能力分三批——AI 基座（FastAPI 编排 + 教材知识库 RAG + 文字陪练）、AI 评测（发音/写作/句法）、实时与数字人（商业 RTC + Rive 数字人 + Lip-Sync）。
- **第三阶段**：升学与职场人群扩展、行业词库、规模化。
- 终端：uni-app 一套代码编译 Web/H5/iOS/Android/iPad/微信小程序（见 ADR-0004）。
- 详细批次与通过条件见 `docs/09-roadmap/roadmap.md`。

## 核心闭环

1. 入学定位：学习目标选择（四级/六级/日常提升）与免费水平自测。
2. 结构化内容：词书、语法卡片、句型与情景会话，按目标与熟练度组织。
3. 记忆复习：SuperMemo-2 间隔重复、错题回流和个人词库。
4. 打卡激励：今日任务、徽章成就、学习战队与能量树。
5. AI 陪练（第二阶段）：文字、语音、角色扮演和即时结构化反馈。
6. 考试与排行（第一阶段）：计时刷题、四六级模拟、成绩报告与周榜激励。

## 技术分层

- apps/：各端产品与后台。
- services/：核心 API（Spring Boot 3）、AI 编排（FastAPI）、语音实时会话、异步任务。
- packages/：跨端共享的类型、契约（OpenAPI 单一事实源）、领域逻辑、设计令牌和埋点。
- database/：数据库结构、迁移、种子和测试夹具。
- content/：课程、对话、练习、词汇和媒体素材。
- ai/：提示词、评测集、策略、实验和模型适配资料。
- requirements/：需求、用户故事、MVP 范围和验收标准。
- docs/：产品、架构、设计、运营和合规文档。
- infra/：本地开发、部署、监控和安全配置。
- tests/：端到端、集成、契约、AI 评测、性能和安全测试。
- agent/：供编码 Agent 使用的项目上下文、工作流和决策记录。

## 推荐的第一条开发路线

1. 先完成 requirements/mvp-scope.md 的标准学习闭环与首发词书（四级核心词汇）。
2. 先做 Web + H5 + 核心 API（study.clyune.com / api.clyune.com / work.clyune.com），不要一开始拆成十几个微服务。
3. AI 能力第二阶段再上：先文字陪练、结构化反馈和知识库 RAG，再接入实时语音与数字人。
4. 用第一批真实用户完成 8 周闭环后，再推进 App 送审与更多内容线。
